Webフォームと電子メールから受信したリクエストに適用する業務ルールを設定できます。業務ルールでは条件を設定し、リクエストがその条件を満たす場合に実行するアクションを定義します。
サイトの業務ルールを表示するには、リスト上にあるコンボボックスからサイトを選択してください。特定のサイトに設定されている業務ルールがリスト表示されます。

メモ：

  • SDAdmin(管理者)はすべてのサイトに業務ルールを追加できます。一方でSDSiteAdmin(サイトの管理者)は所属サイトに対してのみ業務ルールを追加/表示できます
  • サイトが、管理タブ＞サイトページで定義されていない場合は、サイトを選択するコンボボックスは表示されません

新規業務ルールの追加

[新規業務ルールの追加]リンクをクリックします。
サイトに業務ルールを追加するには、コンボボックスからサイトを選択します。サイトを選択しない場合は、デフォルト設定の下に業務ルールが追加されます。

業務ルールの設定には、業務ルール情報、条件とアクション、通知の３ブロックがあります。

業務ルール情報

  • ルール名：　業務ルールの名前を入力（入力必須項目）
  • サイト：　業務ルールが作成されたサイトの表示（編集不可）
  • 説明：　業務ルールの補足情報を入力
次のリクエストオペレーション時に実行で業務ルールを発動するタイミングを設定します（デフォルトはリクエスト作成時）
  • 業務ルールを無効にする：　条件に一致するリクエストへの業務ルールは適用しない。
  • カスケード実行を有効にする：　リクエストの作成/編集された内容が、条件が一致する度に業務ルールを適用する。
    デフォルトでは、カスケード実行は無効になっているので、一度業務ルールが適用されると、リクエスト内容を編集してもそのルールが維持される。
  • 業務ルールの値でリクエストを上書きする：リクエスト内容が定義された条件に一致する場合、元の値よりも業務ルールで設定されたアクションを優先する。
    例：　依頼者が優先度を「高」に設定しても、業務ルールで「低」が設定されていれば、リクエストの優先度は「低」と上書きされる。
メモ： 同時に複数の業務ルール設定変更をしたい場合は、業務ルールリスト画面で対象ルールをチェックし、アクションのプルダウンメニューから任意の設定を選択する。


条件とアクション

  1. 業務ルールの条件を設定
    ＊リクエストの受信時に実行したいアクションの条件を設定します。ここで設定した条件に一致するリクエストは、自動的に後で設定するアクションが実行されます。
  2. [条件]コンボボックスから基準を選択。条件を選び[選択]ボタンをクリック。値を選択して[条件に追加]ボタンをクリック。
  3. 上記で設定した条件のアクションを設定。
  4. アクションの選択リストから、実行する項目を選択。
  5. [選択]ボタンをクリックして値を選択。
  6. [追加]ボタンをクリック。追加したアクションがリスト表示される。


通知

業務ルールが適用されるたびに、指定された技術担当者へメールまたはSMSで通知を行います。

  1. 通知を送る方法をメール/SMSから選択
  2. [テンプレートを編集]リンクから通知内容を設定
  3. [追加]ボタンをクリックして通知の受信者になる技術担当者を選択、[OK]ボタンをクリック


業務ルールの優先順序

業務ルールを適用する優先順序を設定します。

  1. 業務ルールの優先順序リンクをクリック
  2. 業務ルールを選択して繰り上げ/繰り下げボタンをクリック

リストの上にある業務ルールから順番に業務ルールを適用します。
