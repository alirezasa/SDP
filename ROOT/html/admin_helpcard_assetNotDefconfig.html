Notification Rules

Notification Rules are helpful when an event has to be notified to the technicians. Say, when a Purchase order is overdue or notify administrator about audit changes during discovery or when prohibited softwares are identified during discovery or when an asset warranty is about to expire.

When the above-mentioned situations are managed suitably it not only helps technicians in efficient management the assets but also bring in cost savings to the organization.

Enabling Notification Rules

Notifications are grouped by modules (Assets, Purchase, Contracts) and placed under respective tabs. To set the notification rules, select the relevant notification rules by enabling the check box. These notification rules are self-explanatory. You can assign technicians or email-IDs to notify for few notification rules.

1. Click on the text area besides Choose technicians label and it opens up a dropdown containing technicians names.

2. Click on the technician name to select that technician from that dropdown.

3. Search other technicians by typing the name of the technician in the text area provided.

4. Select as many technicians as you want and click outside the dropdown to close the same.

5. Enter comma separated e-Mail ID's to whom you want to send notification (Ex: a group e-Mail ID, a user which is not enrolled as technician, an alternate e-Mail ID of technician...) and the maximum number of e-Mail ID's is limited to 25.

6. For asset notifications, Choose at least one technician or enter one valid e-Mail ID.

7. Enter the number of days before which to send a notification as Notify before value for Asset lease expiry, asset warranty expiry, asset expiry notifications.

8. Click the Customize template link to customize the mail content for the notifications as appropriate.

9. Uncheck the check box to disable any notification.

Click Save button to save the notification rules. The Outgoing Mail Server settings should be configured as the notifications to the technicians are generally sent through email.
