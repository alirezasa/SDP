알림 규칙

알림 규칙은 이벤트를 기술자에게 알릴 때 유용합니다. 예를 들어, 구매 주문서의 기한이 지났거나, 탐색 중 감사(자산) 변경 사항을 관리자에게 알리거나, 탐색 중 금지된 소프트웨어가 확인되거나 자산 보증이 만료되려고 할 때입니다.

이러한 상황을 적절히 관리하면 기술자가 자산을 효율적으로 관리하는 데 도움이 될 뿐만 아니라 조직의 비용 절감 효과도 얻을 수 있습니다.

알림 규칙 활성화

알림은 모듈(자산, 구매, 계약)별로 그룹화되어 각 탭 아래에 배치됩니다. 알림 규칙을 설정하려면 확인란을 활성화하여 관련 알림 규칙을 선택합니다. 몇 가지 알림 규칙을 알리기 위해 기술자 또는 이메일 ID를 지정할 수 있습니다.

1. 기술자 선택 레이블 옆에 있는 텍스트 영역을 클릭하면 기술자 이름이 포함된 드롭다운이 열립니다.

2. 기술자 이름을 클릭하여 드롭다운에서 해당 기술자를 선택합니다.

3. 텍스트 영역에 기술자의 이름을 입력하여 다른 기술자를 검색합니다.

4. 원하는 수의 기술자를 선택하고 드롭다운 외부를 클릭하여 닫습니다.

5. 알림을 받을 이메일 ID(예: 그룹 이메일 ID, 기술자로 등록되지 않은 사용자, 기술자의 대체 이메일 ID...)를 쉼표로 구분하고 입력하십시오. 이메일 ID는 최대 개수는 25개로 제한됩니다.

6. 자산 알림의 경우, 기술자를 한 명 이상 선택하거나 유효한 전자우편 ID를 하나 입력하십시오.

7. 자산 임대 만료, 자산 보증 만료, 자산 만료 알림에 대해 사전 알림 값으로 만료일 이전에 이리 보내는 일수를 입력하십시오.

8. 템플릿 사용자 정의 링크를 클릭하여 알림에 대한 메일 콘텐츠를 적절하게 사용자 정의합니다.

9. 알림을 비활성화하려면 확인란을 선택 취소합니다.

저장 버튼을 클릭하여 알림 규칙을 저장합니다. 기술자에 대한 알림은 일반적으로 이메일을 통해 전송되므로 보내는 메일 서버 설정을 구성해야 합니다.
