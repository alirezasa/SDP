このページでは、コールバックカスタム関数の構築や編集が可能です。

関数を構築するための手順は以下の通りです。

  1. 必要な詳細事項、ここでは関数名、戻り値の型、説明、API名を入力します。
  2. 外部のアプリケーションからの入力値を使用するために、関数のパラメーターを設定します。
  3. Delugeエディターを用いて、関数を構築します。
  4. ［保存］をクリックして関数を保存します。

注意：

  • 設定できるパラメーターの最大数は10個までです。
  • API名は一意である必要があります。
  • 関数を実行する際のURLは与えられたAPI名に基づいて自動的に生成されます。
  • 外部アプリケーションがURLを用いて関数を実行できるようにするためには、必ず［公開］のチェックボックスにチェックを入れてください。

コールバックカスタム関数に関する詳細は、こちらをご覧ください。
