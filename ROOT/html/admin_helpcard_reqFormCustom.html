The Request Form Customizer helps you to create tailor-made Request Form to ensure that users submit all the required information along with the request.

The Help Desk Staff can design a customized Request Form. The request form can have  
  • Certain important fields as Mandatory
  • Certain fields that users can be View
  • Fields that user can also Edit
All the must-have information that technicians need to resolve the request is defined as Mandatory.  Fields with View Only and Edit permissions enables the Help Desk Staff to create simple and efficient request forms. 
 
Example: When you customize the request form, you can define
  • Title of the request field as mandatory
  • Level and mode of the request can be hidden from requester’s view. The Requester can View check box helps you to hide fields requesters
  • Workstation fields can be made as Edit and View, as users can report problems with any workstations they own
Now click Save, to save the settings and Save and Preview, to save and see the preview of New Request form for Requester login.
