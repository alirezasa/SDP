您可以通过定义对发布管理过程不同阶段的访问权限并指定可以分配角色的人员来配置角色。

  1. 为发布角色输入一个名称。 此字段是必填字段。
  2. 为角色添加一个描述。
  3. 您可以决定限制角色的关联为：
    1. 所有用户：任何用户都可以与发布角色关联。
    2. 关联地点的技术员：只有属于该发布请求的地点的技术人员才能与该角色相关联。
    3. 关联了地点和组的技术员：只有属于发布请求地点和组的技术人员才能与该角色关联。
  4. 定义发布阶段的访问权限。以下是发布生命周期中六个默认阶段的访问权限：
    1. 查看：查看权限允许用户查看所选阶段的发布请求。他们无法执行任何进一步的操作。
    2. 编辑：编辑权限允许用户查看和编辑所选阶段的发布请求。他们不能审批/拒绝发布请求。
    3. 审批：审批权限允许用户查看所选阶段中的发布请求并对其执行审批操作。
  5. 您可以通过选中“所有访问权限”复选框，可以为所有阶段提供完整的访问权限。
  6. 点击保存或保存并新添。
