La priorité associée à la requête détermine l’importance qui doit lui être accordée. Pour ajouter une nouvelle priorité, cliquez sur le lien Ajouter une nouvelle priorité à l’angle droit du tableau Liste des priorités.

Ajouter une nouvelle priorité
Le formulaire Ajouter une priorité a deux champs, à savoir Nom de la priorité et Description.

Nom : Renseignez un nom unique pour identifier chaque priorité.
Couleur : Sélectionnez une couleur de priorité à l'aide de la palette ou renseignez un code de couleur dans la zone de texte.
Description : Vous pouvez saisir une brève description sur la priorité dans le champ Description. Il sera ainsi plus facile de comprendre le type de priorité associé au nom indiqué dans le nom de la priorité.

Pour enregistrer la priorité et revenir à l’affichage liste, cliquez sur le bouton Enregistrer.
Pour enregistre la priorité et en ajouter une nouvelle, cliquez sur le bouton Enregistrer et ajouter un nouveau.
