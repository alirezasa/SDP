Le Comité consultatif sur les modifications (CAB) comporte un groupe de personnes assistant le Gestionnaire de modification dans l'évaluation, la priorisation et la planification des modifications. Les membres du CAB sont sélectionnés selon leur expertise et leur capacité à évaluer efficacement le changement d'un point de vue professionnel et technique.

Ajouter un CAB

  1. Cliquez sur le bouton Nouveau CAB.

  2. Indiquez le Nom du CAB dans le formulaire d'ajout. Ce champ est obligatoire.

  3. Saisissez une brève Description du CAB dans le champ approprié.

  4. Cliquez sur le lien Ajouter un membre CAB pour sélectionner des membres à ajouter au CAB. Une liste d'utilisateurs apparaît dans une fenêtre contextuelle.

  5. Cochez la case des membres à ajouter au CAB. Cliquez sur le bouton Ajouter un membre CAB.  Cliquez sur Ajouter un membre CAB et fermer pour ajouter les membres CAB sélectionnés et fermer la fenêtre contextuelle.

  6. Les membres sélectionnés sont répertoriés dans la section Membres de ce CAB avec leur Service et Adresse de messagerie associés.

  7. Cliquez sur le bouton Enregistrer. L'entrée CAB est affichée dans la page Liste CAB.

Cliquez sur le bouton Enregistrer et ajouter nouveau pour enregistrer et ajouter un autre CAB. Pour revenir à page Liste CAB, cliquez sur le bouton Annuler.
