Vous pouvez classer les différents types de demande dans différentes catégories. (Exemple : Toutes les demandes d’installation de logiciels peuvent être classées dans la catégorie « Installation de logiciels »). De même la hiérarchie Catégorie -> Sous-catégorie -> Élément est prise en charge à l’aide du type d’incident pouvant être catégorisé de façon granulaire. L'utilisation de catégories différentes vous permet de configurer ServiceDesk de manière à rediriger automatiquement les cas au technicien appropriée. Par exemple, tous les cas relatifs à la connectivité Internet peuvent être affectés automatiquement à John – votre Ingénieur réseau.

Pour créer une nouvelle catégorie
 
Cliquez sur le bouton Nouvelle catégorie. Le formulaire de catégorie s’affiche.
Renseignez le Nom de la catégorie dans le champ prévu à cet effet. Par exemple : Imprimante. C’est le seul champ obligatoire.
Dans le champ Description, indiquez les informations relatives à la catégorie que vous venez de créer.
Dans la liste déroulante Attribuer au technicien, sélectionnez le technicien qui sera affecté à la catégorie que vous venez de créer. Tous les problèmes liés à cette catégorie seront affectés au technicien sélectionné.
Pour enregistrer les détails, cliquez sur le bouton Enregistrer. La catégorie est désormais répertoriée dans l’affichage liste.
Pour enregistrer les détails et ajouter une nouvelle sous-catégorie, cliquez sur le bouton Enregistrer et ajouter une sous-catégorie.
 
Pour créer une nouvelle sous-catégorie
 
Cliquez sur le bouton Nouvelle sous-catégorie. Le formulaire de sous-catégorie s’affiche.
Renseignez le nom de la Sous-catégorie dans le champ prévu à cet effet. Par exemple : Papier. Ce champ est obligatoire.
Dans le champ Description, indiquez les informations relatives à la sous-catégorie que vous venez de créer.
Dans la liste déroulante, sélectionnez la Catégorie. Par exemple : Imprimante. Ce champ est obligatoire.    
 
Pour créer un nouvel élément
 
Cliquez sur le bouton Nouvel élément. Le formulaire de nouvel élément s’affiche.
Renseignez le nom de l’Élément dans le champ prévu à cet effet. Par exemple : Bourrage papier. Ce champ est obligatoire.
Dans le champ Description, indiquez les informations relatives à l’élément que vous venez de créer.
Dans la liste déroulante, sélectionnez la Sous-catégorie. Par exemple : Papier. Ce champ est obligatoire.
Pour enregistrer les détails, cliquez sur le bouton Enregistrer.
 
Remarque : Vous pouvez également ajouter une nouvelle Sous-catégorie et un nouvel Élément en cliquant sur la catégorie concernée, dans l’affichage liste.
