리소스 섹션은 서비스 요청서 템플릿에 쉽게 연계할 수 있도록 리소스 질문을 그룹화하는 데 사용됩니다.

리소스 섹션 목록 보기에서 활성 리소스 섹션이 기본적으로 표시됩니다. 리소스 섹션과 연계된 요청서 템플릿을 보려면 연계된 템플릿을 클릭합니다.

리소스 섹션 추가

  1. 리소스 추가를 클릭합니다.

  2. 리소스 섹션의 이름과 설명을 입력합니다.

  3. 리소스 질문을 하나 또는 두 개의 열에 표시하도록 선택합니다.

  4. 기존 리소스 질문 목록에서 리소스 질문을 선택하여 섹션에 리소스 질문을 추가할 수 있습니다.

  5. 또는 처음부터 리소스 질문을 만들 수도 있습니다. 여기를 클릭하여 자세히 알아보십시오.

  6. 저장 또는 저장하고 새로 추가를 클릭합니다.

리소스 섹션 편집

리소스 섹션 위로 마우스를 가져간 다음 메뉴 목록 아이콘을 클릭하여 편집합니다. 리소스 섹션에 대한 수정 사항은 관련된 모든 요청서 템플릿에 반영됩니다.

리소스 정보가 이미 기록된 요청서에서 해당 요청서를 수정하지 않는 한 수정 사항은 요청서 세부정보에 영향을 미치지 않습니다.

리소스 섹션 삭제

리소스 섹션 위로 마우스를 가져간 후 메뉴 목록 아이콘을 클릭하여 리소스 섹션을 삭제합니다.

  • 리소스 섹션이 요청 템플릿과 연계되지 않은 경우 영구적으로 삭제됩니다.

  • 리소스 섹션이 현재 사용 중인 경우 완전히 연계 해제될 때까지 비활성 상태로 이동됩니다. 삭제된 리소스 섹션을 보려면 비활성 섹션 필터를 적용하십시오.

비활성 섹션을 편집할 때, 편집할 리소스 활성화 옵션을 선택하여 활성화할 수 있습니다.
