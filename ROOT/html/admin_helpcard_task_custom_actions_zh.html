自定义动作是可操作的自定义函数，允许用户在ServiceDesk Plus和其他外部应用程序中操作数据。自定义功能是建立在Deluge上的，Deluge是Zoho专有的脚本语言。

自定义动作可以在任务自定义触发器中使用，以对任务、其他模块和外部应用程序执行动作。

  • 使用 "新建 "按钮来创建一个自定义动作。
  • 使用 "动作 "按钮可以进行批量删除、停用和启用自定义动作。
  • 要修改单个自定义动作，请使用显示在自定义动作旁边的图标。
  • 使用关键词在提供的字段中搜索自定义动作。使用上面的过滤器来显示特定功能中使用的自定义动作。

注意，只有激活的自定义动作才可以在任务自定义触发器中使用。
