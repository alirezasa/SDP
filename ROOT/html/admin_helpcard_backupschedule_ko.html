백업 일정

페이지 오른쪽에 있는 일정 편집을 클릭합니다.

표시된 페이지에 필요한 모든 세부 정보를 입력합니다.

활성화를 선택하고 백업 빈도, 날짜 및 시간을 선택합니다.

백업이 실패할 경우 알림을 받을 기술자의 이메일 주소를 입력합니다.

백업할 파일의 종류(첨부파일/데이터베이스)를 선택합니다.

패스워드를 변경하려면 패스워드 재설정을 클릭하십시오. (패스워드는 백업 일정 페이지에서 확인할 수 있습니다.)

백업 위치와 백업 파일을 보관할 일 수를 입력합니다.


참고 사항:

부분 백업의 경우 건너뛴 파일의 위치로 이동하여 바이러스 백신 제한을 비활성화합니다.

또한 손상된 파일을 확인하고 백업 일정을 다시 실행합니다.


중요 사항:

패스워드를 안전하고 기밀로 유지하십시오. 패스워드가 없으면 백업 파일을 검색할 수 없습니다.
