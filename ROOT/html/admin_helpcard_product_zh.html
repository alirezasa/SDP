产品

产品，是指客户（企业或机构）所购买的特定商品。如：Dell Lattitude D600就是表示产品类型为“工作站”的产品。在这里，您可以根据需要使用不同的方法创建产品并配置折旧。

添加新产品

    要添加一个新产品，

  1. 点击新建。

  2. 提供以下信息：

    • 产品类型：选择该产品应归入的产品类型。

    • 计算机组：选择计算机组。其他可用选项为台式机、笔记本电脑、其他设备和平板电脑。此字段仅在产品类型设置为"工作站"或"服务器"时可见。

    • 名称：提供一个独特的名称以识别产品类型。比如：Dell Latitude D600。

    • 制造商：输入制造商名称。

    • 部件号：输入产品部件号数字。

    • 添加图片添加产品图片可点击创建图片图标并更新所需图片。

    • 描述：提供产品的相关描述。

  3. 折旧明细：为产品配置折旧。该选项仅适用于资产（软件资产除外）和组件。

    1. 选择一个折旧方法：递减余额法,双倍余额递减法, 直线法,和年数总合法

    2. 选择计算因素：使用寿命或递减百分比。此选项仅在选择递减余额法和直线法作为折旧方法时出现。

    3. 使用寿命（月）/ 递减百分比提供一个可用值。

    4. 折残值($):输入所有折旧被完全计入后的资产账面价值。

  4. 最后，点击保存。

您也可以配置大量折旧。选择产品，点击配置折旧提供必要信息并点击保存。

编辑或删除产品

  • 要编辑产品，点击产品名称或点击名称旁的动作图标，选择编辑，进行必要的变更后，点击更新。

  • 要删除产品，选择产品并点击删除图标。要删除单一的资产状态，点击产品名称旁的动作动作图标并点击删除。

关联供应商

要将产品与供应商关联，

  1. 点击产品名称旁的展开图标。

  2. 点击关联供应商并提供以下信息：

    1. 供应商：u从下拉菜单中选择一个您想与产品相关联的供应商。

    2. 价格：输入产品价格。

    3. 税率：提供适用的税率。

    4. 保修期：配置适用的保修期，以年和月为单位。

    5. 维护供应商：为产品选择一个维护供应商。

    6. 注释：添加任何额外信息。

  3. 最后，点击保存。

编辑或删除产品-供应商关联

  • 要编辑产品-供应商，点击供应商名称或点击名称旁的动作图标，选择编辑，进行必要的变更，点击更新。

  • 要删除产品-供应商，选择关联，点击删除图标。要删除单一的关联，点击供应商名称旁的动作图标，选择删除。

注：您也可以在管理 >> 资产管理 >> 供应商下添加产品。
