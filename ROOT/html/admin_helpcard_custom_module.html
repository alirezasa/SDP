Custom Modules
 
Custom modules enable you to create entities to manage a collection of records or a few custom admin configurations. The entities to manage records are accessed via web tabs and the admin configuration entities are accessed from Admin > Customization > Custom Configuration.Besides these two, you can also create Sub Entity and Subform that you can use within a web tab.
 
For managing a collection of records, the custom modules must be of the Web Tab type. For managing custom admin configurations, the custom modules must be of the Configuration type.
 
Note:
  • The maximum number of custom modules supported is 10 for the Web Tab type and 50 for the Configuration type. For Subform and Sub Entity, you can create a maximum of 20 each.
  • The custom admin configurations can only be used via their respective APIs. However, records added under custom configurations can be used as options for Pick List/Multi Select/Check Box/Radio additional fields in Web Tab/Subform/Sub Entity.
Create Custom Module
  1. Click New.
  2. Under the Details tab, do the following:
    • Configure display name, API name, display plural name, and API plural name.
    • Choose a type: Web Tab or Configuration or Sub Entity or Subform. If you are creating a Subform or a Sub Entity, you need to map them with a Web Tab or a Configuration. Note that, you cannot map a Sub Entity and custom Subform with a Configuration.
    • Enter a description for the custom module.
    • If you have selected web tab, you can enable some features that are supported for the web tab. The available options are Import, Post Hook (Custom Triggers), Pre Hook (Business Rules), and Reports as applicable.
    • Upload an icon for the custom module.
    • Click Save.
  3. Under the Form Customizer tab, design the forms used in the custom module by customizing the layout, adding a title, and adding required fields, and click Next.
    • Under Subform, you can choose your predefined subforms that you have created. You can add a maximum of 5 subforms per web tab/configuration. Each sub form can have 10 fields. A same subform cannot be mapped twice to a web tab. Custom Sub Forms cannot be mapped to configurations.
  4. Under Sub Entity, you can add the sub entities you have created to a Web Tab. Sub Entities cannot be added to configurations.
  5. Under the Configurations tab, do one of the following:
    • For the Web Tab type entity: Configure granular permissions for users to add, edit, delete, or view records based on different parameters. The permissions can be configured for All records or Associated records.If you select All records, users will have access to all records including the records created by other users. However, you can restrict access to who can add/edit/delete/view records. If you select Associated records, users will have access only to the records they create. You can further configure who can add, edit, delete, and view those records.
    • For the Configuration type entity: Select roles that are needed for users to access and modify the custom configuration.
  6. Finally, click Save.
Manage Custom Modules

On this list view page, you can perform different operations on custom modules, namely editing, deleting, and marking as inactive. You can also search, sort, or filter the entries, and view history of all the activities performed in custom modules from the list view.

Note: You can map a maximum of 5 subforms to both web tab and sub entity and a maximum of 10 sub entities to a web tab. In Subform, only one section allowed with max 10 fields in layout. You can create 90 fields but only 10 can be mapped in layout. Only the published custom Subform/Sub Entity can be mapped to a web tab.
