통합 키(Integration Key):

통합 키 (Integration Key)는 안전한 REST API 호출을 수행하는 데 사용할 수 있는 토큰 기반 인증입니다.

새 통합 키:

  • 새 통합 키를 생성하려면 +새로 만들기를 클릭합니다.
  • 키의 유일한 이름을 입력합니다.
  • 역할을 연계하여 선택한 역할을 가진 사용자에게 통합 키를 할당합니다.
  • 목록 보기에서 통합 키를 선택하고 재할당을 클릭하고 기술자를 선택할 수도 있습니다(SDAdmins만 해당).
  • 만료일을 클릭하여 통합 키의 만료일을 선택하고 날짜를 선택하십시오.
  • 만료되지 않음을 선택하여 키에 무기한 유효 기간을 설정할 수도 있습니다.
  • 새 키를 만들려면 생성을 클릭하십시오.

목록 보기:

생성된 키가 목록 보기에 나열됩니다. 여기에서 사용자에게 재할당하거나 수정 또는 삭제할 수 있습니다.
