You can configure a role by defining the access permissions to different stages of the release management process and by specifying who can be assigned the role.

  1. Enter a Name for the release role. This field is mandatory.
  2. Add a description for the role.
  3. You can decide to limit the role's association to:
    1. All Users: Any user can be associated with the release role.
    2. Associated Site's Technicians: Only technicians belonging to the release request's site can be associated with the role.
    3. Associated Site and Group's Technicians: Only technicians belonging to the release request's site and group can be associated with the role.
  4. Define the access permissions across the release stages. The following are the access permissions for the six default stages in the release lifecycle:
    1. View: View permission enables users to view the release request for the selected stage. They cannot perform any further operations.
    2. Edit: Edit permission enables users to view and edit the release request for the selected stage. They cannot approve/reject a release request.
    3. Approve: Approve permission enables the user to view and perform approval actions on the release request in the selected stage.
  5. You can provide complete access permission over all the stages by selecting All access permission check box.
  6. Click Save or Save and Add New.
