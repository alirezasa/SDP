Chaque technicien accédant à l'outil d'assistance disposera d'un ensemble d'autorisations et de tâches à exécuter dans l'application. Ces autorisations d'accès sont nommées Rôles dans ServiceDesk Plus. Chaque technicien peut se voir créer et attribuer plusieurs rôles, selon les besoins. La liste des techniciens assignés à un rôle en particulier peut être consultée dans la page de liste des rôles. Il vous suffit de cliquer sur « Afficher les techniciens configurés ». Le rôle des demandeurs est prédéfini. Il ne peut pas être configuré. Pour ajouter un nouveau rôle, cliquez sur le lien Ajouter un nouveau rôle dans le coin droit de l'affichage Liste des rôles.

 

Ajouter un nouveau rôle

  1. Renseignez le Nom du rôle dans le champ prévu à cet effet. Il permettra d'identifier de manière unique le rôle que vous êtes en train de définir. Ce champ est obligatoire.

  2. Saisissez une brève description du rôle dans le champ Description.

  3. Configurez l'Autorisation d'accès en cochant les privilèges des différents modules.

  4. Les autorisations d'accès des modules Demande, Achat et Équipement possèdent plusieurs catégories répertoriées sous Autorisations avancées
    Exemple :     Si vous souhaitez pas qu'une autorisation en particulier soit octroyée aux techniciens, le fait de modifier l'état d'une demande comme résolue, par exemple, décochez « Résolution d'une demande ». De le même manière, si vous souhaitez qu'un technicien puisse ajouter un produit / fournisseur lors de la création d'un bon de commande, cochez les autorisations « Ajouter un nouveau produit » et « Ajouter un nouveau fournisseur ».
    L'option Analyser maintenant appaîtra sur la page d'informations de la station de travail du technicien si Analyser maintenant est coché.

REMARQUE :

I. Cochez Contrôle total pour un module, l'Autorisation aux demandes sous accès par exemple, aura pour effet d'activer toutes les opérations de demande dans l'autorisation avancée.

II. Si une opération de l'autorisation avancée est désactivée, Ajout d'un demandeur pour le module de demande par exemple, le Contrôle total se verra désactivé automatiquement.

III. Dans le cas où toutes les opérations avancées d'une catégorie principale sont désactivées, Modifier par exemple, l'utilisateur possèdera toujours d'autres autorisations de ce type comme la modification du mode, du niveau, etc.

IV. L'opération Affichage d'un module est activée automatiquement si l'une de ses opérations avancées est sélectionnée.

  1. Cochez l'une des cases d'option suivantes selon l'affichage que vous souhaitez octroyé aux techniciens :

    Tout : Les techniciens pourront voir les équipements et les demandes de l'ensemble des sites d'une organisation.     

    Sites associés : Le technicien pourra voir les équipements et les demandes des sites qui lui est associés.

    Groupe de sites et associations : Le technicien pourra voir les demandes d'un groupe de sites auquel il est associé. Il pourra également voir toutes les demandes qui lui sont assignées.

    Associations : Le technicien ne pourra voir que les demandes qui lui sont associées.

  1. Si vous souhaitez permettre à ce rôle d'approuver des solutions, cochez Technicien autorisé à approuver une solution.

  2. Cliquez sur Enregistrer.. Le rôle apparaît dans l'affichage liste. Pour enregistrer le rôle et en ajouter un nouveau, cliquez sur le bouton Enregistrer et ajouter un nouveau.
