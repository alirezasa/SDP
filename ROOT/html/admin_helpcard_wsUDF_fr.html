Vous pouvez définir les champs propres à votre organisation qui doivent apparaître dans le formulaire de nouvelle station de travail en plus des champs prédéfinis. Vous pouvez ajouter des champs de type texte, des champs de type numérique et des champs de type date dans le formulaire. Sélectionnez chacun des onglets et ajoutez le nom du libellé et la description de chacun des champs que vous voulez ajouter au formulaire de nouvelle station de travail.

Lors de l’ajout de champs texte, vous disposez d’une option pour choisir le type de champ de texte. Le champ de texte peut être un champ de texte à une seule ligne, un champ de texte à plusieurs lignes ou une liste déroulante. Sélectionnez les boutons d’option Une seule ligne, Plusieurs lignes ou Liste déroulante.

Si vous voulez ajouter une valeur par défaut pour ces champs, vous pouvez le faire dans le champ de texte prévu à cet effet.

Pour enregistrer les informations saisies, cliquez sur Enregistrer.
