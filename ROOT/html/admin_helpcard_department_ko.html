다른 사이트에 있는 조직(및 지점 간)의 다양한 부서를 추가하고 봅니다. 각 부서는 부서장이 관리합니다.

사이트가 구성된 경우 부서 콤보 상자에서 사이트를 선택하여 각 사이트의 부서를 볼 수 있습니다.

참고 사항: 사이트 관리자는 자신과 관련된 부서에서 작업을 수행할 수 있습니다. 사이트가 구성되지 않은 경우 콤보 상자에 대한 부서가 나타나지 않습니다.

새 부서 추가

사이트에 새 부서를 추가하려면 부서 콤보 상자에서 사이트를 선택합니다. 부서 목록 표의 오른쪽 모서리에 있는 새 부서 추가 링크를 클릭합니다.

부서 이름: 부서 이름에 추가하려는 부서의 이름을 입력합니다. 동일한 부서가 회사의 다양한 지점에 존재할 수 있으므로 유일할 필요는 없습니다. 필수 필드입니다.

사이트: 부서가 생성되는 사이트는 편집 불가능한 텍스트로 지정됩니다. 이 필드는 사이트가 구성된 경우에만 나타납니다.

설명: 설명 필드에 부서의 활동에 대한 간략한 설명을 제공할 수 있습니다.

부서장: 사용자 조회 아이콘을 사용하여 부서장을 선택합니다. 그러면 사용자 목록이 팝업됩니다. 부서장으로 지정할 사용자의 이름을 선택합니다.

저장을 클릭합니다. 선택한 사이트 아래에 부서가 추가됩니다.
