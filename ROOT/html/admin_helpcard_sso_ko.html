Single Sign-On
 
싱글 사인온을 활성화하면 애플리케이션이 Windows 시스템 사용자 이름과 비밀번호를 직접 인증합니다. 따라서 이 애플리케이션에 들어가기 위해 로그인 자격 증명을 다시 제공할 필요가 없습니다.
 
참고 사항:
  • 싱글 사인온을 활성화하려면 Active Directory의 모든 사용자를 가져와야 합니다.
  • 활성화된 도메인은 양방향으로 신뢰할 수 있어야 합니다. 
  • 싱글 사인온은 Windows Internet Explorer에서만 작동합니다.
싱글 사인온 활성화
 
Active Directory 에서 모든 사용자를 가져오면 페이지에서 활성화 버튼을 사용할 수 있습니다.
활성화 버튼으로 싱글 사인온을 활성화합니다. 기본적으로 Guest 로 로그인만 가능합니다 Admin 관리자는 요청자 목록에서 기술자를 선택하여 기술자 역할을 부여해야 합니다.
