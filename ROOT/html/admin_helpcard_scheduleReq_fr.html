Vous pouvez créer une Tâche de maintenance préventive pour la maintenance classique comme le remplacement d’un toner tous les mois, ou une fermeture de service planifiée. Vous pouvez créer une Tâche de maintenance préventive en deux étapes :
 
Créer un modèle de tâche
Définissez le modèle de tâche selon lequel la requête sera générée. Si vous essayez de créer une tâche de maintenance préventive pour remplacer les cartouches d’encre d’une imprimante, vous pouvez indiquer que la demande doit être ouverte à l’échelon 1. Elle peut être assignée à un groupe pour que tous ses techniciens puisse prendre en charge cette tâche. Vous pouvez également définir le niveau de priorité en fonction de l’utilisation de l’imprimante. Vous pouvez indiquer le titre et le contenu de la tâche. Sur la base de ce modèle de tâche, la tâche de maintenance sera générée conformément à votre planning.

Pour passer à la planification, cliquez sur le bouton Suivant.
 
Programmation de tâche
Pour planifier une tâche, sélectionnez la périodicité parmi les options suivantes :
    • Planification quotidien
    • Planification hebdomadaire
    • Planification mensuel
    • Planification périodique
    • Planification unique
Par exemple, si vous souhaitez planifier une tâche mensuelle pour remplacer les cartouches d’une imprimante, vous pouvez sélectionner la case Tous les mois et choisir la date (ex. le 3 de chaque mois) et l’heure (ex. 15 h 00). Une fois cette planification enregistrée, une tâche de remplacement de cartouches sera envoyée le 3 de chaque mois à 15h. Cette tâche de maintenance préventive peut vous aider à réduire les appels de maintenance reçus.

Saisissez les informations de planification.

Pour enregistrer la Tâche de maintenance préventive, cliquez sur Enregistrer.
