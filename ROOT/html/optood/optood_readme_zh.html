从本地迁移到云

支持从本地迁移到云的管理数据清单

ServiceDesk数据：

  1. 主页 - 后备审批人以及任务
  2. 请求 - 请求、注释、草稿、工作日志计时器、任务、任务依赖性、工作日志、任务注释、会话、通知、附件、解决方法、提醒、审批
  3. 变更 - 变更请求、变更角色、变更状态注释、停机时间、描述字段、通知、附件、任务、任务依赖性、任务注释、工作日志、注释、变更审批级别、变更审批
  4. 项目 - 项目、里程碑、任务、任务依赖性、工作日志、项目&里程碑和任务注释、成员、项目&里程碑和任务附件、请求项目关联
  5. 解决方案 - 主题、解决方案、解决方案状态
  6. 资产 - 所有除软件之外的资产
