보안 설정:

잠재적인 취약성 및 보안 위반으로부터 Asset Explorer 애플리케이션을 보호하기 위해 보안 설정을 구성합니다.

일반 설정:

  • 계정 잠금 임계값 및 기간 구성: 이 옵션을 사용하면 로그인 시도가 미리 지정된 횟수만큼 실패한 후 사용자 계정이 잠기도록 할 수 있습니다.

    계정 잠금 임계값 및 기간을 구성하려면
    • 계정 잠금 임계값 및 기간 구성
      • 을 활성화합니다.
    • 계정 잠금 임계값을 지정합니다.
    • 허용된 로그인 시도 횟수와 잠긴 사용자 계정을 재설정하는 기간을 지정합니다.
    • 로그인이 시도된 컴퓨터 만 사용자 계정을 잠글지 또는 모든 컴퓨터의 해당 사용자의 계정을 잠글지 여부를 선택합니다.
    • 사용자 계정이 잠겨 있을 때 표시할 메시지를 사용자 지정합니다.
    • 기술자에게 이메일로 알리거나 헤더의 기술자 공간 알림으로 알리도록 선택합니다.

  • 동시 로그인 비활성화:
    이 옵션을 선택하면 동시 로그인 기능이 비활성화됩니다. 동일한 계정으로 동시에 여러 로그인 하는 것을 비활성화하려면 이것을 사용하십시오. 이 옵션을 선택 취소하면 동시 로그인 기능이 활성화됩니다. 기본적으로 동시에 여러 로그인이 허용됩니다.

  • 서버 포트 및 프로토콜 구성:
    애플리케이션을 HTTP 또는 HTTPS 모드에서 실행할지 여부를 선택합니다.
    HTTP의 경우: 애플리케이션을 실행해야 하는 기본 서버 포트를 지정합니다.
    HTTPS의 경우: 서버 포트를 지정한 후 TLS 버전 및 암호를 지정하여 해커가 데이터를 도용하지 못하도록 데이터를 적절하게 암호화합니다.


  • 로그인 유지 활성화: 이 옵션을 선택하면 로그인 페이지의 사용자에 대해 "로그인 유지" 옵션이 활성화됩니다. 활성화되면 사용자가 애플리케이션에 로그인된 상태를 유지할 수 있는 기간을 설정할 수도 있습니다. 기본 기간은 45일입니다. 만료되면 사용자는 로그인 자격 증명을 사용하여 다시 인증해야 합니다.

  • 세션 시간 초과 구성: 이 섹션에서 사용자가 로그아웃되기 전까지 사용자가 활동하지 않는 기간을 설정할 수 있습니다. 적절한 옵션을 사용하여 웹 기반 세션 및 모바일 앱 세션에 대한 세션 타임아웃을 개별적으로 구성합니다. 모바일 앱의 경우 필요에 따라 세션 타임 아웃 구성을 활성화/비활성화할 수 있습니다.

고급 설정:

  • 보안 응답 헤더 추가: SDP 에플리케이션을 취약성으로부터 보호하도록 보안 헤더를 구성합니다.
    • 목록에서 필요한 보안 응답 헤더를 선택합니다.
    • 응답 헤더 값을 입력합니다.
    하나 이상의 응답 헤더를 포함하거나 제외할 수도 있습니다.

  • 로그인 할 때, 도메인 드롭다운 활성화: 이 옵션은 로그인 페이지에 도메인 이름을 나열합니다. 비활성화하면 도메인 이름이 사용자를 제외한 모든 사람에게 익명으로 유지됩니다.
    • 로그인 중 : 이 옵션은 입력한 사용자 이름을 기반으로 로그인할 때 나열된 도메인을 필터링합니다. 비활성화하면 전체 도메인 목록이 표시되어 해커가 특정 사용자가 있는 도메인을 알 가능성이 줄어듭니다.

  • 이 옵션을 사용하면 기술자가 ServiceDesk Plus를 타사 애플리케이션과 연결하기 위한 API 키를 생성할 수 있습니다. 비활성화된 경우 Admin 관리자만 기술자용 API 키를 생성할 수 있습니다.

  • 이 옵션은 사용자가 애플리케이션의 모든 비밀번호 필드에 클립보드 데이터를 붙여 넣을 수 없도록 합니다.

  • HTTP 압축을 비활성화하면 이러한 유형의 공격이 HTTP 압축을 통해 전송된 데이터에서만 발생하기 때문에 BREACH 공격을 방지할 수 있습니다. 그러나 이렇게 하면 네트워크 대역폭이 약간 증가합니다.

패스워드 정책:

패스워드 정책을 통해 관리자는 패스워드 생성 기준을 구성하고 시행할 수 있습니다. 이것은 사용자 데이터의 더 나은 보안을 보장합니다.

패스워드 정책을 구성하려면

  • 패스워드 정책을 활성화합니다.
  • 8에서 99 사이의 최소 패스워드 길이를 선택하십시오.
  • 패스워드에 다음이 포함되어야 하는지 여부를 선택하십시오.
    • 대소문자 모두
    • 특수 문자/기호
  • 기억할 이전 비밀번호의 수를 선택합니다. 애플리케이션은 최대 8개의 패스워드를 기억할 수 있습니다.
  • 패스워드의 만료 기간을 선택하세요.

패스워드 정책은 패스워드 변경 시에만 기존 사용자 패스워드에 적용됩니다.

첫 로그인 시 강제로 패스워드 재설정 :

새 사용자가 처음 로그인할 때 패스워드를 재설정하도록 구성합니다.

참고: 저장된 설정을 적용하려면 애플리케이션을 다시 시작해야 합니다.
