1st Page(Features Page)

系统介绍

帮助台 | 资产管理 | 定购单管理 | 合同管理

本系统是完全基于Web的帮助台和资产管理软件。它集成了请求管理、资产追踪、采购管理、合同管理、知识库管理等模块，具有很高的性能价格比。它具备了完全成熟的 IT 帮助台所需的一切，可以帮助您提高IT服务团队的生产效率，改善最终用户的满意度。
 



帮助台
故障工单 | 请求管理 | 事件管理

简单易用、稳定可靠的帮助台，可以帮助您处理内部和外部客户的服务请求与IT支持，从而提供长期的、可靠的、高质量的服务。

自助服务门户

利用基于 Web 的自助服务门户可以减少帮助台的呼叫量。通过此功能，用户可以搜索知识库、提交请求或检查其提交的请求状态。这些都不需要增加呼叫量。

知识库

通过基于 Web 的可搜索知识库，技术人员可以方便地访问答案从而加快问题的解决。

服务级别协议(SLA)管理

可以定义适当的服务级别协议、并监视SLA的顺应性，有违反SLA时及时升级。从而提高客户的满意度。

IT资产和清单管理

可跨整个组织跟踪和管理IT资产，也可以跨系统(Windows/Linux)获取准确的硬件和软件清单信息。

软件许可追踪

跟踪软件使用、许可违反情况，确保软件的顺应性。对组织内部具备什么和需要什么做到确切的了解，从而最小化软件成本。

定购单追踪

使用采购订单跟踪功能跟踪和管理 IT 采购并自动根据定购单创建资产。

产品目录

创建和管理组织拥有的所有资产和产品类型的综合列表，以及每种类型的产品数量。

合同管理

跟踪所有支持/维护合同和租赁协议并在合同到期时或之前及时告警。

OpManager集成

与 OpManager、网络监视软件紧密集成，可以在检测到网络故障时自动创建工单。

报表

提供多种现成的报表供用户选择，也可以根据自己所需的字段，创建自定义报表（列表报表或矩阵报表）。
