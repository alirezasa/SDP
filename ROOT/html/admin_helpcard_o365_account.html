Microsoft 365 integration allows technicians to view software subscriptions and licenses/services consumed by an organization.

Prerequisites

  • Ensure that you have an optimal network connection.
  • Kindly generate Client ID, Client Secret Value, and Tenant ID from Microsoft Graph API.
  • To generate the Client ID, Client Secret Value, and Tenant ID, please follow these below steps:

Register Application in Microsoft 365

1.1 Create a Client ID and Tenant ID:

  1. Log in to Azure Portal.
  2. Go to App registrations.
  3. Click New registration:
    • Enter your app’s name. (Any name for your reference)
    • Keep "Accounts in this organizational directory only" selected.
    • Click Register.
  4. Copy the Application (client) ID and Directory (tenant) ID from the app’s overview.

1.2 Create a Client Secret:

  1. On the overview page, go to Add a certificate or secret > Client secrets > New client secret, Or, go to Certificates & secrets > Client secrets > New client secret.
  2. Provide a description and set Expires to Never/ Longest time period available. Remember this expiry date because you will have to regenerate this client secret and update it after the expiry date.
  3. Click Add and copy the client secret value. This value will be available only after the first time you generate the Client Secret. So please keep a backup.

1.3 Add Permissions:

  1. Go to API permissions > Add a permission.
  2. Select Microsoft Graph > Application permissions.
  3. Search and select:
    • User.Read.All
    • Directory.Read.All
    • Organization.Read.All
  4. Click Add permissions and then click Grant admin consent for <app name>.

Configure Microsoft 365 Integration

  • Provide the Client ID, Tenant Id and Client Secret Value to authenticate the tenant.

  • Specify the schedule to sync the data from Microsoft 365 to ServiceDesk Plus periodically.
    • Mention the date and time to start the data sync
    • Mention the frequency (in days) to refresh the data synced

  • Click Save.

After saving the tenant details, click the Hamburger icon to edit or delete a tenant. You can also initiate data sync manually by selecting Sync Now.

Synced data such as subscriptions, licenses, and services details fetched from Microsoft 365 will be displayed under Assets > Software > Microsoft 365.
