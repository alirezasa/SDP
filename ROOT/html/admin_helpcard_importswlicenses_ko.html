소프트웨어 라이선스 가져오기 옵션을 사용하면 기존 데이터베이스 또는 다른 응용 프로그램에서 소프트웨어 라이선스 정보를 가져올 수 있습니다. 라이선스 키는 소프트웨어 라이선스를 추가하거나 업데이트하기 위한 중요한 식별자입니다. 따라서 라이선스 키는 기존 키를 덮어쓰지 않도록 고유(유일)해야 합니다.  

1단계: 파일 선택기 창에서 CSV 파일을 탐색합니다. 열기를 클릭합니다. 파일 경로는 CSV 파일 찾기 필드에 자동으로 나타납니다. 제출을 클릭합니다.

2단계: 애플리케이션 소프트웨어 라이선스 필드를 CSV 파일의 필드 이름과 매핑합니다. 라이선스 - 추가 필드 아래에 추가 필드가 구성되어 있는 경우 사용자 정의 매핑 양식에 동일한 항목이 나타납니다. 가져오기를 클릭합니다.

가져오기가 완료되면 총 라이선스 수, 가져온 라이선스 수, 가져오기에 실패한 라이선스 수에 대한 데이터가 표시됩니다.

소프트웨어 라이선스를 가져올 때, 실패한 기록이 있는 경우 동일한 CSV 파일을 다시 가져오지 마십시오. 대신 가져온 결과 페이지에서 FailedLicensesList.csv를 다운로드하고 ErrorList.txt 파일과 비교할 때 오류를 수정하십시오. 오류 목록 파일은 해당 오류 메시지와 함께 실패한 소프트웨어 라이선스 레코드를 보여줍니다. 이를 통해 소프트웨어 라이선스의 중복을 피할 수 있습니다.
