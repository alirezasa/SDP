• 역할 유형 및 역할 이름을 선택합니다.

  • XLS 가져오기 옵션을 클릭하여 Excel 시트에서 세부정보를 가져옵니다.

  • 사용자 연계를 클릭하여 역할에 사용자를 추가합니다.

  • 다중 선택 옵션 또는 단일 선택 옵션을 선택합니다.

  • 한 사용자에게 여러 사이트/부서/지역을 배정하려면, 다중 선택 옵션을 선택하십시오.

  • 사이트/부서/지역에 사용자를 개별적으로 배정하려면 단일 선택 옵션을 선택하십시오.

참고 사항: 여러 사용자를 한 단일 역할에 할당할 수 없습니다.

이미 존재하는 역할/사용자를 편집/추가하려면,

  • 검색창을 사용하여 역할/사용자를 검색합니다.

  • 검색 문자 뒤의 "," 을 사용하고, 이메일 주소를 사용하여 사용자를 검색하고, 부서와 연계된 사이트/지역을 검색합니다.

  • 사용자 변경을 클릭하여 사용자를 변경합니다.

  • 역할과의 사용자 연결을 삭제하려면 를 클릭하십시오.

  • 역할의 사이트/부서/지역을 편집하려면 를 클릭하십시오..
