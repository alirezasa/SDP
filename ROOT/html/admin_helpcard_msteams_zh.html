ServiceDesk Plus 集成 Microsoft Teams

设置 ServiceDesk Plus 与 Microsoft Teams 的集成，可利用来自 Microsoft 的协作APP作为IT和企业支持的一个附加渠道。通过集成，用户可以从他们的Microsoft Teams账户查看他们的服务台工单、查看待审批的事项、与服务台聊天等。


设置集成

  • 提供在您的Microsoft Teams账户中生成的应用密码。
  • 在Azure门户设置您的ServiceDesk Plus机器人的Application ID 和 Tenant ID 。
  • 在SDP 寄宿域 下，将自动填充您为应用配置的URL别名，但是如果您的应用寄宿在其它位置，可设置它所寄宿的域。
  • 当您提交了以上配置后，重定向URL 和 Bot Endpoint 将会自动生成，在您的Auzre门户中配置重定向 URL 和 Bot Endpoint 以及 ServiceDesk Plus 机器人，参阅这里了解更多。

在您提交了配置后，一个新的复选框名为启用Microsoft Teams将会出现并启用。

提示：了解在Microsoft Teams可使用的ServiceDesk Plus机器人命令，参阅这里。


更新/移除集成

更新集成中的任何信息，可做出相关修改后，点击更新。

在恢复配置时禁用集成，可取消选择启用Microsoft Teams。

完全移除集成，可点击显示在页面底部的移除选项，需注意，如果您移除集成，那么所有配置将被永久删除且不可回退。
