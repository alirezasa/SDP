Configure additional fields within Incident and Service templates to collect extra information.
To add a new Request additional field,
  1. Click New Field.
  2. Choose the required field type from the drop-down.
Type
Usage
Single Line
Can accommodate a single-line text
Pick List/ Radio
Can accommodate a list of values
Multi Select/ Checkbox
Allows selection of multiple option
Multi Line
Can accommodate a lengthy description
Numeric
Fields specific to numeric values
Date/Time
Fields specific to Date/Time values
Decimal
Fields specific to Decimal values

  1. Enter a Field Name and Description.
  2. Configure the field type as per your requirement.
  3. Configure the field type as per your requirement.
  4. When adding a new field that may contain confidential information, select the Holds personally identifiable information option. You can choose to encrypt the information for all field types except Picklist and Radio.
  5. Configure Reference Entity and refer an existing field's value to populate the current field when choosing pick list, radio, multi select, and checkbox additional fields.
  6. Click Save or Save and Close.

You can view the usage and history of the additional fields and resource questions by clicking Additional Fields Usage and View History.

Sample Scenario:
Consider a situation where a new employee joins the organization and the manager requests the admin to start the process associated with a new hire. Now, in addition to the existing new employee template fields, the admin may require some additional fields. This request form can be customized according to the admin's needs with the following fields to get fulfill the Service.

Login name for the Employee: Login name for the application [Single-line additional field can be used to create this field. ie., for Active Directory, Servicedesk Plus etc]

Type of Employment: Temporary. [Pick list additional field can be used to create multiple options. You can also refer to an existing field to populate this field's value using Reference Entity. Eg: Temporary / Permanent / contract-basis]

Manager's comments on the Assets to be provided : If the employee is a designer, provide him/her with a laptop that meets the specifications required. [Multi line additional field can be used to create such fields used for extra details pertaining to the Service.]

Extension Number : 1234 [Numeric additional field can be used to create such types of fields bearing numeric values.]

Tentative Date of Joining: 21st July 2016 [Date / Time additional field can be used to create fields indicating date and time.]

Extra allowances for Day/Night shift Employees (in Dollars): 3000.34 [Decimal additional field can be used to create fields that can hold decimal values.]

Note:
You can add a maximum of 25 answer choices using the Radio/Checkbox field types. To add more options, use pick list or multi select field type.
