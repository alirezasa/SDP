Theme

Changing Color

For preset colors: Select one of the preset color combinations. For custom colors: Click Custom Color to change color and then click color selection box against the UI element to choose a preferred color using the color gamut.

Changing Font

Select your preferred font from the drop-down list under the Font section.

Previewing Changes

You can preview your customizations using the interactive preview on the right-hand side.

User Personalization

SDAdmin can enable/disable users to customize the application's color and font using Allow other users to personalize their theme and font checkbox This option is enabled by default.

Note:
  • Changes made in Theme Settings will be applied to all Technicians and Requesters.
  • When Allow other users to personalize their theme and font checkbox is selected, user personalization would take preference over Admin configuration of colors and fonts.
