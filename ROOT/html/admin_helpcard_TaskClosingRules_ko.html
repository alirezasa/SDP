작업 종료 규칙은 관리자가 작업에 중요하다고 생각하는 특정 작업 관련 필드를 의무화하는 데 도움이 됩니다. 작업 종료 규칙이 설정되면 작업을 수행하는 기술자는 이러한 규칙을 준수해야 합니다. 그렇지 않으면 필수 필드를 채우라는 오류 메시지가 표시됩니다.

예: 작업 로그를 필수 필드로 설정한 경우, 기술자는 작업 로그 세부 정보를 입력한 후에만 작업을 완료할 수 있습니다.

작업 종료 규칙을 설정하려면

  1. 해당 체크박스를 활성화하여 작업을 종료하기 위한 필수 필드를 선택합니다.

  2. 저장합니다.

작업 완료 상태: 해당 체크박스를 선택하면, 작업 완료는 종료됨 상태로만 표시됩니다. 선택하지 않은 상태로 두면 해결됨, 완료됨 등과 같은 '완료됨' 상태가 작업 완료를 나타냅니다.
