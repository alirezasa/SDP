Add the different types of deployment impact that are likely to occur during the service deployment.

  • Use the New button to add a deployment impact.
  • Use the Hamburger icon next to a deployment impact to edit or delete it. You can also click a deployment impact to edit it.

Note:

A maximum of 50 deployment impacts, inclusive of default and inactive deployment impacts, are supported.

If a deployment impact is deleted while being used in Changes/Releases, it will be disabled. Edit an inactive deployment impact to restore it.
