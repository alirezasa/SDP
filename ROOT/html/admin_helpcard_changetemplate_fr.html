Le Modèle de modification vous permet de personnaliser des modèles destinés aux modifications demandées les plus fréquentes et les plus communes. Chaque modèle peut avoir ses champs, ses valeurs, son flux de travail et ainsi personnaliser le formulaire individuel pour chaque modèle de modification.

Grâce au modèle de modification, le demandeur peut initier rapidement une modification dont tous les champs seront préremplis. Le modèle consistue un gain de productivité pour votre équipe d'assistance.

La liste des modèles de modification vous permet de modifier, supprimer ou dupliquer des modèles. Cliquez sur le bouton Ajouter un modèle de modification pour ajouter un nouveau modèle. Le menu déroulant Filtre vous permet de réorganiser la liste à votre convenance. Plusieurs choix s'offre à vous : Afficher tout, Afficher les modèles généraux ou ficher les modèles d'urgence.

 

Dupliquer des modèles de modification

Vous pouvez, afin d'éviter d'avoir à personnaliser un formulaire individuel pour chaque modèle, dupliquer un modèle destiné à des demandes de modification similaires. Cliquez sur l'icône Dupliquer le modèle situé à côté du nom du modèle. Lors de la duplication d'un modèle, les champs du canevas sont conservés et son nom est intitulé comme tel : « Copie de <Nom du modèle> »  

La duplication de modèle facilite la création de modèles de modification aux champs similaires et permet ainsi de gagner du temps dans la personnalisation de modèles individuels.

 

Le modèle comporte trois sections : l'En-tête, les Champs à glisser-déplacer et le Canevas.

En-tête :  L'en-tête contient le Nom du modèle, le Flux de travail et les boutons Annuler et Rétablir.

  1. Renseignez un nom unique pour le modèle de tâche dans le champ Nom du modèle. Ce champ est obligatoire.

  2. Sélectionnez le flux de travail que doit suivre le modèle de modification dans la liste déroulante Suivre un flux de travail.

  3. Si le modèle intervient sur une modification nécessitant un traitement instantané, cochez Urgence.

Remarque : Marquer un modèle de l'état Urgence permet également de distinguer les modèles d'urgence des autres modèles lors de la création d'une demande de modification. Cocher Urgence dans le formulaire d'une nouvelle modification répertorie tous les modèles en état Urgence dans la liste déroulante Modèle.

  1. Vous pouvez également faire d'un modèle le modèle par défaut en cochant Définir par défaut. Si un modèle par défaut existe déjà, un message s'affichera pour vous demander le changement de ce modèle de modification par défaut. Cliquez sur le bouton OK si vous souhaitez définir ce modèle par défaut.

Remarque :

    1. Définir un modèle par défaut signifie que les nouveaux modèles de modification copieront les configurations de ce modèle par défaut.

    2. Lors de la création d'une nouvelle demande, les champs seront copiés sur le modèle par défaut.

    3. Il vous est en revanche impossible de supprimer directement le modèle par défaut depuis l'affichage liste des modèles de modification.  Il vous faut d'abord définir un autre modèle par défaut avant de supprimer celui d'origine.

  1. Saisissez d'éventuels commentaires sur le modèle de modification dans le champ Commentaires.

Champs à glisser-déplacer : Tous les champs supplémentaires de modification configurés dans l'application sont répertoriés dans la section Champ à glisser-déplacer. La section répertorie également les champs retirés du canevas.

Canevas : Le canevas est une zone de glisser-déplacer réprésentant l'aspect final du formulaire. Les champs du canevas peut être réorganisés, supprimés et rendus obligatoires.  Des valeurs peuvent être également attribuées aux champs, facilitant ainsi la création d'une modification.

 

Ajout d'un nouveau champ au canevas

Vous pouvez ajouter des champs au modèle de modification en déplaçant l'option Ajouter un nouveau champ de la section Champ de glisser-déplacer vers la zone jaune du canevas.

  1. Dans la fenêtre Ajouter un nouveau champ, sélectionnez le Type de champ : texte, numérique ou date/heure en cochant la case appropriée.

  2. Renseignez le nom du champ (tel qu'il sera affiché dans le formulaire) dans le champ Libellé.  Vous devez également sélectionner le type du champ de texte : Une seule ligne, Plusieurs lignes ou Liste déroulante.

  3. Cliquez sur OK pour ajouter le champ dans la zone en surbrillance du formulaire.

Ces champs supplémentaires sont d'ordre commun pour tous les modèles de modification. Ils ne peuvent être modifiés qu'à partir de la section concernée (champs supplémentaires de modification).

Remarque : Lors de l'ajout de nouveaux champs ou la réorganisation des champs existants, les champs ne peuvent être déplacés que dans la zone en surbrillance du canevas.

 

Réorganisation des champs du canevas

Déplacez votre curseur sur le champ à réorganiser. Cliquez avec le bouton gauche de la souris et déplacez le champ dans la zone en jaune du canevas. Si la section Champ de glisser-déplacer contient des champs supplémentaires, ils peuvent être déplacés dans le canevas de la même manière.

 

Rendre des champs obligatoires

Vous pouvez rendre des champs obligatoires à l'aide de l'icône Modifier les propriétés du champ du canevas. Déplacez votre curseur sur un champ pour faire apparaître l'icône Modifier les propriétés du champ. Cliquez sur l'icône et cochez Champ obligatoire.  Les champs obligatoires reçoivent le symbole * pour les identifier comme tel.

Remarque : Rendre le champ Élément obligatoire rend également automatiquement la Catégorie et la Sous-catégorie obligatoires.  

 

Retirer des champs du canevas

Vous pouvez supprimer des champs du formulaire pour personnaliser le modèle de modification à votre convenance. Pour supprimer des champs du canevas, déplacez votre curseur sur un champ et cliquez sur l'icône Supprimer un champ. Le champ est supprimé du canevas et répertorié dans la section Champ à glisser-déplacer.

Remarque : Certains champs ne peuvent pas être supprimés du canevas : Étape, État, Site (si configuré dans l'application), Titre et Description.  

Les champs « Demande par », « Planifier l'heure de début » et « Planifier l'heure de fin » ne peuvent pas être sélectionnés dans le modèle de modification.
