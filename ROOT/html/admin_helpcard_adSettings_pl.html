Możesz skonfigurować uwierzytelnianie konta użytkownika z katalogiem Active Directory (AD).

Uwaga: Przed skonfigurowaniem uwierzytelniania z AD upewnij się, że wcześniej zaimportowałeś użytkowników do bazy programu ServiceDesk Plus. Tylko dla kont założonych w programie ServiceDesk będzie możliwe uwierzytelnienie hasła w katalogu AD.

Konfiguracja Active Directory
Autentykacja w AD jest domyślnie wyłączona. Naciśnij przycisk Włącz, aby uruchomić uwierzytelnianie.

Możesz również w tym miejscu zaimportować użytkowników z katalogu Active Directory. Naciśnij link Importuj użytkowników z Active Directory , a wywoła to okno dialogowe importu.

Z menu domen wybierz domenę, z której chcesz dokonać importu użytkowników. Jeśli już wcześniej wprowadziłeś nazwę kontrolera domeny, nazwę użytkownika i hasło dane te zostaną pobrane do formularza. Naciśnij Zaimportuj!.

Kreator importu wyświetli jednostki organizacyjne (OU) dostępne w domenie. Wybierz właściwą jednostkę organizacyjną, z której chciałbyś zaimportować użytkowników, zaznaczając odpowiednie pole wyboru.

Naciśnij Rozpocznij import.

Trwa import użytkowników. Na końcu procesu wyświetlony zostanie raport o ilości poprawnie zaimportowanych użytkowników oraz wynikłych błędach. Naciśnij Zamknij okno. Jeśli wcześniej dodawałeś konta użytkowników zostaną one nadpisane danymi z Active Directory.
