Task Types allow categorization of similar Tasks. For example, tasks related to troubleshooting of various kinds can be grouped under Task Type Troubleshooting. You can create Request, Problem, Change, and Project specific Task Types, and categorize tasks.

Add Task Type

To add a new Task Type, click New.

Name: Specify a unique name for the Task Type.

Color: Select a color to denote the Task Type using color palette.

Description: Provide a short description about the Task Type.

Click Save or Save and Add New.
