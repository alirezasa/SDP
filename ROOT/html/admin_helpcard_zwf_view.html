Zia Workflow enables you to create a directional path for the various actions configured within the Zia Bot.

Use the graphical user interface to configure the Zia Workflow. An already configured or the default workflow will be available. You can edit the workflow per your requirement.

To add a new Options Menu or Action, click Toggle on the stencil panel.

Drag the required Options Menu and its corresponding Action to the canvas and configure the workflow by connecting the nodes.

Edit the name or title of the nodes, which will be displayed in Zia Bot.

The first message to be displayed in the Zia Bot will be invoked from the Options Menu that is connected to the start node.

Options Menu refers to the various messages that can be displayed in the Zia Bot.

For a given workflow, you can configure up to 25 Options Menu.

Under each Options Menu, you can configure up to 10 Buttons.

There are several default actions/buttons already configured.

You can also create new buttons under the Options Menu. You can use these buttons across the Options Menu within the workflow.

To edit a button, go to the Button List View to edit its name, Bot Command, and User Type.

Creating an Action

An Action, by default, contains the following nodes: Action Node, User Input, Output, and Further Assistance.

For these nodes, choose appropriate titles, which will be displayed to the user in the Zia Bot.

Drag the Action option to the canvas to open it.

In the left panel, hover over Custom Actions and click +

You can now create a custom function on the displayed window using the deluge script.Learn More

Provide a name, select the type, and the module.

Provide the complete API name.

Provide parameter details such as its name, its type, and finally provide the prompt message.

These input parameters will be added to the User Input node of the workflow. If these are not provided, the User Input node will be absent in that Action.

You can add a maximum of 9 parameters for each action.

You can map an action to one button only. However, the button can be used multiple times in other Option Menu across the workflow.

You can add a maximum of 200 actions to the workflow. This count includes the already available 20 default actions.

You can configure Zia Custom actions under Admin > Custom Functions > Zia Functions.

Expanded and Collapsed View

The configured Zia Workflow can be viewed in two modes: Expanded and Collapsed.

Note that you can modify the configuration only in the Collapsed view. Only the workflow of the selected Action Menu or Button will be displayed at a time.

The Expanded view is available only in the read-only mode. In this view, the workflow with all the configured Options Menu and the corresponding Actions will be displayed in its entirety. You can export this view as PDF.

Finally, save the workflow on the top right. Note that only validated workflows can be saved.
