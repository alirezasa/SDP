Capture any extra information in custom module records by creating an additional field under Fields list.

To create a new additional field,

  • Use the New button to create an additional field.
  • After specifying the field type, provide a field name and description. The field properties vary based on the selected field type.
  • You can encrypt single and multi line field types for additional security. Note that you can encrypt a field only while creating it. Field encryption cannot be disabled later.
  • Based on the selected field type, specify the other field properties.
  • Click Save.

To edit or delete an additional field, click the relevant icon beside the field name.

Note: You can add a maximum of 90 additional fields.
