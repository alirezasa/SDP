与Microsoft System Center Configuration Manager（SCCM）单方集成，将扫描的资产数据从SCCM提取到ServiceDesk Plus中。  您可以继续使用SCCM进行库存管理，同时迅速更新应用程序中的资产数据。 

要了解其工作原理，请看此处。要添加新的SCCM配置：
 

  1. 单击新建，然后填写显示的字段的详细信息。
  2. 主机名，数据库名和端口是SCCM数据库服务器的主机名。
  3. 您可以将资产关联到地点。当导入地点SCCM的资产时很有帮助。
  4. 输入在凭证库中配置的SCCM凭证。
  5. 指定何时启动数据获取以及必须重复执行该过程的频率。
  6. 单击测试连接并保存以确保已连接SCCM数据库服务器。


数据获取的成功或失败在列表视图页面中的状态下显示。
失败可能是由于SCCM数据库服务器的凭证不正确或与该服务器未建立连接。
 

您可以在列表视图页面中直接编辑/测试连接/删除SCCM。
