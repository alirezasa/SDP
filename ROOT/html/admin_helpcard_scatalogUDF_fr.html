Il peut être préférable que les champs pré-remplis du formulaire de demande de service ne contiennent pas d'informations clé sur votre entreprise. Les Champs supplémentaires, toutefois, vous permettent de configurer des champs supplémentaires spécifiques à votre organisation. Ces champs s'affichent sous la section Champ de service du formulaire de demande de service. Ils peuvent être configurés pour s'afficher dans l'ensemble des formulaires de demande de service (indépendamment de la catégorie du service), ou dans des formulaires de demande de service spécifiques.

Sélectionnez la Catégorie de service pour laquelle le champ supplémentaire doit apparaître. Sélectionnez « Champs communs » si vous souhaitez que le champ supplémentaire apparaissent pour toutes les catégories.

Vous pouvez ajouter des champs de type texte, des champs de type numérique et des champs de type date/heure dans le formulaire. Sélectionnez les onglets et renseignez le nom du Libellé et la Description des champs à afficher dans le formulaire de demande de service.

Lors de l’ajout de champs de texte, vous disposez d’une option pour choisir le type de champ de texte. Le champ de texte peut être un champ de texte à Une seule ligne, un champ de texte à Plusieurs lignes ou une Liste déroulante . Cochez la case appropriée.

Si vous voulez ajouter une valeur par défaut pour ces champs, vous pouvez le faire dans le champ de texte prévu à cet effet.

Pour enregistrer les informations saisies, cliquez sur Enregistrer.

Cliquez sur Retour pour revenir à l'assistant de configuration du catalogue de service.
