일반 설정

ServiceDesk Plus의 성능을 최적화하기 위해 데이터베이스 유지 관리를 예약하고 디스크 사용량 임계값을 구성합니다.

데이터베이스 유지 관리 일정

쿼리 최적화 프로그램은 테이블 통계를 사용하여 쿼리 계획을 만듭니다. 쿼리 계획의 최적 성능을 보장하려면 테이블 통계를 정기적으로 업데이트해야 합니다. 이 데이터베이스 유지 관리 활동은 데이터베이스 시스템마다 다르게 수행됩니다. Postgres의 경우 "VACUUM ANALYZE" 연산을 사용하고 MS SQL의 경우 "sp_updatestats" 연산을 사용합니다.

매일 또는 적어도 일주일에 한 번 실행하도록 데이터베이스 유지 관리를 예약하십시오.
  • 예약 유지 관리를 구성하려면 표 통계 업데이트를 예약하고 토글 버튼을 사용하여 유지 관리 일정을 활성화하십시오.
  • 원하는 빈도를 선택하고 원하는 시간과 함께 시작일을 설정합니다. 성능 문제를 방지하려면 운영하지 않는 시간에 유지 관리를 예약하십시오.
임계값

디스크 사용량 모니터링은 애플리케이션 장애 또는 다운타임을 방지하는 데 필수적입니다. 이렇게 하려면 관리자에게 이메일 알림을 보내도록 임계값을 구성하십시오.

디스크 사용량 임계값 - 시간이 지남에 따라 디스크 사용량이 증가하고 결국에는 사용 가능한 모든 디스크 공간이 소모되어 애플리케이션 오류가 발생합니다. 이를 방지하기 위해 관리자 사용자에게 알림을 트리거하도록 디스크 사용률 임계값을 구성할 수 있습니다.

디스크 사용률 임계값을 설정하려면 디스크 공간 필드에 원하는 값을 백분율로 입력합니다.

MS SQL 서버는 모든 트랜잭션을 기록하기 위해 트랜잭션 로그 파일(.LDF)을 유지합니다. 모니터링하지 않고 방치하면 이 파일이 커져서 디스크를 가득 채울 수 있으며 애플리케이션 다운타임이 발생할 수 있습니다. 이를 방지하기 위해 MS SQL 사용자가 사용자에게 이메일 알림을 트리거하는 로그 파일 크기 임계값을 구성할 수 있는 추가 옵션이 활성화됩니다.

로그 파일 크기 임계값을 설정하려면 데이터베이스 로그 파일 크기 입력란에 원하는 파일 크기(MB)를 입력하십시오.

보고서 설정

안정성을 최적화하기 위해 행 제한, 최대 동시 사용자 수, 보고서 생성 시간 초과와 같은 다양한 보고서 생성 기준에 대한 제한을 설정하거나 수정할 수 있습니다.
