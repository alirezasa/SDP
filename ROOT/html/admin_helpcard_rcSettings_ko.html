원격 제어 도구 목록

이 기능을 사용하면 AssetExplorer 내에서 다양한 원격 데스크톱 소프트웨어를 사용할 수 있습니다. 기본적으로 애플리케이션에는 4개의 원격 제어 도구가 구성되어 있습니다. 4개 중 Windows 원격 데스크톱은 기본적으로 모든 Windows 컴퓨터에서 사용할 수 있습니다. 에이전트 도구는 해당 제품에서 기본적으로 사용할 수 있습니다. 나머지 원격 제어 도구는 원격 제어가 시작된 시스템(클라이언트 시스템)에 설치해야 합니다.

참고:Remote Control은 AssetExplorer 호스트 서버가 아닌 현재 액세스 중인 시스템(클라이언트 시스템)에서 수행됩니다.

구성된 원격 제어 도구는 워크스테이션/서버의 세부정보 페이지에 있는 원격 제어 드롭다운 메뉴 아래에 옵션으로 나열됩니다. 모든 도구에서 원격 제어를 수행하도록 선택할 수 있습니다.

원격 제어 도구 목록은 클라이언트 및 사용자 컴퓨터의 OS에 따라 다릅니다. OS가 Windows 또는 MAC이 아닌 경우 원격 제어 옵션을 사용할 수 없습니다.
