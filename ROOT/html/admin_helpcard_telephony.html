Computer Telephony Integration enables efficient communication between users in an organization with the help of features like screen pop, click to dial, etc. Configure Computer Telephony settings for your organization using the following pointers.

Note: ServiceDesk Plus supports Asterisk and Avaya servers. You can also configure the integration for a custom server using scripts. Click here to learn more.

  • Service: Choose the telephony server to integrate with ServiceDesk Plus.
  • Telephony Server: Enter the IP address of the telephony server.
  • Port: Enter the server's port number.
  • SIP Protocol: Choose the protocol of your organization's Asterisk server. This field is displayed only if you have chosen Asterisk under Service.
  • TLink: Click the Get TLink button next to the field to populate the drop-down list with the TLinks available in your organization. Choose the required option. This field is displayed only if you have chosen Avaya under Service.
  • Username and Password: Enter the credentials of the call manager to log in to the configured telephony server.

Click Save to establish a connection between ServiceDesk Plus and the telephony server. Upon successful integration, users can make and receive calls from within the application, provided the user's profile is updated with a valid phone/extension number.
