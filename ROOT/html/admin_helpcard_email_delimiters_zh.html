界定符

对于用户来说，要区分来自多个模块的通知是比较困难的。因此，这里设置界定规则，依据规则，用户可以过滤通知并识别其来源。
例如:
如果有个通知，其界定符为：'##RE-123##', 则用户可以鉴别该通知的来源为请求（RE）模块。

对于接收到的电子邮件，既可以添加为新的工单，也可以将其添加为已有工单的会话。其中，判别依据就是在通知邮件的主题中的“请求ID”是否与已有的“父请求ID”一致。

默认的基本界定符的值为 ## ，用户可以根据自己的情况修改为想要的值。一旦用户更改了基本界定符的值，以后所有相关通知的标题将自动更新为新的界定符的值。
例如:
对于通知规则下的'接收到请求时通过邮件通知请求人'的通知 (在 '管理 >> 通知规则'页面)，默认情况下，通知的主题为： 'Your request has been logged with request id ##RE-$RequestId##'，这里，如果用户更改了基本界定符，将其值修改为 @@ （替换原来的 ##），则该通知的主题也将变为：'Your request has been logged with request id @@RE-$RequestId@@'。
