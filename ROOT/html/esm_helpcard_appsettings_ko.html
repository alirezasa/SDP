애플리케이션 설정

이 페이지에서 애플리케이션 전체에 적용 가능한 설정을 구성할 수 있습니다.

별칭 URL

http:// 텍스트 옆의 텍스트 필드에 애플리케이션 서버에 대한 대체 URL을 입력할 수 있습니다(필요한 경우 포트 번호와 함께). 텍스트 필드 바로 아래에 있는 별칭 URL을 새 창에서 열기 링크를 클릭하여 별칭 URL이 작동하는지 확인합니다.

표시 언어

드롭다운에서 애플리케이션을 표시할 언어를 선택하십시오. 브라우저 기본 언어는 영어입니다. 

기타 사용자 정의

제공된 다양한 구성을 사용하여 ServiceDesk를 사용자 정의하십시오.

선택 '예' '아니요'
애플리케이션에서 사용자를 가져오지 않을 때 동적 사용자 추가를 허용하시겠습니까? 사용자를 애플리케이션으로 가져오지 않고 Active Directory를 통해 가져온 경우 사용자는 AD 자격 증명을 사용하여 애플리케이션에 로그인할 수 있습니다. 이렇게 하면 애플리케이션에 대한 로그인 액세스가 자동으로 제공됩니다. '아니요' 라디오 버튼을 활성화하면 사용자가 애플리케이션으로 가져오지 않을 때 동적 사용자 추가가 방지됩니다.
이메일 ID를 기반으로 사용자 정보를 덮어쓰시겠습니까? Active Directory, CSV 및 LDAP를 사용하여 사용자를 가져오는 동안 기존 사용자 정보는 두 가지 기준에 따라 덮어씁니다. 첫 번째 기준은 사용자 이름과 도메인을 기준으로 하고 두 번째 기준은 이메일 ID를 기준으로 합니다. 요청자는 충분한 권한이 부여되지 않는 한 자신의 요청서를 다시 열 수 없습니다.
이메일 요청을 통해 생성된 사용자에게 로그인 액세스 권한을 제공하시겠습니까? 처음으로 이메일 요청을 보내는 동안 사용자에게 자동으로 로그인 액세스 권한이 제공됩니다. '아니요' 라디오 버튼이 활성화된 경우 이메일 요청을 통해 생성된 사용자에게는 로그인 액세스 권한이 제공되지 않습니다.
사용자가 로컬 인증을 기반으로 로그인하도록 허용하시겠습니까? 사용자는 로컬 인증을 사용하여 애플리케이션에 로그인할 수 있습니다. '아니요' 라디오 버튼을 활성화하면 사용자가 로컬 인증을 기반으로 로그인할 수 없습니다.
새 이메일 주소에서 받은 이메일을 처리하시겠습니까? 새 이메일 주소의 메일을 애플리케이션으로 가져올 수 있습니다. 새 이메일 주소의 메일을 애플리케이션으로 가져오는 것을 방지할 수 있습니다.

최종 사용자를 위한 프로필 접근성

최종 사용자가 프로필에서 액세스할 수 있는 정보를 선택합니다.
다음 세 가지 옵션 중에서 선택할 수 있습니다.

    • 프로필 편집: 이 기능을 활성화하면 사용자가 프로필을 편집할 수 있습니다.
    • 기본 세부 정보 보기: 기본 세부 정보만 볼 수 있습니다.
    • 추가 필드 보기: 추가 필드에 입력된 정보를 볼 수 있습니다.

인스턴스에 사용자 추가

기본적으로 기술자는 새 사용자를 인스턴스에 수동으로 추가할 수 없습니다. 특정 인스턴스에서 수동 사용자 추가를 사용 설정하려면 기술자가 인스턴스에서 새 사용자를 생성하도록 허용 옵션을 선택해야 합니다. 이 옵션은 선택한 인스턴스의 사용자 역할에 요청자 추가라는 새 설정을 추가합니다. 이 설정으로 역할을 구성하고 필요한 기술자와 연결합니다.

헤더 이미지 사용자 정의

사용자 정의 이미지를 사용하여 기본 헤더 이미지를 바꿀 수 있습니다. 사용자 정의 이미지 사용 라디오 버튼을 클릭하고 이미지 변경>> 파일 선택>> , 가져오기를 클릭하여 사용자 정의 이미지를 업로드합니다. 헤더 이미지의 크기는 166픽셀(x) 46픽셀(W x H)

이어야 합니다.

로그인 페이지 사용자 정의

요구 사항에 따라 애플리케이션 로그인 페이지를 사용자 정의합니다. 배경 이미지를 업로드하거나 스타일을 추가하거나 요구 사항에 맞게 html 파일을 수정할 수도 있습니다. 지금 사용자 정의을 클릭합니다. HTML 편집기가 열립니다. 표시된 편집기에서 필요한 사항을 변경할 수 있습니다.

참고: 로그인 페이지 이미지의 크기는 252픽셀 X 61픽셀(가로 x 높이)이어야 합니다.
설정을 저장하면 변경 사항이 즉시 적용됩니다.  ; 변경 사항을 모두 취소하려면 오른쪽 상단에 있는 기본값으로 복원 버튼을 클릭하세요.

휴지통 요청서 삭제 기간(일)

선택한 일 수 이전에 휴지통으로 이동한 요청서를 영구적으로 삭제하는 기간을 설정합니다. 예를 들어 5를 선택하면 5일 이내일 전에 휴지통으로 이동한 요청이 애플리케이션에서 영구적으로 삭제됩니다.
