Notification Rules

Notification rules are helpful when an event has to be notified to the technicians. Say, when a Purchase order is overdue, to notify administrator about audit changes during discovery, when prohibited software applications are identified during discovery, or when an asset warranty is about to expire.

When such situations are managed suitably, it not only helps technicians in efficient management of assets, but also brings in cost savings to the organization.

Enabling Notification Rules

The notification rules are self-explanatory and they are grouped by modules (Assets, Purchase, Contracts) and placed under respective tabs. To enable them, select the appropriate check boxes against your preferred notification rules. For some technician-related notifications, you can also assign technicians or specify email addresses to send notifications.


To choose technicians, click the Choose technicians combo box and select your preferred technicians from the drop-down list or search technicians by their name.

To send notifications to specific email addresses, provide email addresses in the appropriate field, each separated by a comma. (Eg: a group email address, a user who is not a technician, an alternate of a technician, etc.)

    • You can add up to 25 email addresses for each supported notification rule.
    • For asset notifications, at least one technician or one email address is mandatory.

For notifications involving asset expiry, warranty expiry, and loan period expiry, provide additional details as given below.

    • Notify Before : Provide a value between 1 and 90 that specifies the number of days before which the notification has to be sent. This is a mandatory field.
    • Notify After : Provide a value between 1 and 90 that specifies the number of days after which the notification has to be sent. This is a mandatory field.
    • Frequency : Configure recurring notifications by specifying the number of days between each notification.

You can also customize the notification template based on your requirement. To do this, click Customize template against the notification for which you wish to customize the template. In the template editor, modify the notification subject and message as required. Also, use variables where required. To insert a variable, type $ and choose the required variable in the message editor.

The value of variables can either be linear text or tabular data. In asset notifications, the variables that show tabular data can also be customized to show specific columns. To do this, click the column chooser icon beside the variable and select/unselect the columns as required.

Note:

    • You can choose non-English columns for variables that support tabular data in asset notifications, but they will be displayed in English in the email notification.
    • For tabular data variables, the column chooser lists some default fields and asset/workstation additional fields. The values are shown in the email based on the type asset.

For changes to be applied, click Save.

Note: The Outgoing Mail Server settings should be configured as the notifications to the technicians are generally sent through email.
