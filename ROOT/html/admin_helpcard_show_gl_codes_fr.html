Vous pouvez associer le Code du grand livre US général (GL) lors de la création d'un nouveau bon de commande. Un compte de grand livre US général (GL) comportera des codes spécifiques aux transactions d'une organisation. La sélection d'un code GL lors d'un achat vous permet de suivre les informations relatives à une transaction spécifique.

Pour ajouter un nouveau code GL, cliquez sur le lien Ajouter un nouveau code GL dans l’angle droit du tableau Liste des codes GL.

Détails du code GL
Le formulaire des Détails des codes GL a deux champs, à savoir Code GL et Description.

Code GL : Saisissez le code GL à ajouter. Ce champ est obligatoire.
Description : Saisissez une brève description des activités du service.

Pour enregistrer les détails du nouveau code GL, cliquez sur Ajouter un code GL.
