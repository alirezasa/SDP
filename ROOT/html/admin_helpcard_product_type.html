Product Type

The product type is a high-level classification of assets to categorize different products purchased for the organization.

Click the Expand icon beside a product type to view the child product types.

Use the filter drop-down to view product types based on their availability (active or inactive).

Use the New button to add a product type. You can specify the product type details and customize fields to be added to each product type.

Click the Actions icon to edit a product type, create child product types, or delete a product type.

Click the Search icon on the toolbar to search through the list view columns.

Use the Column Chooser icon to customize the columns listed.

Note:

  • API name and plural name, category, parent product type, asset type, and asset category cannot be edited.
  • Default product types Workstation, Server, Smart Phone, Tablet, and Software cannot be deleted.
  • If other default product types are deleted, they will be marked as inactive. You can restore an inactive product type by editing it.
Add Product Type

You can create product types as templates with which you can categorize your assets. A product type contains fields which are specific to all the products under that product type/child product type.

Create Product Type
  • Click New.
  • Provide a unique display name and display plural name.
  • The API name and API plural name will be populated automatically in snake_case. You can modify them before saving the form, if needed.
  • Specify the category of the product type - Asset or Consumable.
  • Select a parent product type from the available list.
    • If the parent product type is selected as Asset, specify the asset type and asset category.
    • For consumables, the parent product type and asset type is auto-populated. Specify the asset category.
  • Describe the product type.
  • Add an icon, if required.
  • Click Save.
Configure Fields

The parent attribute fields will be auto-populated. You can add fields specific to the child product type.

  • In the Fields tab, drag and drop the desired field type from the left pane.
  • Click the Add icon to create additional fields.
  • Click View All to associate additional fields with the product type.
  • Hover over a section and click the Edit icon to modify the section properties and customize the layout.
  • Hover over a field to edit or delete it from the template.
  • Click Save.
