Theme

Changing Color

For preset colors: Select one of the preset color combinations. For custom colors: Click Custom Color to change color and then click color selection box against the UI element to choose a preferred color using the color gamut.

Changing Font

Select your preferred font from the drop-down list under the Font section.

Previewing Changes

You can preview your customizations using the interactive preview on the right-hand side.

User Personalization

SDAdmin can enable/disable users to customize the application's color and font using Allow other users to personalize their theme and font checkbox This option is enabled by default.

Note:
  • Changes made in Theme Settings will be applied to all Technicians and Requesters.
  • When Allow other users to personalize their theme and font checkbox is selected, user personalization would take preference over Admin configuration of colors and fonts.



Browser Title

Customizing Browser Title

Default Title: Choose this option to have the title ManageEngine ServiceDesk Plus for all pages in the application irrespective of the modules. Selected Module: Choose this option to customize the browser title to match the module name of the current page.

Details Page: You can configure titles of details page separately. To do this, click the respective checkbox and enter the custom title. Add variables using the dollar sign for dynamic custom titles. For example, if you want the browser title of the request details page to display request id and subject enter #$id, $subject in the text box.

Note:
  • Click Reset to revert to default values.
  • Custom Details Page title will also be applied for Edit forms.



Organize Tabs

Orgnize Tabs enables to re-organize header-pane tabs

User Personalization

SDAdmin can enable/disable users to customize the module tabs using 'Allow other technicians to personalize their tabs' checkbox. This option is disabled by default.

Note:
  • When 'Allow other technicians to personalize their tabs' is selected, 'user personalization' would take preference over Admin configurations.
  • SDAdmin can only reorder the module tabs and other users can enable,disable and reorder the module tabs.
  • 'Reset' button will be available when reordering is performed and reset to default existing order.
  • Changes made in organize tabs Settings will be applied to all Technicians.
