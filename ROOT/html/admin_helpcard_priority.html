Priority associated to the request defines the importance that is to be given to the request. To add a new priority click the Add New Priority link on the right hand side corner of the Priority List table.

Add New Priority
The Add Priority form has two fields, namely, Priority Name and Description.

Name: Specify a unique name to identify each priority.
Color: Select a color to denote the priority using the color palette or specify the color code in the text box.
Description: Enter a short description about the priority in the Description field. This can help in understanding the kind of priority associated with the name mentioned in the priority name.

Click the Save button to save the priority and return to the list view.
Click the Save and add new button to save the priority and add another priority.
