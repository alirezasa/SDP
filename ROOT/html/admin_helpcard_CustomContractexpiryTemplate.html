Contract Expiry Notification Template

You can create a notification mail template which will be sent to the technician on expiry of the contract. You need to specify the mail subject and message here in the given text boxes.

Subject Details

The subject content and variable what you specify in the template will be sent as notification mail to the technician.

 

By default you have the subject content with the variables $Contract Name and $Contract ID in the subject text box. If needed you can change or add subject content and subject variables. To change the subject variable, select the variables from the list available on the right hand side of the page. Ex: The variable $Contract Name & $Contract ID will be replaced with the corresponding values say, Contract Name - Maintenance Contract and Contract ID - MN 1002 in the mail.  

Message Details

Specify the message content and select the message variables from the list available on the right hand side of the page.

Save the template. Every time a contract expires this notification template will be sent as mail to the technician.
