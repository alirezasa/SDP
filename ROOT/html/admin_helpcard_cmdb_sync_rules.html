Sync Rule

Define the data to be synced from assets, users, or software installations to CMDB. The synced data is populated as CIs in CMDB and linked to the corresponding asset, user, or software installation.

Create Sync Rule

Select the source module from where the data is fetched and synced as CIs.

If the source module is selected as Asset, select the product type where the sync rule is applied.

Select the destination CI type where the data from the source module is synced.

Describe the sync rule purpose and usage.

Enable or disable the sync rule.

Define actions to be performed when the sync rule is applicable:
  • Filter Asset and create CIs - The destination CI will be created only when the criteria is met.
  • Map Asset Fields with CI Type Fields - Map asset and CI type fields. Data in the mapped CI fields will be automatically updated if the asset field is edited.
  • Create relationship from Asset - Create relationship between CIs based on a selected asset field.
  • Delete CI when linked Asset is deleted - The destination CI is deleted automatically if asset is deleted from ServiceDesk Plus.
  • Create drop-down option if it does not exist - If a picklist or radio fields value does not exist in the CI type, it will be created as a new option from asset field.
  • Click Save.
List View Operations
  • Use the filter drop-down to view sync rules based on source or destination CI types.
  • Click the Actions icon to edit, delete, or run the sync rule. To bulk-delete, select the sync rules and click Delete on the toolbar.
  • Click Reorder to decide the priority order in which sync rules must be executed when multiple sync rules are configured for the same source module and destination CI type.
  • Use the toggle option on the Status column to enable or disable a sync rule.
