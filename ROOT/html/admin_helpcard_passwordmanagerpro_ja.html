ServiceDesk PlusとPassword Manager Proの連携：

ServiceDesk PlusとPassword Manager Pro（PMP）を連携することで、PMPの管理者とパスワードユーザーが双方のアプリケーションのリソースを効率的に管理することができます。管理者とパスワードユーザーは、リソースのアカウントのパスワードを閲覧したり、ServiceDesk Plusからリモートでリソースにアクセスすることができます。

ServiceDesk Plusサーバー設定とPMPの認証：

入力する詳細情報は以下の通りです：

PMPのホストURL：PMPが起動しているサーバーのホストURLを入力します。

Port :PMPサーバーのPort番号を入力します。

 

［Auth Tokenの生成］をクリックします。 すると、PMPがブラウザーの新しいタブで開き、ServiceDesk Plus用のAuth Tokenを生成する画面に遷移するので、［承認］をクリックして、トークンを生成してください。PMPのAuth Tokenの生成は管理者権限を持つユーザーのみが行うことができます。

 

Auth Token:PMPにて生成したAuth Tokenを入力します。

 

［接続をテストして保存］をクリックすると、ServiceDesk PlusとPMPサーバーの接続を確立し、接続に成功すると、PMP設定が保存されます。
