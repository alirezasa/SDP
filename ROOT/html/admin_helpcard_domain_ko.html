애플리케이션을 설정하고 처음 시작할 때 애플리케이션은 네트워크에서 사용 가능한 모든 Windows 도메인을 자동으로 검색합니다.

그러나 이 외에도 도메인을 추가하고 도메인/Active Directory 또는 Windows 작업 그룹의 일부인 Windows 워크스테이션 및 서버를 검색할 수도 있습니다.< /p>

참고 사항: Windows, Linux, Mac 워크스테이션 또는 서버를 스캔하려면 에이전트가 필요합니다. 같은 페이지에서 에이전트를 다운로드할 수 있는 링크가 제공됩니다. 에이전트를 다운로드하고 배포하려면 에이전트 구성 도움말 카드를 참조하십시오.

새 도메인을 추가하려면 도메인 목록 보기 상단의 새 도메인 추가링크를 클릭하십시오.

새 도메인 추가 양식에는 도메인 이름, 도메인 컨트롤러, 로그인 이름, 패스워드 및 설명의 5개 필드가 필요합니다.

도메인 이름: 도메인 이름을 입력하십시오. 이름은 도메인을 식별할 수 있도록 고유해야 하며 필수 필드입니다.

공개 도메인 확인란: Active Directory 인증이 활성화된 경우 로그인 화면에 도메인을 표시하려면 이 확인란을 선택합니다.

도메인 컨트롤러: 도메인 컨트롤러 Active Directory 서버의 이름입니다. OU는 도메인 컨트롤러 이름이 제공되는 경우에만 나열됩니다. Windows 워크그룹을 스캔하는 경우 도메인 컨트롤러는 비어 있어야 합니다. 그리고 Active Directory에 연결할 포트는 TCP 389입니다.

로그인 자격 증명: 도메인 컨트롤러의 로그인 이름 및 패스워드를 입력하십시오.

설명: 도메인 세부정보와 관련된 모든 관련 정보를 입력하십시오.

 

도메인을 저장하고 목록 보기로 돌아가려면 저장 버튼을 클릭하십시오.

지금 저장하고 스캔 버튼을 클릭하여 도메인을 저장하고 도메인을 스캔합니다.

참고 사항: 워크스테이션 스캔이 성공적으로 실행되려면 다음 사항이 충족되어야 합니다.

  1. 애플리케이션 실행 중인 워크스테이션에서 WMI를 활성화되어 있어야 합니다.
  2. COM/DCOM 서비스는 Windows 도메인에 속한 모든 워크스테이션에서 켜져 있어야 합니다.
