Who are change governors?
  1. By default, change managers assigned to a change are considered change governors.
  2. If there are no change managers assigned, users with the SDCM role are considered as change governors.
  3. When the Allow Change Owners to be Change Governors option is enabled, change owners will be considered change governors.
Privileges of Change Governors:
  1. Change governors can modify the submission stage even when the change has crossed the planning stage.
  2. From the Actions tab, change governors can set statuses as Close Completed or Close Cancelled.
  3. If enabled under change configuration, change governors are granted the following permissions:
    1. Assign change roles within a change.
    2. Edit tasks across all stages, regardless of the change state.
