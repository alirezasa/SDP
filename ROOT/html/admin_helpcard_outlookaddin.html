ServiceDesk Plus Integration with Outlook Add-in

Set up ServiceDesk Plus integration with Outlook Add-in to enable seamless communication between your ServiceDesk Plus instance and users through Microsoft Outlook. This integration help users create requests and access support directly from their Outlook application.


Setup Integration:

  1. Create a new app registration in the Azure Portal
    • Navigate to the Azure Portal and access Microsoft Entra ID.
    • Go to App registrations and create a new registration.
    • Configure the application settings as per the help document.
  2. Assign the necessary API permissions
    • Follow the integration guide to assign the required API permissions.
    • Ensure proper consent is granted for the application.
  3. Copy the Client (Application ID) and update it here
    • From your Azure app registration, copy the Application (Client) ID.
    • Enter this ID in the Application (Client) ID field here.
  4. Download the Add-in manifest file
    • After updating the Application ID, download the manifest file.
    • The manifest will be automatically configured with your Application ID.
  5. Upload the manifest:
    • Upload the manifest file either from the Microsoft 365 admin centre or side load it here to be available in your Outlook application alone.

After completing the setup, the Outlook Add-in will be available to users in their Outlook application, providing direct access to ServiceDesk Plus functionality.
