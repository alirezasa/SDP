Le code de clôture de demande renseigne sur la raison de clôture d'une demande : avec succès, sans succès, annulée, etc. Ce code renseigné par le technicien permet à l'administrateur de saisir le motif de clôture de la demande. Des commentaires peuvent également être ajoutés pour donner une explication détaillée à la clôture. La liste des codes de clôture de demande configurés apparaît à la clôture d'une demaine. Les données saisies, quant à elles, s'affichent dans la page d'informations de la demande.

Cliquez sur lien Ajouter un nouveau code de clôture pour ajouter un nouveau code de clôture de demande.

  1. Renseignez un Nom unique pour le code de clôture de demande. Ce champ est obligatoire.

  2. Donnez une brève Description du code de clôture de demande.

  3. Pour enregistrer le code de clôture de demande et revenir à l’affichage liste, cliquez sur le bouton Enregistrer. Pour enregistrer le demandeur  et en ajouter un autre, cliquez sur le bouton Enregistrer et ajouter un nouveau.
