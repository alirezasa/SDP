SMS 알림 설정

SMS 알림 설정을 사용하면 SMS를 통해 기술자에게 알릴 수 있습니다. 이런 식으로 기술자는 연결된 요청에 대해 수행된 작업에 대해 이동 중에 알림을 받을 수 있습니다.

선택 정의
모바일 서비스 제공업체를 통해 SMS 보내기 기술자의 SMS 메일 ID로 메시지가 전송됩니다.
SMS 게이트웨이 제공업체를 통해 SMS 보내기 기술자의 휴대폰 번호로 직접 메시지가 전송됩니다.

우선 순위가 높은 요청서나 변경은 기술자가 최대한 빨리 조사해야 합니다. Servicedesk Plus는 기술자가 SMS를 통해 알림을 보내 이동 중에도 요청서를 해결할 수 있도록 도와줍니다.

SDP는 알림을 위한 두 가지 옵션을 제공합니다. 첫째, SDP는 Site24*7, Clickatell 및 대량 SMS와 같은 서비스 제공업체와 통합하여 SMS를 전송하여 기술자에게 구성된 휴대폰 번호로 직접 알립니다. 사용자는 서비스 제공자로부터 크레딧을 구매하고 크레딧 잔랙이 소진될 때까지 메시지를 보낼 수 있습니다(Site24*7의 경우). 둘째, SDP는 기술자의 SMS 메일 ID로 알림을 이메일로 보냅니다.

구성하려는 SMS 제공업체를 선택하십시오. Site24*7 및 Clickatell은 인증 세부 정보에 대한 Authtoken이 필요하지만 대량 SMS는 사용자 이름과 암호가 필요합니다.
'유니코드 문자를 사용하여 SMS 보내기' 확인란을 활성화하면 유니코드 문자를 사용하여 알림이 전송됩니다. 유니코드는 플랫폼/프로그램/언어에 관계없이 모든 문자에 고유 번호를 제공합니다.


사용자 지정 공급업체 설정

  • URL은 SMS 게이트웨이 공급자의 URL을 나타냅니다. (예: http://www.smsserver.com/sendsms)
  • URL 매개변수는 쿼리 매개변수이며 URL에 동적으로 추가됩니다.
  • 요청 헤더를 통해 클라이언트와 서버는 요청서 또는 응답과 함께 추가 정보를 전달할 수 있습니다.
  • 기본 인증은 HTTP 사용자 에이전트가 요청할 때 사용자 이름과 비밀번호를 제공하는 방법입니다.
  • 요청 페이로드는 유효한 JSON 형식이어야 하며 콘텐츠 유형은
    • application/json (Ex:{ "foo" : "bar", "name" : "John"} )
    • application/x-www-form-urlencoded (Ex:foo=bar&name=John)
  • 메시지 및 수신자는 '${{message}}' 및 '${{recipients}}'를 사용하십시오.
  • SMS 사업자로부터 응답: SMS가 성공적으로 전송되었는지 여부를 애플리케이션에서 확인할 수 있도록 성공 메시지를 구성하십시오.
참고 사항:
  • SMS 알림을 보내기 위해 기술자 휴대폰 번호를 구성합니다. 또한 모바일 필드에 적절한 국가 코드를 접두어로 지정해야 합니다.
    관리 설정 >> 사용자 >> 기술자 >> 기술자 세부 정보.
  • SMS 메시지는 알림 규칙 > SMS 템플릿.
  • '구성 방법'은 특정 서비스 제공 업체에 가입할 수 있는 링크를 제공하고 가입 지침을 보여줍니다.
