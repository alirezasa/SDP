요청서 종료 규칙을 사용하여 요청서를 종료하는 동안 기술자가 입력해야 하는 필수 필드를 선택할 수 있습니다. 또한 이를 사용하여 기술자에 대한 사용자 동의를 확인하고 수동 또는 자동으로 요청서를 종료할 수 있습니다.

예: 이 페이지에서 필수 필드로 해결방안을 선택한 경우 문제를 해결하는 기술자는 해결 텍스트 필드에 문제의 원인과 해결방안을 입력해야 합니다. 그렇지 않으면 오류 메시지가 나타납니다. 해결방안 필드에 세부 정보를 입력하라는 메시지가 표시됩니다. 예, 메시지를 표시합니다. 라디오 버튼이 활성화된 경우 사용자가 해결 방안을 동의했다면 관련 기술자에게 동의 메시지가 표시됩니다.

요청서 종료 규칙을 설정하려면,

  1. 필드 목록에서 확인란을 활성화하여 요청서를 종료하기 위한 필수 필드를 선택합니다.

  2. 사용자가 해결 방안을 확인했는지 묻는 확인 메시지를 기술자에게 표시하려면 예, 메시지를 표시합니다 라디오 버튼을 활성화하고, 그렇지 않으면 아니요, 메시지를 표시하지 않습니다 라디오 버튼을 활성화합니다.

  3. '요청서 상태를 다음으로 이동' 확인란을 선택하고 드롭다운에서 종료됨(또는) 해결됨 옵션을 선택하여, 연계된 작업 완료 시 요청서 종료를 활성화합니다.

  4. 요청서는 수동 또는 자동으로 종료할 수 있습니다.

수동 종료: 이 라디오 버튼을 활성화하면 해결된 요청서는 관련 기술자가 수동으로 종료해야 합니다.

자동 종료: 요청서가 해결된 상태가 되면 요청자에게 이메일이 전송됩니다. 요청자는 제공된 링크를 사용하여 요청서를 종료하거나 이메일에 회신하여 요청서를 다시 열 수 있습니다(진행 중 상태가 됨). 요청자가 아무 조치도 취하지 않으면 콤보 상자에서 지정된 일 수 후에 요청서가 종료됩니다.

자동 종료 라디오 버튼을 활성화합니다. 해결된 요청서 종료: 대기 기간 콤보 상자에서 해결된 요청서가 종료되어야 하는 기간(일)을 선택합니다.

승인이 거부되면 자동으로 요청서를 종료합니다.

이 옵션을 활성화하면 요청서 승인이 거부된 경우(즉, 요청서의 승인 상태가 "거부됨" 상태로 변경된 경우) 요청서가 자동으로 종료됩니다. 일반적으로 Admin관리자/기술자는 요청서에 대한 승인이 거부될 때 수동으로 요청서를 종료해야 하지만 이 옵션을 사용하면 그럴 필요가 없습니다.

이를 통해 다음을 수행할 수 있습니다:

  1. 승인이 거부된 후 요청서를 종료해야 하는 시간을 구성합니다. 날짜 및 시간 드롭다운을 사용하여 구성합니다.
  2. 적절한 요청서 종료 코드를 선택합니다.
  3. 지정된 필드에 요청서 종료 설명 및 해결 방안(있는 경우)을 추가합니다.
  4. 요청서와 관련된 보류 중인 작업으로 수행해야 하는 작업을 구성합니다(예: 미완료 작업의 상태를 "종료됨", "해결됨" 또는 일부 사용자 지정 완료 상태로 변경하도록 구성할 수 있습니다. 그렇지 않으면 승인이 거부될 때 해당 작업을 삭제하도록 구성할 수 있습니다.

참고: 승인 상태가 "거부됨" 상태로 변경된 경우에만 요청서가 자동으로 종료됩니다.
