The release management process of services is built into 9 sequential stages. Statuses within each stage indicate the progress of the release. Besides customizing the default stages and statuses, you can add custom statuses.

Click a stage name or the drop-down icon beside it. The stage details page will expand, where you can customize the default status and add new status under the stage.

  • Use the New Release Status button to add statuses to a stage. You can mention the status details and configure roles to be notified when a release reaches the status.
  • To edit a status, click the status or use the Edit button under the Hamburger icon.
  • Use the Hamburger icon to delete a status. You cannot, however, delete some default statuses.

Note:

If a release status is deleted while being used in releases, the status will be disabled. You can restore an inactive status by editing it.
