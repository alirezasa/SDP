Agent 설정

 

AssetExplorer 애플리케이션은 Windows, Mac 및 Linux 시스템을 스캔하기 위해 Desktop Central Agent가 필요합니다. Agent를 구성하면 Windows, Mac 및 Linux 장비용 에이전트를 다운로드하고 배포하는 데 도움이 됩니다.

 

Agent 다운로드 및 배치

Desktop Central를 다운로드할 때,

Admin 관리자만 Desktop Central Agent 만 다운로드할 수 있습니다.

    • Windows/Linux/Mac에 대한 Agent를 선택합니다.

    • Desktop Central을 다운로드하고 설치하라는 메시지가 표시됩니다. 이미 Desktop Central을 설치했다면 이 단계를 건너뛰고 Desktop Central 통합을 계속 진행할 수 있습니다.

    • 다운로드를 클릭하고 설치하십시오.

    • 호스트 이름, 포트 이름, 사용자 이름 및 패스워드를 입력하여 프록시 설정을 구성합니다. 다운로드 및 설치를 클릭합니다.

    • 설치가 완료되면 해당 Agent를 다운로드할 수 있는 옵션이 나타납니다. Agent를 다운로드한 경우, 기존 Windows Agent를 Desktop Central Agent로 교체할 수 있습니다.

이전에 설치되었던 Windows Agent를 Desktop Central Agents (Windows만 해당)로 교체합니다.

ReplaceAgents.vbs를 Active Directory에서 한 GPO로 실행하여 Windows Agents를 Desktop Central Agents로 교체할 수 있습니다. 장치가 부팅되면 Agent 가 교체됩니다.

다음 단계에 따라 Active Directory에서 GPO를 구성하십시오.

  1. 한 네트워크 공유를 생성합니다 (예: \\MyServer\MyShare).

  2. Windows Agent zip 파일을 다운로드 하고 압축을 풉니다.

  3. 네트워크 공유에 DesktopCentralAgent.msi 와 DesktopCentralAgent.mst 파일을 저장합니다.

  4. 귀사의 Domain Controller에서, 시작 >> 실행 >> gpmc.msc를 입력하고 클릭하십시오. 만일 gpmc가 귀사의 Active Directory에 설치되지 않았다면, gpmc를 설치하고 계속하십시오.

  5. 도메인을 마우스 오른쪽 버튼으로 클릭하고 GPO 생성 및 연결을 선택하고 GPO의 이름을 입력하십시오.

  6. 선택한 클라이언트 시스템에만 Agent를 설치하려면 다음 단계를 수행하십시오.:

    • GPO를 선택하고 범위 탭을 클릭합니다.

    • 보안 필터링 섹션에서 추가를 클릭합니다.

    • 사용자, 컴퓨터 또는 그룹 선택 대화 상자에서 개체 유형을 클릭합니다.

    • 특정 컴퓨터 개체 유형을 선택하고 확인을 클릭합니다.

    • 컴퓨터 이름을 지정하고 이름 확인을 클릭한 다음 확인을 클릭합니다.

리눅스 및 Mac에 데스크탑 Central 에이전트 설치

리눅스 대량 Agent 설치 도구를 사용하여 리눅스에 데스크탑 Central 에이전트를 설치하고, Mac 에이전트 설치 스크립트를 사용하고 computers.csv에 설치할 시스템 목록을 입력하여 Mac에 Desktop Central Agent를 설치할 수 있습니다.
