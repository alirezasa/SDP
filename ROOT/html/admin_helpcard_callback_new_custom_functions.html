On this page, you can build or edit a callback custom function.

To build a function,

  1. Provide the required details, namely function name, return type, description, and API name.
  2. Set parameters for the function to use input values from external application.
  3. Use the Deluge editor to build your function.
  4. Click Save.

Note:

  • You can set a maximum of 10 parameters.
  • The API name must be unique.
  • The URL to execute the function is generated automatically based on the provided API name.
  • Make sure to select Publish to allow external applications to execute functions using their URLs

Refer to this guide to learn more about callback custom functions.
