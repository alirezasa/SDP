학습 데이터 사용자 정의

각 액션의 사용자 정의 데이터에서 해당 액션관련 키워드, 구문 또는 완전한 문장으로 Zia를 테스트할 수 있습니다. Zia 예측이 정확하지 않거나 사용할 수 없는 경우 학습 데이터 세트에 관련 정보를 수동으로 추가할 수 있습니다. Zia는 새로운 데이터로 즉시 훈련할 것입니다.

정확한 예측을 위해 Zia 훈련에 사용되는 사용자 정의 데이터에 액션에 대한 항목 수가 같거나 거의 동일한지 확인하십시오.

모든 사용자 정의 학습 교육 데이터를 제거하려면 언제든지 기본으로 복원을 클릭하세요.

사용자 피드백

기술자는 Zia의 각 예측을 평가하고 Zia 알림에서 그것이 정확한지 표시할 수 있습니다. 이 피드백은 Zia의 학습 데이터를 재사용하고 Zia가 향후 정보에 입각한 결정을 내릴 수 있도록 하는 데 사용됩니다. Zia는 15분에 한 번씩 사용자 피드백을 통해 제출된 데이터로 자신을 훈련합니다. 범주 및 템플릿 예측을 위해 Zia는 최신 요청서 데이터를 기반으로 매일 밤 훈련을 받고 예측 정확도를 향상시킵니다.

사용자 피드백은 Zia의 정확도를 결정하는 데도 도움이 되며, 이를 통해 Zia의 학습을 추적할 수 있습니다.
