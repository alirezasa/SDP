Custom actions are actionable custom functions that allow users to manipulate data in ServiceDesk Plus and other external applications. Zia Custom Functions are built on Deluge, Zoho's propriety scripting language.

Use the New button to create a Zia function. The Delete button allows you to remove a Zia function.

You can search through custom actions using keywords

To modify individual Zia Custom actions, use the hamburger icons beside the custom action.

You can use Zia custom functions to create custom actions to be used within the Zia Bot Workflow.

Edits made to the custom function will be reflected in the workflow if the function is used in the workflow.

Note that you can delete the custom function only if it's not used in the Zia Bot Workflow.
