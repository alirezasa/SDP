Actionable Messages for Outlook

Actionable Messages for Outlook 통합을 통해 사용자는 ServiceDesk Plus에서 보낸 실행 가능한 이메일을 사용하여 Outlook 편지함 내에서 다양한 헬프 데스크 작업을 수행할 수 있습니다. 기술자는 요청을 선택 및 해결하고 메모를 추가하고 승인 작업을 수행할 수 있으며 최종 사용자는 요청에 메모를 추가할 수 있습니다.


통합 설정

  • Azure portal에서 ServiceDesk Plus 애플리케이션에 대해 생성된 애플리케이션 ID 및 테넌트 ID를 입력하십시오.
  • 작업 가능 전자 메일 개발자 대시보드에서 얻은 Originator를 입력하고 저장을 클릭합니다. 이러한 구성이 저장되면 SDP 호스팅 도메인, 리디렉션 URL 및 공개 키와 같은 새 필드가 자동 생성된 값과 함께 표시됩니다.
  • SDP 호스팅 도메인에서 애플리케이션에 대해 구성된 별칭 URL이 자동으로 채워집니다. 그러나 SDP 애플리케이션이 다른 곳에서 호스팅되는 경우 호스팅되는 도메인을 지정하십시오.
  • Azure Portal 및 Actionable Email Developer Dashboard에서 각각 리디렉션 URL 및 공개 키를 구성해야 합니다.

구성을 제출하면 Outlook용 실행 가능한 메시지 사용(활성화)이라는 새 확인란이 표시되고 활성화됩니다.


통합 업데이트/제거

통합에서 구성을 업데이트하려면 변경하고 업데이트를 클릭하십시오.

구성을 복원하는 동안 통합을 비활성화하려면 통합 페이지 상단에 표시된 Outlook용 실행 가능한 메시지 사용(활성화)를 선택 취소합니다.

통합을 완전히 제거하려면 페이지 하단에 표시된 제거를 클릭하십시오. 통합을 제거하면 모든 구성이 삭제되고 복원할 수 없습니다.


Actionable Messages for Outlook에 대해 자세히 알아보려면 이 링크를 방문하십시오..
