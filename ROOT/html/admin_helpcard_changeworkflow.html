Organizations face various kinds of changes which differ in process and control. Changes such as, replacing switches or routers across the organization requires a systematic flow with approvals at every stage. Whereas, changes initiated frequently or carried out periodically like, upgrading the RAM for users or changing the printer toner; do not have to undergo the entire change lifecycle process. Such changes can be implemented directly and closed, and at times may not even require approval from the concerned authority.

The Change Workflow Wizard lets you simplify the change lifecycle by configuring change workflows that suits your organizations needs. The configured workflows are listed in the Workflow drop down field in new change form, enabling the change request to follow the process defined in the selected workflow.

Add Change Workflow  

You can configure a new change workflow by clicking Add Change Workflow button.

  1. Provide a name for the Change Workflow in the Name field.

  2. Select Is Emergency check box if the workflow defines instant processes.

  3. You can also set a workflow as default by selecting Set as default check box. If a workflow is already set as default, then a popup message appears asking you to change the default change workflow. Click Yes button if you want to set this workflow as default.

Note:

    1. By setting a workflow as default, new change workflows will copy the workflow configurations as the default workflow.

    2. While creating a change request, the workflow field will be populated with the default workflow, by default.

    3. Also, you cannot delete the default workflow from the Change Workflow List View.  To delete a default workflow, set another workflow as default and delete the workflow.

  1. Enter a brief description about the workflow in Description field.

  2. Click Save button. The change workflow detail is saved and appears in the list view. Click Save and Configure to save and configure the change workflow.  

The Filter drop down menu lets you organize the change workflow list view. You can either View All the change workflows, View General Workflows or View Emergency Workflows.

From the Change Workflow List View, you can edit, delete and duplicate workflows. Click Configure Workflow button beside a change workflow to configure workflow process.

 

Duplicating Workflows

Certain workflows may be similar, except for one or two stages. In such cases, you can duplicate workflows instead of configuring them all over again. By duplicating a workflow, the stage and status configurations are retained and the workflow name is denoted as "Copy of <Workflow Name>".

  1. In the Change Workflow List View, move your cursor over a workflow to duplicate.  

  2. Click Duplicate Workflow icon. The Duplicate Workflow form pops up.

  3. Enter a Name for the Workflow. By default, the name of the workflow is denoted as "Copy of <Workflow Name>".

  4. Select Is Emergency check box if the workflow defines instant processes.

  5. Provide a brief description about the change workflow in Description field.

  6. Click Save and Configure, to save and configure the workflow.

Alternatively, you can duplicate workflows while configuring workflows from Change Management Workflow configuration page.

 

The Change Management Workflow process configuration lets you define the change lifecycle by changing the stage and status for a given statue. For each status, you can set the next status and stage and, also notify certain change roles on the progress of the change request.

Note: Change Workflow can be configured for status that has Action Name specified in Status and Stage Configuration.

Lets take an example of the Status - Accept in the Stage - Submission.

  1. Click Configure Next Stage link.

  2. Select the roles to notify once the change request is accepted in Submission Stage using the Role List icon.

  3. Select the next Stage and Status to move the change request from Move to Stage & Status drop down menu. Say, the next stage is Planning and status as Planning in Progress.

  4. When the change request is moved to Planning in Progress, you can notify another set of roles on the progress of the change request. Select the roles by clicking Role List icon.

  5. Click Save button.

Likewise, you can configure the next stage and status for the remaining stages.

For changes recommended by all CAB members, you can bypass the approvals from the Change Approvers (Change Manager/Change Approver) by selecting Auto approve a change request when all CAB members recommend it.

From the Change Management Workflow configuration page, you also have an option to duplicate the workflow. Click Duplicate link to duplicate the workflow.
