Vous pouvez associer le Centre de coûts au Bon de commande lors de la création d'un nouvel achat pour votre organisation. Pour ajouter un nouveau centre de coûts, cliquez sur le lien Ajouter un nouveau centre de coûts dans l’angle droit du tableau Liste des centres de coûts.

Détails du centre de coût
Le formulaire Centre de coûts comporte cinq champs : Code du centre de coûts, Nom, Service, Propriétaire et Description.

Code du centre de coûts : Renseignez le code du centre de coûts. Ce champ est obligatoire.
Nom : Renseignez le nom du centre de coûts. Ce champ est obligatoire.
Service : Sélectionnez et mappez plusieurs services à un centre de coûts. Ce champ est obligatoire.
Propriétaire: Renseignez le propriétaire du centre de coûts. Il s'agit généralement du chef de service ou d'un employé de votre organisation. Ce champ est obligatoire.
Description : Saisissez une brève description des activités du service.

Pour enregistrer les détails du nouveau centre de coûts, cliquez sur Ajouter un centre de coûts.
