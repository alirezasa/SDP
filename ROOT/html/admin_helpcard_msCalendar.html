Integrate ServiceDesk Plus with Microsoft Calendar to auto sync technician leave records in ServiceDesk Plus Calendar and Microsoft Calendar. Technicians can leverage Microsoft Calendar as an additional channel for creating, updating and deleting their leave records in ServiceDesk Plus and vice versa.

Configure Integration

  1. Provide the Application ID and Tenant ID values auto-generated while registering your app in Microsoft Azure.
  2. Enter the Client Secret value generated for your app in Microsoft Azure as the Application Password.
  3. Click Save.

In the The SDP Hosted Domain field, the alias URL configured for your application will be auto-populated. If your application is hosted elsewhere, you can edit the domain.

After you submit the configurations, a new check box called Enable Microsoft Calendar will appear enabled.

Update/Remove Integration

  • To modify any configuration in the integration, make the changes and click Update.
  • To disable the integration settings temporarily, uncheck Enable Microsoft Calendar option at the top of the integration page.

To delete the integration, click Remove. Note that if you delete the integration, all configurations will be permanently deleted and cannot be restored.
