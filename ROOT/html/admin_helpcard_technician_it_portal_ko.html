기술자 / 사이트 연계 모델

IT 헬프데스크 팀은 헬프데스크 팀 관리자, 헬프 데스크 담당자 및 조직의 다양한 직원이 게시/제출한 요청서를 처리할 기술자로 구성됩니다. SDP 애플리케이션에서 기술자를 편집하고 역할과 필요에 맞는 다양한 액세스 권한을 제공할 수도 있습니다. 기술자 콤보 상자에서 사이트를 선택하여 특정 사이트의 기술자 목록을 볼 수도 있습니다.

참고 사항 :
사이트 Admin 관리자는 기술자 콤보 상자에서 자신이 연계된 사이트에 사용 가능한 기술자를 추가하고 볼 수 있습니다. 사이트가 관리설정-사이트에서 구성되지 않은 경우, 콤보 상자에서 기술자를 볼 수 없습니다.
특정 사이트의 기술자가 다른 사이트의 설정을 참조하는 경우, 사이트 변경 시 선택한 사이트의 참조 사이트를 나타내는 팝업이 표시됩니다. 삭제할 사이트에 대해 구성된 기술자가 하나 이상의 사이트에서 참조되는 경우 사이트 삭제 프로세스 중에 삭제할 사이트가 참조하는 기술자와 함께 나열됩니다. 참조 사이트의 설정을 선택하여 기본 설정을 참조하거나 원하는 다른 사이트 설정으로 변경할 수 있습니다.

 

기술자로 변경

이 페이지에서, Admin은 이 '사용자' 목록에서 이미 가져온 사용자 만 기술자로 수정할 수 있습니다.

기술자로 변경 드롭다운에서 사용자를 선택하고 사용자를 클릭하여 기술자로 수정합니다. 사용자 이름을 클릭하면 선택한 사용자의 데이터와 함께 기술자 세부 정보 페이지가 팝업됩니다. 연계된 그룹, 시간당 비용, 프로젝트 역할 필드 및 인스턴스에서 추가된 추가 필드만 업데이트할 수 있습니다. 저장을 클릭하여 사용자 유형을 기술자로 변경합니다.

참고 : 회색으로 표시된 필드는 ESM 디렉토리 아래에서 편집할 수 있습니다.

사이트를 기술자와 연계:

사이트를 추가한 경우 여러 사이트를 기술자에게 연계할 수 있습니다. 연계된 사이트 필드 근처에 있는 팝업에서 기술자를 연계할 사이트를 선택합니다. 마찬가지로 사이트를 분리할 수도 있습니다. 기술자 목록 페이지에서 기술자의 사이트를 연계/해제할 수도 있습니다.

 

기술자의 그룹 배정:

기술자에게 그룹을 배정할 수도 있습니다. 연계된 그룹 필드

근처에 있는 팝업에서 그룹을 선택합니다.

 

추가 기술자 세부 정보:

사용자 정의 필드가 추가된 경우 추가 기술자 세부 정보에 동일한 항목을 입력합니다. 기술자에게 구매 주문 승인자 권한을 활성화하려면, 해당 확인란을 활성화합니다.

 

사용자 역할:

이제 SDP 애플리테이션의 다양한 모듈에 대한 액세스 권한을 정의하는 역할을 기술자에게 배정해야 합니다. 기술자가 완전한 관리자 액세스 권한을 갖도록 하려면 할당된 역할 드롭다운에서 SDAdmin 역할을 선택합니다. 사이트 관리자가 자신의 로그인 자격 증명을 사용하여 애플리케이션에 로그인하는 경우 이 옵션을 사용할 수 없습니다. (또는)

기술자가 위에서 선택한 사이트에 대한 완전한 관리자 액세스 권한을 가지도록 하려면 SDSiteAdmin 역할을 선택하십시오.

그렇지 않으면 배정된 역할

드롭다운에서 역할을 선택하십시오.

 

데스크톱 관리 기능에 대한 액세스 활성화:

기술자에게 로그인 권한이 있는 경우 기술자에게 Desktop Central 로그인 액세스 및 DC(Desktop Central) 역할을 제공할 수도 있습니다. 두 가지 DC 역할이 있으며, DC 관리자와 DC 게스트입니다. 데스크톱 관리 기능에 액세스할 수 있음 확인란을 선택하고 두 역할 중 하나를 기술자에게 제공합니다. 기술자가 자격 증명을 사용하여 SDP 애플리케이션에 로그인하면 해당 기술자가 데스크톱 관리 드롭다운 메뉴를 볼 수 있으며, 여기에서 기술자는 SDP 애플리케이션 웹 콘솔 내에서 데스크톱 관리 기능을 수행합니다.

 

참고 사항:

  1. 데스크톱 관리 기능에 액세스할 수 있음 확인란과 한 DC 역할을 선택하면, Desktop Central 애플리케이션에서 동일한 로그인 자격 증명을 가진 사용자가 생성됩니다.
  2. Desktop Central과 SDP 애플리케이션 간의 연결이 성공적으로 설정된 경우에만 데스크톱 관리 기능에 액세스할 수 있음 확인란을 선택할 수 있습니다. Desktop Central과의 통합에 실패하면 이 옵션이 회색으로 표시됩니다.

저장 버튼을 클릭하여 기술자를 저장하고 목록 보기로 돌아갑니다.

사이트 연계/연계해제

이 옵션을 사용하여 사이트에서 기술자를 연계/연계 해제(분리)할 수 있습니다.

  1. 기술자 목록 보기 페이지에서 사이트를 연계/분리하려는 기술자 옆에 있는 확인란을 선택합니다.
  2. 기술자를 한 사이트에 연계하려면 액션 버튼을 클릭하십시오. --> 사이트에 연계. 사이트에 기술자 연계 팝업 창이 나타납니다. 콤보 상자에서 기술자를 연계할 사이트를 선택합니다. 연계 버튼을 클릭합니다.      
  3. 사이트에서 기술자를 분리하려면 액션 버튼을 클릭하십시오. --> 사이트에서 분리. 사이트에서 기술자 분리 팝업 창이 나타납니다. 콤보 상자에서 기술자를 분리할 사이트를 선택합니다. 연계 해제(분리) 버튼을 클릭합니다.

프로젝트 역할 배정

기술자 목록에서 기술자에게 프로젝트 역할을 할당할 수 있습니다.

액션을 클릭합니다. --> 프로젝트 역할 배정 . 프로젝트 역할 드롭다운에서 프로젝트 역할을 선택하고 연계를 클릭합니다.
