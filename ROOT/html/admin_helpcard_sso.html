Single Sign-On
 
On enabling single sign-on, application directly authenticates your windows system user name and password . Hence you need not provide login credentials again to enter this application.
 
Note:
  • All the users from the active directory has to be imported to enable single sign-on.
  • Enabled domain should be two way trusted. 
  • Single sign-on works only on Windows Internet Explorer.
Enabling Single Sign-On
 
Once you have imported all the users from the active directory you can see the Enable button available in the page.
Click on the Enable button to activate single sign-on. By default you will only be able to login as a guest. The administrator should select the technicians from the requesters list to provide you with the technician role.
