凭证库用于保存资产扫描/远程控制过程中使用各种凭证。可以在网络扫描，单体扫描或者远程控制时关联这里已配置的凭证。 凭证支持的协议包括：WMI、Telnet/SSH、 SNMP V1/V2 和 VMWare。

添加凭证:

  1. 从扫描协议下拉框中选择凭证类型(Windows WMI, Telnet/SSH Protocol, SNMP V1/V2, VMWare & Remote Control)
  2. 为该凭证指定名称及简要描述。
  3. 输入用户名和密码。
  4. 如果是Telnet/SSH凭证，指定以下参数：
    协议- Telnet/SSH
    端口号- 22（默认）
    通过选择 使用公有密钥进行认证选项，可以支持基于密钥的认证方式。
  1. 对于 SNMP V1/V2凭证，需要指定以下参数：
    SNMP读团体字串密码。
    SNMP端口号 - 161（默认）
    超时时间(超过该时间后连接将被中断) - 5秒（默认）
    重试次数(超时发生前可以重试的次数) - 0（默认）
  1. 对于SNMP V3凭证，指定以下参数：
    输入用户名和上下文名称。
    授权和加密协议：

    为授权协议选择MD5或SHA，为加密协议选择DES或AES-128或AES-192或AES-256。
    注意：加密协议只有在配置了授权协议之后才能配置。这两个协议的配置非强制性。
    授权和加密密码：

    如果启用了相应的协议类型，请输入密码。
    SNMP部件号 - 161（默认）
    超时时间(超过该时间后连接将被中断) - 5秒（默认）
    重试次数(超时发生前可以重试的次数) - 0（默认）
  1. 对于VMWare凭证，指定以下参数：
    HTTPS部件号 - 443（默认）
    超时时间(连接终止的时间) - 默认为60秒。
  1. 对于SCCM凭证，指定以下参数：
    认证类型 - 选择SCCM数据库服务器是否支持Windows或SQL认证。根据选择的认证类型填写其他字段。
    Windows - 输入账户的域名、用户名、和密码，该账户有权限读取SCCM数据库服务器中的信息。
    SQL - 输入账户的用户名和密码，该账户有权限读取SCCM数据库服务器中的信息。
    注意：为所有地点的SCCM保存共同的凭证以简化更新过程。然而，您可以为不同地点的SCCM保存多个凭证。
  2. 保存凭证。

注意：远程控制凭证（在凭证库下配置）将在远程控制期间可供选择。
