Key Manager Plus 連携

ServiceDesk PlusとKey Manager Plusを連携することで、技術担当者がServiceDesk Plusのコンソール画面から離れることなく、期限切れのSSL/TLS証明書の判別したり、証明書を更新したり、新規発行された証明書に直接展開したりすることができます。さらに、連携することで、IT管理者がネットワーク全体のSSL/TLS暗号の強度を継続的に監視することができます。また、技術担当者は弱い暗号スイートなどの脆弱性が発見されるたびに警告を受けとり、即座に是正措置をとることができます。

ServiceDesk PlusでKMPを設定する手順

KMPのホストURL：Key Manager PlusがインストールされているアプリケーションURLを入力します。

Auth Token：Key Manager Plusで生成したAuth Tokenを入力します。

 

［保存］をクリックし、設定を保存します。
