ServiceDesk Plus, lors de son premier démarrage, découvre les domaines Windows de votre réseau. Pour analyser les stations de travail, vous n'aurez qu'à renseigner les identifiants de connexion pour ces domaines.

Vous pouvez également ajouter des domaines comme analyser les stations de travail et serveurs Windows de votre domaine/Active Directory ou du groupe de travail Windows.

Pour ajouter un nouveau domaine, cliquez sur le lien Ajouter un nouveau domaine dans l’angle droit du tableau Liste des domaines Windows.

Ajouter un nouveau domaine
Le formulaire Ajouter un nouveau domaine comporte cinq champs : Nom du domaine, Contrôleur de domaine, Nom de connexion, Mot de passe et Description.

Nom de domaine : Renseignez le Nom de domaine. Il s'agit d'un champ obligatoire. Le nom doit également être unique.

Case Domaine public : Cochez cette case si vous souhaitez afficher le domaine sur l'écran de connexion lorsque l'authentification Active Directory est activée.

Contrôleur de domaine : Renseignez le nom du Contrôleur de domaine du serveur Active Directory. Les unités de l’organisation ne sont répertoriés que si le nom du contrôleur de domaine est renseigné. Le contrôleur de domaine ne doit pas être renseigné si vous analysez un groupe de travail Windows. Le port de connexion à Active Directory est TCP 389.

Identifiants de connexion : Renseignez le Nom de connexion et le Mot de passe du contrôleur de domaine.

Description : Saisissez des informations sur les détails du domaine.

 

Cliquer le bouton Enregistrer pour enregistrer le domaine et revenir à l'affichage liste.

Cliquez sur le bouton Enregistrer et analyser maintenant pour enregistrer et analyser le domaine.

REMARQUE: Pour que l’analyse des stations de travail soit bien exécutée, les points suivants doivent être vérifiés :

  1. WMI (Infrastructure de gestion Windows) doit être activé sur la station de travail sur laquelle ServiceDesk est exécuté.
  2. Le service COM/DCOM doit être mis en route sur toutes les stations de travail appartenant au domaine Windows.
