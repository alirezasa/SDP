Project Status denotes the level of progress of a project, based on which appropriate actions can be taken.

Default Project Statuses are: Open, Onhold, Canceled and Closed.

Add Project Status

To add a new Project Status, click New and fill out the displayed form.

Name: Specify a unique name for the Project Status.

Configure the status: Pending or Completed.

Color: Select a color to denote the Project Status using color palette.

Description: Provide a short description about the Project Status.

Click Save or Save and Add New.
