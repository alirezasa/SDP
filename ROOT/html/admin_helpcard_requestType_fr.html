Vous pouvez configurer un type de demande qui diffère des options par défaut : un incident, une demande de service, etc. Cette démarche est essentielle lors de la création d'une nouvelle demande sous le module de demande. Pour ajouter un nouveau type de demande, cliquez sur le lien Ajouter un type de demande à l’angle droit du tableau de la liste des types de demandes.

Ajouter un type de demande

Nom : Renseignez le nom du type de demande dans le champ prévu à cet effet. Par exemple : Incident, Demande d'informations.

Description : Donnez une brève description du type de demandes à intégrer dans cette catégorie.

Pour revenir à l’affichage liste, cliquez sur le bouton Enregistrer. Cliquez sur Enregistrer et ajouter nouveau pour enregistrer et créer un autre type de demande.

 

Supprimer un type de demande

Dans la page de liste des types de demande, cochez la case du type de demande à supprimer.

Cliquez sur le bouton Supprimer. Un message de confirmation de la suppression s'affiche. Cliquez sur Ok pour continuer. Le demandeur est supprimé de la liste.
