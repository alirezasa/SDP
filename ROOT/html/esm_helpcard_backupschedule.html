Schedule periodic backups of your application files. All these backup files are password-protected.

To schedule a backup:

  • Click Edit Scheduling.
  • On the Edit Settings page, fill out the required fields.
  • For MSSQL backups, you can Enable/Disable the backup schedule and select the backup frequency. However, this is not possible for Postgres database backup since for Postgres, the backup will be taken everyday by default.
  • Provide the email address of the technician to be notified if the backup fails.
  • Set a time to start the backup and select type of files (Database/File Attachments) that need to be backed up. Please note, for postgres, by default the database checkbox will be selected and cannot be configured.
  • Click Reset Password if you want to change the password. (You can view the password on the Backup Scheduling home page). Select if you want to notify the password update to any email address. If yes, the email address in the respective field.
  • Provide the backup location and the number of days to retain the backup files.
  • In case of partial backups, go to the location of the skipped files and disable any anti-virus restrictions. Also, check for corrupted files and rerun the backup schedule.

Note: Backup scheduling is for the entire application, and it is not specific to any instance.

Password Protection of Backup Files

You will be required to use a password to access the backup files. The SDAdmin configures the password while scheduling the backup. The password can be viewed and reset in the Backup Scheduling home page. This password applies to all files backed up manually as well by schedule.
The password is necessary to restore the application by using backup files. When you configure the password afresh or reset it, a notification email is sent to you and to all users configured to be notified each time a backup fails.

Note: Postgres database backup is made mandatory to help you restore data in the event of a database corruption. The application will take a backup everyday which may result in increased application storage space.
