Asset State

Asset denotes the different states of assets in the organization such as In Use, In Store, Expired, etc. By default, there are six asset states and you can also create new asset states.

To add new asset state,

  1. Click New.

  2. Provide the following information:

    • Name: Provide a unique name for asset state.

    • Requires Ownership: Select this to show "Assign asset to User/ Department" and "Associate to Asset" options for this asset state.

    • Requires Scan: Select this to enable or disable scanning when the assets are in this asset state.

    • Description :Add a relevant description about the asset state.

  3. Finally, click Save.

    4. Note: The Requires Scan option will be available only for the IT help desk instance.

    Edit or Delete Asset States

  4. To edit an asset state, click the name of the asset state or click the Actions icon beside the asset's name and choose Edit, make necessary changes, and click Update.

  5. To delete asset states, select the asset states, and click the Delete icon. To delete a single asset state, click the Actions icon beside the name of the asset state and choose Delete.

    6. Note:

  6. Default Asset states cannot be deleted

  7. The Requires Ownership field is not configurable for default asset states.
