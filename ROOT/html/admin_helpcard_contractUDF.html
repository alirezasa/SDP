Contract Additional Fields

 

You can define your own organization specific fields that need to appear in the Add New Contract form apart from the pre-defined fields provided by default. You can add Text fields, Numeric fields and Date/Time fields in the form. Select each tab and add the label name and description for the fields to be added in the Add New Contract form.

While adding the text fields, you have an option to select the type of text field to be displayed in the contract form. Say, Single-line text field, Multi-line text box and Pick list (drop down menu list) by selecting the corresponding radio buttons.

If you would like to add any default values for each fields, then specify the value in the given Default Value text field.

Click Save to save the settings.
