Actionable Messages for Outlook

The Actionable Messages for Outlook integration allows users to perform a host of help desk actions from within their Outlook mailbox, using the actionable emails sent from ServiceDesk Plus. Technicians can pick up and resolve requests, add notes, and perform approval actions, while end users can add notes to their requests.


Setting Up Integration

  • Provide the Application ID and Tenant ID generated for your ServiceDesk Plus application in the Azure portal.
  • Provide the Originator obtained from the Actionable Email Developer Dashboard and click Save. After these configurations are saved, new fields such as SDP Hosted Domain, Redirect URL and Public Keys will appear with auto-generated values.
  • Under SDP Hosted Domain, the alias URL configured for your application will be auto-populated. But if your application is hosted elsewhere, specify the domain where it is hosted.
  • You need to configure Redirect URL and Public Keys in your Azure portal and Actionable Email Developer Dashboard respectively.

After you submit the configurations, a new checkbox called Enable Actionable Messages for Outlook will appear, enabled.


Update/Remove Integration

To update any configuration in the integration, make the changes and click Update.

To disable the integration while restoring the configurations, uncheck Enable Actionable Messages for Outlook displayed at the top of the integration page.

To completely remove the integration, click Remove displayed at the bottom of the page. Note that if you remove the integration, all configurations will be deleted and cannot be restored.
