Add and view the various departments located in different sites of your service desk instance. Each department is managed by a department head.

If sites are configured, the department under each site can be viewed by selecting the site from the Departments for combo box.

Note: Site Admin can perform operations on the departments to which he is associated. If no site is available, then the Department for combo box will not be displayed.

Add New Department

Departments are imported automatically from ESM Directory. You can add departments only in non-ESM setups.

  • Select the site from Department for combo box.
  • Click the Add icon.
  • Enter a name for the department. As the same department can exist across various branches of your firm, this need not be unique.
  • Select the department head.
  • The site for which the department is created is specified in a non-editable text. This field appears only when sites are configured.
  • Provide a brief description about the activities of the department.
  • Provide details in the additional fields configured by your administrator, if any.
  • Click Assign roles to select users to be assigned to department-level organization roles.
  • Add attachments, if any. Ensure the attachment does not exceed 10MB.
  • Click Save.

List View Operations

  • Use the filter drop-down to view departments based on their availability (active or inactive).
  • Click the Actions icon beside a department to edit or delete it.
  • To bulk-delete, select the departments and click Delete on the toolbar.
  • In ESM setups, you can only edit instance-specific additional fields and add attachments while editing department details.
  • Click the department name to view the department details.
  • Use the Search icon to search through the columns listed.
  • Use the Column Chooser icon to customize the columns listed.

Note:

  • You can delete departments inside portal only in non-ESM setups.
  • If a department is deleted while it is in use, it will be marked as inactive. You can restore an inactive department by editing it.
