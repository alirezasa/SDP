With Import CIs from CSV option, you can import CIs from your existing database instantly. The CI Name is mandatory for all the CI Types selected.   

Step 1: Select the CI Type for which the CIs should be imported. Browse through the CSV file from the file chooser window. Click Open. The path to the file appears automatically in Locate CSV File field. Click Submit button.

Step 2: Select the format in which all the date fields should represent. Map the CI field with the field names from the CSV file. If there are any additional attributes configured, then the same appears in the customized mapping form. Click Import.

Note: If the CI Type chosen in Step 1 is a parent and a CI row in the csv file corresponds to the sub CI Type, then the same can be mapped in the customize mapping form. Please note that the values specified for the sub CI type in the csv file should already be added while configuring the CI Types.  

On completion, the data on the total CIs, the number of CIs imported and the number of CIs failed to import are displayed.

If there are any failure records while importing the CIs, do not re-import the same CSV file. Instead, download the FailedCIsList.csv available in the Imported Result page, correct the errors and then try to import to avoid duplicate CIs.
