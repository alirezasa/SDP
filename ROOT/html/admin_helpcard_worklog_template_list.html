From the work log list view, you can click on the Actions icon beside each template to perform the following actions:

Edit: Use the edit option to modify the template.

Set as default: Use this option to set a template as the default template for users.

Delete: Delete the work log template. You can bulk delete templates by selecting multiple templates using the check box and clicking Delete.

Active and Inactive Templates

When you delete a work log template that is being used in a work log, it will be moved to the Inactive work log template list. You can move templates from the Inactive work log template list by marking them as active.

All the newly created templates and the ones being used will be listed under the Active work log template list.

Note: You can create a maximum of 10 templates.
