Desktop Central과 통합
통합을 위한 단계적 절차 :

ServiceDesk Plus를 ManageEngine Desktop Central과 통합하여 모든 데스크탑 및 모바일 장치 관리 기능을 관리하십시오. Desktop Central은 패치 설치, 소프트웨어 배포, 원격 제어, 채팅 시작, 클라이언트 컴퓨터 보안, USB 사용 제한 적용 등과 같은 데스크탑 관리 활동을 자동화합니다. 또한 프로필 관리, 앱 관리, 보안 관리 및 자산 관리를 통해 모바일 장치를 관리할 수 있습니다. 이 두 제품을 모두 설치했다면 Desktop Central이 설치된 컴퓨터의 세부 정보와 포트 번호를 제공하면 됩니다.

참고: Desktop Central 버전은 버전 8.1 이상이어야 합니다.

제공할 세부 정보:

서버 이름: Desktop Central 애플리케이션 설치된 서버의 이름을 입력하십시오.

서버 포트: Desktop Central 서버의 포트 번호를 입력하십시오.

프로토콜 설정: 프로토콜 설정을 선택하십시오. http 또는 https를 선택하십시오.

API Key: Desktop Central 서버의 Admin 관리자의 API 키 를 입력하십시오.

 

참고 사항: Desktop Management 및 MDM을 표시하려면 드롭다운 메뉴에서 데스크톱 관리 메뉴 활성화 및 MDM(모바일 장치 관리) 메뉴 활성화 확인란을 각각 선택합니다. Desktop Management 메뉴는 Desktop Central 빌드 번호 #80100 이상에만 표시됩니다. 데스크톱 관리 또는 MDM 기능 통합에 관심이 없고 데스크톱 관리 또는 MDM 드롭다운 메뉴를 제거하려면 해당 확인란의 선택을 취소하고 저장하십시오.

 

저장을 클릭합니다. 설정이 성공적으로 저장되고 ServiceDesk Plus가 설정을 시도합니다. Desktop Central 서버와의 연결. 연결이 설정되면, Desktop Central 서버에서 구성된 소프트웨어 세부 정보를 가져옵니다.
