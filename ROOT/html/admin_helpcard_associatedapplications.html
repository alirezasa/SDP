Integrate with ADManager Plus

Integrate ServiceDesk Plus with ManageEngine ADManager Plus and manage your Active Directory user accounts easily. ADManager Plus is a simple, easy to use Windows Active Directory Management and Reporting Solution that facilitates bulk Active Directory User Creation/Management, Active Directory User/Group Modification. Active Directory Computer Management and more. If you have installed both these products, you just have to provide the details of the computer where ADManager Plus is installed along with its Port Number.

Details to be provided:

Server Name: Enter the Server where ADManager Plus application is installed.

Server Port: Enter the Port Number of the ADManager Plus server.

Protocol Settings: Select the Protocol Settings. Say, http or https.

 

Click Save. The settings are saved successfully and ServiceDesk Plus will try to establish a connection with the ADManager Plus server. Once the connection is established, using the jump to link we can switch over ADManager Plus server.

Integrate with ADSelfService Plus

Integrate ServiceDesk Plus with ManageEngine ADSelfService Plus and allow your Active Directory users to self-service their Active Directory passwords and Active Directory accounts easily. ManageEngine ADSelfService Plus is a secure, web-based, end-user password reset management program. This software helps domain users to perform  password self service,  account self service and self service of their personal details (e.g telephone number, e-mail id etc) in Microsoft Windows Active Directory. If you have installed both these products, you just have to provide the details of the computer where ADSelfService Plus is installed along with its Port Number.

Details to be provided:

Server Name: Enter the Server where ADSelfService Plus application is installed.

Server Port: Enter the Port Number of the ADSelfService Plus server.

Protocol Settings: Select the Protocol Settings. Say, http or https.

 

Select Enable AD Self Service menu for Technician option to show AD Self Service menu for technicians. This menu will be shown irrespective of the integration status of ServiceDesk Plus with ADSelfService Plus product. Select Enable AD Self Service tab for Requester option, to show AD Self Service tab for requesters. "Ad Self Service" tab will be shown to requester login only if ServiceDesk Plus is integrated with ADSelfService Plus product.

 

Click Save. The settings are saved successfully and ServiceDesk Plus will try to establish a connection with the ADSelfService Plus server. Once the connection is established, using the jump to link we can switch over ADSelfService Plus server.

Integrate with Endpoint Central (formerly Desktop Central)

Step-by-Step procedure for Integration : Video | Help Document

Integrate ServiceDesk Plus with ManageEngine Endpoint Central to manage all your Desktop & Mobile Device Management functions. Endpoint Central automates desktop management activities like installing patches, deploying software, talking remote control, initiating chat, securing the client computers, applying USB usage restrictions and much more. It also enables managing Mobile Devices with profile management, App management, security management and asset management. If you have installed both these products, you just have to provide the details of the computer where Endpoint Central is installed along with its Port Number.

NOTE: Endpoint Central version should be version 8.1 and above.

Details to be provided:

Server Name: Enter the Server where Endpoint Central application is installed.

Server Port: Enter the Port Number of the Endpoint Central server.

Protocol Settings: Select the Protocol Settings. Say, http or https.

 

NOTE: To display Desktop Management and MDM drop-down menus, select Enable Desktop Management Menu and Enable MDM (Mobile Device Management) Menu check boxes respectively. The Desktop Management menu will be displayed only for Endpoint Central build number #80100 and above. If you are not interested in integrating Desktop Management or MDM functions and want to remove the Desktop Management or MDM drop-down menus, deselect the check box respective check box and Save.

 

Click Save. The settings are saved successfully and ServiceDesk Plus will try to establish a connection with the Endpoint Central server. Once the connection is established, the configured software details from Endpoint Central server are fetched.

Integrate with Password Manager Pro

SDP-Password Manager Pro Integration helps PMP Administrators and Password Users to efficiently manage their resources in both the Applications. Administrators and Password Users can view the password of the accounts of the resources and can access the resources remotely from ServiceDesk Plus.

ServiceDesk Plus Server configuration and Authentication in PMP :

Details to be provided :

PMP Hosted URL : Enter the Server where Password Manager Pro application is installed.

Port : Enter the Port Number of the Password Manager Pro server.

 

Click Generate Auth Token. The Password Manager Pro application will be opened in a New Tab of the browser, where you can generate an Auth Token, specific for this ServiceDesk Plus application, by clicking the Authorize button (Administrator privilege is required).

 

Auth Token: Enter the generated Auth Token from the Password Manager Pro application.

 

Click Test Connection and Save. ServiceDesk Plus will try to establish a connection with the Password Manager Pro server. Once the connection is established, the Password Manager Pro configurations will be saved.

 

Integrating with Other ME Products (running in HTTPS mode)

  1. Download the .zip file from the link given below and extract it to "ManageEngine\ServiceDesk":

    2. For Linux: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1cb6g423n1gp9135o97nfchub1/lincertgeneration.zip

    For Windows: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1cb6g2tdh126s6hmhpvjja2si1/windowscertgeneration.zip

  2. Connect to the command prompt. Go to "ManageEngine\ServiceDesk" and run the batch file with following format:

    3. For Linux:
    C:>ManageEngine\ServiceDesk>gencert.sh servername:portnumber

    For Windows:
    C:>ManageEngine\ServiceDesk>gencert.bat servername:portnumber

  3. On running the command, you will receive an exception PKIX and then it will ask you to enter a value. Provide value 1 which will generate a file named jssecacerts under "ManageEngine\ServiceDesk".

  4. Copy the jssecacerts file under "ManageEngine\ServiceDesk\jre\lib\security" folder and then restart the ServiceDesk Plus application.
