Manage Groups

Using this option, you can group assets based on the asset properties. You can group assets of users belonging to the same team and location. Organizing assets based on groups gives you more fine-grained control and helps you manage assets efficiently. For e.g. you can group assets based on OS, service packs, memory size and so on. When you are getting ready for migration you will be able to pinpoint assets with 256 MB Ram that need upgrade before rolling out windows Vista.

 

Create New Group

For easier channelization, users can be categorized under Static and Dynamic groups. Under Static group you define the group by listing its members. Under Dynamic group resources are grouped automatically based on certain criteria set by the administrator.

Click Add New Group link on the right hand side corner of the Manage Groups page. This opens Create Group page. It has three fields namely Group Name, Description & Group Type. Group Name & Group Type are mandatory fields.

Specify the group name in the Group Name text field. This is a mandatory field.
Provide relevant information about the newly created group in the Description field. Say the group name is Test DL600 you can specify the Test DL 600 stands for Dell Lateral 600.

Select any one of the Group Type by enabling the radio button. Say Static or Dynamic group. 

Static Group: You define the group by listing its members
Dynamic Group: Resources are grouped automatically based on certain criteria.

Click save button to save the group.

 

To add resources to the static Group,


Select the filter criteria from the filter Showing combo box. For ex. you can select All Assets in Use.

Specify the Search criteria in the given text field.

Click Go button to list all resources based on the filter criteria. You can see the list of all filtered resources.

Select the resources to be added to the group by enabling the check box.

Then click Add button to add resources to the group. You can see the selected resources added tot he group, shown under Resources in group column.

 

To add resources to the dynamic group, 

You define the filter criteria by selecting the Criteria and Conditions from the combo box.

Select the Criteria from the combo box say Resource Criteria or Workstation Criteria.

Select Conditions from the combo box, which will be listed based on the selected criteria.

Select any one of the Match Criteria by selecting either of the radio buttons. Say (And) or (OR) criteria.

Click Choose button to choose the resource or workstation criteria listed based on the criteria you have selected. For ex. If you have selected resource criteria as Product Type and conditions as is then on clicking choose button you will get the list of all product types say scanners, keyboard, printers etc.

Select any one of the listed product type and click OK button to add to the group.  

Click Save and View group button to view the list of all resources on the filter criteria        

 

Remove Resources from the Group


Select the resource name from the list by enabling the check box under the Resources in-group column.

Click Remove button to remove the added resources. You can see the selected resources deleted from the list.
