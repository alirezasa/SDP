页面脚本允许您根据需要逐页自定义应用程序。您可以使用用户的页面脚本在应用程序中修改UI元素以及页面的功能。例如，您可以在用户的​​请求列表视图或请求详细信息页面中隐藏某些按钮。您还可以选择在模块中的页面之间为请求人或技术员添加新的小部件，视频，网页和表单。 

 

要执行页面脚本，您需要首先定义一个规则并配置一个条件。

  • 通过添加规则名称并选择应将规则应用于谁来创建新规则；例如请求人/技术员或所有用户。  
  • 选择应该在哪里应用规则；例如，请求列表视图/请求详细信息页面/所有页面（所有模块中的页面）。 
  • 配置必须执行页面脚本的条件。您可以添加多个条件。 
  • 一旦配置了规则，就可以编写自定义脚本来执行自定义。 
  • 默认情况下会提供一些基本的自定义脚本。您可以根据需要使用它们。 

您也可以编写自己的脚本并执行它们。
