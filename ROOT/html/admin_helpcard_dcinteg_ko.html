Desktop Central과 통합

 

AssetExplorer를 ManageEngine Desktop Central과 통합하여 Desktop Central의 데스크탑 및 모바일 장치 관리 기능을 활용하여 귀사의 모든 단말 장치들을 관리하십시오. Desktop Central은 패치 설치, 소프트웨어 배포, 원격 제어 말하기, 채팅 시작, 클라이언트 컴퓨터 보안, USB 사용 제한 적용 등과 같은 데스크탑 관리를 자동화합니다. 또한 프로필 관리, 앱 관리, 보안 관리 및 자산 관리를 통해 모바일 장치를 자세하게 관리할 수 있습니다. 이 두 제품을 모두 설치했다면 Desktop Central이 설치된 컴퓨터의 세부 정보와 포트 번호를 제공하면 됩니다.

참고 사항: Desktop Central 버전은 8.1이상이어야 합니다.

상세 정보를 입력하십시오:

서버 이름: Desktop Central이 있는 서버가 설치된 서버의 이름입니다.

서버 포트: Desktop Central이 설치된 서버의포트 번호입니다.

서버 프로토콜: 프로토콜 설정을 선택하십시오. http 또는 https 를 선택하십시오.

API 키: Desktop Central 서버의 Admin관리자의 API 키 를 입력하십시오

 

저장을 클릭합니다. AssetExplorer는 Desktop Central 서버와 연결하려고 시도할 것입니다. 연결이 완료되면 구성된 설정이 저장됩니다.
