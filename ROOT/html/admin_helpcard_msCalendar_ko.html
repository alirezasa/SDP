ServiceDesk Plus를 Microsoft 캘린더와 통합하여 기술자가 ServiceDesk Plus 캘린더 및 Microsoft 캘린더의 기록을 자동으로 동기화합니다. 기술자는 Microsoft Calendar를 ServiceDesk Plus에서 휴근 기록을 생성, 업데이트 및 삭제하기 위한 추가 채널로 활용할 수 있으며 그 반대의 경우도 마찬가지입니다.

통합 구성

  1. Microsoft Azure에 앱을 등록하는 동안 자동 생성된 애플리케이션 ID 및 테넌트 ID 값을 입력하십시오.
  2. Microsoft Azure에서 애플리케이션 패스워드로 SDP 앱에 대해 생성된 Client Secret value를 입력합니다 .
  3. 저장을 클릭합니다.

SDP 호스팅 도메인 필드에, SDP 애플리케이션에 대해 구성된 별칭 URL이 자동으로 채워집니다. SDP 애플리케이션이 다른 곳에서 호스팅되는 경우 도메인을 수정할 수 있습니다.

구성을 제출하면 Microsoft 캘린더 사용(활성화)이라는 새 확인란이 활성화된 것으로 나타납니다.

통합 업데이트/제거

  • 통합 구성을 수정하려면 변경하고 업데이트를 클릭하십시오.
  • 통합 설정을 일시적으로 비활성화하려면 통합 페이지 상단에서 Microsoft 캘린더 활성화 옵션을 선택 취소합니다.

통합을 삭제하려면 제거를 클릭하십시오. 통합을 삭제하면 모든 구성이 영구적으로 삭제되고 복원할 수 없게 됩니다.
