Classify your help desk team into various support groups. Each support group can consist of a group of technicians in charge of handling specific requests. And also, based on the technicians expertise, the incoming requests can be categorized and distributed.

In addition, e-mail settings can be configured for each support group. So when an e-mail is sent to a group mail ID, the request is fetched and automatically sent to the group.

You can also enable notifications to be sent to the technicians on receiving a new request and if a request is left unpicked. If Sites are configured, the Support Groups under each site can be viewed by selecting the site from Support Groups for drop down.

If the Support Groups of a particular site refers to another site's settings, then during the site change, a pop-up denoting the selected site's refer site will be displayed. If the Support Groups configured for the Site to be deleted is being referred by one or more Site(s), then during the Site deletion process, the Site(s) to be deleted will be listed along with the support groups that they refer. You can either choose the refer Site's settings to refer default settings or change to any other Site's settings that you require.

Active and Inactive Groups

Active group includes all the support groups that are currently in use. An active support group will become Inactive, if an active group that is being used by other modules is deleted. Only an active group that is not being used by any module can be deleted. Inactive group(s) can be moved to active state by selecting the required groups and clicking the 'Mark as Active' option.

Add New Group

To add a new Group to site, select the site from Support Groups for drop down. Click the Add New Group link on the right hand side corner of the Group List table.  

Name: Specify a unique Name to identify the support group.

Site: The site for which the support group is created is specified in non editable text. This field appears only when sites are configured.  

Technicians: Associate technicians under this group. Select the technicians from the Available Technicians list box and click Assign (>>) button. For multiple select of technicians, use Ctrl or Shift key.

Notifications: You can enable notifications to be sent to the above group of technicians when a new request is added to the group or inform the technicians available in your help desk when a request in the group is unassigned. Enable the corresponding check boxes and choose the technician. Based on your need, you can enable both the check boxes or select any one or none.

Description: Enter a short description about the Support Group in the Description field. This will help in knowing the kind of requests that will be grouped under this Group and hence help in assigning technicians to this Group.

Group Mail Settings: Entering the configured Group E-mail ID will automatically assign the incoming ticket to the group. If a support group has multiple email IDs, the email IDs should be unique and can be separated by commas or semi colon. The Sender's name and Sender's E-mail ID defined will be specified while sending e-mails.  

Click the Save button to save the Support Group and return to the list view.
