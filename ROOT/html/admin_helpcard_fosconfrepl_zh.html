FOS文件复制配置可以支持您配置一个自动化的复制计划，将数据从主服务器复制到备服务器。数据复制的操作每分钟会执行一次，确保在主服务器出现故障时，备服务器可以平滑的接管服务，而不导致数据的丢失。
配置FOS数据复制，输入主备服务器的明细。
主服务器明细 :
  • 主服务器IP - 主服务器的IP地址会从FoS配置中自动提取填充。
  • 用户名 - 输入登录到主服务器的用户名。
  • 密码 - 输入登录到主服务器的密码，密码会加密保存在ServiceDesk中。
备服务器明细 :
  • 备服务器IP - 备服务器的IP地址会从FoS配置中自动提取填充。
  • 用户名 - 输入登录到备服务器的用户名。
  • 密码 - 输入登录到备服务器的密码，密码会加密保存在ServiceDesk中。
注意：您仅可在FOS配置完成后配置FoS文件复制设置，重启ServiceDesk以使配置生效。
