변경 종료 코드는 변경 요청을 종료한 이유, 완료로 인해 변경이 종료되었는지 여부, 거부 등을 나타냅니다. 종료 코드를 사용하여 변경 관리자는 변경 요청을 종료하는 목적을 파악할 수 있습니다.

종료 코드 추가

  1. 종료 코드 추가을 클릭합니다.

  2. 변경 종료 코드에 대해 유일한 이름을 지정합니다. 이 필드는 필수입니다.

  3. 변경 종료 코드에 대한 간략한 설명을 입력합니다.

  4. 저장 버튼을 클릭합니다. 변경 종료 코드가 저장되고 목록 보기에 나열됩니다.

구성된 변경 종료 코드와 설명 섹션은 변경 요청의 종료 단계에 나타납니다. 여기에서 변경 담당자는 종료 코드를 선택하고 변경 종료에 대한 자세한 설명을 입력할 수 있습니다.
