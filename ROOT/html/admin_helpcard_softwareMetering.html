Software Metering

Software metering allows you to define the thresholds or ranges to classify software applications based on their usage, namely Rarely used, Occasionally Used, and Frequently Used. The thresholds and ranges are configured based on the Run Time and/or Run Count values that are obtained from the Endpoint Central scan data. On this page, you can manage default and custom software metering configurations.

To create a custom software metering configuration,

  1. Click New.

  2. Provide a name for the configuration.

  3. Use the combo box to select the software applications to which the metering configuration must apply.

  4. Configure usage thresholds based on either or both of the following:

    • Run Time: Select the checkbox and provide threshold values for the Rarely Used and Frequently Used classifications. For the Occasionally Used classification, provide a range.

    • Run Count: Select the checkbox and provide threshold values for the Rarely Used and Frequently Used classifications. For the Occasionally Used classification, provide a range.

  5. Finally, click Save.

Note:

  • If you are selecting both Run Time and Run Count options, you can combine them using AND or OR operator.

  • Software metering can be configured only for applications that have metering enabled in Endpoint Central.

  • The default All Softwares configuration will apply for applications that are not part of any software metering configuration.

  • You can edit or delete custom software metering configurations.

  • The default All Softwares configuration cannot be deleted. The name and the list of software applications in the All Softwares configuration cannot be edited. However, you can update the threshold and range values in the configuration.
