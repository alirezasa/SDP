可以根据终端用户的需要配置服务请求表单，它由可模板组成，可进行拖放操作，定制非常方便。如果服务涉及到资源，还可以在此配置资源信息。同时也可以在此指定对应的服务请求的审批人、关联的服务级别协议以及任务等。

 

添加服务

要在某个服务目录下添加服务，可直接点击对应服务目录旁边的添加服务按钮。它将进入服务请求表单的定制页面，该页面由三部分组成：标题、服务字段和服务预览。

标题 : 包含服务名和服务的描述。  

服务字段 : 列出可用的参数字段和响应的附件字段。

服务预览 : 显示提交服务请求时的表单形式，包括可拖放的字段，以及撤销、重做按钮。可以很方便地添加/移除字段，设置字段属性，对表单进行布局调整等。不同的服务可定制不同的表单。

 

添加新的字段

可以通过将 新添字段 拖放至表单中来添加新的字段。添加新的字段时，可设置字段类型，字段的标签名称和对应的描述等。字段类型有文本、数值和日期。对于文本类型还有单行、多行、精选列表等选项。设置完成后点击确定按钮即完成字段的添加工作。

这样新添加的字段只适用于目前选定的服务目录。若要添加所有服务目录都通用的字段，可在服务目录页面，通过管理->附加字段->通用字段来实现，通过这种方式也可添加特定服务目录所用的字段，还可以编辑/删除已有的字段。  

拖放操作

服务字段可以被拖放至服务预览的表单中。也可以通过拖放操作来改变表单的字段排列和布局。请求人信息只能整块移动。如果需要，可以通过撤销和重做按钮来恢复操作。

设置字段属性

若要从表单中去掉已有的字段，可将鼠标移至相应的字段，点击移除字段图标。若要对其进行编辑，可点击编辑字段的图标。 编辑字段可有如下选项：

必填字段 : 表示提交服务请求时必须填写对应字段所要求的信息。

注意: 如果分类的项目被设置为必填项，则相应的子分类和分类也会标记为必填项。类似地，如果子分类为必填项，则分类也必须是必填项。

请求人可以设置 : 表示请求人/用户可以编辑该字段，输入相应的值。选中该选项时，'请求人可以查看' 选项也会被选中。

请求人可以查看 : 用户提交请求时，不允许输入/编辑该字段的值。

对于请求人明细、主题、地点字段，不能编辑其属性，只能更改其摆放位置(布局)。

点击移除字段 图标，将从表单中删除对应的字段。所删除的自动将重新显示在字段列表中。不能移除如下字段：状态、描述、请求人明细、地点和主题。

 

资源信息

如果服务涉及到资源，可在资源块中进行配置。它主要用于向提交服务请求的用户询问一系列的问题（来了解相应的资源信息）。它们可以是，复选框、下拉框、文本框和简单的是与否的问答。

  1. 点击 添加资源 按钮；

  2. 指定资源标题 和简要的描述；

  3. 接下来设置问题，可以从已有问题中选择，也可以创建新的问题；

  4. 选择问题类型：简单的是与否、下拉框、复选框、文本框等；

  5. 如果选定下拉框或复选框，需要添加相应的选项来供用户选择。可以手动添加，也可以从已有的产品中选择；

  6. 对于手动添加，需要输入资源，并点击添加按钮；然后点击确定来保存问题；

  7. 点击 保存 按钮保存资源信息。

显示给请求人 : 选中该选项，则请求人也可以使用该服务请求。如果定义了用户组，在此还可以选择可用该服务请求的用户组。

点击保存并配置工作流 按钮。

 

工作流

 

所提交的服务请求可能需要经过审批，可选择审批人。审批人可以是技术员，也可以是具有请求审批权限的请求人。服务请求审批后可指派给某个技术员。

    • 提交服务请求时自动发送审批通知 - 选中该选项将在提交请求的时候立即发送审批通知。

      • 必须经过所指定的所有审批人的审批 - 选中该选项则所指定的所有审批人都必须同意后该请求才能实施，如果任何一个审批人驳回了该服务请求，则不能继续进行处理。

      • 服务请求得到批准之前不指派技术员 - 选中该选项，服务请求只有在经过批准后才能指派技术员。

服务级别协议(SLA) : 从下拉框中选择该类服务请求的 SLA 。也可以直接从本画面创建新的服务级别协议。

任务 : 可以在此配置与此类服务请求相关的任务。点击添加任务 按钮，填写相应的任务内容。在此可以设置任务的优先级及其先后顺序。服务请求的任务将在提交服务请求的时候自动创建，并指派给相应的技术员。

模板动作 : 该功能只有在集成了Desktop Central 7.0或更高版本时才可用。要使用它，需要在系统中配置Desktop Central的服务器及其相应的端口。

 

点击 保存并配置请求人 按钮，可配置请求人用的服务请求表单。

 

请求人用的服务请求表单

如果选中了"显示给请求人"选项，则请求人也可以查看该服务请求。

从服务目录页面选择某个服务请求模板时，缺省情况下，将打开技术员用的服务请求模板。点击请求人视图页签，模板标题部分是灰色的，不可编辑。可以对请求字段进行拖放操作调整布局。操作完成后点击保存，使更改生效。
