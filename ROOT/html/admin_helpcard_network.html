Discover networks part of your organization and scan them at regular intervals using Network Scan. Apart from scanning various operating systems like Windows, Linux, MAC, Solaris and AIX workstations network scan also allows for scanning of SNMP devices and VMware machines.


Add a new Network
Linux, MAC, Solaris, IBM-AIX

  1. Click Add New Network link.

  2. Decide Scan Range: you can either scan the Entire Network or mention a specific IP Address Range for scanning.

  3. Enter the Network Address.

    • To scan the Entire Network, the IP address should be mentioned as 192.168.27.0
    • To scan part of a Network, the IP address range should be mentioned as follows: 192.168.27.0 - 192.168.27.30

  4. Provide a suitable description.

  5. For scanning Windows, Linux, and Mac machines, Agent configuration is required. Click Agent Configuration to download the Agent. Refer Agent Configuration page help card to know more.

  6. Specify Network Scan Credentials for scanning different subnets of your network. Scan credentials added in Credentials Library will be available for selection in this pop-up. If you haven't added any scan credentials, you can add one by clicking the Add new Scan Credential icon. To learn how to add a new scan credential, refer to Credential Library help card.

  7. Click Save (or) Save and Scan now to scan the network immediately.

Scanning the Network

  1. From the Network List View page, click the Scan Network icon.

  2. If your organization is distributed across various sites, select the Site to which the workstations/devices are associated.

  3. Click Start Scanning. Once scanned, you will get the complete report on the success and failed workstations of the scan.

You can also Edit and Delete a Network by clicking on the edit and delete icon.
