Distributed Asset Scan

You can scan assets distributed across multiple sites. Install a Remote AE server in the remote sites where you want to scan assets. When the scanning is complete, export the data from the Remote AE server in the site and import it in your Central  Server either manually or automatically.

The data pushed in the Central Server is listed along with the details such as Site from which the data is imported, Received time, Imported time and so on. 

The work flow :

1. Export workstations information (zip file format) from the remote AE server.
2. Import the generated information into the central ServiceDesk Plus server.
