Urgence
 
L’urgence désigne la rapidité de résolution attendue pour un incident présentant un certain impact. Par défaut, quatre détails d’urgence sont répertoriés sur cette page.
 
Ajouter une nouvelle urgence
 
Cliquez sur le lien Ajouter une nouvelle urgence, sur la droite de la page. La page Ajouter - Urgence s’affiche.
Indiquez le Nom de l’urgence dans le champ de texte prévu à cet effet. Ce champ est obligatoire.
Indiquez les détails de l’urgence dans le champ Description.
Enregistrez les modifications.  
Pour enregistrer l’urgence et en créer une nouvelle, cliquez sur le bouton Enregistrer et ajouter nouveau.
