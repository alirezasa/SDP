Project Types classify projects based on the goals they are trying to meet. Example: several projects created for some kind of maintenance can be declared under the project type ‘maintenance’.

In the same way create new Project Types to classify various projects under this section.

Add Project Type
Add Project Type form has two fields, namely, Name and Description.

Name: Specify a unique name to identify Project Type.
Description: Enter a short description about the Project Type in the Description field.

Inactive Checkbox: To render a Project Type inactive, check this option; uncheck for reactivation.
Color: Select a color to denote Project Type using the color palette or specify the color code in the text box.

Click the Save button to save Project Type and return to the list view.
Click the Save and add new button to save Project Type and add another.
