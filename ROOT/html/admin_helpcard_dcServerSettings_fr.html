Procédure pas-à-pas pour l'intégration : Vidéo | Document d’aide

Intégrez ServiceDesk Plus avec ManageEngine Desktop Central pour gérer toutes vos fonctions de gestion du bureau. Desktop Central automatise les activités de gestion du bureau : l'installation des correctifs, le déploiement des logiciels, la sécurisation des ordinateurs client, l'application de restrictions d'utilisation et davantage. Si les deux produits sont installés, vous n'avez qu'à renseigner les informations de l'ordinateur (plus le numéro de port) où Desktop Central est installé.

REMARQUE : Desktop Central doit être en version 7 ou ultérieure.

Nom de serveur : Renseignez le Serveur où l'application Desktop Central est installée.

Port de serveur : Saisissez le Numéro du port du serveur Desktop Central.

Paramètres du protocole : Sélectionnez les Paramètres du protocole. Par ex. : http ou https.

 

Cochez Activer le menu Desktop Management pour afficher le menu déroulant Desktop Management. Le menu Desktop Management ne s'affichera que dans la compilation #70242 ou ultérieure de Desktop Central. Si les fonctions de Desktop Management ne vous intéresse pas, vous pouvez supprimer le menu déroulant Desktop Management en décochant Activer le menu Desktop Management et en sélectionnant Enregistrer.

 

Cliquez sur Enregistrer. Les paramètres sont d'abord enregistrés, puis ServiceDesk Plus tente d'établir une connexion avec le serveur Desktop Central. Une fois cette connexion établie, les informations du logiciel configurées dans le serveur Desktop Central seront récupérées.

 

ServiceDesk Plus se synchronise automatiquement et quotidiennement avec le serveur Desktop Central pour les packages logiciels configurés. Sélectionnez le lien Cliquez ici pour récupérer instantanément les packages logiciels configurés.
