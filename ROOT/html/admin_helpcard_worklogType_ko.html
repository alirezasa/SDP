Worklog(작업 로그)를 추가할 때, Worklog Type(작업 로그 유형)을 설정할 수 있습니다. 이는 요청서 모듈 아래에 새 작업 로그를 생성할 때 필수적입니다. 새 작업 로그 유형을 추가하려면 요청서 유형 목록 페이지의 오른쪽 모서리에 있는 작업 로그 유형 추가 링크를 클릭하십시오.

작업 로그 유형 추가

이름: 이름 필드에 작업 로그 유형의 이름을 지정하십시오.

설명: 설명 필드에 해당 범주에 속하는 작업 로그의 유형에 대한 간략한 설명을 입력합니다.

저장을 클릭하여 저장하고 목록 보기 페이지로 돌아갑니다. 저장하고 새로 추가를 클릭하여 저장하고 다른 작업 로그 유형을 만듭니다.

 

작업 로그 유형 삭제

작업 로그 유형 목록 페이지에서 삭제하려는 작업 로그 유형 옆에 있는 확인란을 활성화합니다.

삭제 버튼을 클릭합니다. 삭제 작업에 대한 확인 메시지가 나타납니다. 계속하려면 확인을 클릭하십시오. 작업 로그 유형이 목록에서 삭제됩니다.
