Commande d'e-mail

 
La commande d'e-mail permet au technicien de délimiter les champs de l'e-mail, en fonction de quoi l'e-mail peut être analysée et les champs correspondants configurés.

Pour configurer la commande d'e-mail :

1. Dans la page Paramètres du serveur de messagerie, cliquez sur l'onglet Commande d'e-mail L'écran de configuration Commande d'e-mail apparaît.

2. Cochez Activer la commande d'e-mail pour activer la fonction d'analyse de message. Si cette option n'est pas sélectionnée, l'e-mail entrant sera traité de manière classique et en fonction des règles métier établis même si les e-mails entrants comportent le chaîne d'analyse dans l'objet.

3. Dans le champ L'objet de l'e-mail contient, saisissez une ligne d'objet valide qui déterminera les e-mails à analyser. Les e-mails comportant ce texte seront analysés pour divers champs.  Par ex. : pour l'identificateur d'objet d'e-mail @SDP@, les e-mails dont l'objet est uniquement @SDP@ seront analysés.

4. Indiquez un caractère spécial (@@, ##, $$, %%, &&, etc) comme Délimiteur de commande.  Les valeurs de champ assignées entre ces caractères spéciaux sont assignés aux champs correspondants lorsque les demandes sont créées. Par ex. : si le délimiteur de commande est @@ et la description de l'e-mail doit définir le champ Catégorie en Imprimante, la description de l'e-mail doit contenir @@Catégorie=Imprimante@@.

Remarques :

  • Une demande peut être créé / mise à jour / clôturée / récupérée par un technicien par e-mail. Les chaînes opérationnelles « Operation = AddRequest », « Operation = EditRequest », « Operation = CloseRequest », « Operation = PickupRequest » sont utilisées dans ce but.

  • Pour mettre à jour, récupérer ou clôturer une demande par e-mail, la chaîne opérationnelle correspondante (EditRequest / PickupRequest / CloseRequest) et RequestId doivent être présentes. Dans le cas contraire, l'e-mail sera traité de manière classique et comme une nouvelle demande.

  • Lorsqu'une demande est mise à jour par e-mail, la conversation n'y est pas ajoutée. Ainsi, les pièces jointes et les images en lignes de l'e-mail ne seront pas mises à jour dans la demande. Les informations de la mise à jour ne seront toutefois pas ajoutées à l'historique.

  • Le nom du champ donnée dans l'e-mail n'est pas disponible dans ServiceDesk Plus, l'analyse excluera ce champ.

  • Si un champ de l'e-mail comporte plus d'une valeur, seule la dernière sera prise en compte.

  • Les threads de demande dont le sujet contient l'« IdDemande » sans chaîne opérationnelle (EditRequest) sera mise à jour en tant que conversation classique et aucune nouvelle demande ne sera créée.

  • L'analyse nécessite que l'expéditeur de l'e-mail ait les identifiants de connexion pour ServiceDesk Plus.  Cet aspect a une raison : différentes opérations d'analyse qui peuvent être traitées par un utilisateur sont définis par le rôle de l'utilisateur. Les autorisations de demande (clôturer / récupérer / mettre à jour une demande, accepter la clôture d'une demande, etc) sont configurées à l'aide des Rôles dans ServiceDesk Plus.

  • L'expéditeur de l'e-mail sera considéré comme demandeur si le nom du demandeur n'est pas indiqué dans l'e-mail.

  • Autorisations et paramètres pris en charge :

    1. Si l'expéditeur de l'e-mail est un demandeur avec les autorisations correspondantes, les champs à analyser sont limités. Une demandeur ne peut analyser que les champs qu'il est en mesure d'afficher dans le formulaire de demande à la création d'une demande.

    2. Si l'expéditeur de l'e-mail est un technicien avec les autorisations correspondantes, les champs qui peuvent être analysés sont ceux qu'il peut voir dans le formulaire de demande à la création d'une demande.

    3. Les champs suivants peuvent être analysés : NIVEAU, MODE, PRIORITE, URGENCE, IMPACT, DETAILSIMPACT, CATEGORIE, SOUS-CATEGORIE, ELEMENT, GROUPE, TECHNICIEN, EMAILTECHNICIEN, DEMANDEUR, EMAILDEMANDEUR, IDDEMANDE, MODELEDEMANDE, TYPEREQUETE, ETAT, SITE, EQUIPEMENT, RESOLUTION et un libellé de champ supplémentaire (le libellé de champ indiqué dans l'e-mail doit correspondre au libellé de champ configuré dans le produit).

    4. Pour modifier les champs qu'un demandeur ou un technicien peut analyser, rendez-vous dans Admin --> Modèles de demande (sous le domaine Assistance), sélectionnez le Modèle par défaut et ajouter / supprimer des champs.

  • L'IdDemande présent dans la description de l'e-mail bénéficiera d'une priorité plus élevée que l'IdDemande de l'objet de l'e-mail.
