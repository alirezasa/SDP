사용자 정의 클래스 또는 스크립트 파일을 자동으로 호출하는 규칙을 정의할 수 있습니다. 요청서가 생성(또는 수신)되거나 편집되거나 혹은 둘 다일 때 액션 규칙을 요청에 적용할 수 있습니다.

 

새 액션 규칙 추가

 

새 액션 규칙을 추가하려면 요청서 사용자 정의 액션 목록 페이지의 오른쪽 상단에 있는 새 액션 추가 링크를 클릭합니다.

 

통합을 식별하기 위해 유일한 액션 이름을 지정합니다.

액션 규칙을 자세히 설명하려면 설명 텍스트 상자에 그 내용을 입력하면 됩니다. .

액션 실행 드롭다운에서 두 가지 실행 옵션 중 하나를 선택합니다.

  • 요청서가 생성될 때 - 요청서가 생성될 때 규칙을 적용하려면 이 옵션을 선택합니다.
  • 요청서가 수정될 때 - 요청서가 수정될 때 규칙을 적용하려면 이 옵션을 선택합니다.
  • 요청서가 생성 및 수정될 때 - 요청서가 생성되고 수정될 때 규칙을 적용하려면 이 옵션을 선택합니다.
  • 요청서가 승인될 때 - 요청서가 승인될 때 규칙을 적용하려면 이 옵션을 선택합니다.
  • 요청서가 거부될 때 - 요청서가 거부된 경우 이 규칙을 적용하려면 이 옵션을 선택합니다.
  • 요청서가 승인되거나 거부될 때 - 요청서가 승인되거나 거부될 때 이 규칙을 적용하려면 이 규칙을 선택합니다.
  • 새 회신을 수신할 때 - 요청서에 대해 새 회신이 수신될 때 이 규칙을 적용하려면 이 옵션을 선택합니다. .

규칙을 정의하고 접수되는 요청서(양식 기반 요청 및 전자 메일)를 기반으로 일치 기준을 설정할 수 있습니다. 기준과 일치하는 요청서에 대해 지정된 실행기가 호출되고 수동 개입 없이 적절한 액션이 수행됩니다.

 

기준 콤보 상자에서 특정 기준을 선택한 다음 콤보 상자에서 일치하는 조건을 선택합니다. 선택 버튼을 클릭하여 특정 값을 추가합니다. 'AND' 옵션을 선택하여 설정된 모든 기준과 일치하도록 선택하거나 드롭다운에서 'OR' 옵션을 선택하여 그 중 하나와 일치하도록 선택할 수 있습니다. 다른 기준 추가 링크를 클릭하여 기준 및 조건이 있는 규칙을 더 추가할 수 있습니다.

 

이제 추가한 위의 기준과 일치하는 요청서에 대해 수행해야 하는 적절한 액션을 설정합니다.

 

액션 수행에서 클래스, 스크립트 또는 사용자 정의 함수를 실행할지 여부를 선택하고 다음 포인터를 사용하여 구성합니다.

  • 클래스: Executor 클래스를 지정합니다. 예: com.servicedeskplus.integration.JiraActionImplementation.
  • 스크립트: 스크립트 파일의 이름과 경로를 지정합니다. 예: cmd / c Index.bat. 스크립트는 [SDP_Home]/integration/custom_scripts에서 실행됩니다..
  • 사용자 정의 기능: 사용자 정의 기능을 실행하여 ServiceDesk Plus 및 기타 외부 응용 프로그램의 데이터를 조작할 수 있습니다. requestObj 및 context는 맞춤 함수에서 지원되는 인수입니다.

참고 사항: 스크립트에서 모든 API 매개변수를 인수로 전달할 수 있으며, requestObj 및 context는 사용자 정의 함수에서 지원되는 인수입니다.

예제 

스크립트의 경우 : cmd / c Index.bat $COMPLETE_V3_JSON_FILE

클래스의 경우  : com.servicedeskplus.integration.JiraActionImplementation

지원되는 기타 매개변수 중 일부

$COMPLETE_V3_JSON_FILE ---> 전체 요청서 개체는 JSON 파일에 저장되고 파일 경로는 문자열 개체로 전달됩니다. 액션이 요청서가 편집될 때인 경우 DIFF_JSON(이전 요청서 데이터와 새 요청서 데이터의 차이)도 JSON 파일에 저장됩니다.

JSON 파일 경로  : (SDP_Home\integration\custom_scripts\request\12_1426143538036.json).

이메일과 SMS 알림 

우선순위가 높은 요청서가 생성되는 즉시 이메일이나 SMS를 통해 사용자에게 알릴 수 있습니다. 알림을 구성하려면 기본 모드 옆에 있는 추가를 클릭하고 필요한 템플릿을 선택하십시오. 이메일 수신자를 추가하고 저장을 클릭하십시오. 템플릿 드롭다운에서 이러한 알림에 대한 템플릿을 만들 수도 있습니다.

기본적으로 이후 액션 처리 중지 확인란이 활성화되어 있으며 한 요청서에 한 규칙이 적용되면 작업 실행이 중지됩니다. 이 옵션을 선택 해제하면 요청서에 액션 규칙이 적용된 후에도 연속 액션 실행(액션 규칙 순서에 따라)이 계속됩니다.

 

사용자 트리거 순서 편성
액션을 순서를 편성 액션 편성 링크를 클릭하고 팝업에서 비즈니스 규칙을 선택하고 위로 이동 또는 아래로 이동 버튼을 클릭합니다. 접수되는 요청서에 규칙이 적용되는 순서를 결정합니다.
