Auto Update

Apply patch updates in a single click from the application's UI and ensure that the application is up-to-date. Currently, only security patches can be auto-updated.

If the auto update URL (https://updates.manageengine.com/) is not reachable,

  • check your network connection
  • whitelist the URL in firewall settings
  • configure proxy in the application

Configure Auto Update
  • Enable Emergency Mitigation. Security patch updates are checked periodically and whenever an update is available, the Update and Restart button is displayed. Use the Update and Restart button to apply the security patch and restart the application.
    Note: Currently, application restart will not be notified to logged-in users. We recommend administrators to inform users about the application unavailability.
  • Under Settings, enable HotSwap to auto-apply minor patch updates temporarily without restarting the application. The updates will be reverted when the application is restarted.
  • Select SDAdmins or SDOrgAdmins to notify about auto updates. If users are not selected, a banner will be displayed prompting you to choose users for receiving security updates.
  • Click Save.
You can view the detailed status update of patches under Patch Details.
Click View History to view the configuration activities.
