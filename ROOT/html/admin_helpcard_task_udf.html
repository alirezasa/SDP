Use task additional fields to capture any extra information in tasks apart from the information captured through the default fields.

To create a new additional field,

  1. Click the +New button.
  2. Select a field type. Available field types include: Single Line, Multi Line, Pick List, Numeric, Decimal, and Date/Time.
  3. Provide a field name and description. The field properties vary based on the selected field type.
  4. Based on the selected field type, specify the other field properties.
  5. Click Save.

To edit or delete an additional field, click the relevant icon beside the field name in the list view.

NOTE: If an additional field is deleted, it will be removed from task templates where it gets automatically populated.
