Attachment Settings

  • Maximum attachment size ( MB ): Set a maximum size for file attachments. By default, it is set to 10 MB.
  • Configure custom location to save attachments and inline media files: Configure a specific path for saving the attachments and inline media files (supported by rich-text fields) across the application. You can reset the path by clicking the Reset option.
    Note:
    1. The default path will be used for saving the attachments and inline media files, if no specific path is provided.
    2. A directory that is inside the <SERVICEDESK_HOME> directory cannot be configured as the storage location for attachments and inline media files.
    3. Usage of ".." is not allowed in the path to the storage location.

  • File attachment filtering: Configure which file attachments you want to allow and which ones you want to restrict in the application by selecting the file extensions under Include or Exclude section. If you want to allow all file types, choose No Restriction.
  • Strict mode: Validates the extension and its corresponding attachment type before the file is added. .
  • Lenient mode: Validates the extension and content type with all allowed types instead of corresponding content type..
Note: Application must be restarted for the saved settings to take effect.
