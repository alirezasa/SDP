On this page, you can search, add, reorder, delete, disable and enable incident templates.

Click New Template and fill out the displayed form.

Click the Reorder button and either drag the template to the correct location or enter the position in the box provided.

When you delete a template that's currently used in requests, the template will not be available for further use. To revert this, click the template and deselect the Template not for further usage option.


Customizing Technician Template

Fill out the displayed fields.

You can customize the font including its size and color, background color, and field orientation by clicking the Customization icon displayed for the template, section, or field.

Besides the default and available fields, you can add custom fields under New Field. When you add a new custom field that may contain confidential information, select the Contains Personally Identifiable Information option. Also, select if the information must be encrypted.

Note that encrypted data will not be displayed in reports, advanced search, or custom filters.

Use sections to group fields. You can add a new section under New Field.

Limit the template's usage by associating the template to select support groups. If you don't associate any support group, the template will be accessible for all technicians.

Select Show to Requester if you want the template to be displayed to the requester. You can also restrict the template to be used by specific user groups by associating the user groups with the template. Edit individual fields and choose whether requesters can view and/or edit those fields.

Only the fields selected for requesters to set will be displayed as default fields in the requester template.

Note: Fields selected for requesters to view will be displayed only in the request details page.

Use Copy Template button to duplicate the template.


Customizing Requester Template

Customize the template per your requirement.

You can customize the font including its size and color, background color, and field orientation by clicking the Customization icon displayed for the template or section.

Add default fields to the form. (You cannot edit the fields.)

The default values for the fields can be set only under the Technicians tab.

Use sections to group fields.


Configuring Workflow

  • Approvals: You can choose to mandate approval by all approvers or allow anyone of the approvers to approve the request.
  • Checklists: You can configure checklists to guide technicians to complete the requests in a systematic way. Checklist supports multiple field types such as radio button, single-line textbox, numeric-only text box, and decision box.
  • Tasks: You can configure multiple tasks for the incident template, organize, and establish dependencies. You can also associate request properties with tasks to aid task owners, make tasks visible to requesters, choose when to add tasks (after request creation or approval), and choose when to trigger tasks (after request creation, approval, or manual).
