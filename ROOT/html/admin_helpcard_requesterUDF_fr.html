Lors de l'ajout d'un nouveau demandeur ou technicien, vous avez la possibilité d'enregistrer des informations supplémentaires sur les utilisateurs en plus des champs pré-remplis du formulaire. Les Champs d'utilisateur supplémentaires vous permettent d'ajouter des champs aux formulaires de demandeur / technicien, ou des champs communs à ces deux types de formulaire.

Par défaut, la liste des Champs d'utilisateur supplémentaires affiche les Champs supplémentaires communs configurés dans l'application. Pour afficher la liste des Champs de demandeur supplémentaires, sélectionnez l'option Champs de demandeur supplémentaire dans le menu déroulant Filtrer par type. Vous pouvez, de la même manière, afficher la liste des Champs de technicien supplémentaires en sélectionnant l'option Champs de technicien supplémentaires.

Pour ajouter des champs supplémentaires personnalisés :

  1. Sélectionnez une option dans le menu déroulant Filtrer par type. Par ex. : vous souhaitez ajouter un champ supplémentaire au formulaire du technicien ET du demandeur, sélectionnez alors l'option Champ supplémentaire commun.
  2. Cliquez sur le bouton Ajouter un champ.
  3. Plusieurs types de champ sont disponibles : Texte, Numérique et Date/heure. Il existe également plusieurs types de champs de texte : Une seule ligne, Plusieurs lignes et Liste déroulante. Sélectionnez l'un des types de champ.
  4. Renseignez un nom unique pour le champ supplémentaire dans le champ Nom du champ.
  5. Si vous avez sélectionné des champs de texte à une seule ligne ou à plusieurs lignes, vous pouvez saisir une Valeur par défaut. La valeur par défaut s'affiche dans le formulaire de nouveau demandeur/technicien et peut être modifiée, le cas échéant.
  6. Saisissez une brève description du champ dans le champ Description.
  7. Cliquez sur le bouton Enregistrer. Le champ supplémentaire apparaît dans les formulaires de demandeur et de technicien.

REMARQUE :

  1. Vous pouvez ajouter autant de champs supplémentaires que vous le souhaitez, pour le demandeur comme le technicien.
  2. Les champs date/heure ne peuvent pas recevoir de valeurs par défaut.
  3. La valeur saisie pour un champ supplémentaire inséré au nouveau formulaire de demandeur / technicien sera perdue si ce même champ supplémentaire est supprimé.
