Configure outgoing mail server settings to send emails and trigger notifications.
You can use email protocols (SMTP/SMTPs), Exchange Web Services (EWS), or Microsoft Graph to send emails from application.
Depending on the connection protocol selected, the configurations may vary. Click the pointers below to understand how to configure each connection protocol.
SMTP/SMTPS
FieldExplanation
Authentication Type
  • Use Basic authentication to authenticate mailbox using credentials
  • The application supports OAuth 2.0 Authentication. Know more.
Server Name/IP Address

Mention the name or IP address of the mail server.
Alternate Server Name/IP Address

Provide details of a backup server if needed.
Sender Name

Specify the name to displayed in emails sent from the application.
Reply to

Specify an email address to be mentioned as From address in outgoing emails. Reply emails will be received from this email address.
Username (For OAuth Authentication only)

Enter the username to access the mailbox.
Protocol

Select the protocol to connect to the mailbox.
TLS Enabled

Enable TLS (Transport Layer Security) if required.
Port

Specify the port number as per the selected protocol.
Requires Authentication (For Basic Authentication only)

Choose if you want to authenticate the mailbox while sending emails.
Authorization Server Details (For OAuth Authentication only)

Obtain Client ID, Client Secret, Authorization URL, Token URL from the Authorization Server as discussed here.

In the Scope field, define the accessibility of the obtained OAuth tokens in the mailbox. Know more about default values populated as scope.

Configure Redirect URL in the authorization server to obtain tokens.
Note: If you are using Office365 GCC High mailbox, ensure the TLD (top-level domain) is .us in the hostname, connect URL, authorization URL, token URL, and scope.
