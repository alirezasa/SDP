Backup Scheduling

Click Edit Scheduling on the right half of the page.

Fill out all the required details on the displayed page.

For MSSQL backups, you can Enable/Disable the backup schedule and select the backup frequency. However, this is not possible for Postgres database backup since for Postgres, the backup will be taken everyday by default.

Provide the email address of the technician to be notified if the backup fails.

Set a time to start the backup and select type of files (Database/File Attachments) that need to be backed up. Please note, for postgres, by default the database checkbox will be selected and cannot be configured.

Click Reset Password if you want to change the password (You can view the password on the Backup Scheduling page). Select if you want to notify the password update to any email address. If yes, the email address in the respective field.

Provide the backup location and the number of days to retain the backup files.


Note:

In case of partial backups, go to the location of the skipped files and disable any anti-virus restrictions.

Also, check for corrupted files and rerun the backup schedule.

Postgres database backup is made mandatory. The application will take a backup everyday which may result in increased application storage space.


Important:

Please keep your password safe and confidential. Retrieval of your backup files without the password is impossible.
