Purchase Additional Fields

You can define your own organization specific fields that need to appear in the new Purchase Order form apart from the pre-set fields that have been provided by default. You can add Text fields, Numeric fields, Date fields and Cost fields in the form.

Select each of the tabs and add the label name and description for each of the fields that to be added in the new Purchase Order form.

While adding text fields, you have an option to select the type of text field. The text field can be of a Single line text field, Multiple line text box or a Pick list (drop down menu list). To select the text field type, click the corresponding radio button.

Similarly you have two cost type fields, Add cost (for cost addition) and Subtract cost (for cost subtraction). Click the corresponding radio button to select the cost fields.

If you wish to add any default values for the Text field and Cost field then, specify the values in the given text box.

Click Save to save the settings.
