요청서 종료 코드는 요청서를 종료한 이유, 요청서가 성공적으로 종료었는지, 실패했는지, 취소되었는지 등을 나타냅니다. 요청서 종료 코드를 사용하여 관리자는 기술자가 요청서를 종료하는 목적을 이해할 수 있습니다. 또한 요청서 종료에 대한 자세한 설명을 제공하기 위해 의견/참고사항을 입력할 수 있습니다. 요청서를 종료할 때, 구성된 요청서 종료 코드 목록이 나타나고 입력한 데이터는 요청서 세부 정보 페이지에서 볼 수 있습니다.

새 요청서 종요 코드를 추가하려면 새 종료 코드 추가 링크를 클릭하십시오. .

  1. 요청서 종료 코드에 대한 유일한 이름을 입력하십시오. 이 필드는 필수입니다.

  2. 요청서 종료 코드에 대한 간단한 설명을 입력하십시오.

  3. 저장 버튼을 클릭하여 요청서 종료 코드를 저장합니다. 목록 보기로 돌아갑니다. 저장하고 새로 추가 버튼을 클릭하여  를 저장하고 다른 요청서 종료 코드를 추가하십시오.
