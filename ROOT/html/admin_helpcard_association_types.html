Association Types

Association type denotes the nature of association between records in the source and associated module. The association type is expressed twice:

  • Association Type:The nature of the association like impact, enables andsSubmits.
  • Inverse Association Type:The Inverse of the association type like impacted by, Is enabled by and submitted by.

By default, some association types available in the application. To customize a association type, click New.

  • Enter the association type name and the inverse type name.
  • Provide a brief description of the association types and the context in which they can be used.
  • Click Save or Save and Add New.
Edit/Delete Association Types

On the list view, click the Hamburger icon to edit or delete an association type.

You can also bulk-delete assoication types by selecting them and clicking Delete icon on the toolbar.
