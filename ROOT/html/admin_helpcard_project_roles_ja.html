プロジェクトメンバーに割り当てるアクセス権限と一緒にプロジェクトの役割を設定します。 これらの役割によって、プロジェクトの中で、 ‘どのプロジェクトメンバーが何にアクセスするか‘ が決まります。プロジェクトの役割の例: Project Admin, Milestone Supervisor, Task owner 他。 初期設定では、４つのプロジェクトの役割があり、このうち２つの役割を編集することができます。


プロジェクトの役割を追加する
プロジェクトの役割の追加フォームには、４つのフィールドがあります: 役割の名称、説明、非アクティブ、アクセス権限テーブル

役割の名称: プロジェクトの役割を識別するために一意となる名称を指定します。
説明: プロジェクトの役割についての説明を入力します。

非アクティブ・チェックボックス: プロジェクトの役割を非アクティブにします。 アンチェックすると、アクティブになります。
アクセス権限テーブル: プロジェクトの役割に対するアクセス権を選びます。

プロジェクトの役割を保存して、リストビューへ戻るには、保存ボタンをクリックします。
プロジェクトの役割を保存して、次の役割を追加する場合は、保存/新規追加ボタンをクリックします。
