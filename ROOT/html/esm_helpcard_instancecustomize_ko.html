ESM 포털의 레이아웃과 테마는 사용자 지정할 수 있습니다. 조직의 리소스 페이지 또는 인트라넷 페이지에 대한 외부 링크도 포털에 추가할 수 있습니다.

사용자 정의하려면,

  • ESM 포털 사용자 정의 섹션에서 포털 사용자 정의를 클릭합니다.
  • 사용자 정의 페이지에는 레이아웃에 다양한 요소를 렌더링하기 위한 템플릿 변수가 있습니다.
  • 필요한 변수를 클릭하여 코드에 추가합니다. 인트라넷 페이지 또는 리소스 페이지에 대한 외부 링크를 추가하기 위해 고유한 HTML 코드를 입력할 수 있습니다.
  • 미리보기 모드를 전환하여 출력을 미리 볼 수 있습니다.
  • 코드 편집기에서 변경한 사항을 취소하고 기본 레이아웃을 되돌리려면 오른쪽 상단에 있는 바꾸기 버튼을 클릭하세요.
  • 기본 레이아웃으로 되돌리려면 기본 콘텐츠로 바꾸기를 사용합니다. 게시된 콘텐츠로 바꾸기를 사용하여 레이아웃의 게시된 버전을 다시 가져옵니다.
  • 모든 변경 사항을 적용한 후 임시 저장을 클릭하여 변경 사항을 사용자에게 게시하지 않고 로컬에 저장합니다.
  • 업데이트된 포털 콘텐츠를 저장하고 모든 사용자에게 게시하려면 저장하고 게시를 클릭합니다.
