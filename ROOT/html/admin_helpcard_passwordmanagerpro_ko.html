SDP-PMP 통합 :

SDP와 Password Manager Pro 통합은 PMP 관리자와 패스워드 사용자가 두 애플리케이션에서 리소스를 효율적으로 관리할 수 있도록 도와줍니다. 관리자 및 패스워드 사용자는 리소스 계정의 비밀번호를 볼 수 있으며 ServiceDesk Plus에서 원격으로 리소스에 액세스할 수 있습니다.

PMP에서 ServiceDesk Plus Server 구성 및 인증:

제공해야 할 세부정보:

PMP 호스팅 URL: Manager Pro 가 설치된 서버를 입력하십시오.

포트: Password Manager Pro server의 Port Number를 입력하십시오..

 

인증 토큰 생성을 클릭합니다. Password Manager Pro 애플리케이션은 브라우저의 새 탭에서 열리며, 여기서 승인 버튼(관리자 권한이 필요함)을 클릭하여 ServiceDEsk Plus 애플리케이션을 위한 인증 토큰을 생성할 수 있습니다.

 

인증 토큰: Password Manager Pro 애플리케이션에서 생성된 인증 토큰을 입력하십시오.

 

연결 테스트 및 저장을 클릭합니다. ServiceDesk Plus는 Password Manager Pro 서버와 연결을 시도합니다. 연결이 설정되면 Password Manager Pro 구성이 저장됩니다.
