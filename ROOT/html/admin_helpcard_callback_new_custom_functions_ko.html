이 페이지에서 콜백 사용자 정의 함수를 작성하거나 편집할 수 있습니다.

기능을 구축하려면

  • 함수 이름, 반환 유형, 설명 및 API 이름과 같은 필수 정보를 입력합니다.
  • 외부 애플리케이션의 입력 값을 사용하도록 함수에 대한 매개변수를 설정합니다.
  • Deluge 편집기를 사용하여 함수를 빌드합니다.
  • 저장을 클릭합니다.

    • 참고:

    • 최대 10개의 매개변수를 설정할 수 있습니다.
    • API 이름은 유일해야 합니다.
    • 제공된 API 이름을 기반으로 함수를 실행할 URL이 자동으로 생성됩니다.
    • 외부 애플리케이션이 URL을 사용하여 기능을 실행하도록 허용하려면 게시(Publish)를 선택해야 합니다.

    콜백 사용자 정의 함수에 대해 자세히 알아보려면 이 안내서를 참조하십시오 .
