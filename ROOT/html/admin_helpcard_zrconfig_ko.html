On Premise -

Pre-requisite:
  • ManageEngine Analytics Plus를 다운로드하고 설치.
  • Asset Explorers 서버와 ManageEngine Analytics Plus Server 간에 포트 8200 및 8443(설치 시 변경되지 않는 한 기본 포트)에 액세스할 수 있는지 확인하십시오.
구성:
  • 호스트 이름/IP 주소 - ManageEngine Analytics Plus가 설치된 서버의 호스트 이름 또는 IP 주소를 입력합니다.
  • HTTPS 포트 번호 - ManageEngine Analytics Plus 웹 클라이언트에 액세스하는 웹 서버 포트를 입력합니다. 설치 시 변경하지 않는 한 기본 포트는 8443입니다.
  • Analytics Workspace Name - ManageEngine Analytics plus에서 생성할 작업 영역의 고유한 이름을 입력합니다. 기존 작업 공간 이름을 사용하는 경우 Asset Explorer 의 구성에 따라 해당 작업 공간을 덮어씁니다.
  • 사용자 이름 - ManageEngine Analytics Plus에서 사용되는 관리자 계정의 사용자 이름을 입력합니다. 기본값은 Admin 입니다.
  • 패스워드 - 해당 관리자 계정의 비밀번호를 입력합니다. 기본 비밀번호는 admin입니다.
  • 프록시 설정 변경 - ManageEngine Analytics Plus 서버에 대한 HTTP 요청이 프록시 서버를 통해 라우팅되는 경우 프록시 설정을 구성합니다.
  • 다음부터 동기화 - Asset Explorer 데이터를 ManageEngine Analytics Plus로 푸시해야 하는 날짜와 기간을 선택합니다.

On Cloud -

사전 요구 사항:
  • Zoho Analytics 계정 가입.

구성:
  • 데이터 센터 선택 - Zoho Analytics 계정에 대한 OAuth 클라이언트를 만들 데이터 센터를 선택합니다. 선택한 데이터 센터는 Zoho Analytics 계정을 만든 가입 URL과 일치해야 합니다.
    • Analytics Workspace Name - Zoho Analytics에서 생성할 작업 영역의 고유한 이름을 입력합니다. 기존 작업 공간 이름을 사용하는 경우 Asset Explorer의 구성에 따라 해당 작업 공간을 덮어씁니다.
    • Zoho 이메일 ID - Zoho Analytics 계정에 가입할 때 사용한 이메일 ID를 입력합니다.
    • 클라이언트 ID/클라이언트 암호 - Zoho Analytics 계정에 대해 생성된 OAuth 클라이언트 ID 및 클라이언트 암호를 입력합니다. 여기를 클릭하여 자세히 알아보십시오. 더.
    • 리디렉션 URL - OAuth 클라이언트를 생성하는 동안 주어진 URL을 복사하여 승인된 리디렉션 URL 필드에 붙여넣습니다.
    • 프록시 설정 변경 - 인터넷에 대한 HTTP 요청이 프록시 서버를 통해 라우팅되는 경우 프록시 설정을 구성합니다.
    • 다음부터 동기화 - Asset Explorer 데이터를 Zoho Analytics 클라우드로 푸시해야 하는 날짜와 기간을 선택합니다.

    재동기화 : 초기 저장 및 동기화 프로세스가 완료되면 '재동기화' 버튼이 나타납니다. Asset Explorer와 Advanced Analytics 모듈 간의 데이터는 이 버튼을 사용하여 수동으로 동기화할 수 있습니다. 주기적인 동기화는 '추가 설정' 탭의 옵션을 사용하여 설정할 수 있습니다.

    작업 공간을 새 Admin 관리자로 이동: 사용자 이름/Zoho 이메일 ID 필드 옆에 있는 편집 아이콘을 클릭합니다. 사용자 이름 또는 이메일 ID를 입력하여 작업 영역에 대한 새 Admin 관리자를 배정합니다. 새 Admin 관리자에게 동일한 이름의 기존 작업 영역이 없는지 확인하십시오.

    보안 정보 : Asset Explorer와 Advanced Analytics 모듈 간의 데이터 동기화는 암호화되고 현재 Asset Explorer 데이터만 동기화됩니다. Advanced Analytics 모듈은 Asset Explorer에 데이터를 쓰지 않습니다. 클라우드의 데이터 보안에 대한 자세한 내용을 보려면 여기를 클릭하십시오.

    참고: 데이터 동기화 프로세스로 인해 Advanced Analytics 통합 페이지가 정지됩니다. 동기화 상태는 동기화가 완료될 때까지 상태가 '실행 Running'으로 표시됩니다.


    추가 설정:

    다음 옵션을 사용하여 Advanced Analytics 모듈과의 데이터 동기화를 제어합니다.

    • 주기적인 데이터 동기화: Asset Explorer와 Advanced Analytics 모듈 간의 데이터 동기화 빈도를 선택합니다. 기본 구성은 1시간입니다.
    • 데이터 보존 정책 - Asset Explorer 데이터를 Advanced Analytics 모듈에 보존해야 하는 기간을 구성합니다. 이 정책은 7일마다 실행됩니다.
    • 사용자 정보 - Advanced Analytics 모듈에서 Asset Explorer 데이터베이스에 액세스할 수 있는 사용자를 나열합니다. 사용자 목록은 7일마다 새로고침됩니다.
    • 라이선스 정보 - 사용 가능한 레코드 수와 Advanced Analytics 모듈의 라이선스 만료 정보를 표시합니다.
