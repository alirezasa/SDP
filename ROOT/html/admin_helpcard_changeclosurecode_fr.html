Le code de côture de modification renseigne sur la raison de clôture d'une demande : terminée, rejetée, etc. Ce code permet au Gestionnaire de modification de saisir le motif de clôture de la demande de modification.

Ajouter un code de clôture

  1. Cliquez sur le bouton Ajouter un code de clôture.

  2. Renseignez un Nom pour le code de clôture de modification. Ce champ est obligatoire.

  3. Saisissez une brève Description du code de clôture de modification.

  4. Cliquez sur le bouton Enregistrer. Le code de clôture de modification est enregistré et répertorié dans l'affichage liste.

Les codes de clôture de modification configurés ainsi qu'une section destinée à d'éventuels commentaires s'affiche dans l'Étape de clôture d'une demande de modification. Le propriétaire de la modification peut ici sélectionner le code de clôture et saisir la raison détaillée de cette clôture.
