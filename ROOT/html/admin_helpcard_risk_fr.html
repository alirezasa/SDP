La plupart des modifications proposées implique un niveau de risque durant son implémentation. Les utilisateurs concernés par une modification doivent être informés de ces riques.

L'application propose quatre niveaux de risque dans l'affichage liste. Le risque configuré est assigné à une nouvelle demande de modification.

Ajout d'un risque  

1. Cliquez sur le bouton Ajouter un risque.

2. Renseignez le Nom du niveau de risque. Par exemple élevé, faible ou normal.

3. Saisissez une brève Description sur les risques encourus dans ce niveau.

4. Cliquez sur le bouton Enregistrer. Le risque s'affiche dans la Liste des risques
