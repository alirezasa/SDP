Rich Text Area Settings

Customize default font, size, color, image options, and Tab key functions for rich text areas across the application.

On this page, you can configure only instance-specific settings.

  • Select your preferred font, size, color, image options, and tab key functions.
  • Click Save.

Reset restores default settings. By default, Font is Roboto, Size is 10, Color is Black, Image Options - Best Fit, Tab Key Functions - Insert Space.
