Structure Templates

Create and save templates for frequently created structures such as administrative buildings, laboratories, indoor playgrounds, outdoor fields, etc., to aid users while they create similar structures.

On this page, you can create new structure templates, edit or delete the existing ones.

To create a new structure template, click New Structure Template.

The new structure template has two sections,

1. Details: Here, you can define the structure template by adding a display name, name, and description for it.

2. Fields: Once you have saved the details section, you can add new fields to the structure template by dragging the required fields from the New Field Section on the right side.

To name a section, click Untitled text and type in the desired section name.

Finally, save the field configuration.
