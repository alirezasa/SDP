Zia Bot helps users perform 20 different operations including raising tickets, assigning technicians to requests, accessing service catalogs, raising service requests, and viewing solutions/announcements, etc., by just typing a command or asking Zia via the chat box.

On this page, you can enable or disable the Zia Bot. Once enabled, the Zia Bot icon will be displayed at the right bottom bar for users and will show actions only as per the users' scope. When you enable the auto-open option, the Zia Bot will open automatically each time a requester logs in.

On the Buttons List View, you can perform the following actions:

Enable or disable buttons.

Edit or delete buttons using the hamburger button.

Note: You can disable or delete only the buttons that are NOT used within the workflow. For unused/disabled actions, you'll be able to view only the successor nodes.

You can edit each Button by clicking on the hamburger button or on the name of the Button. This will display only the nodes that follow the button within a workflow. Click the edit icon over the button and define its name, Bot Command, and User Type, which is the permission level for the button. For now, you can choose All or Technicians. In this view, you can also select and view other buttons from the drop-down on the header.

View History lists when Zia Bot was enabled and disabled, details about enabling, disabling, and deletion of specific button, along with timestamp and role information. In addition, details of editing the button name, bot-command and user type will be shown.

Click Bot Commands to add, edit, and delete the commands of all the buttons in one go.
