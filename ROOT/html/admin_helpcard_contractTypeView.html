Contract Type

Contract type is a classification used to categorize contracts into different types such as maintenance, support, warranty, etc. Here, you can configure new contract types and use them when creating a new contract as required.

To create a new contract type

  1. Click New.

  2. Provide the following information:

    • Contract Type: Provide a unique name for the contract type.

    • Description: Add a relevant description about the contract type

  3. Finally, click Save.

Edit or Delete Contract Types

  • To edit a contract type, click the name of the contract type or click the Actions icon beside the name and choose Edit, make necessary changes, and click Update.

  • To delete contracts, select the contract types, and click the Delete icon. To delete a single contract type, click the Actions icon beside the contract type and choose Delete.

Note : When contract types that are associated with existing contracts are deleted, they will be marked as inactive and cannot be used with future contracts. You can view inactive contract types by choosing Inactive Contract Types from the view filter drop-down on the top-left. To restore, select the contract types, and click Mark as Active.
