복잡한 네트워크 조직의 경우 Central AE 서버가 사이트의 모든 자산에 액세스하지 못할 수 있습니다. 따라서 원격 AE 서버가 각 사이트에 설치되어 모든 워크스테이션과 해당 사이트의 사용자 정보를 스캔하고 유지 관리합니다. 원격 AE 서버의 데이터는 수동으로 가져오거나 또는 주기적으로 데이터를 보내도록 예약하여, 중앙 AE 서버로 보내도록(푸시하도록) 합니다.  

 

수동

1. 원격 AE 서버에서 zip 형식으로 데이터를 추출하고 내보내기로 데이터를 중앙 서버로 보냅니다.

2.이 ZIP 파일을 가져오기하여 AE Server로 가져옵니다.   

 

자동 동기화

1. Central Server 설정에서 상제 정보를 구성합니다.

  • 서버 이름: Central AE 서버이 서버 이름 혹은 IP 주소를 입력합니다.

  • 서버 포트: Central AE Server가 설치된 서버의 포트 번호입니다.

  • 서버 프로토콜: Central 서버와 원격 서버를 연결하기 위한 프로토콜로서 Http, Https 중에서 선택합니다.

  • 사이트: 원격 AE 서버가 설치된 사이트입니다. 지정되는 사이트는 Central 서버에서 구성되며, 자산 및 사용자가 해당 사이트에 연계됩니다.

  • API Key : SD 관리자 권한을 가진 기술자의 API 키

Central Server는 프록시 서버를 통해 연결할 수 있습니다. 이 경우,

  • 프록시 서버를 통해 연결됨 확인란을 활성화합니다.

  • 프록시 서버 이름 : 프록시 서버의 서버 이름 또는 IP 주소입니다.

  • 프록시 서버 포트: 프록시 서버의 포트입니다.

  • 프록시 사용자 이름 & 패스워드: 프록시 서버의 자격 증명입니다.

2. 지금 중앙 서버로 데이터 내보내기 및 푸시 버튼을 선택합니다. 중앙 서버에 연결할 수 있는 경우, 데이터가 자동으로 중앙 서버로 푸시됩니다.
