Champs de contrat supplémentaires

 

Vous pouvez définir les champs propres à votre organisation qui doivent apparaître dans le formulaire Ajouter un nouveau contrat en plus des champs prédéfinis qui ont été fournis par défaut. Vous pouvez ajouter des champs de type texte, des champs de type numérique et des champs de type date/heure dans le formulaire. Sélectionnez chaque onglet et renseignez le nom du libellé et la description des champs à ajouter au formulaire Ajouter un nouveau contrat.

Vous pouvez choisir le type des champs de texte ajoutés au formulaire de contrat en cochant les cases appropriées. Par ex. : Une seule ligne, Plusieurs lignes et Liste déroulante.

Si vous souhaitez qu'un champ hérite d'une valeur par défaut, renseignez-la dans le champ Valeur par défaut.

Pour enregistrer les informations saisies, cliquez sur Enregistrer.
