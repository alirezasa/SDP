Vendor

You can configure different vendors from whom you purchase different products and services for your organization and maintain the list of products/services that are supplied by each vendor.

Add New Vendor

  1. Click New.

  2. Provide the following information:

    • Name: Enter your vendor's name.

    • Currency: Select the currency for transactions with this vendor. You can also add a new currency using the Add icon. In ESM setups, you can add currencies under the ESM Directory.

    • Description: Enter a relevant description about the vendor.

    • Contact Person: Enter the name of the contact person working with the vendor.

    • Address fields: Provide the vendor's address by filling out information such as Door Number, Street, Landmark, City, Postal code, State, and Country.

    • Contact Info fields: Provide vendor's contact details such as E-mail, Phone, Fax, and Web URL.

    • Enter details in additional fields, if any.

  3. Click Save.

Import Vendor Details

  1. Use the Drop-down icon beside the New button.

  2. In the import wizard, select the file format: XLS, XLSX, or CSV.

  3. Choose how you want to import the records:

    • Add and update records - Add new vendors and update existing vendors.

    • Delete existing records and new ones - Delete existing vendors and add vendor details from the file.

    • Ignore duplicate records - Add new vendors and ignore existing vendor details.

  4. Select the file to be imported.

  5. Click Next.

  6. Map the columns in the file with vendor fields.

  7. Click Import.

You can also import the product or service details associated with the vendor.

Note: You can update multiple product and service associations to a vendor during import by adding several rows with the same vendor name and different products/service. On importing the details, the products/services will be associated with the vendor in the application.

Export Vendor Details

  1. Click Export Vendor.

  2. Select the format to export the vendor details: HTML, XLS, XLSX, PDF, or CSV.

  3. Click Export.

Edit or Delete Vendors

Use the Hamburger icon beside the vendor name to edit or delete a vendor. To bulk delete vendors, select the vendors and click the Delete icon.

  • On deleting vendors associated with assets, purchase orders, purchase requests, or contracts:

    • Vendors associated with assets will be moved to an inactive state.

    • Vendors associated with purchase orders, purchase requests, or contracts will move to an inactive state only if the associated records are in Canceled, Closed, or Expired state. Otherwise, the vendors will not be deleted.

  • When vendors are deleted or moved to an inactive state, the associated products and services will be deleted as well.

Associate Product with a Vendor

  1. Click a vendor name or the drop-down icon beside it to expand the vendor details.

  2. In the Product tab, click Associate Product.

  3. Provide the following information:

    1. Product: Select the product to associate with the vendor from the drop-down.

    2. Price: Enter the price of the product.

    3. Tax Rate (%): Provide the applicable tax rate.

    4. Warranty Period: Configure the applicable warranty period in years and months.

    5. Maintenance vendor: Select a maintenance vendor for the product.

    6. Comments: Add any additional information.

  4. Click Save.

Use the Hamburger icon beside the product name to edit or delete the vendor-product association. To bulk delete, select the products and click the Delete icon.

Associate Service with a Vendor

  1. Click a vendor name or the drop-down icon beside it to expand the vendor details.

  2. Go to the Service tab, click Associate Service

  3. Provide the following information:

    1. Vendor Services: Select the service to associate with the vendor from the drop-down.

    2. Cost: Enter the cost of the service.

    3. Tax rate: Enter the applicable tax rate.

    4. Service Period: Configure the applicable warranty period in years and months.

    5. Support vendor: Select a support vendor for the service.

    6. Comments: Add any additional information.

  4. Click Save.

Note: You can also add services to a vendor under Admin > Customization > Purchase Management > Vendor Services.

Use the Hamburger icon beside the service name to edit or delete the vendor-service association. To bulk delete, select the services and click the Delete icon.
