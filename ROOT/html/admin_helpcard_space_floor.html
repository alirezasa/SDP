Floor Templates

Create and save templates for frequently created floors such as office, cafeteria, etc., to aid users while they create similar floors.

On this page, you can create a new floor template, edit or delete the existing ones.

To create a new floor template, click New Floor Template.

The new floor template has two sections,

1. Details: Here, you can define the floor template by adding a display name, name, and description of it.

2. Fields: Once you have saved the details section, you can add new fields to the floor template by dragging the required fields from the New Field Section on the right side.

To name a section, click Untitled text and type in the desired section name.

Finally, save the field configuration.
