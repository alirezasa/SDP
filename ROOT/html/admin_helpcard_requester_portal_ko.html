이 페이지에서 ESM 디렉터리에서 인스턴스에 사용자를 추가하는 방법을 선택할 수 있습니다.기준을 설정하여 사용자를 추가하거나 조직의 모든 사용자를 가져올 수 있습니다. 또한 새 사용자 또는 조직 사용자를 인스턴스에 수동으로 추가할 수 있습니다.


기준에 따라 사용자 추가

기준을 선택하여 사용자를 가져오면 설정된 기준과 일치하는 사용자 프로필이 자동으로 인스턴스로 이동됩니다. 예를 들어, 기준을 "Department" "is" "Administration"으로 설정한 경우 부서가 관리 사용자 프로필이 인스턴스에 추가됩니다.

이 추가는 사용자가 부서를 업데이트/수정하는 경우에도 발생합니다. 마찬가지로 사용자가 부서를 인스턴스 사용자 기준과 일치하지 않는 부서로 변경하면 해당 부서는 인스턴스에서 자동으로 제거됩니다. 이는 사이트에도 적용됩니다.


모든 조직의 사용자 가져오기

조직의 모든 사용자를 연계하도록 선택하면 ESM 디렉토리에서 가져온 모든 사용자가 인스턴스에 추가됩니다.

참고: 인스턴스에서 사용자를 삭제할 수 없습니다. 삭제는 ESM 디렉토리에서만 수행될 수 있습니다.


수동으로 사용자 추가
Click 새로 추가를 클릭하고, 사용자 정보를 모두 입력하고 저장을 클릭합니다.

참고사항:

  • 표시 이름 또는 기본 이메일을 입력하면 검색됩니다. 유사한 이름 또는 이메일 주소에 대해 조직 전체에서 추가하려는 사용자가 검색 결과에 나타나면 해당 사용자를 인스턴스와 연계하기만 하면 됩니다.
  • 요청서 양식 내에서 새 사용자를 추가할 수도 있습니다.


사용자 편집

인스턴스 아래에서 사용자의 일부 필드만 편집할 수 있습니다. 이러한 필드에는 비즈니스 영향도, 시간당 비용, 연결된 그룹, 프로젝트 역할, 볼 수 있는 요청자가 포함됩니다. 이미 추가한 추가 필드를 편집할 수도 있습니다. 인스턴스에서 사용자에게 서비스 승인자 및 구매 승인자 권한을 부여할 수도 있습니다. 사용자 목록 보기에서 사용자에게 프로젝트 역할을 할당할 수 있습니다.


참고 사항: 회색으로 표시된 필드는 ESM 디렉토리 아래의 조직 관리자만 편집할 수 있습니다. ESM 디렉토리에서 추가된 사용자/기술자 추가 필드(글로벌 추가 필드)는 인스턴스에서 편집할 수 없습니다.
