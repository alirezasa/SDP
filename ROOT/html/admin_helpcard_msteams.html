ServiceDesk Plus Integration with Microsoft Teams

Set up ServiceDesk Plus integration with Microsoft Teams to leverage the collaboration app from Microsoft as an additional channel for IT and enterprise support. Through this integration, users can view their service desk tickets, view pending approval, and chat with help desk technicians―all from within their Microsoft Teams accounts.


Setup Integration

  • Provide the Application Password that you generated in your Microsoft Teams account.
  • Provide the Application ID and Tenant ID of your ServiceDesk Plus bot in the Azure portal.
  • Under SDP Hosted Domain, the alias URL configured for your application will be auto-populated. But if your application is hosted elsewhere, specify the domain where it is hosted.
  • When you submit the above configurations, Redirect URL and Bot Endpoint will be auto-generated. Configure the Redirect URL and the Bot Endpoint in your Azure portal and the ServiceDesk Plus bot as instructed here.

After you submit the configurations, a new checkbox called Enable Microsoft Teams will appear, enabled. You can use the checkbox to disable the integration while restoring the configurations.

To update any configuration, make the changes and click Update. To completely remove the integration, click Remove displayed at the bottom of the page. Note that if you remove the integration, all configurations will be deleted and cannot be restored.


Configure Bot Commands

Configure custom commands for ServiceDesk Plus integration with Microsoft Teams.

By default, ServiceDesk Plus contains a list of default commands. You can create more custom commands and execute any action in Microsoft teams using the ServiceDesk Plus bot.

  1. Click Custom Command.
  2. Enter the Name of the command.
  3. Briefly outline the functioning of the command in Description.
  4. Configure the Action to be performed when the command is executed. You can associate global functions as the action or create a global function using the New option.
  5. Click Create Command.

The created commands are reflected immediately in Microsoft Teams. You can use the Check icon to disable a command and prevent users from using it. You can enable it later if needed.

Click on a command name to modify the command details. Use Update to save the changes. You can use the Delete icon beside the command name to delete the command.

Note:

  • With respect to the default commands, only the name and description can be edited. Default commands cannot be deleted, only disabled.
  • You can create cards to be displayed in Microsoft Teams on initiating the command, using global functions. Click here to learn how.
  • To learn the ServiceDesk Plus bot commands that can be used in Microsoft Teams, visit this link.

Enable Notifications

After the bot is added to a team, ServiceDesk Plus will be able to access the channels present in the team.

You can map the various support groups present in ServiceDesk Plus with respective teams channels. When a request is assigned to a support group, the bot will trigger a notification to the respective channel.

  • Select Enable Support group notifications to send alerts in the channel.
  • Map the support group and the teams channel from the respective drop-down. Use the Add icon to map multiple groups with their respective channels.
  • Click Update to save the mapped relationships.
