Guidelines for import
  • If a user login name is provided with a domain name, the username will not be considered for identifying the user uniquely.
  • Ownership details will be considered only if an asset is in In Use state or the asset state is not provided.
  • While mapping fields,
    • If Retain user site as asset site is enabled, the asset will be moved to the corresponding user/department site.
    • Refer entities such as products or sites will be created only if Create as new refer entities is enabled.
  • Assets cannot be added for the Asset Product Type.
  • Only up to 80 admin entities can be added or updated during an import. Operations exceeding this limit will fail.
