Guidelines for import
  • Ensure that Request Properties (such as Mode, Impact, Priority, etc.) are added prior to the request; otherwise, the request will be created with unassigned values.
  • We strongly recommend to disable Request closure rules before importing request.
  • Upon importing, the Request(s) will be created using the default incident template.
  • NOTE: While adding Resolved/Closed request during import, and if the request closure rule is not matched, then the ticket will be added with Open status.
