Guidelines for Solution import
  • Solution import supports importing solution details
  • Supported file formats: CSV, XLS, XLSX
  • Solution Title, Topic and Content are mandatory fields.
  • Add and Update records - Based on Solution ID field, the solution data will be added new or overwritten over existing solution data.
  • Delete existing records and add new onces - Based on Solution ID field, delete the existing solution and and added new solution
  • Ignore duplicate records - Based on Solution ID field, ignored the existing data and added new solution
