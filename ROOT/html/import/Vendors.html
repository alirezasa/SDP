Guidelines for import
  • Vendor import supports importing vendor details along with associated products and services.
  • Supported file formats: CSV, XLS, XLSX
  • Vendor Name and Currency are mandatory fields. For currency, input the Currency name.
  • Based on Vendor Name field, the vendor data will be added new or overwritten over existing vendor data.
  • Ensure that vendor names are the same in the import file and application while updating the vendor details. If the vendor name is different, a new vendor will be created in the application.
  • Product Type, Service Type and GL Code cannot be added during vendor import and must be imported before adding a product or service.
  • Products of type Software cannot be created during import.
  • If the maintenance or support vendors specified in the import file are not present in the application, the corresponding maintenance or support vendor details will be ignored during import.
  • Product association and service association can be imported at the same time.
  • You can import the following fields:

    Vendor fields: Name, Currency, E-mail, Country, Contact Person, City, mobile, Description, Web URL, Phone, Street, Door Number, State, Fax, Landmark, Postal code and additional fields.

    Product fields: Product, Price, Maintenance Vendor, Product Comments, Product Type, Tax Rate (%), Product Warranty Years , Product Warranty Months

    Service fields: Vendor Services, Cost, Support Vendor, Part No., GL Code, Service Comments, Service Type, Tax Rate, Service Warranty Months, Service Warranty Years
