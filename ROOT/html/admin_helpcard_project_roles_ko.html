프로젝트 구성원에게 할당할 고유한 액세스 권한 세트로 각각 다양한 프로젝트 역할을 구성합니다. 이러한 역할은 ‘어느 프로젝트 구성원이 무엇에 액세스하는지’를 결정합니다. 프로젝트 내에서. 프로젝트 역할 예: 프로젝트 관리자, 마일스톤 감독자, 작업 소유자 등. 기본적으로 4개의 프로젝트 역할이 있으며 그 중 2개는 편집할 수 있습니다.


프로젝트 역할 추가
프로젝트 역할 추가 양식에는 이름, 설명, 비활성 확인란 및 액세스 권한 테이블의 4개 필드가 있습니다.

이름: Specify a unique name to identify Project Role..
설명: Enter a short description about the Project Role in the Description field.

비활성 점검 박스: 프로젝트 역할 비활성화 활성화 역할을 다시 활성화하려면 선택을 취소하십시오...
액세스 권한 테이블: 프로젝트 역할에 대한 액세스 권한을 선택합니다.

저장 버튼을 클릭하여 프로젝트 역할을 저장하고 목록 보기로 돌아갑니다.
저장 및 새로 추가 버튼을 클릭하여 프로젝트 역할을 저장하고 다른 역할을 추가합니다.
