SDP-KMP Integration :

SDP-Key Manager Plus Integration helps technicians to identify the expired SSL/TLS certificates in target endpoints, invoke certificate renewal, and deploy the newly issued certificates to the respective applications, directly without leaving their Service Desk Plus consoles. Furthermore, this integration enables IT administrators to continuously monitor the SSL/TLS cipher strength across the network. Technicians are alerted whenever vulnerabilities such as weak cipher suites are spotted, allowing them to take immediate remedial action.

Configuring KMP settings in SDP :

KMP Hosted URL : Enter the Application URL where Key Manager Plus application is installed.

Auth Token: Enter the generated Auth Token from the Key Manager Plus application.

 

Click Save to save the settings.
