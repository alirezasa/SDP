Resolution templates can be created to handle repeated requests with the same solution. The solutions of frequently raised requests, such as printer configuration can be made into a Resolution Template. Thus the technicians need not type the same resolution repeatedly for the request raised.

To add a new resolution Template click the New button from the resolution template list page.

Add New Resolution Template

To add resolution template,

Specify a unique Name for the resolution template. For ex. Solution to configure the printer.

Enter the resolution in the Description text field. Name and Description are mandatory fields.

You can make the resolution inactive by enabling the Make as Inactive check box.

Click Save to save and go back to the list view page.
Click Save and add New to save and add another resolution template.
