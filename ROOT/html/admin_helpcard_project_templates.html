Project Templates

Project templates help create new projects quickly and efficiently, saving time, effort, and resources.

Template name: Provide an easily identifiable, unique name

Description: List the must-haves, checklists, and important links, if any

Project Title: Add the name of the project.

Project description: A brief account of project objectives, life cycle, and desired outcomes.

Project Type: Select from the list you have created

Site: Select the project location.

Estimated Hours: Provide an estimate of the time required

Status: Choose from open, closed, onhold, or canceled. You can also configure custom statuses on the Admin tab.

Estimated Cost: Provide an estimate of the expenses.

Priority: Choose from low, medium, normal, or high. You can also configure custom priorities on the Admin tab.
