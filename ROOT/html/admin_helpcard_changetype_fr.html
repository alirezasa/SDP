Modifier les types

Le Type de modification renseigne sur l'importance d'une modification initiée par l'organisation. Certaines demandes de modification peuvent être assez communes pour ne pas nécessiter un processeur d'approbation. De ce cas, une option est disponible pour marquer le type de modification comme pré-approuvé. Vous pouvez également renseigner l'importance d'un type de modification par un code de couleur.

L'application propose quatre types de modification dans l'affichage liste. Vous pouvez cliquer sur le lien Ajouter un nouveau type de modification pour ajouter un type de modification.

Ajouter un nouveau type de modification

1. Renseignez le Nom du type de modification. Par ex. : majeur, mineur, standard, etc. Ce champ est obligatoire.

2. Sélectionnez une Couleur pour indiquer la sévérité de la modification.

3. Donnez une brève Description de l'importance de ce type de modification.

4. Cochez Pré-approbation si vous ne souhaitez pas que les demandes de modification fassent l'objet du processus d'approbation.

5. Cliquez sur le bouton Enregistrer. Le type de modification est enregistré et affiché dans l'affichage liste.

Pour enregistrer le type de modification et en ajouter un autre, cliquez sur le bouton Enregistrer et ajouter nouveau Pour revenir à l’affichage liste, cliquez sur le bouton Annuler. Pour afficher la liste des types de modification, cliquez sur Afficher la liste.
