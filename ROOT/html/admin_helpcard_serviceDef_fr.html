La catégorie de service est une liste compréhensive des services informatiques fournis par votre organisation aux utilisateurs finaux. Chaque service possède des éléments du service de groupe classés qui peuvent être rendus disponibles à des groupes d'utilisateurs spécifiques.

Ajouter une nouvelle catégorie de service

  1. Cliquez sur le lien Ajouter une nouvelle catégorie de service La page Catégorie de service s'ouvre.

  2. Renseignez le Nom de la Catégorie de service du service informatique. Ce champ est obligatoire.

  3. Saisissez une brève Description du service informatique dans le champ prévu à cet effet.

  4. Définissez une Icône pour la catégorie de service. Vous pouvez choisir une icône dans la palette d'icônes ou la télécharger directement. La Palette d'icônes comprend toutes les icônes disponibles dans l'application par défaut. Pour télécharger une icône, cliquez sur Télécharger une icône et sélectionnez l'icône.

Cliquez sur le bouton Enregistrer pour enregistrer les informations et revenir à l’affichage liste.

Cliquez sur Enregistrer et ajouter nouveau pour ajouter une autre catégorie de service.  

 

Cliquez sur Afficher la liste pour afficher la liste des catégories de service.

Cliquez sur Retour pour afficher l'assistant de configuration du catalogue de service.
