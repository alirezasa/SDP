SDP-PAM360 Integration :

Integrate with PAM360 to manage and monitor privileged access to critical assets in your organization.

Configure Integration

  • Select the Enable PAM360 menu check box to display the option in the application's header.
  • PAM360 Hosted URL: Enter the server name of the PAM360 application.
  • Port: Enter the port number of the PAM360 server.
  • Click Generate Auth Token. The PAM360 application will open in a new tab. Generate an auth token for ServiceDesk Plus by clicking the Authorize button.
  • Auth Token: Enter the Auth Token generated from the PAM360.
  • Click Test Connection and Save.
ServiceDesk Plus will establish a connection with the PAM360 server.
