Integrate with Site24x7

SDP-Site24x7 통합은 DevOps 엔지니어와 IT 관리자가 중앙 패널에서 IT 사건을 효율적으로 관리하고 해결할 수 있도록 도와줍니다. 파일 크기 나열, 로그 지우기, 서비스/프로세스 다시 시작과 같은 빠른 액션 메뉴를 SDP 요청서 템플릿과 연결할 수 있습니다. 완료되면, DevOps 기술자는 Site24x7 IT 자동화 액션을 원격으로 실행하여 SDP 플랫폼 내에서 디스크 공간 부족, 애플리케이션 충돌 등과 같이 일반적으로 보고되는 사건을 쉽게 수정할 수 있습니다. 이 도움말 카드는 SDP에서 Site24x7 IT 자동화 작업을 위한 빠른 작업 메뉴를 만드는 단계를 제공합니다.


Site24x7과 연결

  1. SDP 계정에 로그인하고 관리 설정 > 통합 > Site24x7에 액세스합니다.
  2. 기본적으로 "Enable Site24x7" 확인란이 표시되어 있습니다. 확인란을 사용하면 Site24x7 헤더 탭을 표시하거나 숨길 수 있습니다.
  3. 이제 사용 가능한 목록에서 선호하는 Site24x7 데이터 센터(미국, 유럽, 중국, 인도)를 선택하고 Site24x7 서비스를 사용하기 위해 가입하십시오.
  4. OAuth 자격 증명 생성 링크를 클릭하여 클라이언트 ID, 클라이언트 암호 및 생성된 코드를 가져옵니다.
  5. 연결 테스트 및 저장 버튼을 클릭하여 통합이 성공적으로 설정되었는지 확인합니다.

참고 사항: 이 통합을 해제하려면 제거 버튼을 클릭하면 됩니다.


SDP 요청서 템플릿에 Site24x7 IT 자동화 액션 연계

요청서 템플릿을 사용하면 애플리케이션 충돌, 프린터 문제 또는 잘못된 메일 가져오기와 같이 빈번한 요청서를 신속하게 해결하는 데 필요한 정보를 포함할 수 있습니다. 모든 Site24x7 IT 자동화 액션은 SDP와 동기화되고 SDP의 Site24x7 액션으로 자동 나열됩니다. 템플릿 액션 설정에 따라 관련 IT 자동화 액션이 정의된 사용자 역할에 대한 요청서 > "액션" 메뉴 섹션에 표시됩니다.

자동화 액션을 SDP 요청서 템플릿에 연계하려면 다음 단계를 수행해야 합니다.

  1. Site24x7 작업 페이지를 편집하려면 특정 자동화 액션을 클릭하십시오.
  2. 편집 액션 페이지는, 실제 액션 이름과 액션 설명을 제공합니다.
  3. 라디오 버튼을 사용하여, 일부 지원 그룹 기술자 또는 모든 기술자가 사용하도록 템플릿을 제한할 수 있습니다.
  4. IT 자동화 액션을 "애플리케이션이 자주 충돌함"과 같은 사전 정의된 사건 템플릿과 연계하고 업데이트 버튼을 클릭합니다.

SDP 요청서 페이지 및 액션 메뉴

SDP 포털에 서비스 요청서가 추가되면(예: 특정 서버 호스트의 빈번한 애플리케이션 오류) 문제 해결을 담당하는 기술자는 요청서 세부 정보 페이지의 "액션" 메뉴에 즉시 액세스하고 빠른 액션 메뉴를 클릭할 수 있습니다. 서비스/프로세스를 다시 시작하기 위한 버튼입니다. 결과 액션은 "액션이 시작됨"이라는 메시지와 함께 요청서의 참고 섹션에 한 항목으로 캡처됩니다.
