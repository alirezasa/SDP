SMS通知設定

SMS通知設定によってSMS経由で技術担当者に通知することができます。これにより、技術担当者は関連のあるリクエストが完了したら外出先でも通知を受け取ることができます。

オプション 定義
モバイルサービスプロバイダー経由でSMSを送信 メッセージは技術担当者のSMSアドレス宛に送信されます
SMSゲートウェイプロバイダー経由で送信 メッセージは技術担当者の携帯番号に直接送信されます

優先度の高いリクエストや変更は早急に確認するように技術担当者に要求することができます。Servicedesk PlusがSMS経由で通知を送信することで技術担当者は外出先でもリクエストを解決できます。

ServiceDesk Plusでは2つの通知オプションを提供します。1つ目は、Site24*7やClickatell,Bulk SMSなどサービスプロバイダーと統合することによって技術担当者の携帯番号に直接通知を送信するオプションです。ユーザーは各サービスプロバイダーからクレジットを購入して、メッセージの送信を行います。2つ目は、ServiceDesk Plusは技術担当者のSMSアドレス宛に送信するメールとして通知を送信するオプションです。

設定したいSMSプロバイダーを選択します。Site24*7とClickatellを選択すると認証のためにAuthtokenを要求され、Bulk SMSを選択するとユーザー名とパスワードを要求されます。
"SMSをUnicode形式で送信する"を有効にすると、Unicode形式で通知が送信されます。Unicodeはプラットフォーム/プログラム/言語に関わらず、標準化された文字コードです。


メモ:
  • SMS通知を送信する技術担当者の携帯番号を入力します。 また、"携帯"フィールドに国コードも入力します。
    これは管理タブ >> ユーザー >> 技術担当者 >> の技術担当者追加/編集画面で確認できます。
  • SMSメッセージは通知ルール > SMSテンプレートからカスタマイズできます。
  • "設定するには？" リンクをクリックすると各サービスプロバイダーでの設定方法が確認できます。
