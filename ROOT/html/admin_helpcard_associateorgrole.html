• Select the Role Type and Role Name.

  • Click on Import XLS option to import details from the excel sheet.

  • Click on Associate User to add a user to the role.

  • Select either the Multi Select Option or the Single Select Option.

  • If you want to assign multiple sites/departments/regions to a user, opt for the Multi Select Option.

  • If you want to individually assign users to site/department/region, opt for the Single Select Option.

Note: Multiple users cannot be assigned to a single role.

To edit/add an already existing role/user,

  • Search the Role/User by using the search box.

  • Use a "," followed by the search text to search the users using their email address and also to search sites/regions associated to the departments.

  • Click on Change User to change the user.

  • To delete the user's association with the role click on.
