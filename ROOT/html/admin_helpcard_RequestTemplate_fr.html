Vous pouvez personnaliser votre propre modèle de demande pour les demandes les plus courantes. Par ex. : problème d'imprimante ou de récupération d'e-mails. Une demande dont les champs sont pré-remplis peut être ainsi être créée plus rapidement. Pour créer un formulaire de modèle de demande personnalisé, cliquez sur le bouton Créer nouveau dans la page de liste des modèles de demande. Le formulaire de modèle de demande apparaît pour le technicien.

Le modèle de demande comporte trois sections : En-tête, Liste de champs et Canevas.

En-tête : L'en-tête contient le Nom du modèle, les Commentaires et les boutons Annuler et Rétablir.

Liste de champs : La liste des champs contient les différents champs et l'option pour en ajouter de nouveaux.

Canevas : Le canevas est une zone de glisser-déplacer réprésentant l'aspect final du formulaire.

Montrer au demandeur : Les modèles de demandeur peuvent être restreints à un groupe d'utilisateurs. Il vous suffit de cocher « Montrer au demandeur » et sélectionnez le groupe d'utilisateurs concerné dans la liste.  

 

Personnalisation du formulaire

Vous pouvez ajouter/supprimer des champs, configurer les propriétés des champs, réorganiser les champs du canevas et ainsi personnaliser un formulaire individuel pour chaque modèle de demande.

 

Ajouter un nouveau champ

Vous pouvez ajouter de nouveaux champs au canevas en déplaçant l'option Ajouter un nouveau champ dans la zone Glisser-déplacer. Sélectionnez le type de champ et ses informations dans la fenêtre Ajouter un nouveau champ. Cliquez sur Ok pour ajouter le champ dans la zone glisser-déplacer du canevas.

Ces nouveaux champs, ainsi que leur nom, sont communs à l'ensemble des modèles. Le nouveau champ peut être modifié à partir des Champs de demande supplémentaire.

 

Glisser et déplacer

Glissez le champ depuis la Liste des champs et déposez-le sur le canevas. Les zones disponibles seront mises à surbrillance. Seules ces zones seront à même de recevoir le champ déplacé.

Les champs du formulaire peuvent être réarrangés en les déplaçant sur une cellule vide. Seules les zones en surbrillance seront à même de recevoir le champ. La section contenant les informations du demandeur ne peut être déplacée qu'en bloc. Pour annuler/rétablir une modification, cliquez sur le bouton correspondant.

 

Propriétés du champ Paramètre

Vous pouvez personnaliser les champs État, Priorité et Mode en modifiant les propriétés des champs (à savoir rendre les champs obligatoires) ou en clôturant les champs. Vous pouvez, de cette manière, personnaliser le formulaire en conservant dans le canevas les champs appropriés au modèle correspondant. Pour personnaliser le formulaire, placez votre curseur sur le champ pour faire apparaître la priorité Modifier le champ et le bouton Clôturer le champ. Cliquez sur la propriété Modifier le champ. Une liste déroulante avec les options disponibles apparaît :

Champ obligatoire : Rendre le champ obligatoire en cochant la case d'option correspondante.

Remarque : Si le champ Élément est rendu obligatoire, la catégorie et la sous-catégorie le seront également. De la même manière, si les informations sur l'impact sont rendues obligatoires, le champ Impact le sera également.

Demandeur peut définir : Cette option permet au demandeur de modifier le champ, à savoir qu'il a la possibilité de saisir ou de sélectionner les valeurs du champ lors de la création d'une nouvelle demande. L'option « demandeur peut afficher » sera activée automatiquement.  

Demandeur peut afficher: Contrairement à l'option « Demandeur peut définir », cette option interdira aux demandeurs de saisir des valeurs pour ce champ lors de la création d'une nouvelle demande. Ils pourront en revanche consulter le champ dans la page d'informations de la demande.

Les champs sans propriétés (informations, sujet, description, etc) ne peuvent être que réarrangés dans le canevas.

 

Cliquez sur le bouton Clôturer le champ pour supprimer le champ du canevas et l'ajouter à la liste des champs. Les champs suivants ne possède pas l'option Clôturer le champ : état, priorité, description, sujet et informations sur le demandeur.

 

Prévisualisation de la demande

Vous pouvez consulter l'aperçu  des modèles de demande destinés aux techniciens comme aux demandeurs. Les demandeurs peuvent consulter le modèle de demande si « Montrer au demandeur » est coché. Vous pouvez également autoriser la consultation du modèle de demande à un groupe d'utilisateurs en particulier.

Cliquez sur le formulaire du modèle de demande sur la page de liste des modèles de demande. Le formulaire du modèle de demande pour un technicien s'ouvre par défaut. Vous pouvez déposer des champs dans le canevas, en ajouter, les réarranger et définir leurs propriétés.

 

Pour afficher le formulaire du modèle de demande pour un demandeur, cliquez sur l'onglet Demandeur dans le coin gauche supérieur de la page. La section d'en-tête sera grisée et non modifiable. Dans la page d'aperçu du demandeur, les champs ne peuvent être que réarrangés.

 

Les tâches liées à la demande peuvent être consultées dans l'onglet Tâches. Des tâches peuvent également y être ajoutées. Les tâches du modèle s'affichent. Cliquez sur le bouton Ajouter une tâche pour ajouter de nouvelles tâches.

 

Supprimer des champs

Dans la page de liste des modèles de demande, cochez la case du modèle à supprimer. Cliquez sur le bouton supprimer. Une fenêtre apparaît pour vous confirmer la suppression. Cliquez sur Ok pour continuer. Le modèle est supprimé de la liste. Le modèle sera grisé s'il est déjà utilisé par une demande et donc indisponible. Pour que le formulaire soit à nouveau disponible, décochez « Modèle non destiné à une utilisation ultérieure ».
