이 옵션을 사용하여 사건 요청서, 서비스 요청서 등 기본 옵션 이외의 요청서 유형을 구성할 수 있습니다. 이는 요청 모듈에서 새 요청을 생성할 때 필수적입니다. 새 요청 유형을 추가하려면 요청 유형 목록 페이지의 오른쪽 모서리에 있는 요청 유형 추가 링크를 클릭하십시오.

요청서 유형 추가

이름: 주어진 텍스트 필드에 해당 요청서 유형의 이름을 지정하십시오. 예: 사건, 정보 요청.

설명: 해당 요청서 유형에 대한 간략한 설명을 입력합니다.

저장을 클릭하여 저장하고 목록 보기 페이지로 돌아갑니다. 저장하고 새로 추가를 클릭하여 저장하고 다른 요청서 유형을 만듭니다.

 

요청서 유형 삭제

요청서 유형 목록 페이지에서 삭제할 요청서 유형 옆에 있는 확인란을 활성화합니다.

삭제 버튼을 클릭합니다. 삭제 오퍼레시션에 대한 확인 메시지가 나타납니다. 계속하려면 확인을 클릭하십시오. 요청서 유형이 목록에서 삭제됩니다.
