소프트웨어 업그레이드, 방화벽 정책 업데이트 또는 Windows 패치 업데이트와 같은 빈번한 서비스 릴리스를 위한 템플릿을 만듭니다. 각 템플릿에는 릴리스 관리에 필수적인 다양한 필드와 역할이 포함되어 있습니다.

릴리스 템플릿을 만들려면

  • 새 릴리스 템플릿 버튼을 사용하여 릴리스 템플릿을 만듭니다. 템플릿 양식의 필드를 사용자 지정하는 것 외에도 사용 가능한 필드와 역할을 추가하고 새 항목을 만들 수 있습니다. 필드를 섹션으로 그룹화하고 템플릿 레이아웃을 사용자 지정합니다. 템플릿을 미리 보거나 복사하려면 상단에 표시된 버튼을 사용하세요.
  • 햄버거 아이콘을 사용하여 릴리스 템플릿을 수정, 비활성화, 삭제하거나 기본 템플릿으로 표시할 수 있습니다. 그러나 기본 템플릿을 비활성화하거나 삭제할 수 없습니다.
  • 릴리스 템플릿을 일괄 삭제하려면 템플릿을 선택하고 삭제 아이콘을 클릭합니다.

참고 사항:

기본 템플릿은 삭제할 수 없습니다.

릴리스 템플릿이 릴리스하는 데 사용되는 동안 삭제되면, 해당 템플릿이 비활성화됩니다. 비활성 릴리스 템플릿을 편집하여 복원할 수 있습니다.
