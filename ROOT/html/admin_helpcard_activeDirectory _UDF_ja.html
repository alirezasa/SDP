依頼者のログインをActive Directory（AD）で認証するよう設定できます。

メモ：AD認証を設定する前に、依頼者のインポートを完了してください。ServiceDesk Plus内にユーザアカウントが存在する場合のみ、Active Directoryでのユーザアカウントとパスワードの認証が可能です。

Active Directoryから依頼者をインポート

  1. Active Directoryから依頼者をインポートリンクをクリックすると、Acrive Directoryからインポートポップアップページが表示されます。

  2. ドロップダウンリストからドメインの名称を選択します。Windowsドメインスキャンにて、ドメインコントローラや選択ドメインの認証情報を保存している場合は、同じ情報を自動的に表示します。

  3. 詳細が設定されていない場合は、ドメインコントローラの名称を入力します。例： winmasterログイン名とパスワードを入力します（入力必須フィールド）。

  4. Active Directoryからインポートするフィールドを選択します。インポートするフィールド（電話、部署、役職、携帯電話、サイトの名称、メールアドレス）のチェックボックスを有効にします。

  5. インポートするActive Directoryの属性を指定します。例：　電話番号がActive Directory属性の"telephoneNumber"に設定されている場合、テキストフィールドに telephoneNumber と入力します。

  6. デフォルトのフィールドの他にも、依頼者追加フィールドの値をActive Direcotryからインポートすることが可能です。依頼者追加フィールドを設定していない場合は、クリックして構成リンクから追加することができます。Active Directoryからインポートしたいフィールドを依頼者追加フィールドに設定します。設定した依頼者追加フィールド（テキスト/数値/日時フィールド）は、Active Directoryからインポートウィンドウにて、青、緑、赤の文字で表示されます。Enable the check box beside the requester additional fields to import, and specify the field name configured in active directory beside the selected field.未選択のフィールドはインポートされません。

Active Directoryの設定手順

デフォルトでは、AD認証は無効です。Active Directory認証のチェックボックスを選択します。

 依頼者としてAD認証でのログインが可能です。技術担当者としてログインするには、管理者は依頼者リストの技術担当者に技術担当者としてログインする権限を与える必要があります。

"Pass-through"認証 [Single Sign-On: SSO]
シングルサインオンを有効にすると、ServiceDesk PlusはWindowsシステムのユーザ名とパスワードを証明に利用することができます。そのため、ServiceDesk Plus固有のユーザ名とパスワードを毎回使用してログインする必要はありません。
 
ServiceDesk PlusのPass-through認証では、セキュリティメカニズムが向上したNTMLV2認証プロトコルとNETLOGONサービスを利用して認証を有効にしています。
 
Active Directoryから依頼者をインポート完了後、シングルサインオンを有効にできます。

  1. "Pass-through"認証の有効をチェックします。

  2. 特定のドメイン/ADフォレストからアクセスするユーザに対して、Pass-through認証を有効にするには、ドロップダウンリストからドメイン名を選択します。他のドメインユーザの認証を行う場合は、選択ドメインとの信頼関係があるか、または、親子関係である必要があります。親子関係の場合は、ドメイン名に親ドメインを選択します。

  3. ドメインのDNSサーバIPを指定。

  4. NTLM SSP（NTLMセキュリティサポートプロバイダ）を認証サービスとして使用するため、Active Directory内にパスワードを持つコンピュータアカウントを新規作成する必要があります。アカウントを作成するためにコンピュータアカウントとパスワードを指定します。

  5. バインドストリングパラメータには、Active Directoryサーバの完全修飾DNSドメイン名 or 特定のActive Directoryサーバの完全修飾DNSホスト名を指定します。

  6. 保存をクリックします。

メモ ：アクティブなユーザアカウントをコンピュータアカウントとして指定することはできません。

新しいコンピュータアカウントがActive Directory上に作成されます。アカウントの作成にはVBスクリプトを補助的に用いることもあります。もし、既存のコンピュータアカウントを指定すると、Active Directory上のコンピュータアカウントのパスワードがリセットされます。コンピュータアカウントのパスワードをリセットする場合は、パスワードのリセットリンクをクリックします。

ServiceDesk PluサーバからのVBスクリプト（保存時に自動的に呼び出される）による新規コンピュータの作成とパスワードのリセットに失敗した場合でも、アカウントの詳細はServiceDesk Plus上に保存されます。なお、失敗した場合は、Active Directoryサーバのローカル上でスクリプトを再度実行して、同じコンピュータアカウントの作成/パスワードのリセットを行ってください。

コンピュータアカウントの作成に問題がある場合は、既存のコンピュータアカウントを利用します。パスワードのリセットスクリプトでコンピュータアカウントのパスワードをリセットしてください。

 

ADインポートのスケジュール

指定した日数でアクティブディレクトリのインポートをスケジュールすることが可能です。

ADインポートのスケジュールチェックボックスを選択します。テキストボックスに日数を指定します。保存ボタンをクリックします。設定した日数ごとに、ドメインから依頼者情報が自動的にインポートされます。
