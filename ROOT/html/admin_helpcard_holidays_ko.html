다양한 사이트에 위치한 조직의 휴일 목록을 추가하고 볼 수 있습니다. 근무 시간과 함께 이 정보는 해당 요청서에 적용되는 우선 순위 또는 SLA에 따라 서비스 요청서의 예상 완료 시간을 계산하는 데 사용됩니다.

특정 사이트의 공휴일을 보려면 공휴일 목록 페이지의 휴일 콤보 상자에서 사이트를 선택합니다.

새 휴일을 추가하려면 휴일 콤보 상자에서 휴일을 추가하려는 사이트를 선택합니다. 휴일 목록 표의 오른쪽 모서리에 있는 새 휴일 추가 링크를 클릭합니다.

Note:

  1. 휴일 콤보 상자에서 사이트를 선택하지 않으면 기본 설정 아래에 휴일이 추가됩니다.< /p>

  2. 관리 사이트에서 사이트를 구성하지 않은 경우 휴일 콤보 상자가 표시되지 않습니다.

  3. 사이트 관리자는 휴일 콤보 상자에서 연계된 사이트에 휴일을 추가하고 볼 수 있습니다.

  4. 특정 사이트의 공휴일이 다른 사이트의 설정을 참조하는 경우 사이트 변경 시 선택한 사이트의 참조 사이트를 나타내는 팝업이 표시됩니다. 삭제할 사이트에 구성된 휴일이 하나 이상의 사이트에서 참조되는 경우 사이트 삭제 프로세스 중에 삭제할 사이트가 참조하는 휴일과 함께 나열됩니다. 참조 사이트의 설정을 선택하여 기본 설정을 참조하거나 필요한 다른 사이트 설정으로 변경할 수 있습니다.

새 휴일 추가

날짜 필드 옆에 있는 캘린더 아이콘을 호출하여 날짜를 선택합니다. 필수 입력란입니다.

설명 텍스트 필드에 휴일의 중요성에 대한 간략한 설명을 입력합니다.

연말연시인 경우 1월 1일st(새해 일)을 선택한 다음 정기 휴일인지 확인 옆의 확인란을 선택합니다. 이 확인란을 활성화하면 매년 휴일을 추가할 필요가 없습니다.

저장 버튼을 클릭합니다. 휴일은 지정된 사이트에 저장됩니다. 휴일을 저장하고 다른 휴일을 추가하려면 저장 및 새로 추가 버튼을 클릭하세요.
