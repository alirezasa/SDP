Impact
 
L’impact est une mesure de l’influence d’un incident ou d’un problème sur l’activité. L’impact est souvent mesuré par le nombre de personnes ou de systèmes affectés.
Par défaut, cette liste compte quatre descriptions d’impacts. Pour modifier les détails d’un impact, cliquez sur leur titre.
 
Ajouter un nouvel impact
 
Cliquez sur le lien Ajouter un nouvel impact, sur la droite de la page. La page Ajouter - Impact s’affiche.
Indiquez le Nom de l’impact dans le champ de texte prévu à cet effet.
Précisez les détails de l’impact dans le champ Description prévu à cet effet.
Enregistrez les modifications.
Cliquez sur le bouton Enregistrer et ajouter nouveau pour enregistrer l’impact et en ajouter un autre.
