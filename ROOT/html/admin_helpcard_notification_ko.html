알림 규칙

알림 규칙은 이벤트가 기술자에게 알려야 할 때 유용합니다. 예를 들어 구매 주문이 기한이 지난 경우 검색 중 감사 변경 사항에 대해 관리자에게 알리거나 검색 중에 금지된 소프트웨어 애플리케이션이 식별되거나 자산 보증이 만료되려고 할 때 알립니다.

이러한 상황을 적절하게 관리하면 기술자가 자산을 효율적으로 관리하는 데 도움이 될 뿐만 아니라 조직의 비용 절감 효과도 얻을 수 있습니다.

알림 규칙 활성화

알림 규칙은 자체의 이름으로 설명이 가능하며 모듈(자산, 구매, 계약)별로 그룹화되어 각 탭 아래에 배치됩니다. 규칙을 활성화하려면 원하는 알림 규칙에 대해 적절한 확인란을 선택합니다. 일부 기술자 관련 알림의 경우 기술자를 지정하거나 알림을 보낼 이메일 주소를 지정할 수도 있습니다.


기술자를 선택하려면 기술자 선택 콤보 상자를 클릭하고 원하는 기술을 선택하십시오. 드롭다운 목록에서 기술자를 검색하거나 이름으로 기술자를 검색합니다.

특정 이메일 주소로 알림을 보내려면 해당 필드에 이메일 주소를 입력하십시오. 쉼표로 구분합니다. (예: 그룹 이메일 주소, 기술자가 아닌 사용자, 대체 기술자 등)

    • 지원되는 각 알림 규칙에 대해 최대 25개의 이메일 주소를 추가할 수 있습니다.
    • 자산 알림의 경우 최소 한 명의 기술자 또는 하나의 이메일 주소가 필수입니다.

자산 만료, 보증 만료 및 대여 기간 만료와 관련된 알림의 경우 아래와 같이 추가 세부정보를 제공합니다.

    • 이전 알림: 알림이 지정된 날짜 이전에 미리 보내야 하는 날짜 수를 지정하는 1에서 90 사이의 값을 입력합니다. 필수 입력란입니다.
    • 이후 알림: 알림을 지정된 날짜 이후에 보내야 하는 일 수를 지정하는 1에서 90 사이의 값을 입력합니다. 필수 입력란입니다.
    • 빈도: 반복 알림을 위해 각 알림 사이의 일 수를 지정하여 구성합니다.

요구 사항에 따라 알림 템플릿을 사용자 지정할 수도 있습니다. 이렇게 하려면 템플릿을 사용자 정의하려는 알림에 대해 템플릿 사용자 정의를 클릭합니다. 템플릿 편집기에서 필요에 따라 알림 제목과 메시지를 수정합니다. 또한 필요한 경우 변수를 사용합니다. 변수를 삽입하려면 $를 입력하고 메시지 편집기에서 필요한 변수를 선택하십시오.

변수 값은 선형 텍스트 또는 테이블 형식 데이터일 수 있습니다. 자산 알림에서 테이블 형식 데이터를 표시하는 변수는 특정 열을 표시하도록 사용자 지정할 수도 있습니다. 이렇게 하려면 변수 옆에 있는 열 선택기 아이콘을 클릭하고 필요에 따라 열을 선택/선택 취소합니다.

참고 사항:

    • 자산 알림에서 테이블 형식 데이터를 지원하는 변수에 대해 영어가 아닌 열을 선택할 수 있지만 이메일 알림에서는 영어로 표시됩니다.
    • 표 형식 데이터 변수의 경우 열 선택기에 일부 기본 필드와 자산/워크스테이션 추가 필드가 나열됩니다. 필드의 값은 자산 유형에 따라 이메일에 표시됩니다.

변경사항을 적용하려면 저장을 클릭하십시오.

참고 사항: 기술자에 대한 알림은 일반적으로 이메일을 통해 전송되므로 보내는 메일 서버 설정이 먼저 구성되어 있어야 합니다.
