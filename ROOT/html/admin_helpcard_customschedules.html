Custom Schedules enable you to access any data from ServiceDesk Plus and schedule periodic customized actions such as sending notifications, reopening requests or updating asset details. You can specify the actions in a customized script file. ServiceDesk Plus data can be sent to these scripts using Query Reports.

Use the pointers below to create a custom schedule:

Schedule Details: Enter a unique Schedule Name and a relevant Description to explain what the custom schedule action does. You can enable/disable a custom schedule as preferred.

Executor: Specify the action to be executed using scripts. You can execute your script using a third-party application or you can use Zoho's inbuilt propriety scripting application, Deluge.

  • Execute Script - Specify the name of the text file containing the script and save it under [SDP_Home]/integration/custom_scripts/executor_files directory. The application will fetch and execute the script from the specified file
    • [SDP_Home]/integration/custom_scripts/ folder. In the text field, specify the script file name using the command py filename.py to fetch the script.
  • Execute Custom Functions - Create and save your own scripts using Deluge in Custom Schedule Function. Choose the relevant script from the drop-down. You can also create a custom schedule function from the drop-down.
    • Click here to learn how to create a script using Custom Schedule Function.

Arguments: Select the Query Report whose data is used to pass arguments. Ensure that the reports are stored in a folder under the Reports tab. You can associate up to 3 query reports.

How are query reports converted as arguments?

When a schedule starts, the associated query reports will be generated and the results will be saved in a directory under [SDP_Home]/integration/custom_schedule_reports/ as a JSON file. This JSON file path is passed as an argument to the Custom Schedule Executor.

Let's assume the query report SLA Violated Requests by High Priority gives the following result:

Request ID Subject Technician
47 Unable to fetch mails Heather Graham
128 Cannot connect to MSSQL server Shawn Adams

The result JSON will have the following format:

[
    {
        "Request ID":"47",
        "Subject":"Unable to fetch mails",
        "Technician":"Heather Graham"
    },
    {
        "Request ID":"128",
        "Subject":"Cannot connect to MSSQL server",
        "Technician":"Shawn Adams"
    }
  ]

After the action is executed, the JSON file will be deleted.

From: You can start executing the custom schedule by selecting a date range and time from the calendar icon. If the selected date and time is earlier than the created/edited time of the custom schedule, the action will be executed immediately after saving the custom schedule.

Repeats: Choose the frequency to repeat the custom schedule from the drop-down: once, daily, weekly, monthly, or yearly.

Advanced Options: Set the duration to repeat the schedule. Depending on the selected Repeats frequency, you can choose the required day/month to run the schedule.

Repeats Ends: Set when the repeat frequency ends. You can configure the schedule never to end, end after a specified number of occurrences, or on the specified date.

Note

The Result column in the Custom Schedules list view has the latest output of the corresponding action.

Detailed results of the executed action can be viewed in the System Log Viewer under Quick Actions or from the Community tab.
