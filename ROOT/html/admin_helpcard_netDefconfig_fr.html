Avec l'analyse planifiée, vous pouvez programmer une analyse périodique de votre réseau, mettre en place un nettoyage régulier des informations analysées et définir l’intervalle d’analyse des stations de travail. Pour configurer une analyse régulière, sélectionnez la case Analyse programmée activée. Ensuite, définissez la périodicité selon laquelle vous voulez que l’analyse programmée soit effectuée.

Scannage programmé activé
Sélectionnez l’un des 5 boutons Radio du sous-titre Analyse programmée activée, expliqué ci-dessous :

Analyse unique
Sélectionnez la date et l'heure de l'analyse. L'analyse ne sera effectuée qu'une fois à la date et l'heure indiquées.

Analyse quotidienne
Sélectionnez l'Heure (en heures et minutes) de l'analyse quotidienne. Sélectionnez ensuite la Date à laquelle l'analyse quotidienne doit commencer.

Analyse hebdomadaire
Cochez le jour de la semaine auquel l'analyse doit être effectuée. Indiquez ensuite l'Heure (heures et minutes) de l’analyse. Vous pouvez également rendre l'analyse quotidienne en cochant Tous les jours.

Analyse mensuelle
Cochez Tous les mois dans l'option d'analyse mensuelle pour la définir comme telle tout au long de l'année. Vous pouvez également choisir les mois durant lesquels l'analyse sera effectué en cochant les cases correspondantes. Sélectionnez ensuite le Jour ou la Date d'exécution de l'analyse. Indiquez finalement l'Heure (heures et minutes) de l’analyse.

Analyse périodique
Vous pouvez saisir une période aléatoire durant laquelle l’analyse sera reproduite. Saisissez le nombre dans le champ affiché. L’analyse sera effectuée tous les « n » jours où « n » est le nombre que vous aurez indiqué dans le champ.

Nettoyage de l'historique du scan activé

Vous pouvez activer un nettoyage régulier des informations analysées, sélectionnez la case Nettoyage de l'historique des analyses activé et, dans le champ prévu à cet effet, indiquez un nombre de jours. Les informations antérieures seront supprimées.

Vérifier les nouvelles stations de travail ajoutées
Vous pouvez également chercher si de nouvelles stations de travail ont été ajoutées en effectuant une nouvelle analyse de votre réseau. Pour cela, sélectionnez la case Vérifier les nouvelles stations de travail ajoutées puis saisissez le nombre de jours auquel la nouvelle analyse de votre réseau sera effectuée.

Pour enregistrer les informations saisies, cliquez sur Enregistrer.
