이 기능을 사용하면 자신의 스크립트를 사용하여 요청서 페이지의 액션 메뉴를 사용자 지정할 수 있습니다. 다른 액션업 메뉴를 만들고 사용자 정의 클래스 또는 스크립트 파일을 메뉴와 연결하여 관련 액션을 실행할 수 있습니다. 여기에서 만든 메뉴는 요청서 세부정보 페이지의 액션 메뉴 아래에 나열됩니다.

새 메뉴 추가

새 메뉴를 만드는 동안 다음 세부 정보를 제공해야 합니다.

메뉴 이름: 생성 중인 메뉴의 유일한 이름을 지정합니다(메뉴 이름은 요청서 페이지의 액션 메뉴 아래에 표시됩니다)

설명: 메뉴의 목적을 나타내는 적절한 설명을 입력합니다.

역할 연계: 이 메뉴에 액세스할 기술자 역할을 결정합니다(선택 옵션: 모든 역할 또는 '선택한 역할')

템플릿 연계: 템플릿을 선택하면 이 메뉴가 표시됩니다(선택 가능한 옵션: '모든 템플릿', '모든 인시던트 템플릿, '모든 서비스 템플릿'(또는) '선택한 템플릿 ')

사용자 정의 HTML 파일: 메뉴가 호출될 때 사용자 정의 HTML 파일을 로드하려면 html 파일을 "[SDP_Home]/Integration/resources/" 디렉토리에 배치해야 합니다. 확장자가 htt/htx/htm/html/htmls인 파일은 호출에만 지원됩니다. 또한 JavaScript 및 CSS와 같은 종속성 파일은 동일한 위치에 배치되어야 합니다.

액션 유형 선택:

액션 유형 드롭다운에서 '스크립트 실행' 또는 '클래스 실행' 옵션을 선택합니다. '클래스 실행' 옵션을 선택한 경우 제공된 필드에 Executor 클래스를 지정해야 합니다. 예: "com.servicedeskplus.integration.JiraActionImplementation". '스크립트 실행' 옵션을 선택한 경우 지정된 필드에 스크립트가 포함된 텍스트 파일의 파일 이름을 지정해야 합니다. 애플리케이션은 [SDP_Home]/integration/custom_scripts/executor_files 디렉토리에 저장된 언급된 텍스트 파일에서 스크립트를 가져옵니다.

사용자 정의 스크립트/클래스에 대한 인수를 전달할 수도 있습니다. 모든 API 매개변수는 인수로 지원됩니다. 

예 

스크립트의 경우 : cmd / c 색인. bat $COMPLETE_V3_JSON_FILE

클래스의 경우  : com.servicedeskplus.integration.JiraActionImplementation

지원되는 기타 매개변수 중 일부

$COMPLETE_V3_JSON_FILE ---> 전체 요청서 개체는 JSON 파일에 저장되고 파일 경로는 문자열 개체로 전달됩니다.

JSON 파일 경로  : (SDP_Home\integration\custom_scripts\request\12_1426143538036.json) .

$HTML_DATA_JSON_FILE ---> Ajax call request "data" 매개변수는 메뉴 이름, 요청 json 및 xml 파일 경로와 함께 JSON 파일에 저장되고 파일 경로는 String Object로 전달됩니다. 사용자 정의 HTML 파일과 함께 사용됩니다. 예: (SDP_Home\integration\custom_scripts\request\12_1426143538036.json).

$HANDSHAKE_KEY ---> Handshake 키는 String Object로 전달됩니다.

저장을 클릭합니다.

이제 메뉴가 만들어지고 요청 세부정보 페이지의 액션 메뉴에서 볼 수 있습니다.
