CSV에서 CI 가져오기 옵션을 사용하면 기존 데이터베이스에서 CI를 즉시 가져올 수 있습니다. CI 이름은 선택한 모든 CI 유형에 대해 필수입니다.   

1단계: 가져올 CI의 CI 유형을 선택합니다. 파일 선택기 창에서 해당 CSV 파일을 찾습니다. 열기를 클릭합니다. 파일 경로는 CSV 파일 찾기 필드에 자동으로 나타납니다. 제출 버튼을 클릭합니다.

2단계: 모든 날짜 필드가 나타내는 형식을 선택합니다. CSV 파일의 필드 이름으로 CI 필드를 매핑합니다. 추가 속성이 구성되어 있으면, 해당 속성이 사용자 정의 매핑 양식에 나타납니다. 가져오기를 클릭합니다.

참고 사항: 1단계에서 선택한 CI 유형이 상위이고 csv 파일의 CI 행이 하위 CI 유형에 해당하는 경우 사용자 정의 매핑 양식에서도 동일하게 매핑할 수 있습니다. csv 파일의 하위 CI 유형에 대해 지정(표시)된 값은 CI 유형을 구성하는 동안 이미 추가되어 있어야 합니다.  

완료 시, 전체 CI의 데이터 수, 가져온 CI 수 및 가져오기에 실패한 CI 수가 표시됩니다.

CI를 가져오는 동안 실패 기록이 있는 경우 동일한 CSV 파일을 다시 가져오지 마십시오. 대신 가져온 결과 페이지에서 사용할 수 있는 FailedCIsList.csv를 다운로드하고 오류를 수정한 다음 CI가 중복되지 않도록 가져오기를 시도하십시오.
