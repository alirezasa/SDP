Vous pouvez définir les champs propres à votre organisation qui doivent apparaître dans le formulaire de nouveau problème en plus des champs prédéfinis qui ont été fournis par défaut. Vous pouvez ajouter des champs de type texte, des champs de type numérique et des champs de type date dans le formulaire. Sélectionnez chacun des onglets et ajoutez le nom du libellé et la description de chacun des champs que vous voulez ajouter au formulaire de nouveau problème.

Lors de l’ajout de champs texte, vous disposez d’une option pour choisir le type de champ de texte. Il peut s’agir d’un champ de texte à une seule ligne, à plusieurs lignes ou d’une liste déroulante. Sélectionnez les boutons d’option Une seule ligne, Plusieurs lignes ou Liste déroulante.

Si vous voulez ajouter une valeur par défaut pour ces champs, vous pouvez le faire dans le champ de texte prévu à cet effet.

Pour enregistrer les informations saisies, cliquez sur Enregistrer.
