Une organisation peut établir des relations commerciales avec un ou plusieurs fournisseurs en vue de l’achat de ressources diverses pour l’organisation. Il est donc essentiel de tenir un registre incluant chaque fournisseur et une liste de produits vendus par un fournisseur particulier. Pour ajouter un nouveau fournisseur, cliquez sur le lien Ajouter un nouveau fournisseur dans le coin droit du tableau Liste des fournisseurs.

Ajouter un nouveau fournisseur
Le formulaire Ajouter un fournisseur est composé de plusieurs champs dans trois sections principales : Détails du fournisseur, Adresse et Info sur le contact. Le Nom du fournisseur est le seul champ obligatoire.

Les Détails du fournisseur comportent trois champs : Nom, Description et Interlocuteur. Saisissez le nom de l’entreprise du fournisseur où vous achetez l’équipement. Saisissez un bref profil du fournisseur dans le champs Description. Saisissez le nom ou l’adresse électronique d’identification de l’interlocuteur du site du fournisseur dans le champ Interlocuteur.

Renseignez les champs restants : Adresse, Ville, Code postal, État, Pays, ID de messagerie, Téléphone, Télécopie et Adresse URL Internet.

Cliquez sur le bouton Enregistrer pour enregistrer les informations sur le fournisseur et continuer à jouter des produits pour ce fournisseur. Un onglet Produits est ajouté. Il permet d’ajouter la liste des produits vendus à votre organisation par le fournisseur. Pour associer des fournisseurs au produit, cliquer sur Produits puis sur le bouton Produit associé.

Pour enregistrer le fournisseur et en ajouter un autre, cliquez sur le bouton Enregistrer et ajouter un nouveau. Dans ce cas, vous devez associer les produits en allant au fournisseur spécifique à partir de l'affichage liste, puis en cliquant sur l’onglet Produit dans fenêtre Fournisseur, puis en cliquant sur le bouton Associer un produit.

Associer un produit
Le formulaire Produit associé regroupe six champs : Nom de fournisseur, Nom de produit, Prix, Période de garantie, Fournisseur de maintenance et Commentaires. Parmi ces champs, le Nom du produit et le Prix sont des champs obligatoires dont la valeur ne peut être nulle. Le nom de fournisseur est un champ d’affichage non modifiable.

À partir de la liste des produits disponibles dans la liste déroulante, sélectionnez le produit de votre choix pour le champ Nom du produit.

Saisissez le prix évalué par le fournisseur pour le produit ci-dessus dans le champ Prix.

S’il existe une Période de garantie donnée par le fournisseur, sélectionnez-la.

Si le produit nécessite un entretien particulier, choisissez Fournisseur de maintenance dans la liste déroulante.

Écrivez tous les Commentaires utiles pour les informations sur le produit et le fournisseur ci-dessus.

Pour enregistrer les informations saisies, cliquez sur Enregistrer.
