사용자 정의 기능을 사용하면 AssetExplorer 및 기타 외부 애플리케이션에서 데이터를 조작할 수 있습니다. 사용자 정의 기능은 Zoho의 적절한 스크립팅 언어인 Deluge를 기반으로 합니다.

전역 함수는 필요할 때마다 사용자 정의 작업을 변경하고 요청에서 호출할 수 있는 사용자 정의 함수입니다. 외부 애플리케이션, 공통 기능 및 구성과 연결하는 데 필수적인 정보를 저장할 수 있으며, 이 모든 정보는 요청 및 사용자 지정 액션에서 호출할 수 있습니다.

새로 만들기 버튼을 사용하여 전역 함수를 만듭니다. 삭제 버튼을 사용하면 전역 기능을 제거할 수 있습니다. 전역 함수를 수정하거나 삭제하려면 사용자 정의 함수 옆에 있는 아이콘을 사용하십시오.

키워드를 사용하여 제공된 필드에서 전역 기능을 검색합니다.
