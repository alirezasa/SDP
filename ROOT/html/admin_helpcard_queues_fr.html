Classez votre équipe d'assistance en plusieurs groupes d'assistance. Chaque groupe d'assistance peut comporter un groupe de techniciens en charge de demandes spécifiques. Les demandes entrantes peuvent également être classer et distribuer selon l'expertise des techniciens.

Vous pouvez, de plus, configurer les paramètres de messagerie pour chaque groupe d'assistance. Ainsi, lorsqu'un e-mail est envoyé à l'adresse de messagerie d'un groupe, la demande est récupérée et envoyée automatiquement au groupe.

Vous pouvez également envoyer des notifications aux techniciens à la réception d'une nouvelle demande, ou si une demande n'a pas été récupérée. Si des sites sont configurés, les groupes d'assistance de chaque site peuvent être consultés dans la liste déroulante Groupes d'assistance pour.

Ajouter nouveau groupe

Pour ajouter un nouveau groupe à un site, sélectionnez ce site dans le menu déroulant Groupes d'assistance pour. Cliquez sur le lien Ajouter un nouveau groupe dans l’angle droit du tableau Liste des groupes.  

Nom : Renseignez un nom unique pour identifier le groupe d'assistance.

Site : Le site du groupe d'assistance créé apparaît dans un champ de texte non modifiable. Ce champ n'apparaît que lorsque des sites sont configurés.  

Techniciens : Associer des techniciens à ce groupe. Sélectionnez les techniciens dans la liste Techniciens disponibles et cliquez sur le bouton Assigner (>>). Pour la sélection de plusieurs techniciens, utilisez la touche Ctrl ou Shift.

Notifications : Vous pouvez activer l'envoi de notifications au groupe de techniciens ci-dessus lorsqu'une nouvelle demande est ajoutée au groupe, ou aux techniciens disponibles dans votre assistance pour les informer qu'une demande du groupe n'est pas attribuée. Cochez les cases correspondantes et choisissez le technicien. En fonction de vos besoins, vous pouvez activer les cases ou sélectionner n’importe lequel ou aucun.

Description : Donnez une brève description du groupe d'assistance dans le champ Description. Cela aidera à connaître le type de requêtes groupées dans ces file d’attente et par conséquent à affecter des techniciens à cette file d’attente.

Paramètres de messagerie du groupe : Saisir l'Adresse de messagerie du groupe assignera automatiquement le ticket entrant au groupe. Si un groupe d'assistance comporte plusieurs adresses de messagerie, celles-ci doivent être uniques et séparées par des virgules/points-virgules. Le Nom de l'expéditeur et l'Adresse de messagerie de l'expéditeur seront renseignés lors de l'envoi d'e-mails.  

Pour enregistrer le groupe d'assistance et revenir à l’affichage liste, cliquez sur le bouton Enregistrer.
