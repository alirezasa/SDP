Modification - Champs supplémentaires vous permet d'ajouter des champs supplémentaires au formulaire de nouvelle modification, en plus des champs pré-remplis par défaut. Vous pouvez ajouter des champs de type Texte, des champs de type Numérique et des champs de type Date/heure dans le formulaire. Sélectionnez chaque onglet et ajoutez le Nom du libellé et la Description des champs à ajouter du formulaire de nouvelle modification.

Lors de l'ajout de champs de texte, vous pouvez choisir son type : Une seul ligne, Plusieurs lignes ou Liste déroulante. Vous pouvez également ajouter des valeurs par défaut à ces champs. Ils seront pré-remplis dans le formulaire.

Cliquez sur le bouton Enregistrer.

Remarque : Pour rendre les champs supplémentaires disponibles dans le formulaire de nouvelle modification, vous devez configurer les champs dans le Modèle de modification.
