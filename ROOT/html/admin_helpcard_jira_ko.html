SDP-JIRA 통합:

ServiceDesk Plus (SDP) - JIRA 통합은 기술자가 선호하는 사건 유형을 사용하여 JIRA에서 그 사건 유형으로 SDP 요청서를 생성하는 데 도움이 됩니다.


SDP에서 JIRA 설정 구성:
  • 현재 JIRA 애플리케이션을 실행 중인 서버 이름과 서버 포트 번호를 입력하고 http 및 https 프로토콜 설정 중에서 하나를 선택합니다.
  • JIRA 관리자 자격 증명(사용자 이름/패스워드)을 입력하고 구성을 저장합니다. 패스워드는 암호화되어 데이터베이스에 안전하게 저장됩니다.
  • 저장을 클릭하여 설정을 저장합니다.
JIRA 통합에 대한 자세한 내용을 보려면 여기를 클릭하십시오.
