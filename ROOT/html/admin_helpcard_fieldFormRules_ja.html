フィールド&フォームルールにより、リクエストフォームで実行するルールを定義します。フィールド & フォームルールは、リクエストフォームがロードされてから送信される前にクライアントサイドで実行されます。サーバーサイドでは実行されません。ルールは無効／有効にでき、無効にしたルールは適用されません。

フィールド & フォームルールでは、次のイベントに対応しています:

フォームロード時

リクエストフォームをロードしたときに実行します。このイベントで定義したルールは、少なくとも一つ以上の実行するアクションに設定します。アクションは基準をチェックした後に実行され、基準が定義されていない場合は、定義済みのアクションがそのまま実行されます。

フォーム変更時

フィールド値を変更したときにルールを実行します。このイベントで定義したルールは、少なくとも一つ以上の実行するアクションに設定します。アクションは基準をチェックした後に実行され、基準が定義されていない場合は、定義済のアクションがそのまま実行されます。

フォーム送信時

リクエストフォームが送信されたときにルールを実行します。このイベントで設定できるのは、スクリプトの実行のみです。このイベントで定義したルールは、有効なスクリプトを含みます。アクションは基準をチェックした後に実行され、基準が定義されていない場合は、定義済のアクションがそのまま実行されます。


ユーザーに適用

ルールは、依頼者、技術担当者、またはすべてのユーザーに対して適用できます。依頼者だけに適用したルールを技術担当者へ適用することはできません。その逆も同様です。


ルールの実行

新規リクエストの作成時、既存リクエストの編集時、またはその両方の操作時にルールを実行できます。


他のテンプレートにルールをコピー

コピールールを使用すると、一つ以上のルールをテンプレート間でコピーできます。ルールのコピー中にコピー先のテンプレートに該当するフィールドが存在しない場合は、フィールドはコピーされません。同様に基準やアクションをコピーできないルールはコピーされません。


リクエストフォームからフィールドを削除

テンプレートからフィールドを削除すると、テンプレートに定義されたルールからそのフィールドを自動で削除します。これらのフィールドを削除した後に、ルールに基準やアクションが残っていない場合、そのルールは削除されます。


次のアクションは、フィールド&フォームルールでサポートされています:

Show Fields/フィールドを表示する : 適用されるリクエストフォームで定義されたフィールドを表示します。

Hide Fields/フィールドを非表示にする : 適用されるリクエストフォームで定義されたフィールドを非表示にします。

Enable Fields/フィールドを有効にする : 適用されるリクエストフォームで定義されたフィールドを有効にします。ユーザーは、これらのフィールドを編集できます。

Disable Fields/フィールドを無効にする : 適用されるリクエストフォームで定義されたフィールドを無効にします。ユーザーは、これらのフィールドを編集できません。

Mandate Fields/フィールドを必須にする : 適用されるリクエストフォームで定義されたフィールドを必須入力にします。ユーザーは、これらのフィールドに値を入力しないとフォームを送信できません。

Non-Mandate Fields/フィールドを任意にする : 適用されるリクエストフォームで定義されたフィールドを任意入力にします。ユーザーは、これらのフィールドに値を入力しなくてもフォームを送信できます。

Execute Script/スクリプトを実行する : リクエストフォームのスクリプトを実行します。スクリプトは、有効なJavaScriptコードで記述し、その他の記述では実行できません。スクリプトの実行には、デフォルトメソッドとしていくつかのメソッドをサポートしています。例えば、カテゴリーやレベルフィールドを非表示にするために、フィールド配列を引数として次のメソッドを呼び出すことができます。 例:$CS.hideField(["CATEGORY","LEVEL"]);

Add Options/オプションを追加する : リクエストフォームのピックアップ／複数選択／チェックボックスフィールドにオプションを追加します。フィールドにアクセスし、後でオプションを選択できます。

Remove Options／オプションを削除する : リクエストフォームのピックアップ／複数選択／チェックボックスフィールドに追加されたオプションを削除します。

Set Fields／フィールドを設定する : リクエストフォームで必要なフィールドの値を設定します。

Clear Fields／フィールドをクリアする : 適用されているリクエストフォームのフィールドをクリアにします。
