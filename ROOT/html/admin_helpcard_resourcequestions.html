You can create resource questions to collect additional information about the requested service. Resource questions can be associated with multiple service templates via resource sections.

In the resource questions list view, active resource questions are displayed by default. Click Associated Resources Sections to view the sections associated with a resource question.

Add Resource Questions

You can create four types of resource questions: plain text, check box, radio, and drop down.

To allow the users to enter an individual answer, along with a single line of text, create a plain text resource question:

  1. Click New Question.

  2. Choose Plain Text.

  3. Enter the name of the question.

  4. In accordance with the GDPR Regulations, you can mark if your resource question includes personally identifiable information (PII). This will be crucial in protecting user data.

  5. Click Save.

Alternatively, you can provide a range of options and prompt your user to select from the provided choices by creating check box/radio/drop-down questions:

  1. Click New Question.

  2. Choose Check Box to allow your users to select multiple resources for a single question. To restrict the answer to a single choice, select Radio or Drop-Down.

  3. Enter the name of the question.

  4. In accordance with the GDPR Regulations, click the checkbox and mark if your resource question includes personally identifiable information (PII). This will be crucial in protecting user data.

  5. Select the option type between manual, product or software.

    6. Note: Resource Question option type cannot be modified between Product, Software, and Manual once created. Click Save and Add options.


    Click Save and Add options.

  6. You can add the choices for your users to select from in 3 ways:

    1. Add choices manually - Enter your choice in the Option text box, add the cost of the choice, and click the add icon.

    2. Import from XLS file - Import your choices and their cost from an XLS file. The sheet number is auto-populated. Map the Name and Cost fields to the relevant columns in the XLS file and click Import.

    3. Select from the assets present in the application - Select the product type and use the arrow icon to move the option to the selected options area.

  7. Select Enable Cost to display the cost of each resource to your users. If selected, you must add the cost for at least one resource option.

  8. Select Enable Image to add a reference picture to each resource in the Manual option type..

    • If images are enabled, you can only add options manually using the New Option button.

    • Enter the option and cost.

    • Upload a picture from your device. The picture can be in .jpg, .png, .jpeg, .bmp formats. You can add up to 5 images for a resource question. Note that the file size should not exceed 5MB.

    • Add a description in the editor text box, if needed.

    • Click Save or Save and Add New.

  9. Use the Type drop down to change the resource question type anytime without resetting the data you added.

  10. Click Save to create the question.

Edit Resource Questions

Hover over the resource questions and click the menu list icon to edit a resource question. Edits made on a resource question will be reflected in all the resource sections and request templates associated with it.

In requests, where the resource information is already recorded, the edits will not affect the request details unless the request is edited.

Delete Resource Questions

Hover over the resource questions and click the menu list icon to delete a resource question.

  • If a resource question is not associated to a request template, it will be deleted permanently.

  • If the resource question is currently in use, it will be moved to an inactive state until it is disassociated completely. Apply Inactive Question filter to view the deleted resource questions.

You can activate inactive questions by selecting Activate question to edit option while editing them.

Note:
If only one resource question with no active options and is present in a resource section:

  • The resource section will be deleted if the resource question is deleted

  • The resource section will be marked as inactive if the resource question is deleted while it is used in a request.
