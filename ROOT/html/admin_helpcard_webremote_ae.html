Web Remote is an inbuilt tool to facilitate remote sessions on client machines (windows machines). The tool can be used from the application without being installed in the client's machine. It also features the session capture and replay option. Web Remote will function as a separate service running on a default port 8083. The default port can be changed by configuring the port number.

To know more about the web remote click here

Using Web Remote

  • Server Name of the workstation will be populated automatically.
  • Enter the Server Port number.
  • If you want to record the remote session, tick the 'Enable record session' checkbox.
  • To enable Web Remote, tick on 'Enable web remote' check box.
  • Enter the Web Remote Port number. The default port is set at 3389.
  • Click Submit.
