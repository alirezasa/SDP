On this page, you can automate custom module workflow by creating custom triggers. Triggers can be configured to work based on user input. Define actions to be executed on custom module records that satisfy specific conditions. You can categorize and execute custom triggers in different trigger groups.

    To create a new trigger group, click Trigger Group and provide the required details.

    To add a new custom trigger to the group, hover over the group and click Add Trigger.

  • Select whether the trigger must be executed - when the record is created, edited, moved to trash, or deleted permanently.
  • Specify the conditions to be met.
  • If the trigger is set to execute when the record is edited and based on conditions, you can choose to execute the trigger:
    • Every time the record is edited.
    • Only when the fields configured in the conditions are edited.
  • Choose the action to be executed on records via the trigger - field update, custom function, or execute scripts.

    • List View Actions

    You can organize custom triggers and trigger groups, configure cascade execution, and move triggers across groups.
