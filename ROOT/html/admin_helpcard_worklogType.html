On this page, you can record different modes of technicians work input such as travel, on-site visit, remote support, overtime support, weekend support, and more and compute charges for the same.

You can configure Worklog Type while adding a worklog. This is essential while creating a new worklog under the request module.

Add WorkLog Type

To add a Worklog Type, click New.

Name: Specify a unique name for the Worklog Type.

Color: Select a color to denote the Worklog Type using color palette.

Description: Provide a short description about the Worklog Type.

Click Save or Save and Add New.
