리소스 상태

리소스는 귀사가 정한 리소스 상태에 따라 분류할 수 있습니다. 예: 리소스 사용 중, 재고 중, 만료됨 등

새 리소스 상태를 추가하려면

  1. 링크 클릭 페이지 오른쪽에 있는 새 리소스 상태를 클릭합니다. 그러면 리소스 상태 세부정보 페이지가 열립니다. 기본적으로 AssetExplorer에는 5개의 리소스 상태가 있습니다. 이들 리소스 상태를 수정하거나 삭제할 수 없습니다.

  2. 리소스 상태 이름을 해당 텍스트 필드에 입력하십시오. 필수 입력란입니다.

  3. 설명 필드에서 리소스 상태에 대한 관련 정보를 입력합니다.

  4. 리소스 상태 추가 버튼을 클릭하여 애플리케이션에 리소스를 추가합니다.
