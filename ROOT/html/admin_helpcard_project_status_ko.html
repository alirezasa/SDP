프로젝트 상태는 적절한 조치를 취할 수 있는 프로젝트의 진행 수준을 나타냅니다. 기본 프로젝트 상태는 진행 중(미완료), 보류(보류 중), 취소 및 종료입니다. 새 프로젝트 상태를 추가하려면 아래 나열된 단계를 따르세요.

프로젝트 상태 추가
프로젝트 상태 추가 양식에는 이름, 설명 및 비활성 확인란의 세 가지 필드가 있습니다.

이름: 프로젝트 상태를 식별하기 위해 고유한 이름을 지정합니다.
설명: 설명 필드

에 프로젝트 상태에 대한 간단한 설명을 입력합니다. 상태 선택:미완료 (혹은) 완료됨.
비활성 확인란: 상태 비활성화에 대해 활성화하고 역할을 다시 활성화하려면 선택을 취소합니다.

색상:색상 팔레트를 사용하여 프로젝트 상태를 나타내는 색상을 선택하거나 텍스트 상자에 색상 코드를 지정합니다.

저장 버튼을 클릭하여 프로젝트 상태를 저장하고 목록 보기로 돌아갑니다.
저장하고 새로 추가 버튼을 클릭하여 프로젝트 상태를 저장하고 다른 상태를 추가합니다.
