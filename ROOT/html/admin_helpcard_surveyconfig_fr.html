Les paramètres de l’enquête vous permettent de configurer les valeurs par défaut du message d’accueil, de l’email, du message de réussite ou d’échec de l’enquête, et du message de remerciement.
 
Activer l’enquête

Vous pouvez également activer ou désactiver une enquête. Si vous activez une enquête, vous pouvez programmer la périodicité de son exécution.
Pour activer l’enquête, sélectionnez la case Activer l’enquête utilisateur. Saisissez les valeurs pour les champs suivants dans la section Détails de l’enquête :
 
Détails de l’enquête

Message de bienvenue : Saisissez le message de bienvenue que vous souhaitez afficher lorsque l’utilisateur ouvre la page d’enquête.
Contenu de l’email : Dans le champ de texte Contenu de l’email, indiquez l’objet de l’email. Ce contenu sera affiché dans l’email adressé aux demandeurs. $RequesterName et $SurveyLink sont des variables dont le contenu change en fonction du demandeur et de l’adresse URL d’inscription.
Message de réussite : Saisissez le message qui sera affiché une fois que les réponses aux questions de l’enquête seront achevées.
Message d’échec : Saisissez le message qui sera affiché si l’utilisateur a déjà répondu à l’enquête.
Message de remerciement : Saisissez le message de remerciement. Ce message sera affiché juste avant le bouton soumettre dans le formulaire d’enquête.

Planifier l’enquête
 
Pour programmer une enquête, choisissez l’un des boutons d’option dans la section Planifier l’enquête. Les options sont les suivantes :
Une requête est close : Durant la clôture, un email d’enquête sera envoyé pour chaque requête
Requêtes sont closes : Dans la zone de texte, indiquez le nombre de requêtes à clore sur le total. Une fois le nombre de requêtes clôturées atteint, un email d’enquête est envoyé.
Requêtes provenant du demandeur sont closes : Dans la zone de texte, indiquez le nombre de requêtes à clore pour un demandeur. Une fois le nombre défini atteint, un email d’enquête est adressé au demandeur.  Cette boîte de texte n’admet que des nombres entiers.
Pour enregistrer les informations saisies, cliquez sur Enregistrer.
