Change - Additional Fields lets you configure any additional fields that need to appear in the new change form apart from the default pre-set fields. You can add Text fields, Numeric fields, and Date/Time type fields in the form. Select each tab and add the Label Name and Description for the fields you wish to add in new change form.

While adding Text fields, you have an option to choose the type of text field from Single-line text field, Multiple-line text box, or Pick List which is a drop down menu list. You can also add default values for these fields which will be pre-filled in the form. Label Name can have a length of maximum 100 characters.

Click Save button.
