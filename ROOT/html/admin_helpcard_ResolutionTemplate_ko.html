동일한 솔루션으로 반복되는 요청서를 처리하기 위해 해결 방안 템플릿을 생성할 수 있습니다. 프린터 구성과 같이 자주 제기되는 요청서에 대한 솔루션을 해결 방안 템플릿으로 만들 수 있습니다. 따라서 기술자는 제기된 요청서에 대해 동일한 해결 방안을 반복적으로 입력할 필요가 없습니다.

새 해결 방안 템플릿을 추가하려면 해결 방안 템플릿 목록 페이지에서 새로 만들기 버튼을 클릭하십시오. .

새 해결 방안 템플릿 추가

해결 방안 템플릿을 추가하려면,

해결 방안 템플릿의 고유한 이름 을 지정합니다. 예를 들어 프린터를 구성하는 솔루션입니다.

설명 텍스트 필드에 해결 방안을 입력합니다. 이름 및 설명은 필수 필드입니다.

해상도를 비활성화하려면 비활성 상태로 만들기 확인란을 클릭합니다.

저장을 클릭하여 저장하고 목록 보기 페이지로 돌아갑니다.
해결 방안 템플릿을 저장하고 새로 추가하려면 저장하고 새로 추가를 클릭하십시오.
