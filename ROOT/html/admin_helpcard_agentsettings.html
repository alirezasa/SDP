Agent Settings

 

The application requires a dependant Manage Engine scan component, UEM Product Agent to scan Windows, Mac, and Linux machines. Agent Configuration helps you download and deploy Agents for Windows, Mac, and Linux machines.

 

Downloading and Deploying Agent

To download Endpoint Central (formerly Desktop Central),

Only SDAdmins can deploy the UEM Product Agent.

    • Select the Agent for Windows/Linux/Mac.

    • You will be prompted to Download and Install Endpoint Central (formerly Desktop Central). You can skip this step and proceed with UEM Product integration if you have already installed the UEM Product.

    • Click Download and Install.

    • Configure the proxy settings by entering Host Name, Port Name, Username, and Password. Click Download and Install.

    • Once the installation is complete, you will get an option to download the Agent. Once you have downloaded the Agent, you can proceed with replacing the existing Windows Agents with UEM Product Agents.

Replace the old Windows Agents with UEM Product Agents (Windows only).

You can replace the Windows Agents with UEM Product Agents by executing the ReplaceAgents.vbs as a GPO in Active Directory. The Agents will be replaced once the machines boot up.

Follow the below steps to configure a GPO in Active Directory.

  1. Create a network share (e.g,\\MyServer\MyShare).

  2. Download and extract Windows Agent zip file.

  3. Save the UEMSAgent.msi and UEMSAgent.mst files in the network share.

  4. From your Domain Controller, click Start >> run >> enter gpmc.msc and click OK. If gpmc is not installed in your Active Directory, install gpmc and proceed.

  5. Right-click the domain and select Create and Link a GPO and specify a name for GPO.

  6. To install Agents in only a select client computers, follow these steps:

    • Select the GPO and click the Scope tab.

    • Click Add in the Security Filtering section.

    • Click Object Types in the Select User, Computer, or Group dialog box.

    • Select the specific computer Object Types and click OK.

    • Specify the computer names, click Check Names and click OK.

Installing UEM Product Agents in Linux and Mac

You can install UEM Product Agents in Linux by using the Linux bulk agent installation tool and in Mac by using the Mac Agent installation script and providing the list of machines to be installed in computers.csv.
