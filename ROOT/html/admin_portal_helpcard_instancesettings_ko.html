이 페이지에서 인스턴스의 이름, 설명, 인스턴스 상태 및 인스턴스 로고를 업데이트할 수 있습니다. 담당자를 추가하거나 제거합니다. 인스턴스에 여러 담당자를 추가할 수도 있습니다. 위에서 언급한 오퍼레이션 외에도 조직(Org) Admin 관리자 권한이 있는 경우, 필요할 때 라이선스를 업데이트할 수 있습니다.

기술자에게 인스턴스 담당자 권한을 부여하면 인스턴스 내 인스턴스 구성 권한과 함께 Admin 관리자와 동등한 권한이 부여됩니다.

참고: 인스턴스를 삭제하면 인스턴스의 모든 데이터가 지워집니다. 이 오퍼레이션은 되돌릴 수 없습니다.

라이선스 행위

신규 기본적으로 모든 인스턴스는 기본 상태로 신규를 갖습니다. 사전 프로덕션

인스턴스 담당자가 애플리케이션에 로그인하고 인스턴스에 액세스하면 상태가 자동으로 사전 프로덕션으로 변경됩니다. 라이선스가 만료되면 인스턴스의 상태도 사전 프로덕션으로 변경됩니다. 이 시점에서 인스턴스 담당자만 인스턴스를 볼 수 있습니다.

프로덕션

라이선스가 적용된 후 인스턴스 담당자는 인스턴스 상태를 프로덕션으로 전환할 수 있습니다. 인스턴스에 추가된 사용자는 ESM 포털에서 인스턴스를 볼 수 있습니다.

사용 중지

인스턴스 담당자가 프로덕션에서 인스턴스를 사용 중지해야 하는 경우 소유자는 상태를 사용 중지됨으로 변경하면 됩니다. 인스턴스가 사용 중지됨 상태로 이동되면 인스턴스를 다시 프로덕션 상태로 돌아 갈 수 없습니다. 인스턴스는 읽기 전용 모드로 전환되고 인스턴스 담당자만 액세스할 수 있습니다.

라이선스 만료됨

이 상태로의 전환은 인스턴스 라이선스가 만료되면 시스템에서 자동으로 수행됩니다. 인스턴스는 읽기 전용 모드로 바뀌고 이 상태에서는 인스턴스 담당자에게만 표시됩니다. 라이선스가 적용되면 상태가 자동으로 프로덕션으로 바뀌고 최종 사용자가 인스턴스에 액세스할 수 있습니다.
