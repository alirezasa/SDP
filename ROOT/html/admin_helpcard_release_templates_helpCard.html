Create templates for frequent service releases, such as software upgrades, firewall policy updates, or Windows patch updates. Each template contains different fields and roles that are vital in managing the release.

To create a release template,

  • Use the New Release Template button to create a release template. Besides customizing the fields in the template form, you can add the fields and roles available and create new ones. Group fields into sections and customize the template layout. To preview or copy the template, use the buttons displayed on top.
  • Using the Hamburger icon, you can edit, disable, delete a release template or mark it as default. You cannot, however, disable or delete the default template.
  • To delete release templates in bulk, select the templates are click the Delete icon.

Note:

Default templates cannot be deleted.

If a release template is deleted while being used in releases, the template will be disabled. You can restore an inactive release template by editing it.
