콜백 사용자 정의 기능을 사용하면 외부 응용 프로그램에서 ServiceDesk Plus의 데이터에 액세스하거나 데이터를 조작할 수 있습니다. Deluge 스크립팅 언어를 사용하여 콜백 사용자 정의 함수를 작성할 수 있습니다.

  • 새 콜백 맞춤 함수를 만들려면 새로 만들기
    • 를 클릭하십시오.
  • 콜백 함수를 수정하려면 함수 이름을 클릭하십시오.
  • 콜백 함수를 삭제하려면 함수를 선택하고 삭제
    • 를 클릭하십시오.

또한 함수에 대해 작업 메뉴에서 적절한 작업을 선택하여 단일 콜백 함수를 편집하거나 삭제할 수 있습니다.

참고: 페이지 헤더에는 키워드를 사용하여 기능을 검색하고, 페이지 당 항목 수에 제한을 설정하고, 페이지를 탐색하는 옵션도 포함되어 있습니다.
