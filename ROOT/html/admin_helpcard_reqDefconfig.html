Set the default values that need to appear in the above listed fields (Category, Priority, Level, and Mode) of the new request form. You can choose from the list of values that are displayed in each of the combo-boxes.

Selecting the check box beside Show workstations associated to requester in Self-Service Portal, displayes only those workstation that are associated to the requester, in the workstation combo-box in the self-service portal while generating a new request.

Click Save to save the settings.
