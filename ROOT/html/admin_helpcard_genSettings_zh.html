要在解决方案页面显示或移除FreeAnswers.net链接，可以根据需要，选择 是 或 否 。

要提供替换用的URL
  1. 可以在相应的字段输入 URL (如果需要，可输入端口号)。
  2. 点击 在新窗口中打开URL测试该URL能否正常工作。
您可以定制本应用的显示图标，它们将替换登录页面和其它页面顶部的图标。两个图片文件的尺寸大小不同。登录页面的尺寸为 252 px x 61 px (W x H), 页面顶部的图片的尺寸为 166 px x 46 px.

要导入登录页面的图片，
  1. 点击 导入图片 ...按钮。
  2. 点击 浏览按钮，
  3. 在文件选择窗口，选择要导入的文件后，点击打开。
  4. 点击 导入。
导入的图片将替换登录页面的图片。同样的步骤，可以导入页面顶部的图片。点击保持按钮，保持设置。
