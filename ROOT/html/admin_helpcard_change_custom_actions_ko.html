사용자 지정 액션은 사용자가 ServiceDesk Plus 및 기타 외부 응용 프로그램에서 데이터를 조작할 수 있도록 하는 실행 가능한 사용자 지정 기능입니다. 사용자 정의 기능은 Zoho의 스크립팅 언어인 Deluge를 기반으로 합니다.

사용자 지정 액션은 변경 사용자 지정 트리거에서 변경, 기타 모듈 및 외부 응용 프로그램에 대한 액션을 수행하는 데 사용할 수 있습니다.

새로 만들기 버튼을 사용하여 사용자 정의 액션을 만듭니다.

액션 버튼을 사용하면 맞춤 작업을 일괄 삭제, 비활성화 및 활성화할 수 있습니다. 개별 사용자 정의 액션을 수정하려면 사용자 정의 액션 옆에 표시된 아이콘을 사용합니다. 사용자 정의 트리거 변경에서는 활성사용자 정의 액션만 사용할 수 있습니다.

키워드를 사용하여 제공된 필드에서 사용자 정의 액션을 검색하십시오. 상단의 필터를 사용하여 특정 기능에 사용된 사용자 정의 액션을 표시합니다.
