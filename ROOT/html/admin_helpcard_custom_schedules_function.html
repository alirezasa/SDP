Scheduled functions allow users to manipulate data within the application and other external services via custom schedules. You can write a script to fetch data from query reports and execute an action based on the fetched data. Scheduled functions are built on Deluge, Zoho's propriety scripting language.

  • Click New to create a scheduled function. The custom schedule where the scheduled function is active is displayed in the list view.
  • You can search through scheduled functions using keywords.
  • Use the drop-down menu beside the search bar to filter scheduled functions used in specific features.
  • The Actions drop-down allows you to bulk delete, disable, and enable scheduled functions. To modify individual scheduled functions, use the Hamburger icon.

Note: Only active scheduled functions will be available to use in the configurations mentioned above.
