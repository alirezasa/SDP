When you set up the application and start it for the first time, the application automatically discovers all the available Windows domain in your network.

But apart from this, you can also add domains and scan for Windows Workstations and Servers that are part of your Domain/Active Directory or Windows Workgroup.

Note: Please note that you will need Agents to scan Windows, Linux, Mac workstations, or servers. You will get a link to download the Agent in the same page. Refer Agent Configuration help card to download and deploy the Agent.

To add a new domain, click Add New Domainlink on the top of the Domain list view.

Add New Domain form has five fields, namely Domain Name, Domain Controller, Login Name, Password, and Description.

Domain Name: Enter the Domain Name. The name should be unique to identify the domain and is a mandatory field.

Public Domain check box: Select this check box if you want to display the domain in the login screen when Active Directory Authentication is enabled.

Domain Controller: Enter the Domain Controller name for the Active Directory Server. The organizational units are listed only if the domain controller name is provided. The Domain Controller should be blank if you are scanning Windows Workgroup. And, the ports to connect to Active Directory is TCP 389.

Login Credentials: Specify the Login Name and Password for the domain controller.

Description: Provide any relevant information pertaining to the domain details.

 

Click the Save button to save the domain and return to the list view.

Click the Save and Scan now button to save the domain and scan the domain.

NOTE: For the workstation scan to execute successfully the following things need to be true:

  1. WMI needs to be enabled in the workstation where the application is running.
  2. COM/DCOM service needs to be switched on in all the workstations belonging to the windows domains.
