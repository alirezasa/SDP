ServiceDesk Plus - ADManager Plus 連携 :

この連携により、AD管理者とヘルプデスク担当者はServiceDesk PlusとADManager Plusの両方から効率良くAD管理を行うことができます。 管理者はServiceDesk PlusからADユーザーのパスワードリセット、ユーザー作成、削除、ロック解除、有効化、無効化を行うことができます。

ADManager PlusでのServiceDesk Plus サーバーとの連携設定：

ADManager Plusで次の設定を行う必要があります。設定は"ADMP >> 管理 >> 一般設定 >>ServiceDesk Plus"から可能です。

  • サーバー情報: ServiceDesk Plusのホスト名とポート番号を入力し、プロトコルを選択します。
  • "ServiceDesk Plusと連携する"にチェックをして有効にします。この設定によりServiceDesk PlusからADとExchange関連のタスクを実行できます。
  • 認証情報: ServiceDesk Plus のログイン名とパスワードを指定のフォーマットで入力します。"接続テスト&保存"をクリックします。 ServiceDesk PlusとADManager Plus間で接続が確立され、設定が保存されます。

この連携はADManager Plusでヘルプデスクの担当者として設定され、ServiceDesk Plusで技術担当者となっているユーザーのみが対象です。ADユーザーをServiceDesk Plusで技術担当者として設定するには:

  • "オペレーター >> オペレータの追加"に進みます。
  • ドメイン、ADユーザー、オペレータの役割、OUを選択し、もしオペレーターを管理者にする場合は"管理者として振る舞う"にチェックをします。 ＊"オペレーター >> オペレーターの役割" で予め役割を作成しておくことができます。

メモ: ログイン名とドメイン名はADManager PlusとServiceDesk Plusで同一である必要があります。

ServiceDesk PlusでのADManager Plusサーバー設定:

  • ADManager Plusのサーバー名とサーバーポート番号を入力し、プロトコルを選択します。
  • 両アプリケーション間での接続を確認するために、"接続をテストして保存"をクリックします。
  • 連携設定を削除するには"削除"、キャンセルするには"キャンセル"をクリックします。削除、キャンセルすると保存はされず、一覧表示画面に戻ります。

ADManager Plus アクション: リストにはアクション名とと説明、編集するためのアイコンが表示されます。

役割の関連付け: 管理者は"すべての役割"と"役割の選択"の両方が選択できます。"すべての役割"を選択するとアクションを実行するための権限が全技術担当者に割り振られます。"役割の選択"を選択すると、役割のリストが表示され、管理者はアクションを実行するための役割を持つユーザーを選択できます。例: SDAdmin, SDSiteAdmin など。

テンプレートの関連付け: 管理者はアクションを表示させる対象テンプレートを"すべてのテンプレート" "すべてのインシデント/サービステンプレート" "テンプレートの選択" から選択できます。選択されたテンプレートを使用してリクエストを作成すると、各リクエスト情報内の"アクション"に表示されます。

ServiceDesk PlusからADManager Plusのユーザーを作成:

各リクエストテンプレートで技術担当者は権限のあるアクションを実行することができます。

例: リクエスト情報のアクションから"ADにユーザーを作成"を実行すると、必要フィールドが含まれるポップアップが表示されます。両アプリケーション間でこれらのフィールドが関連付いている必要があります。すべての情報を入力し、"ADユーザーを作成"をクリックしてください。さらにフィールドを追加するには：

  • [ADMPインストールディレクトリ] >> integration >> resources >> admp >> conf にあるAdmp.xml を開いてください。
  • "ユーザーを作成" メニューをクリックし、要望の追加フィールドを追加する。フィールドはテキスト形式/日付形式/ピックリスト形式です。

メモ: 追加フィールドを含めるには、ADManager Plusで存在する関連する追加フィールドのIDが必要です。詳細はアドミンガイドを参照してください。

ドメイン設定:

ServiceDesk PlusとADManager Plusの連携のために、ドメイン構成は必須です。

  • "管理 >>技術担当者?>> ログイン情報 >> ドメイン "からServiceDesk Plusに既に存在するユーザーにドメインを構成することができます
  • "管理->ディスカバリ->Windowドメインスキャン" でServiceDesk Plusに新規ドメインを追加できます。
