Org Admins can create new service desk instances and assign any ESM user as the owners for the same. The owner of an instance will have the SDAdmin privilege along with the instance configuration permission for that instance. By default, only the IT service desk instance will be listed.

If the Org Admin assigns a user other than themselves as the owner to an instance, they will not be able to access that instance or perform any configurations specific to that instance.

To create a service desk instance,

  1. Click New Instance.
  2. Enter your instance name and description.
  3. Select your instance type - Facilities, Human Resources, or blank. Depending on the instance type, the service desk features will be limited.
  4. The Status will be updated automatically depending on the license behavior.
  5. Enter an alias URL to access the instance directly. The alias URL directs a user to the Home tab of the instance. Note that the application server must be restarted for the URL to take effect.
  6. Choose a license from the drop-down to associate with the service desk instance.
  7. Click Create.
License Behavior

When a user is added as a technician in two instances, two technician licenses will be consumed for that user.

The following statuses are updated to an instance depending on the license behavior:

  • New: All newly created instances will have New as their default status.
  • Pre-production: When the assigned owner logs in to the instance, the status will be changed to Pre-production. At this point the instance will be visible only to the owner.
  • Production: After the license is applied to an instance, the instance owner can change the status to Production after setting up the configurations. Instances in Production status will be visible to users added to the instance.
  • Retired: Retired instances will be moved in to this status in a read-only mode and remain accessible only to the instance owner. Retired instances cannot be moved to the Production status again.
  • License Expired : An automatic status that is applied to an instance by the system when the instance license expires. The instance will turn to read-only mode and be visible only to the instance owner. Once the license is applied the status will turn to Production automatically and the instance will be accessible for users.
Note:

  • A maximum of 50 service desk instances can be created.
  • IT service desk status cannot be changed.
To configure the admin settings of an instance, go to the Admin tab inside each instance.
