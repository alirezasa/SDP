Saisissez tous les renseignements sur votre organisation ici.

Nom: Saisissez le nom complet de votre organisation ici. Il sera utilisé comme en-tête pour générer des bons de commande.
Description Introduisez une brève information sur l’activité de votre organisation ou tout autre renseignement qui vous paraît important.
Adresse e-mail: Saisissez l’identifiant de l’adresse électronique principale de votre organisation.

Renseignez les champs restants : adresse, ville, code postal, État, pays, numéro de téléphone, n° de fax et adresse Web. Ces données seront utilisées dans les modules ServiceDesk.

Vous pouvez importer le(s) logo(s) et utiliser n’importe lequel d’entre eux dans les emplacements où les données de l’organisation sont utilisées.

  1. Cliquez sur Importer une image à côté du champ du logo de l’entreprise.
  2. Cliquez sur le bouton Parcourir puis sélectionnez le fichier image dans la fenêtre de sélection, puis cliquez sur Ouvrir.
  3. Cliquez sur Importer.
Par défaut, la case Utiliser cette image est sélectionnée. Si vous ne souhaitez pas utiliser l’image, désélectionnez la case.

Pour enregistrer les informations saisies, cliquez sur Enregistrer.

Une organisation peut posséder des succursales dans plusieurs sites et régions, ces derniers détermineront le calcul des horaires d'ouverture, des congés, du SLA et des règles commerciales. Considérons que les succursales de l'organisation ZOHO sont situées à Chennai et Mumbai en Inde, et à Pleasanton aux États-Unis. Les attributs que sont les horaires d'ouvertures, les congés, le SLA et les règles commerciales sont calculés pour chaque site.
