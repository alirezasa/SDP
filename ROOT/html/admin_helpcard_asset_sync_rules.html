Sync Rules

Define the data to be synced from the CMDB to the Assets module. The synced data is populated as assets in Assets module and linked to the corresponding CI in the CMDB.

Create Sync Rule
  1. Choose the CI type to be synced to the Assets module.
  2. Select the destination product type where the data from the CI type is synced.
  3. Describe the sync rule purpose and usage.
  4. Enable or disable the sync rule.
  5. Define actions to be performed when the sync rule is applicable:
    • Filter CI and create assets: The asset will be created only when the criteria is met.
    • Map CI Type Fields with asset fields: Map CI type and asset fields. Data in the mapped CI fields will be automatically updated if the asset field is edited.
    • Delete asset when linked CI is deleted: Asset is deleted automatically if the linked CI is deleted from ServiceDesk Plus.
    • Create drop-down option if it does not exist: If a picklist or radio field value does not exist in the asset type, it will be created as a new option from the CI type field.
  6. Click Save.
List View Operations
  • Use the filter drop-down to view sync rules based on source module or CI types.
  • Click the Actions icon to edit, delete, or run the sync rule.
  • To bulk-delete, select the sync rules and click Delete on the toolbar.
  • Click Reorder to decide the priority order in which sync rules must be executed when multiple sync rules are configured for the same source module and CI type.
  • Use the toggle option in the Status column to enable or disable a sync rule.

Note: Sync rules for CIs and assets will bypass fields mandated in the layout.
