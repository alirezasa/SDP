Collect additional details related to departments.

Create Additional Field

  • Click New Field.
  • Choose the field type. The following types of additional fields are available for you to choose from:
    • Single Line: For specific information.
    • Multi Line: For descriptive information.
    • Pick List: To provide options for users to choose from.
    • Numeric: For adding numerical information.
    • Date/Time: To add a specific date and time.
    • Date: To add a specific date.
  • Provide a field name.
  • Enable Holds personally identifiable information (PII) if the field contains personal information.
  • You can encrypt single and multi-line field types for additional security. Note that you can encrypt a field only while creating it. Field encryption cannot be disabled later.
  • The API field name is auto-populated based on the field name. You can modify it if needed.
  • Describe the field usage.
  • Based on the selected field type, specify the other field properties.
  • Click Save.

List View Operations

  • Click the Edit icon to modify field details.
  • Click the Delete icon to remove a field permanently.
  • Use the Search icon to search through the columns listed.

Note: You cannot modify the API Field Name while editing the field details.
