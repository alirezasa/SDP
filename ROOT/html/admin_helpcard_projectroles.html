Configure Project Roles with a unique set of access permissions to be assigned to project members. These roles decide the access of each project member within the project. By default there are four Project Roles. Project Admin and Team member roles are non-editable.

Add Project Role

To add a Project Role, click New and fill out the displayed form.

Name: Specify a unique name to identify Project Role.

Description: Provide a short description about Project Role.

Permissions: Configure access levels for the Project Role.

Project Member allowed to view: Use radio buttons to configure the access permission for Project Role.

All Projects: Role with permission to view and edit all projects.

Associated Projects: Role with permission to view and edit projects associated with the member.

Associated Milestones: Role with permission to view and edit milestones associated with the member.

Associated Tasks: Role with permission to view and edit tasks associated with the member.

Click Save or Save and Add New.
