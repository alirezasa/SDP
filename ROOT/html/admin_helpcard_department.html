Add and view the various departments in your organization (and across branches) located in different sites. Each department is managed by a department head.

If Sites is configured, the Department under each site can be viewed by selecting the site from Departments for combo box.

Note: Site Admin can perform operations on the departments to which he is associated. If sites are not configured, then the Department for combo box will not appear.

Add New Department

To add a new department to a site, select the site from Department for combo box. Click the Add New Department link on the right hand side corner of the Department List table.

Department Name: Enter the name of the department you wish to add in Department Name. As the same department can exist across various branches of your firm, this need not be unique. This is a mandatory field.

Site: The site for which the department is created is specified in a non editable text. This field appears only when sites are configured.

Description: You can provide a brief description about the activities of department in the Description field.

Department Head: Select the department head using the user look up icon. This will pop-up a list of users. Select the name of the user to assign as the department head.

Click Save. The department is added under the selected site.
