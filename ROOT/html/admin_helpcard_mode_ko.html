서비스 요청을 지원 팀에 제출할 수 있는 방법은 여러 가지가 있으며 SDP 애플리케이션에서 추적됩니다. 서비스 요청을 제출할 수 있는 요청방식(모드)은 다음과 같습니다.

1. 웹 기반의 새 요청서 양식을 사용하여 질문을 제출합니다.
2. 서비스 데스크 담당자에게 전화를 걸어 요청하면, 그 요청을 접수할 것입니다.
3. 지원팀에 이메일을 보내면 자동으로 SDP 애플리케이션에 서비스 요청서로 기록됩니다.

새 요청방식(모드)을 추가하려면 요청방식(모드) 목록 표의 오른쪽 모서리에 있는 새 요청방식(모드) 추가 링크를 클릭하십시오.
새 요청방식 추가
요청방식 추가 양식에는 모드 이름과 설명이라는 두 개의 필드가 있습니다.

요청방식 이름은 각 요청방식을 식별하는 데 사용되는 유일한 이름을 지정하는 곳입니다.

설명 필드에 모드에 대한 간단한 설명을 입력할 수 있습니다. 이것은 이 요청방식에서 생성된 서비스 요청서가 SDP 애플리케이션에서 어떻게 추적되는지 이해하는 데 도움이 될 수 있습니다.

저장 버튼을 클릭하여 해당 요청방식을 저장하고 목록 보기로 돌아갑니다.
저장하고 새로 추가 버튼을 클릭하여 해당 요청방식을 저장하고 다른 요청방식을 추가합니다.
