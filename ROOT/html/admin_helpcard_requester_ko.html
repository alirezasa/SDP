이 페이지에서 사용자에게 역할을 검색, 추가, 삭제 및 할당할 수 있습니다. 또한 VIP 사용자로 표시하고 사용자 계정을 병합할 수 있습니다.


사용자 추가


개별 사용자

새로 추가를 클릭하고, 표시된 양식을 채우고 저장합니다.

셀프 서비스 포털에서 유일한 로그인 이름을 입력했는지 확인하십시오.


사용자 역할:

사용자를 추가하거나 편집하는 동안 사용자에 대한 프로젝트 역할, 구매 승인자 역할 및 서비스 요청 승인자 역할을 부여할 수 있습니다. 승인자가 승인할 구매 금액 한도를 설정할 수도 있습니다.


Active Directory에서 가져오기

Active Directory에서 가져오기를 클릭하고 표시된 양식을 작성한 다음 가져오기를 클릭합니다.

도메인 스캔 페이지에 도메인 관련 세부정보를 이미 입력했다면 자동으로 채워집니다. 그렇지 않으면 세부 정보를 수동으로 입력하십시오.


CSV 파일에서 추가

CSV에서 가져오기를 클릭하고 CI 유형을 선택하고 파일을 선택한 다음 제출을 클릭합니다. >.


부서/역할 배정

사용자를 선택하고 액션을 클릭한 다음 부서에 배정을 선택합니다.

드롭다운에서 사이트 및 부서 이름을 선택하고 연계를 클릭합니다.


사용자 통합 (기준 없이)

중복되거나 고유한 사용자 계정을 수동으로 선택하고 병합합니다.

사용자 계정을 선택하고 액션 드롭다운에서 사용자 병합을 클릭합니다.

상위 계정을 선택하고 사용자 병합을 클릭합니다.


중복된 사용자 병합(기준 포함)

다른 도메인에서 중복된 로그인 이름 또는 이메일 주소가 있는 계정 병합합니다. 해당 속성 값도 병합됩니다.

사용자 병합을 클릭하고, 로그인 이름 또는 이메일 주소로 중복을 식별하는 기준을 선택하고, 도메인 이름 (두 개의 도메인/1개의 도메인 및 없음으로 레이블된 도메인 없음 )을 클릭하고 필터 적용을 클릭합니다.

선택한 도메인의 중복 계정 쌍이 나열됩니다. 병합할 계정을 선택하고 사용자 병합을 클릭합니다.

상위 도메인을 선택하고 사용자 병합을 클릭합니다.


다음은 두 병합 프로세스에 공통적입니다.

  • 진행 중인 다른 병합 프로세스가 없을 때만 병합 프로세스를 시작할 수 있습니다.
  • 병합 프로세스가 완료되면 모든 SDAdmin에게 알림이 전송됩니다.
  • 사용자 자산의 사이트 연결은 다른 사이트의 사용자를 병합할 때 변경되지 않은 상태로 유지됩니다.
  • 병합 프로세스가 완료된 후 알림 또는 커뮤니티>>시스템 로그 뷰어에서 요약을 볼 수 있습니다.

참고 사항:

기준 없이 계정을 병합하면 선택한 계정의 속성 값이 병합되지 않습니다. 대신 상위 계정의 속성 값이 유지됩니다. 유일한 예외는 상위 계정에 추가될 하위 계정의 이메일 주소입니다.


사용자 삭제

목록 보기에서 사용자를 선택하고 액션을 클릭한 다음 사용자 삭제를 선택합니다.

개인 정보 설정에서 GDPR 설정을 활성화한 경우 삭제하는 동안 사용자 이름을 임의의 텍스트로 변경할 수 있습니다. 이 변경 사항은 SDP 애플리케이션 내의 모든 모듈에 적용됩니다.
