Credentials library serves as a repository for creating/safekeeping of scan credentials and remote control credentials used with Asset Explorer. Credentials configured in this library can be associated to Network Scan, Individual Scan or Remote Control. Scan protocols for which credentials can be configured are: Telnet/SSH, SNMP V1/V2 & VMWare.

Adding Credentials:

  1. Select Scan Protocol - for configuring Scan Credentials - from drop-down (Telnet/SSH Protocol, SNMP V1/V2, VMWare & Remote Control).
  2. Provide a suitable Name and Description.
  3. Enter the Username and Password.
  4. In case of Telnet/SSH credentials specify the following:
    Protocol - Telnet/SSH.
    Port Number - 22 by default.
    Key based authentication is also possible by selecting Use Public Key Authentication Checkbox.
  1. For SNMP V1/V2 credentials, specify the following: 
    SNMP Read Community Password.
    SNMP Port Number - 161 by default.
    Timeout (time after which the connection would be terminated) - 5 secs by default.
    Retries (no. of attempts that can be made before the Timeout happens) - 0 by default.
  1. For SNMP V3 credentials, specify the following: 
    Enter the Username and Context Name.
    Authorization and Encryption Protocols:

     Choose Either MD5, SHA, SHA-256 or SHA-512 for Authorization Protocol and DES or AES-128 or AES-192 OR AES-256 for Encryption Protocol.
    Note : Encryption Protocol can be configured only after the Authorization Protocol is configured. These two protocol configurations are not mandatory.
    Authorization and Encryption Passwords:

    Enter the passwords if corresponding protocol types are enabled.
    SNMP Port Number - 161 by default.
    Timeout (time after which the connection would be terminated) - 5 secs by default.
    Retries (no. of attempts that can be made before the timeout happens) - 0 by default.
  1. For VMWare credentials, specify the following:
    HTTPS Port - 443 by default.
    Timeout (time after which connection would be terminated) - 60 secs by default.
  1. For SCCM credentials, specify the following:
    Authentication Type - Select whether the SCCM database server supports Windows or SQL authentication. Fill out other fields based on the authentication type selected.
    Windows - Enter the domain name, username, and password of the account that has permission to read information in the SCCM database server.
    SQL - Enter the username and password of the account that has permission to read information in the SCCM database server.
    Note : Save common credentials for SCCMs of all sites to simplify the update process. You can, however, save multiple credentials for SCCMs of different sites.
  2. Save Credential.

Note: Remote Control Credentials (configured under Credentials Library) will be available for selection during Remote Control.
