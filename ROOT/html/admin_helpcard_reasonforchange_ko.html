변경 이유는 변경 요청을 시작하는 목적을 나타냅니다. 예를 들어 조직의 프린터가 프린터 카트리지의 손상으로 인해 작동하지 않는 경우, 변경 사유는 프린터가 작동하지 않음일 수 있으며 시작된 변경 요청은 프린터 카트리지 변경일 수 있습니다.

마찬가지로, 변경 요청을 시작하는 가장 빈번한 이유를 문서화할 수 있습니다. 이것은 경영진이 조직에서 변경을 발생시키는 이유에 대한 보고서를 얻는 데 도움이 됩니다.

변경 이유 추가

  1. 변경 이유 추가 버튼을 클릭하십시오.

  2. 이름 필드에 변경 사유를 입력하십시오.

  3. 변경에 대한 간단한 설명 을 입력하십시오.

  4. 저장 버튼을 클릭합니다.
