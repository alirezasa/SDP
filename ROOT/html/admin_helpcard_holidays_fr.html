Vous pouvez ajouter et consulter la liste des jours fériés de votre organisation diviser sur plusieurs sites. Cette information associée aux heures de service sera utilisée pour calculer le temps prévu de résolution de la requête d’assistance, en fonction de la priorité ou du SLA (Contrat de niveau de service) applicable à cette requête.

Pour afficher les jours fériés d'un site en particulier, sélectionnez-le dans la liste déroulante Congés pour de la page de liste des jours fériés.

Pour ajouter un nouveau jour férié, sélectionnez d'abord le site concerné dans la liste déroulante Jours fériés pour. Cliquez ensuite sur le lien Ajouter un nouveau jour férié dans l’angle droit du tableau Liste des jours fériés.

Remarque :

  1. Si aucun site n'est sélectionné dans la liste déroulante Jours fériés pour, le jour férié sera ajouté sous les Paramètres par défaut.

  2. Les sites non configurés dans Admin- Sites n'apparaîtront pas dans la liste déroulante Jours fériés pour.

  3. L'administrateur du site peut ajouter et consulter les sites auxquels il est associé dans la liste déroulante Jours fériés.

Ajouter un nouveau jour férié

Cliquez sur l'icône du calendrier à côté du champ de la date et sélectionnez la Date. Ce champ est obligatoire.

Donnez une brève description de la signification du jour férié dans le champ Description.

Si il s'agit d'un jour férié récurrent, comme le 1er Jan (Nouvel An), sélectionnez la case Cocher s'il s'agit d'un d'un jour férié récurrent. Vous n'aurez pas à rajouter ce jour férié chaque année si cette option est activée.

Cliquez sur le bouton Enregistrer. Le jour férié est enregistré pour le site sélectionné. Pour enregistrer le jour férié et en ajouter un autre, cliquez sur le bouton Enregistrer et ajouter nouveau.
