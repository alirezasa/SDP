Scan new assets added to the network and sync previously scanned asset information periodically. You can configure different scanning schedules for IT assets with and without a UEM agent.

Configurations

  • Schedule agent-based UEM scan - Schedule agent-based scanning of IT assets such as Windows, Linux, and Mac machines. Set the scan frequency, start time, time zone, and recurrence pattern.

  • Schedule agentless scan - Set the frequency and recurrence pattern to scan IT assets such as Solaris, AIX, HP-UX, SNMP supported network device, VMware, and Cisco IP Phone.

  • Scan History Clean up - Specify the number of days after which the scanned information can be deleted.

  • Scan new devices added to the network - Provide the recurrence period to scan the new devices added to the domain/network.
