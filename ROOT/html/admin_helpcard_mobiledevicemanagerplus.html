Integrate with Mobile Device Manager Plus

Step-by-Step procedure for Integration : Help Document


Integrate ServiceDesk Plus with Mobile Device Manager Plus to manage and secure your mobile devices directly from your ServiceDesk Plus console. Mobile Device Manager Plus automates various mobile device management tasks like app distribution, device management and restrictions, email management, and asset management. It also provides additional security to the mobile devices by restricting the transfer of data between apps, devices, and third-party cloud services. It helps admins locate lost devices and wipe the data on it, if necessary. If you have installed both the products, just enter the details of the computer where the Mobile Device Manager Plus server is installed along with the port numbers.

Prerequisite: You should be running Mobile Device Manager Plus version 92370 and above.

Set Up the Integration

  1. Enter the URL where the application is currently hosted.
  2. Enter the API Key of an admin user in Mobile Device Manager Plus.
  3. Enter the API Key of an admin user in UEM application.
  4. Select Enable MDM (Mobile Device Management) menu to display the desktop management menu for technicians. The menu will be displayed only for MDM build number #92263 and above.
  5. Select Enable MDM (Mobile Device Management) Menu to display MDM functions as a drop-down menu to technicians.
  6. Click Test Connection and Save to check for an established connection between ServiceDesk Plus and Mobile Device Manager Plus in their respective ports

Integrating with Other ME Products (running in HTTPS mode)

  1. Download the .zip file from the link given below and extract it to "ManageEngine\ServiceDesk":

    2. For Linux: https://downloads.zohocorp.com/dnd/ServiceDesk_Plus/o_1af3b3o2010mg10kbj961mdt18sq1/lincertgeneration.zip

    For Windows: https://downloads.zohocorp.com/dnd/ServiceDesk_Plus/o_1af360niepdjr7j1flk1o323fa1/wincertgeneration.zip

  2. Connect to the command prompt. Go to "ManageEngine\ServiceDesk" and run the batch file with following format:

    3. For Linux:
    C:>ManageEngine\ServiceDesk>gencert.sh servername:portnumber

    For Windows:
    C:>ManageEngine\ServiceDesk>gencert.bat servername:portnumber

  3. On running the command, you will receive an exception PKIX and then it will ask you to enter a value. Provide value 1 which will generate a file named jssecacerts under "ManageEngine\ServiceDesk".

  4. Copy the jssecacerts file under "ManageEngine\ServiceDesk\jre\lib\security" folder and then restart the ServiceDesk Plus application.
