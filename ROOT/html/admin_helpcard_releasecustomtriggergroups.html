On this page, you can automate release workflow by creating custom triggers. Triggers can be configured to work based on user input. Define actions to be executed on releases that satisfy specific conditions. You can categorize and execute custom triggers in different trigger groups.

To create a new trigger group, click Trigger Group and provide the required details.

To add a new custom trigger to the group, hover over the group and click Add Trigger.

  • Select whether the trigger should be executed - when the release is created, edited, or deleted permanently.
  • Specify the conditions to be met.
  • If the trigger is set to execute when the release is edited and based on conditions, you can choose to execute the trigger:
    • Every time the release is edited.
    • Only when the fields configured in the conditions are edited.
  • Choose the action to be executed via the trigger - notification action, custom function, execute script, webhooks, If-If, or If-Else.

    • Choosing Deleted enables you to trigger notifications to specific users when the releases is deleted.

    List View Actions

    You can organize custom triggers and trigger groups, configure cascade execution, and move triggers across groups.
