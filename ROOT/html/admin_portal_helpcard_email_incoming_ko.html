요청자와 기술자가 이메일을 주고받을 수 있도록 수신 및 발신 이메일 설정을 구성합니다.
이 페이지에서 다음을 구성할 수 있습니다.

수신 메일 서버 설정

EWS(Exchange 웹 서비스)를 사용할지 POP, IMAP, POPS 또는 IMAP과 같은 외부 메일 서버를 사용할지 선택합니다.

인증 유형을 선택합니다. OAuth를 선택하는 경우 이메일 서비스 제공업체의 승인 서버에서 SDP 애플리케이션 서버를 한 애플리케이션으로 구성하고 클라이언트 세부정보를 생성해야 합니다. 여기에서 방법을 알아보십시오.

그런 다음 구성을 진행합니다.

아래에 제공된 포인터를 사용하여 표시된 필드를 채우십시오.
필드 설명
서버 이름/IP 주소 메일을 가져올 서버 주소를 입력하십시오
사용자 이름 및 비밀번호 서버 자격 증명을 입력하십시오.
이메일 주소 서비스 요청을 받는 이메일 주소
이메일 유형 이메일 가져오기 유형을 선택합니다. IMAP을 선택한 경우 TSL을 활성화합니다.
포트 포트 번호를 지정합니다.
메일 가져오기 간격 메일을 가져오는 시간 간격을 입력하십시오.
프록시 서버 활성화 보안 연결을 위해 프록시 설정을 활성화하고 구성합니다.
이메일 디버그 활성화 이메일을 디버깅해야 하는지 여부를 선택합니다.
이메일로 새 요청서 생성 비활성화 사용자가 이메일로 요청서을 생성하지 못하도록 제한하려면 선택하십시오.

설정을 변경하여 적용하려면, 메일 가져오기 프로세스를 일시 중지하십시오.
