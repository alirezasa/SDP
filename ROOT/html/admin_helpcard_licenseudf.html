License Additional Fields

 

If you require any further additional information while adding a software license apart from the pre-defined fields, you can configure them under License-Additional Fields. You can add Text fields, Numeric fields, Date/Time fields and Cost fields in the form.

 

Select each tab and add the Label name and Description for the fields to be displayed in the Software License form.

While adding text fields, you have an option to choose the type of text field you want. The text field can be of a Single-line text field, Multiple-line text box, and a drop down menu list. Select the radio buttons Single Line, Multi-line or Pick List.

While adding a cost field, you can either Add Costs or Subtract the cost fields. Select the appropriate radio button.

You can also specify Default values for these fields in the text box provided for the same.

Click Save to save the settings.
