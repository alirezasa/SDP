Webhook

On this page, you can create a webhook that enables you to call an external URL or API to facilitate communication between ServiceDesk Plus and any third-party applications.

Only the SDAdmin can define webhooks.

Create Webhook

  • Provide a unique name and description for the webhook.
  • Select the required Pre Function and Post Function from the corresponding drop-down.
  • Choose the required HTTP method.
  • Enter the API URL and specify URL parameters and Request Headers.
  • Choose the type of Authentication details.
  • Enter the Request Payload and select the Content Type from the drop-down.
  • Click Save to create a new webhook.

List View Actions

You can create, edit, delete, enable, disable, and test the webhooks.
