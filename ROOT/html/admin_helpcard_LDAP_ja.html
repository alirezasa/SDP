LDAP認証を使用してLDAPサーバからユーザをインポートできます。LDAP認証を有効にすると、ユーザはLDAPの認証でServiceDesk Plusにログインできます。デフォルトではLDAP認証は無効に設定されています。

 

メモ : LDAP認証を設定する前に、必ずユーザをインポートしてください。LDAP認証はLinuxとWindowsユーザをサポートしています。そのため、LDAP認証を有効にするとWindowsユーザに有効にしていたAD認証は自動的に無効化されます。

 

新規ドメインからユーザをインポート

  1. ドメインコントローラブロックから新規ドメインの追加ボタンをクリック。ドメインコントローラの追加ウィンドウが開く。
  2. ユーザをインポートするドメインコントローラを指定。例： ldap://<サーバ名>:<ポート番号>。デフォルトのポート番号は389。
  3. フィールドにユーザ名を指定。例：CN:john, CN=Users, DC=domain name, DC=com。
  4. パスワードを指定。
  5. 識別名を示すBaseDNを指定。例：CN = Users, DC = domain name, DC = com。
  6. 検索フィルタフィールドに特定のドメインコントローラに適用する条件を指定。例：mail=* を設定すると、指定したドメインコントローラにおいてパラメータメールからユーザをインポート。
  7. LDAPサーバタイプをコンボボックスから選択。例：OpenLDAP。

メモ： Microsoft Active Directory、 NovelleDirectory、OpenLDAPなどのサーバタイプをデフォルトのLDAPとして選択している場合は、ログイン属性ラベル、メール属性ラベル、ユーザログオン名属性ラベルは自動的に出力されます。

  1. LDAPサーバタイプがその他の場合は、ログイン属性ラベルとメール属性ラベルを指定。
  2. ユーザログオン名属性ラベルはBase DNと同様。
  3. 保存 をクリックしてドメインコントローラを保存。設定を保存してインポートする場合は保存/インポートボタンをクリック。

インポートボタンをクリックして既存のドメインからユーザをインポートできます。同じドメインから再度ユーザをインポートする場合は、既存データは上書きされます。ユーザをインポートしたら、チェックボックスを選択してLDAP認証を有効化してください。

保存をクリックすると、ユーザはLDAP認証を使用してアプリケーションにログインできます。
