Vous pouvez définir des règles de notification pour les demandes, les problèmes, les modifications et les modules de solution. Pour configurer les règles de notification, sélectionnez les cases en regard de chacun des rapports indiqués ci-dessus, puis cliquez sur Enregistrer. Vous pouvez également adapter le modèle d'e-mail de la notification qui sera envoyée pour une option particulière. Pour cela, cliquez sur le lien Modèle personnalisé à côté de l’option pour laquelle vous souhaitez modifier le modèle de notification. L’écran actualise les paramètres du Modèle du message où vous pouvez éditer l’objet de la notification et du message en ajoutant ou en supprimant des variables à l’une des sections. Cliquez sur Enregistrer. Pour ajouter ou supprimer les variables de l’objet ou du message du modèle d'e-mail, il suffit de cliquer sur la variable correspondante dans la boîte de liste du côté droit.

Vous pouvez sélectionner quelques techniciens que vous souhaitez informer dès la création d’une nouvelle requête. Pour ce faire, sélectionnez une des cases suivantes :
    • Avertir le(s) technicien(s) par e-mail en cas de nouvelle demande.
    • Avertir le(s) technicien(s) par SMS en cas de nouvelle demande.
Puis, cliquez sur le bouton Sélectionner le technicien, sélectionnez la liste de techniciens que vous souhaitez avertir dès la création d’une nouvelle requête, à partir de la fenêtre instantanée Sélectionner nom de technicien, puis cliquez sur OK.

Cliquez sur Enregistrer.

Les Filtres de notifications indésirables permettent d’éviter que des accusés de réception ou des notifications indésirables ne soient envoyés aux demandeurs/techniciens quand le service d’assistance reçoit un email d’information. Les emails d’information sont des messages qui ne sont pas des requêtes et pour lesquelles aucune action n’est requise. Les Filtres de notification vous permettent d'éviter les e-mails de reconnaissance non souhaités / les alertes envoyées aux demandeurs/techniciens qui pourraient résulter en une boucle e-mail du système non nécessaire. Les reconnaissances d'e-mails comme les réponses Absent(e) du bureau, les notifications de retour lorsque la destionation de l'e-mail est inaccessible (pour cause de mauvaise adresse) peuvent ne pas être reconnues ou notifiées.

Vous pouvez également cliquer sur Modifier les critères et créer un nouveau filtre. Vous pouvez définir une règle désignant les emails n’exigeant pas d’accusé de réception.

Exemple : Vous pouvez créer une règle Titre ne contient pas « Absent » puis l’ajouter à Répond aux critères. Les accusés de réception/notifications seront filtrés lorsqu’une requête répondant aux critères définis est reçue.
