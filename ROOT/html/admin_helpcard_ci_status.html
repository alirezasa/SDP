CI Status

CI status denotes the current state of a CI in the organization.

Create CI Status
  1. Click New.
  2. Provide a unique name to identify the status.
  3. Select a color to denote the status using the color palette.
  4. Describe the status usage and purpose.
  5. Click Save or Save and Add New.
List View Operations
  • Use the filter drop-down to view CI status based on their availability (active or inactive).
  • Use the Actions icon to edit or delete a CI status. You can also click a status name to edit it.
  • To bulk-delete, select the statuses and click Delete on the toolbar.
  • Click the Search icon on the toolbar to search through the list view columns.

Note: If the CI status is deleted while it is in use, it will be marked as inactive.
