Asset Additional Field

Configure asset additional fields to capture extra information about assets. These fields must be added to the product type layout in order to be visible for assets under the product type.

To add a new field:

  • Click New Field.
  • Select the field type from the filter at the top. Available field types include Text, Numeric, and Date/Time.
    • Text fields are of three types: Single-line, Multi-line, and Pick List.
  • Enter a name for the field.
  • If you select a single-line or multi-line text field, you can specify a default value. When this field is included in the product type layout, the default value will be displayed for the field in the asset form.
  • You can encrypt Single-line, Multi-line, and Pick List fields. Data in encrypted fields will not appear in reports or advanced search.
    • Enable the Encrypt the Field checkbox if the field will hold personally identifiable information (PII) or electronic protected health information (ePHI) of users in compliance with GDPR regulations.
  • Enter a brief description of the field.
  • Click Save.

Note:

  • A maximum of 1500 asset additional fields can be created and associated across product types.
  • Default values cannot be entered for date/time fields.
  • When deleting an additional field, any values entered for that field will also be deleted.
