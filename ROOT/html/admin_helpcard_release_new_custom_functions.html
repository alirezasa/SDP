On the displayed page, provide a name and description for your custom action.

Use the simple drag-and-drop interface called the Deluge Script Editor to build your custom action. releaseObj and context will be passed as arguments to the function. The function should return data of the Map type. For more details, visit this page.

Click Save and Test to test run the custom action on releases. Output will be printed along with info statements that are used for debugging. You can also simply save the custom action.
