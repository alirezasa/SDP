Mode refers to the different ways in which incident or service requests can be submitted to the support team and tracked through ServiceDesk Plus. By default, users can submit requests through the following modes:

Email: Sending an email to the support team, which will be automatically logged as a request in the application.
Web Form: Using a web-based Add Request form.
Phone Call: Placing a phone call to a help desk technician, who will in turn file your request.
Chat: Using the live chat option on the application footer to contact your technicians.
Mobile App: Using the Add Request form in ServiceDesk Plus mobile application.

Note:
  • For requests raised via email, chat, or mobile app: Mode will be auto-updated as detected by ServiceDesk Plus. Else, the default mode value configured in request templates will be applied.
  • For requests raised via other modes: Mode will not be auto-updated if the request template has a default mode value.


Add New Mode
1.Click New.
2.Specify a unique name to identify the mode.
3.Enter a short description to explain how the requests are generated in the specific mode.
4.Click Save or Save and Add New.

Edit/Delete Mode
Use the Hamburger icon to edit or delete a mode. To delete modes in bulk, select the modes and use the Delete icon on the toolbar.

Note: If any modes are deleted while being used in requests, the mode will be disabled and marked as inactive. You can restore an inactive mode by editing it.
