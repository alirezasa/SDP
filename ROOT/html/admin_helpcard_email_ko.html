SDP 애플이케이션에서 메일을 가져오고 보내기 위해 필요한 메일 서버 세부 정보를 설정합니다. 문제없이 메일을 보내고 받으려면 수신 및 발신 메일 서버 설정을 모두 설정해야 합니다.

수신 메일 서버 설정
수신 메일 서버 설정에는 다음 필드가 있습니다.

서버 이름/IP 주소: 메일을 가져와야 하는 수신 메일 서버를 나타냅니다.
사용자 이름: 위 서버에 대한 로그인 이름입니다.
패스워드: 위 서버의 메일에 접근하기 위한 패스워드입니다.
이메일 주소: 서비스 요청이 전송되고 이러한 메일만 가져와야 하는 이메일 주소/주소입니다.
이메일 유형: 메일 이메일 가져오기 유형을 나타냅니다(예: IMAP 또는 POP 등). IMAPS를 선택한 경우 전송 계층 보안(TLS)을 활성화하는 옵션이 있습니다. .
포트: 메일을 가져와야 하는 포트입니다.
메일 가져오기 간격: 메일을 수동으로 가져올 필요 없이 주기적으로 가져올 시간 범위를 입력합니다.

이 중 이메일 유형을 제외한 다른 모든 필드는 필수 필드이며 null 값을 사용할 수 없습니다. 위의 세부 사항을 입력한 후 저장 버튼 클릭하십시오. 구성이 저장되고 응용 프로그램이 메일 서버와 연결을 시도합니다. 연결에 성공하면 메일 가져오기 상태가 활성화됩니다. 메일 가져오기를 시작하려면 가져오기 시작 버튼을 클릭하세요. 이제 저장 버튼이 비활성화되었습니다. 수신 메일 서버 설정을 변경하려면 메일 가져오기를 중지한 다음 변경하고 저장해야 합니다.

보내는 메일 서버 설정
보내는 메일 서버 설정에는 다음 필드가 있습니다.

서버 이름/IP 주소: 외부 세계로 메일을 보낼 발신 메일 서버를 나타냅니다.
대체 서버 이름/IP 주소: 위에서 언급한 주 서버가 충돌할 경우 대신할 백업 서버가 있는 경우 여기에 백업 서버 정보를 입력하십시오.
발신자 이름: 발신자의 이메일 ID 옆에 메일에 표시될 이름입니다.
회신 주소: 회신을 보내야 하는 이메일 주소입니다. 일반적으로 수신 메일 서버 설정의 이메일 주소 필드에 값이 지정됩니다.
이메일 유형: 메일 이메일 발송 유형을 나타냅니다(예: SMTP, SMTPS).
TSL 사용: Transport Layer Security(TLS)을 활성화하는 옵션.
포트: 메일을 보내야 하는 포트입니다.

위의 필드 중 서버 명/IP 주소, 회신 이메일 주소, 포트 번호는 필수 필드이므로 null 값을 사용할 수 없습니다.

보내는 메일 서버에 인증이 필요한 경우 인증 필요 확인란을 선택합니다. 보내는 메일을 인증하는 데 필요한 사용자 이름 및 비밀번호를 입력하십시오.

저장을 클릭하여 설정을 저장합니다.

스팸 필터 설정
스팸 필터는 정보 이메일이 헬프 스크에 도달할 때 원치 않는 요청서로 변환되는 것을 방지합니다. 스팸 이메일은 헬프데스크에 로그인하기 위한 것이 아닌 이메일입니다. 스팸 필터를 사용하면 원치 않는 이메일이 요청서로 변환되는 것을 방지할 수 있습니다. 다른 도메인의 이메일(헬프데스크가 내부 고객에게만 서비스를 제공하고 있을 때)이(가) 새 요청서로 생성되는 것을 중지할 수 있습니다. 

요청서로 생성할 필요가 없는 메일을 지정하는 규칙을 정의할 수 있습니다..

예: 발신자에 '@manageengine.com'이 포함되지 않은 규칙을 만들어 기준 일치에 추가할 수 있습니다. 이메일이 도착하고 정의된 기준과 일치할 때 생성되지 않은 요청서를 제외합니다.

저장을 클릭하여 설정을 저장합니다.
