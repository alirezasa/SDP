작업 유형을 사용하면 유사한 작업을 분류할 수 있습니다. 예를 들어, 다양한 종류의 문제 해결과 관련된 작업은 작업 유형 "문제 해결" 아래에 그룹화될 수 있습니다. 이러한 작업 분류는 요청, 문제, 변경 및 프로젝트별 작업 유형을 생성하는 데 도움이 됩니다. 이 작업 유형은 작업을 생성하는 시기에 따라 작업을 분류하는 데 사용할 수 있어 더욱 세분화됩니다.

작업 유형 추가
작업 유형 추가 양식에는 이름, 설명 및 비활성 확인란의 세 가지 필드가 있습니다.

이름: 작업 유형을 식별하는 고유한 이름을 입력합니다.
색상:색상 팔레트를 사용하여 작업 유형을 나타내는 색상을 선택하거나 텍스트 상자에 색상 코드를 지정합니다.
설명: 설명 입력란

에 작업 유형에 대한 간단한 설명을 입력합니다.

저장 버튼을 클릭하여 작업 유형을 저장하고 목록 보기로 돌아갑니다.
저장 및 새로 추가 버튼을 클릭하여 작업 유형을 저장하고 다른 작업 유형을 추가합니다.
