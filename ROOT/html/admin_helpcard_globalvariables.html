Global Variables

Create data placeholders to store information in the application. You can invoke global variables where placeholders are invoked through the dollar sign ($).

Add Global Variables

Global variables are created and stored under groups.
  1. Click New.
  2. Add a name and description for the group.
  3. Specify a unique variable name and its values.
    • Use Toggle to encrypt the values.
  4. Click the Plus icon to add multiple variables in a group.
  5. Click Save or Save and Add New.
Edit/Delete Global Variables
  • On the list view page, click the Hamburger icon to edit or delete variables groups.
  • To bulk delete, select the variable groups and click Delete icon on the toolbar.
View Global Variables in a Group
  • On the list view page, click the Drop-down icon to expand a variable group and preview the variables configured.
Note: You can create up to 50 variable groups with a maximum of 10 variables in each group.
