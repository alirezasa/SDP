그룹 관리

이 옵션을 사용하면 자산 속성을 기반으로 자산을 그룹화할 수 있습니다. 동일한 팀 및 위치에 속한 사용자 자산을 그룹화할 수 있습니다. 그룹을 기반으로 자산을 구성하면 보다 세부적으로 제어할 수 있고 자산을 효율적으로 관리할 수 있습니다. 예를 들어 OS, 서비스 팩, 메모리 크기 등에 따라 자산을 그룹화할 수 있습니다. 마이그레이션을 준비할 때 Windows 11을 배포하기 전에 업그레이드가 필요한 2 GB RAM의 자산을 정확히 찾아낼 수 있습니다.

 

새 그룹 만들기

보다 쉬운 사용자 관리를 위해 사용자를 정적 및 동적 그룹으로 분류할 수 있습니다. 정적 그룹에서 구성원을 나열하여 그룹을 정의합니다. 동적 그룹에서 리소스는 Admin 관리자가설정한 특정 기준에 따라 자동으로 그룹화됩니다.

그룹 관리 페이지의 오른쪽 모서리에 있는 새 그룹 추가 링크를 클릭합니다. 그러면 그룹 만들기 페이지가 열립니다. 여기에는 그룹 이름, 설명 그리고 그룹 유형의 세 필드가 있으며, 그룹 이름과 유형을 필수 입니다.

그룹 이름 텍스트 필드에 그룹 이름을 입력합니다. 필수 입력란입니다.
설명 필드에 새로 생성된 그룹에 대한 관련 정보를 제공합니다. 그룹 이름이 Test DL600이라고 가정하고 Test DL 600은 Dell Lateral 600을 의미하도록 지정할 수 있습니다.

라디오 버튼을 활성화하여 그룹 유형 중 하나를 선택하십시오. 정적 또는 동적 그룹이 있습니다.

정적 그룹: 그룹 구성원을 나열하고 선택하여 정적 그룹을 정의합니다.
동적 그룹: 리소스는 특정 기준에 따라 자동으로 그룹화됩니다.

저장 버튼을 클릭하여 그룹을 저장하십시오.

 

정적 그룹에 리소스를 추가하려면


필터 표시 콤보 상자에서 필터 기준을 선택합니다. 예를 들어 사용 중

인 모든 자산을 선택할 수 있습니다.

검색 필드에 검색 기준을 지정합니다.

Go(실행) 버튼을 클릭하면 필터 기준에 따라 모든 리소스가 나열됩니다. 필터링된 모든 리소스의 목록을 볼 수 있습니다.

확인란을 활성화하여 그룹에 추가할 리소스를 선택합니다.

그런 다음 추가 버튼을 클릭하여 그룹에 리소스를 추가합니다. 그룹의 리소스 열 아래에 표시된 그룹에 추가된 선택한 리소스를 볼 수 있습니다.

 

동적 그룹에 리소스를 추가하려면  

콤보 상자에서 기준 및 조건 을 선택하여 필터 기준을 정의합니다.< /p>

콤보 상자에서 리소스 기준 또는 워크스테이션 기준과 같은 기준을 선택합니다.

콤보 상자에서 조건 을 선택하면 선택한 기준에 따라 나열됩니다.

라디오 버튼 중 하나를 선택하여 일치 기준 중 하나를 선택하십시오. (AND) 또는 (OR) 입니다.

선택 버튼을 클릭하여 선택한 기준에 따라 나열된 리소스 또는 워크스테이션 기준을 선택하십시오. 예를 들어 리소스 기준을 제품 유형 으로, 조건을 is 로 선택한 경우 선택 버튼을 클릭하면 스캐너, 키보드, 프린터 등과 같은 모든 제품 유형 목록이 표시됩니다. ,

나열된 제품 유형 중 하나를 선택하고 확인 버튼을 클릭하여 그룹에 추가합니다.  

저장하고 그룹 보기 버튼을 클릭하면 필터 기준에 있는 모든 리소스 목록이 표시됩니다.         

 

그룹에서 리소스 제거


그룹 내 리소스 열 아래의 확인란을 선택하여 목록에서 리소스 이름을 선택합니다.

추가된 리소스를 제거하려면 제거 버튼을 클릭하십시오. 목록에서 삭제된 선택된 리소스를 볼 수 있습니다.
