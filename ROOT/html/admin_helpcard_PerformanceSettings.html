General Settings

Schedule database maintenance and configure disk usage threshold to optimize the performance of ServiceDesk Plus.

Database Maintenance Schedule

The query optimizer uses table statistics to create query plans. To ensure optimal performance of query plans, the table statistics must be updated regularly.

  • PGSQL - Uses operation VACUUM ANALYZE
    1. Shutdown the application.
    2. Go to [SDP_Home]/bin.
    3. Execute the DBMaintenance.sh (in Linux machines) or
      DBMaintenance.bat (in Windows)script.
  • MSSQL - Uses operation sp_updatestats
    1. Enable Maintenance Schedule.
    2. Select a preferred frequency.
    3. Set a starting date, along with a preferred time.

To avoid performance issues, schedule database maintenance during non-operational hours..

Threshold

Monitoring disk usage is essential to prevent application failure or downtime. You can configure thresholds for the items listed below to ensure your application performance is optimum and send notification if the threshold is reached.

Field Explanation Configuration
Log file size
(displayed only in MSSQL setups)		 Prevent application downtime caused when the transaction log file (.LDF) used to record all transactions in MSSQL server grows large and fills up the disk Enter a preferred file size in MB.
Disk usage
 Prevent application failure caused when the available disk space is consumed as the disk usage increases with time. Enter a preferred value in percentage.
Memory threshold Monitor heap usage. If the memory space used exceeds the configured value, a heap dump will be generated. Enter preferred value in percentage.
CPU usage Ensure steady application performance by monitoring unexpected increase in CPU usage. Enter a percentage value in the CPU usage field.

Enable Send email notification and select the user roles or users to send the email if a threshold is reached.

Click Save.
