On this page, you can configure roles that are company-wide. Besides configuring the roles, you can associate users to these roles. Note that these configured roles can be specific to a region, site, or department.

Note:You can add organization roles from under the ESM directory only.

Organization Roles:For organizational level employees such as CEO, CFO, or CTO.

Regional Roles: For heads of regions such as regional managers or regional sales heads.

Site Roles: For specific roles within a site, given its unique requirements.

Department Roles: For roles that might be unique to each department.

You can create any number of roles within a role type by clicking the symbol. Fill out the required details and click Save.

To associate a user to a role, click the icon inside a role.

For organization roles, select the username in the Associate User pop-up.

For regional, site, and department roles, the Associate User page will be displayed where you will need to select the users.
