Closure code denotes the reason for closing a change request. Using closure code, the Change Manager can comprehend the purpose of closing the change request.

Choose to view Active or Inactive Closure Codes using the dropdown.

Use the Actions icon to edit or delete a closure code.

Use the Search icon to find your preferred closure code.

Click View History to view edits made to closure code.

Adding Closure Code

  • Click New.
  • Specify a unique Name and provide a brief Description about the change closure code.
  • Click Save.
