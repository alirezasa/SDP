Define Survey allows you to add various questions that would be a part of the user survey. Along with adding questions, you can also add the satisfaction levels that will be displayed as answers to each of the questions from which the user has to choose the best answer that will describe their experience.

To add a Survey question
  1. Click + Add Question button in the Question tab. The question window pops up.
  2. Enter the question in the text area provided.
  3. Click Save. The question is added to the survey and is displayed in the Define Survey page under the Questions tab.
To change the order of the questions, click the Move up or Move Down link against the corresponding question.

To add the satisfaction levels
  1. Click Satisfaction Levels tab
  2. Click + Add Level button. The Satisfaction Level window pops up.
  3. Enter the value of the satisfaction level in the text area provided.
  4. Click Save. The level is appended to the end of the list. You can move the same up or down the list of satisfaction levels, by clicking Move up or Move Down links.
The order of the levels determines the value that is associated with each level. The satisfaction level that is on top of the list means that it is the lowest satisfaction level and is associated with the value 1. The reports are generated based on the values associated to each of the satisfaction levels.
 
If the user has purchased multi language license then the Survey Translation tab appears. The survey can be displayed in various languages supported by the application to users located in various locations.  
 
To add a new Translation
  1. Click Survey Translation tab.
  2. Select New Translate link.
  3. Select the language for the survey from Survey Language drop down list. The languages supported by the application is displayed. The language once selected does not get displayed in the drop down list.
  4. Enter the Survey Questions, Satisfactory Levels and Messages in the language selected from Survey Language.
  5. Click Save. The survey for the Translated Language is added to the list view. By default, while adding a new translation, the translated language is enabled. To disable the language, select the check box beside the language to be disabled and click Disable Button.
The survey form for the requester consists of Display Language drop down box consisting of the list of languages configured under Survey Translation. Select the language to view the survey. Disabled languages do not appear under Display Language drop down in User Satisfactory Survey form.
