On this page, you can search, add, delete, and assign roles to users. In addition, you can mark VIP users and merge user accounts. Users you add here can be imported to instances across organization by instance owners.

Adding Users

You can add users into the application manually by importing from Active Directory or by using a CSV file.

Adding Users Manually

Click the New button, fill out the displayed form, and save.
Create a login name and password for the user. This is the credentials with which the user will log into the application. Users can also be added via Active Directory. Refer Active Directory section for more details.
You can also choose to generate API key for the user. The API key can be used to access the web services API. If required set an expiry date for the API key. 

Editing Users

Click the edit icon beside the user in the users list view. Modify the required details and click save. 
Note: Adding/updating Department/site of an user will automatically add/remove the user from the respective instances based on the criteria used to add users in the specific instance.

User Roles

From the ESM Directory, you can only grant Organization Administrator Privileges for an user. Granting this permission for users will give them access to the ESM directory. Use the check box to grant the Org Admin access to the user. 

Importing Users from Active Directory

Click the New drop-down, select Import from Active Directory, fill out the displayed form, and click Import Now.

If you've already entered the domain-related details under Admin->Windows Domain Scan , the details will be auto-populated. Otherwise, go to Admin->Windows Domain Scan in IT HelpDesk and import the user under the ESM Directory.

Adding Users from a CSV file Click the + New drop-down, select Import from CSV, choose your file, and click Submit.

Send Password Reset Link
You can send a password reset link to the users who have forgotten their passwords.
Select a user from the list view to go to the user's details page.
Click Actions menu in the details page and select Send Password Reset Link.
An email with the password link will be sent to the user. The link will be valid for 15 minutes.
Incase if the outgoing mail server is not configured, or if the user doesn't have a primary email ID, or if the user doesn't have a unique email ID, then the email will not be sent. In such cases, a popup with the password reset link will be displayed to the administrator who can share the link with the user.

Merge Users (without criteria) Select duplicated or unique user accounts manually, click Merge user(s) from the Actions drop-down.
Select the parent account and click Merge user(s).

Merge Duplicated Users (with criteria) Merge accounts with duplicate Login Name or Email ID in different domains. Their attribute values will also be merged.

Click Merge User, select criteria to identify duplication as Login name or Email ID, enter the domain names (two domains/one domain and no domain labelled as None), and click Apply Filter.

The duplicate account pairs across the selected domains will be listed. Select the accounts to be merged and click Merge user(s). Select the parent domain and click Merge user(s).

Deleting Users

Select users from the list view, click Actions, and select Delete User(s). Deleting a user will delete the user from all instances as well. 
If you have enabled the GDPR settings under Privacy Settings, you can change the user names to any random text during deletion. This change will be effected across all modules within the application.
