Release roles are defined by the tasks and responsibilities assigned to them. You can configure a role by specifying the access permissions to different stages of the release management process and by defining who can be assigned the role.

Users can play multiple roles in one or more releases. The Release Manager can access all releases without being assigned any release role. Besides customizing default release roles, you can add new release roles per requirements.

  • Use the New button to add a release role. Specify who can be associated with the role and select the access permissions.
  • Use the Hamburger icon to edit or delete a release role. You can also click a role name to edit it.

By default, all release roles will have permission to view releases in all stages.

Note:

Roles such as Release Manager, Release Engineer and Release Requester cannot be deleted.

If a release role is deleted while being used in releases, the role will be disabled. You can restore an inactive release role by editing it.

The disabled/deleted role will be removed from the release templates they are configured with.
