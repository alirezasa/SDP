휴근 종류은 휴근을 적용하는 가장 일반적인 이유를 구성할 수 있는 곳입니다. 기술자가 스케줄러에서 휴근을 신속하게 신청할 수 있도록 휴근 유형을 구성하는 것이 중요합니다. 각 휴근 유형은 색상 코드를 사용하여 명확하게 식별되므로 관리자가 기술자가 휴근을 신청하는 이유를 쉽게 이해할 수 있습니다.

휴근 종류 목록 보기 페이지의 오른쪽에 있는 새 휴근 종류 링크를 클릭합니다.  

 

새 휴근 종류

  1. 주어진 텍스트 필드에 휴근 종류의 이름을 입력합니다. 예를 들어, 병가, 근무 중, 선택 사항 등이 있습니다. 지정된 이름은 고유해야 하며 필수 필드입니다.
  2. 기술자 근무 차트에서 휴근 종류를 나타내려면 색상을 선택합니다.
  3. 설명 텍스트 필드에 휴근 종류에 대한 간략한 설명을 지정합니다.
  4. 저장을 클릭합니다. 휴근 종류가 목록 보기 페이지에 나열됩니다.
  5. 다른 휴근 종류를 저장하고 추가하려면 새로 저장 및 추가를 클릭하십시오.
