SDP-ELA Integration :

EventLog Analyzer Integration helps collect, manage, and generate reports of ServiceDesk Plus debug logs and web server access logs.

  • Select the Enable EventLog Analyzer check box to display the menu in the application's header. After integration, technicians can use this menu to access EventLog Analyzer.

  • Use the following pointers to configure the server settings.

    • Hosted URL: Enter the hosted URL of the EventLog Analyzer.
    • Username: Provide the EventLog Analyzer admin credentials.
    • Password: Provide the EventLog Analyzer admin credentials.
    • Logs: Select the type of logs that you want EventLog Analyzer to collect from ServiceDesk Plus. Select either Debug Logs, Access Logs, or both.

  • Click Save to save the settings or Remove to clear the fields.
