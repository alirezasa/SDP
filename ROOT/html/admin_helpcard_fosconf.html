FOS Configuration Failover Service (FOS) configurations ensure availability of ServiceDesk Plus in case of hardware/software failure.
Failover Service works by implementing a hot-standby system: a primary server actively runs ServiceDesk Plus while the secondary server stays in a standby mode and monitors the health of the primary server periodically. In the event of failure, it takes over as the primary server. When the primary server comes back online, it will start as the standby server.
Both primary and secondary servers are connected to a common database server.
Select the Enable FOS Startup mode check box to launch ServiceDesk Plus in the failover service mode.
Primary Machine Details :
  • Primary Server IP - Enter the IP address of the primary server where ServiceDesk Plus is running.
  • NIC of Primary Server - Enter the Network Interface Card (NIC) address (also called the physical address) of your primary server. The NIC address should be enclosed within curly braces { }.
    • Tool to identify the NIC address
    • ServiceDesk Plus contains a built-in provision to help you identify your NIC address.
    • Go to {SDP_Home}\bin directory in your primary server and execute the iflist.exe tool.
    • Locate the NIC Card whose Adapter Status is UP and copy its Adapter Name to ServiceDesk Plus.
  • Subnet Mask of Primary Server - Enter the subnet mask to determine your network ID and host ID from your primary server IP address. The default subnet mask is set at 255.255.255.0. You can also configure other valid subnet mask values.

General Details :
  • Virtual IP - Ensure that the virtual IP address you configure belongs to the subnet mask and not bound to any existing servers in the network.
    • How to test the virtual IP address?
    • Open your command prompt and execute the following command: ping {insert IP address}.
    • If you receive request timed out message, it means the virtual IP address is available for use.
  • Common Alias Name -  Specify a custom domain name to access ServiceDesk Plus.
  • In case of failover notify to -  Add email addresses of technicians who must be notified about alerts on self monitoring, data sync, and secondary server takeover. Use commas to separate the email addresses.
Note : After setting up the high availability configuration, set up the file replication configuration and restart ServiceDesk Plus for the settings to take effect.
DR Configuration In a disaster recovery model, resources are replicated to a different data center located in a geographical region away from the disaster zone.
Both primary and secondary servers are connected to a common database server.
Select the Enable DR Startup mode check box to launch ServiceDesk Plus in the disaster recovery mode.
Disaster Recovery Details :
  • Primary Server IP - Enter the IP address of the primary server where ServiceDesk Plus is running.
  • Secondary Server IP - Enter the IP address of your secondary server(standby server).
  • Common Alias Name - Specify a custom domain name to access ServiceDesk Plus.
  • In case of disaster notify to -  Add email addresses of technicians who must be notified about alerts on self monitoring, data sync, and secondary server takeover. Use commas to separate the email addresses.
Note : After setting up the high availability configuration, set up the file replication configuration and restart ServiceDesk Plus for the settings to take effect.
