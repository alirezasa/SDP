ADManager Plus 통합

ServiceDesk Plus를 ManageEngine ADManager Plus와 통합하고 Active Directory 사용자 계정을 쉽게 관리하십시오. ADManager Plus는 대량 Active Directory 사용자 생성/관리, Active Directory 사용자/그룹 수정을 용이하게 하는 간단하고 사용하기 쉬운 Windows Active Directory 관리 및 보고 솔루션입니다. Active Directory 컴퓨터 관리 등. 이 두 제품을 모두 설치한 경우에는 포트 번호와 함께 ADManager Plus가 설치된 컴퓨터의 세부 정보를 제공하기만 하면 됩니다.

제공해야 할 정보:

서버 명: ADManager Plus가 설치된 서버를 입력하십시오.

서버 포트: ADManager Plus의 포트 번호를 입력하십시오.

프로토콜 설정: 프로토콜 설정을 선택하십시오. http 혹은 https.

 

저장을 클릭하십시오. 설정이 성공적으로 저장되고 ServiceDesk Plus가 ADManager Plus 서버와 연결을 시도합니다. 연결이 설정되면 점프 링크를 사용하여 ADManager Plus 서버를 사용할 수 있습니다.

ADSelfService Plus와 통합

ServiceDesk Plus를 ManageEngine ADSelfService Plus와 통합하고 Active Directory 사용자가 Active Directory 암호와 Active Directory 계정을 쉽게 셀프 서비스할 수 있도록 합니다. ManageEngine ADSelfService Plus는 안전한 웹 기반 최종 사용자 비밀번호 재설정 관리 프로그램입니다. 이 소프트웨어는 도메인 사용자가 Microsoft Windows Active Directory에서 비밀번호 셀프 서비스, 계정 셀프 서비스 및 개인 세부정보(예: 전화번호, 이메일 ID 등)의 셀프 서비스를 수행하는 데 도움이 됩니다. 이 두 제품을 모두 설치한 경우 포트 번호와 함께 ADSelfService Plus가 설치된 컴퓨터의 세부 정보를 제공하기만 하면 됩니다.

제공해야 할 정보:

서버 명: ADSelfService Plus가 설치된 서버를 입력하십시오.

서버 포트: ADSelfService Plus의 포트 번호를 입력하십시오.

프로토콜 설정: 프로토콜 설정을 선택하십시오. http 혹은 https.

 

기술자를 위한 AD 셀프 서비스 메뉴 활성화 옵션을 선택하여 기술자를 위한 AD 셀프 서비스 메뉴를 표시합니다. 이 메뉴는 ServiceDesk Plus와 ADSelfService Plus 제품의 통합 상태와 상관없이 표시됩니다. 요청자에 대해 AD 셀프 서비스 탭 사용 옵션을 선택하여 요청자에 대해 AD 셀프 서비스 탭을 표시합니다. "Ad Self Service" 탭은 ServiceDesk Plus가 ADSelfService Plus 제품과 통합된 경우에만 요청자 로그인에 표시됩니다.

 

저장을 클릭합니다. 설정이 성공적으로 저장되고 ServiceDesk Plus가 ADSelfService Plus 서버와 연결을 시도합니다. 연결이 설정되면 점프 링크를 사용하여 ADSelfService Plus 서버를 사용할 수 있습니다.

Integrate with Desktop Central

톨합 절차 : 비디오 설명 | 도움말 문서

ServiceDesk Plus를 ManageEngine Desktop Central과 통합하여 모든 데스크톱 및 모바일 장치 관리 기능을 관리하십시오. Desktop Central은 패치 설치, 소프트웨어 배포, 원격 제어, 채팅 시작, 클라이언트 컴퓨터 보안, USB 사용 제한 적용 등과 같은 데스크톱 관리 활동을 자동화합니다. 또한 프로필 관리, 앱 관리, 보안 관리 및 자산 관리를 통해 모바일 장치를 관리할 수 있습니다. 이 두 제품을 모두 설치했다면 Desktop Central이 설치된 컴퓨터의 세부 정보와 포트 번호를 제공하면 됩니다.

참고: Desktop Central 버전은 8.1 이상이어야 합니다.

제공할 정보:

서버 명: Desktop Central이 설치된 서버를 입력하십시오.

서버 포트: Desktop Central의 포트 번호를 입력하십시오.

프로토콜 설정: 프로토콜 설정을 선택하십시오. http 혹은 https.

 

참고: To display Desktop 관리와 MDM 드롭 다운 메뉴를 표시하려면, 데스크톱 관리 메뉴 활성화 및 MDM(모바일 장치 관리) 메뉴 활성화 확인란을 각각 선택하십시오. 데스크탑 관리 또는 MDM 기능 통합에 관심이 없고 데스크탑 관리 또는 MDM 드롭다운 메뉴를 제거하려면 해당 확인란의 선택을 취소하십시오. and Save.

 

저장을 클릭합니다. 설정이 성공적으로 저장되고 ServiceDesk Plus가 Desktop Central 서버와의 연결을 시도합니다. 연결이 설정되면 Desktop Central 서버에서 구성된 소프트웨어 세부 정보를 가져옵니다.

 

OpManager 와 통합

ServiceDesk Plus를 ManageEngine OpManager와 통합하고 네트워크를 효과적으로 모니터링하십시오. OpManager는 대기업, 서비스 제공업체 및 중소기업이 데이터 센터와 IT 인프라를 효율적이고 비용 효율적으로 관리하는 데 도움이 되는 네트워크 및 데이터 센터 인프라 관리 소프트웨어입니다. 자동화된 워크플로, 지능형 경고 엔진, 구성 가능한 검색 규칙 및 확장 가능한 템플릿을 통해 IT 팀은 설치 후 몇 시간 이내에 24x7 모니터링 시스템을 설정할 수 있습니다. 이 두 제품을 모두 설치했다면 OpManager가 설치된 컴퓨터의 세부 정보와 포트 번호만 제공하면 됩니다.

제공할 정보:

서버 명: OpManager가 설치된 서버를 입력하십시오.

서버 포트: OpManager의 포트 번호를 입력하십시오.

프로토콜 설정: 프로토콜 설정을 선택하십시오. http 혹은 https.

 

Click Save. 설정이 성공적으로 저장되고 ServiceDesk Plus가 OpManager 서버와 연결을 시도합니다. 연결이 설정되면 점프 링크를 사용하여 OpManager 서버를 사용할 수 있습니다.

 


Password Manager Pro와 통합

SDP-Password Manager Pro 통합은 PMP 관리자와 비밀번호 사용자가 두 애플리케이션에서 리소스를 효율적으로 관리할 수 있도록 도와줍니다. 관리자 및 암호 사용자는 자원 계정의 암호를 볼 수 있으며 ServiceDesk Plus에서 원격으로 자원에 액세스할 수 있습니다.

ServiceDesk Plus Server 구성과 PMP 내의 인증 :

제공할 정보 :

PMP가 호스트된 URL :Password Manager Pro가 설치된 서버를 입력합니다.

포트 : Password Manager Pro 의 포트 번호를 입력하십시오.

 

Click Auth Token(인증 토큰) 생성. Password Manager Pro 애플리케이션은 브라우저의 새 탭에서 열리며, 여기서 승인 버튼(관리자 권한 필요)을 클릭하여, ServiceDesk Plus에 대한 인증 토큰을 생성할 수 있습니다..

 

인증 토큰: Password Manager Pro 애플리케이션에서 생성된 인증 토큰을 입력합니다.

 

Click 연결을 시험하고 저장을 클릭합니다. ServiceDesk Plus는 Password Manager Pro 서버와 연결을 시도합니다. 연결이 설정되면 Password Manager Pro 구성이 저장됩니다.

 

다른 ME 제품(HTTPS mode로 동작)과 통합

  1. 아래 링크에서 .zip 파일을 다운로드하고 "ManageEngine\ServiceDesk"에 압축을 풉니다.

    2. Linux 용: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1cb6g423n1gp9135o97nfchub1/lincertgeneration.zip

    Windows 용: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1cb6g2tdh126s6hmhpvjja2si1/windowscertgeneration.zip

  2. 명령 프롬프트에 연결합니다. "ManageEngine\ServiceDesk"로 이동하여 다음 형식으로 배치 파일을 실행합니다.

    3. Linux 용:
    C:>ManageEngine\ServiceDesk>gencert.sh servername:portnumber

    Windows 용:
    C:>ManageEngine\ServiceDesk>gencert.bat servername:portnumber

  3. 명령을 실행하면 PKIX 예외가 발생하고, 한 값을 입력하라는 메시지가 표시됩니다. 1을 입력하면"ManageEngine\ServiceDesk" 아래에 jssecacerts이라는 파일이 생성됩니다.

  4. "ManageEngine\ServiceDesk\jre\lib\security" 폴더 아래의 jssecacerts 파일을 복사한 다음 ServiceDesk Plus 애플리케이션을 다시 시작합니다.

Zoho Creator와 다른 앱과 통합

ServiceDesk Plus를 Zoho Creator 앱과 통합하여 조직에 유용한 양식을 작성하고 외부 링크를 입력하십시오.

제공해야 할 정보:

활성화/비활성화 : '활성화'를 클릭하면 드롭다운과 함께 빠른 링크 탭에 앱 이름이 표시됩니다. 비활성화하면 빠른 링크 탭에서 이름이 숨겨집니다.

앱 관리: '앱 관리'를 클릭하면 활성화하고 세부 정보를 제공해야 하는 새 창을 볼 수 있습니다.
