Create templates to capture details about frequent incidents as problem requests. Each template can be configured with different fields and tasks vital in problem management.

To create a problem template,

    Click New Problem Template. You can customize fields in the template form, add available fields, associate tasks, or create new ones. Design the template layout by grouping the fields into sections.
  • Using the Hamburger icon, you can edit, delete a problem template or mark it as default.
  • To delete problem templates in bulk, select the templates and click the Delete icon.
  • Click View History to track all operations performed on problem templates.

Note:

Default templates cannot be deleted.

If a problem template is deleted while being used in problems, the template will be marked as inactive. Use the filter dropdown on the toolbar to view inactive templates. You can restore an inactive problem template by using the Hamburger icon.
