서비스의 릴리스 관리 프로세스는 9개의 순차적 스테이지로 구성됩니다. 각 스테이지의 상태는 릴리스의 진행 상황을 나타냅니다. 기본 스테이지 및 상태를 사용자 지정하는 것 외에도 사용자 지정 상태를 추가할 수 있습니다.

스테이지 이름이나 옆에 있는 드롭다운 아이콘을 클릭합니다. 스테이지 세부 정보 페이지가 확장되어 기본 상태를 사용자 정의하고 스테이지 아래에 새 상태를 추가할 수 있습니다.

  • 새 릴리스 상태 버튼을 사용하여 단계에 상태를 추가합니다. 상태 세부정보를 언급하고 릴리스가 상태에 도달하면 알림을 받을 역할을 구성할 수 있습니다.
  • 상태를 수정하려면 상태를 클릭하거나 햄버거 아이콘 아래의 편집 버튼을 사용하십시오.
  • 햄버거 아이콘을 사용하여 상태를 삭제합니다. 그러나 일부 기본 상태는 삭제할 수 없습니다.

참고 사항:

릴리스에서 사용 중 릴리스 상태가 삭제되면 상태가 비활성화됩니다. 비활성 상태를 편집하여 복원할 수 있습니다.
