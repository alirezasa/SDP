After setting up the service desk instances, you can customize the ESM portal layout, set a default landing page for users, and configure alias URL for instances.

Customize the ESM Portal:

  • Use the Customize button to add template variables to render various elements to the layout.
  • Add variable to the code using the Insert Variable drop-down. You can type in HTML code for adding external links for intranet pages or resource pages.
  • You can preview the output using preview mode or split mode.
  • Use the Replace button at the top right to revert the code to the default version. Use Replace with Published content to get the published version of the layout back.
  • Save the code as a draft to review your changes locally.
  • To publish the changes, click Save and Publish.
Organize Instances

Customize the order of instances effortlessly with the "Organize Instances" feature under ESM Portal Customization. You can change the sequence of instance listings using a simple drag-and-drop method. Additionally, you can allow your users or technicians to personalize the order of instances in their portal.

To rearrange,

  • Drag and drop the instances into their desired order.
  • Click "Save" to apply the new order.
Adding a New Custom Instance Link

Enhance your ESM portal by adding external instance links with ease. For example, you can add a ServiceDesk Plus Cloud instance link and make it accessible to your end users from within your ESM portal.

To add a custom instance link,

  • Provide a name and description for the custom URL, making it easily identifiable.
  • Include an icon that represents the linked instance.
  • Enter the URL of the instance you want to link to.
  • Choose between HTTP or HTTPS, depending on the URL's security protocol.
  • Specify how you want the link to open: either in a new tab or in the same tab.
  • Click the "Save" button to save your custom instance link.
Default Landing Page:

You can set a default landing page for all the users in your organization who do not have a default landing page on their own.

  • You can set the ESM portal as the default landing page for users or allow users to set an instance as their own default landing page.
  • You can also select an instance as the default landing page for all users. Users can override this setting by selecting their own preferred landing page.
  • Click Save.
URL Redirection for Service Desk Instances:

You can configure alias URLs specific to a service desk instance to allow users to access service desk instances directly. Alias URLs allow administrators to customize the URL of an instance and redirect users to the Home tab of the instance.

  1. Select the preferred instance from the drop-down.
  2. Enter the alias URL in the text field.
  3. Click Save.
Note: The application server must be restarted for the alias URL to take effect.
