표시된 페이지에서, 전역 함수의 이름과 설명을 입력하싲시오.

Deluge Script Editor라는 간단한 드래그 앤 드롭 인터페이스를 사용하여 전역 기능을 구축하십시오. 반환 유형을 선택하고 최대 10개의 매개변수를 지정할 수 있습니다. 자세한 내용은 이 페이지를 방문하십시오.

전역 함수를 테스트하려면 Save and Test (저장 및 테스트)를 클릭하고 매개변수 값을 지정한 다음 Execute(실행)을 클릭합니다. 출력은 디버깅에 사용되는 info 문과 함께 인쇄됩니다. 전역 함수를 간단히 저장할 수도 있습니다.

전역 함수를 저장한 후 내부 이름 global_function_<id>이 할당되며 이는 Deluge 편집기의 헤더에 표시됩니다. 이 내부 이름을 사용하여 요청에서 전역 함수를 호출하거나 사용자 정의 함수를 변경할 수 있습니다.
