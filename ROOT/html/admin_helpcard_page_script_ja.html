ページスクリプトを用いることで、要件に応じてServiceDes Plusをページごとにカスタマイズすることができます。ユーザー向けのページスクリプトを利用して、 SrviceDesk Plusのページ内のUI要素や機能を修正することができます。例えば、ユーザーのリクエスト詳細ページやリクエスト一覧ページで、特定のボタンを非表示にすることが可能です。また、モジュール内のページ全体に、技術担当者/依頼者向けの新規ウィジェットや、ビデオ、Webページ、フォームなどを追加することもできます。


ページスクリプトを実行するには、初めにルールと条件を定義する必要があります。

  • 新規ルールを作成するには、ルール名を入力して、そのルールが誰に適用されるかを選択します。選択肢として、「依頼者のみ」、「技術担当者のみ」、「すべてのユーザーに適用」があります。
  • ルールがどこで適用されるかを選択します。選択肢として、「リクエスト一覧ページ」、「リクエスト詳細ページ」、「すべてのページ（全モジュールのページ）」があります。
  • ページスクリプトを実行する条件を設定します。複数の条件を設定することができます。
  • ルールを設定後、カスタマイズを実行するためのカスタムスクリプトを作成することができます。
  • デフォルトで、いくつかの基本的なカスタムスクリプトが用意されています。必要であれば利用することができます。

独自のカスタムスクリプトを作成して、実行することもできます。
