Le niveau de demande est une mesure utilisée pour indiquer la complexité d’une demande. Cela permet la bonne affectation des demandes aux techniciens correspondants qui ont suffisamment d’expérience pour gérer ces demandes.

Pour ajouter un nouveau niveau, cliquez sur le lien Ajouter un nouveau niveau dans l’angle droit du tableau Liste des Niveaux.

Ajouter un nouveau niveau
Le formulaire Ajouter un niveau ci-dessus a deux champs, à savoir Nom et Description.

Dans Nom du niveau, vous indiquez le nom unique qui est utilisé pour identifier chaque niveau.

Vous pouvez saisir une brève description sur le niveau dans le champ Description. Cela aidera à trouver les demandes qui doivent être classées dans ce niveau, à moins bien sûr, que le nom du niveau ne soit suffisamment clair.

Pour enregistrer le niveau et revenir à l’affichage liste, cliquez sur le bouton Enregistrer.
Pour enregistrer le niveau et en ajouter un nouveau, cliquez sur le bouton Enregistrer et ajouter nouveau.
