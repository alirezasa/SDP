이 페이지에서 사건 템플릿을 검색, 추가, 재정렬, 삭제, 비활성화 및 활성화할 수 있습니다.

새 템플릿을 클릭하고 표시된 양식을 작성합니다.

재정렬 버튼을 클릭하고 템플릿을 올바른 위치로 드래그하거나 제공된 상자에 위치를 입력합니다.

현재 요청서에서 사용 중인 템플릿을 삭제하면 템플릿을 더 이상 사용할 수 없습니다. 이를 되돌리려면 해당 템플릿을 클릭하고 템플릿을 더 이상 사용할 수 없음 옵션을 선택 취소합니다.


기술자 템플릿 사용자 정의

표시된 필드를 작성하십시오.

템플릿, 섹션 또는 필드에 대해 표시된 사용자 정의 아이콘을 클릭하여 크기와 색상, 배경색, 필드 방향을 비롯한 글꼴을 맞춤설정할 수 있습니다.

기본 및 사용 가능한 필드 외에 새 필드에서 사용자 정의 필드를 추가할 수 있습니다. 기밀 정보를 포함할 수 있는 새 사용자 정의 필드를 추가할 때 개인 식별 정보 포함 옵션을 선택하십시오. 또한 정보를 암호화해야 하는지 여부를 선택합니다.

암호화된 데이터는 보고서, 고급 검색 또는 사용자 정의 필터에 표시되지 않습니다.

섹션을 사용하여 필드를 그룹화합니다. 새 필드

에서 새 섹션을 추가할 수 있습니다.

템플릿을 선택 지원 그룹과 연계하여 템플릿 사용을 제한합니다. 지원 그룹을 연계하지 않으면 모든 기술자가 템플릿에 액세스할 수 있습니다.

템플릿을 요청자에게 표시하려면 요청자에게 표시를 선택합니다. 사용자 그룹을 템플릿과 연계하여 특정 사용자 그룹이 사용하도록 템플릿을 제한할 수도 있습니다. 개별 필드를 수정하고 요청자가 해당 필드를 보거나 수정할 수 있는지 여부를 선택합니다.

요청자가 설정하도록 선택한 필드만 요청자 템플릿의 기본 필드로 표시됩니다.

참고: 요청자가 볼 수 있도록 선택한 필드는 요청 세부정보 페이지에만 표시됩니다.

템플릿을 복제하려면 템플릿 복사 버튼을 사용하십시오.


요청자 템플릿 사용자 정의

요구 사항에 따라 템플릿을 사용자 정의합니다.

템플릿 또는 섹션에 대해 표시된 사용자 정의 아이콘을 클릭하여 크기와 색상, 배경색, 필드 방향을 비롯한 글꼴을 사용자 정의할 수 있습니다.

양식에 기본 필드를 추가합니다. (필드는 편집할 수 없습니다.)

필드의 기본값은 기술자 탭에서만 설정할 수 있습니다.

섹션을 사용하여 필드를 그룹화합니다.


구성 워크플로

  • 승인: 모든 승인자의 승인을 의무화하거나 승인자 중 누구라도 요청서를 승인하도록 선택할 수 있습니다.
  • 체크리스트: 기술자가 체계적인 방식으로 요청서를 완료하도록 안내하는 체크리스트를 구성할 수 있습니다. 체크리스트는 라디오 버튼, 한 줄 텍스트 상자, 숫자 전용 텍스트 상자 및 결정 상자와 같은 여러 필드 유형을 지원합니다.
  • 작업: 사건 요청서 템플릿에 대해 여러 작업을 구성하고 종속성을 구성 및 설정할 수 있습니다. 또한 요청서 속성을 작업과 연결하여 작업 담당자를 지원하고, 요청자에게 작업을 표시하고, 작업을 추가할 시기(요청서 생성 후 또는 승인 후)를 선택하고, 작업을 트리거할 시기(요청서 생성 후, 승인 후 또는 수동)를 선택할 수도 있습니다..
