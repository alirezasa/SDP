Organize Tabs

Orgnize Tabs enables to re-organize header-pane tabs

User Personalization

SDAdmin can enable/disable users to customize the module tabs using 'Allow other technicians to personalize their tabs' checkbox. This option is disabled by default.

Note:
  • When 'Allow other technicians to personalize their tabs' is selected, 'user personalization' would take preference over Admin configurations.
  • SDAdmin can only reorder the module tabs and other users can enable,disable and reorder the module tabs.
  • 'Reset' button will be available when reordering is performed , reset to default existing order in admin page and reset to admin settings order in organizeTabs panel.
  • Changes made in organize tabs Settings will be applied to all Technicians.
