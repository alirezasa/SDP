認証ライブラリはスキャンおよびリモートコントロールを実行する際に利用する認証情報のライブラリです。ここで設定した認証情報は、ネットワークスキャン、個別スキャン、リモートコントロール実行時に関連付けることができます。スキャンプロトコルは、WMI、Telnet/SSH、SNMP V1/V2、VMwareです。

認証の追加

  1. 認証タイプ- 追加する認証のタイプをドロップダウンリストから選択します
  2. 認証の名称と説明を入力します
  3. 選択したプロトコルに対するユーザ名（ドメイン名\ユーザ名）とパスワードを入力します
  4. Telnet/SSH の認証の場合は次を指定します
    認証タイプ - Telnet/SSH
    ポート番号 - 22 （デフォルト）
    必要に応じて、認証に公開鍵を使用するチェックボックスを有効にする
  1. SNMP V1/V2 の認証の場合は次を指定します
    SNMP Read コミュニティ - パスワード
    SNMP ポート - 161 （デフォルト）
    タイムアウト (接続が試行される時間) - 5秒 (デフォルト）
    リトライ (タイムアウトが発生する前に実行するリトライ回数） - 0 (デフォルト）
  1. VMware の認証の場合は次を指定します
    2. HTTPS ポート - 443 (デフォルト）
    タイムアウト（秒）(接続が試行される時間) - 60 秒 (デフォルト）
  2. 認証の保存をクリック

メモ: リモートコントロール認証（認証ライブラリで設定）はリモートコントロール選択時に表示されます
