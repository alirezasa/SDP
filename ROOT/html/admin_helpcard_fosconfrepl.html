FOS file replication configuration lets you schedule an automated replication of the data from the primary to secondary server. The replication of data occurs once every minute so that if the primary server fails, the secondary server can take over immediately without any loss of data.
To configure FOS data replication, enter the primary and secondary server details as follows,
Primary Server Details :
  • Primary Server IP - The IP address of the primary server is auto-populated from FOS Configuration.
  • Username - Enter the username used to log into the primary server.
  • Password - Enter the password used to log into the primary server. The password is encrypted and stored in ServiceDesk.
Secondary Server Details :
  • Secondary Server IP - The IP address of the secondary server is auto-populated from FOS Configuration.
  • Username - Enter the username used to log into the secondary server.
  • Password - Enter the password used to log into the secondary server. The password is encrypted and stored in ServiceDesk.
Note : You can configure FOS File Replication only if FOS configurations are set up. Restart ServiceDesk for the configurations to take effect.
