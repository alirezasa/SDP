Custom Contract Notification Template

 

Customize and personalize the message content for contract expiry notification which is sent to the users before a contract is about to expire.

 

You can select the variables from the pick list beside the Subject and Message block. Clicking on the variables, automatically adds the variable in the message content. Say, the variable $ContractID is replaced with the contract ID of the contract which is about to expire.

 

Click Save to save the details.
