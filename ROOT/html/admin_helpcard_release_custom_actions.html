On this page, you can create and manage release custom function to perform custom actions such as update release fields, release title, assign priority, add notes, associate changes or projects with release, and the like.

You can also use custom functions to manipulate data in ServiceDesk Plus and third-party applications. Custom functions are built on Deluge, Zoho's propriety scripting language.

  • To create a custom function, click New.
  • To bulk delete, disable, and enable custom functions, click Actions.
  • To modify individual custom function, use the icons beside the custom function.

Note: Only active custom actions will be available for use in the configurations mentioned above.
