OAuth Providers allows you to track and manage authorization servers that enable the application to retrieve user data and authorize logins.

Create an OAuth Provider

  • Click + New.
  • On the slideout,
    • Enter the authorization server name.
    • Specify the Client ID, Authorization URL, and Token URL generated while registering the application in the authorization server.
    • Upload the icon to be displayed on the login form.
    • Click Add.

List View Actions

  • Use the Actions icon next to an OAuth Provider name to edit and delete the record.
  • Use the search icon to filter out a specific OAuth Provider.
  • You can also set the number of records to be displayed per page, navigate through different indexes, and view history.
