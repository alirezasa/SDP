Purchase Default Values

Purchase default values allows you to set default values to be populated in the New Purchase Order form.

  • Default Sales Tax Rate (%): The default tax rate to be displayed in the PO form. You can provide a different tax rate to a specific PO by entering the new rate while creating the PO.
  • Signing Authority: The name of the Signing Authority to be displayed in the PO form.
  • Tax Shipping: Enable this to calculate sales tax on the Total (Net) inclusive of the shipping cost.
  • Shipping Address: Select the default Site to which the PO items needs to be shipped.
  • Billing Address: Select the default Site for invoice and billing the PO items.
  • Cost Center: Default cost center code to be displayed.
  • PO Owner as Approver: Enable the check box if you want the PO owners to approve their own purchase orders.
  • Terms: Default terms while making a purchase.
  • Remarks: Default remarks, if any, while making a purchase.
  • PO# Start From: Customize the PO number sequence by providing the starting value.
  • Mandatory fields for Closing Purchase Order: Configure the mandatory purchase additional fields by selecting your preferred fields from the combo box.
