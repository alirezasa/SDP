Spam Filter Settings

Spam Filter prevents unwanted emails being converted to requests by filtering the e-mails that reach the helpdesk. Spam emails are emails that are not intended to be logged into helpdesk. The e-mails from other domains (when helpdesk is serving only the internal customers) can be stopped from being created into new requests. 

You can define rules stating which e-mails need not be created as requests.

Example: You can create a rule 'Sender does not contain '@manageengine.com'' and add it to Match the Criteria.

Click Save to save the settings.
