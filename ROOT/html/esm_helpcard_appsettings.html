Application Settings

Configure settings that are applicable across the application.

Alias URL

You can provide an alternate URL for the application server in the text field beside the http:// text (along with the port number, if needed). Use the Check alias URL hyperlink below the text field to test the alias URL connectivity.

Display Language

Select the language in which the application should be displayed from the drop-down. The default browser language is English.

Requesters can access their profiles

Configure profile accessibility for end-users by choosing the information you want the end-users to access.

  • Edit profile: Give permission for your users to edit their profiles.
  • View basic details: Let your users view only the basic details in their profiles.
  • View additional fields: Allow users to view information entered in the additional fields.

Allow technicians to create new users in the instance

By default, technicians cannot add new users to their instance manually. To enable manual user addition in specific instances, check Allow technicians to create new users in the instance. This option will add a new setting called Adding Requester to user roles in the selected instances. Configure a role with this setting and associate it with the required technicians.

Other Customizations

Use the various configurations given to customize your ServiceDesk.

Option Enabled Disabled
Allow dynamic user addition when the user is not in the application When a user is not imported into the application but imported through Active Directory, then the user can login to the application using the AD credentials. This will automatically provide login access to the application. Prevent dynamic user addition when the user is not imported into the application.
Override user information based on email ID While importing users using Active Directory, CSV and LDAP, the existing user information is overwritten based on two criteria - The first criteria is based on the username and Domain, and the second criteria is based on e-mail ID. Requesters will not be allowed to reopen their own requests unless sufficient privileges are given.
Allow login access for users created by email requests While sending an email request for the first time, the users will automatically be provided with login access. Login access will not be provided to users created through email requests.
Allow user login based on local authentication Users are allowed to login to the application using local authentication. Prevent users from logging-in based on local authentication.
Process messages from new email ID Mails from a new email address can be fetched into the application. Mails from a new email address can be prevented from being fetched into the application.
Hide ChatGPT Integrations Hide ChatGPT integration in regions where ChatGPT is not supported. Keep ChatGPT integration visible and operational.

Time frame for deleting the Trashed Requests (in days)

Set a time frame for permanently deleting the trashed requests. For example, if 5 is chosen then the requests that are trashed 5 days before will be permanently deleted from the application.

Delete admin histories older than

Use drop-down to select the period to delete admin history.

Customize Header

You can replace the default header image by importing a custom image. Click Import image button to upload a custom image to your header. The dimensions of the header image must be 166 x 46 pixels (W x H). Subsequently, you can change the custom image or use the default image if needed.

Customize Login Page

Customize the application login page as per your requirement. You can upload a background image, add styles, or even modify html file to suit your requirements using Customize now. An HTML editor opens up where you can make the required changes in the displayed editor.

Note:

  • The login page image should be of the dimensions 252 x 61 pixels (W x H).
  • After you save your settings, the changes will be reflected immediately. Use Restore to Default button at the top-right of the customization page to discard the changes you made.
