기본 제공 그래픽 도구를 사용하여 워크플로 편집기에서 워크플로의 기본 세부 정보 및 방향 경로를 구성할 수 있습니다.
워크플로를 만들려면 다음 기본 세부정보를 입력하십시오:
  • 워크플로 이름
  • 설명
  • 유형 (일반/긴급)
워크플로 편집기에는 워크플로 다이어그램과 스텐실 패널을 만들기 위한 확장 가능하고 스크롤 가능한 캔버스가 제공됩니다. 스텐실 패널에는 Stage, Condition, Switch, Notification, Approval 및 Field Update와 같은 다양한 노드가 포함되어 있습니다. 간단한 드래그 앤 드롭 동작을 사용하여 캔버스에 노드를 추가할 수 있습니다. 캔버스에 노드를 추가하면 노드의 속성을 지정해야 하는 팝업 창이 열립니다.
다양한 노드의 사용법을 이해하려면 아래 포인터를 참조하십시오. 자세한 내용을 보려면 포인터를 클릭하여 펼치십시오.:
스테이지 - 워크플로에 변경 스테이지 추가.
  • 관련 드롭다운에서 스테이지와 상태를 선택합니다.
  • 한 스테이지에서 여러 상태를 가질 수 있습니다. 노드의 입력 및 출력 포트 수는 선택한 상태 수에 따라 다릅니다.
  • 기본적으로 전역적으로 구성된 상태 알림은 변경 워크플로의 영향을 받지 않으며 관리 설정에서 구성된 대로 계속 작동합니다. 워크플로에 따라 알림을 무시하려면 상태 위로 마우스를 가져간 다음 메일 아이콘을 클릭하십시오. 필요에 따라 알림을 구성하고 저장합니다.
  • 알림 무시가 활성화된 상태는 노란색 메일 아이콘으로 표시됩니다.
조건 - 변경이 다음 스테이지로 진행되기 전에 충족되어야 하는 조건을 지정합니다..
  • 노드에 대한 이름을 입력하십시오.
  • 열, 기준 및 값을 선택하여 기준을 지정합니다.
  • AND/OR 연산자를 사용하여 여러 기준을 추가하려면 추가 아이콘을 클릭하십시오. 다른 기준 아래의 들여쓰기 공간 위로 기준을 끌어 하위 기준으로 추가할 수 있습니다. 하위 기준이 포함된 기준은 드롭다운 아이콘으로 표시됩니다.
  • 조건 노드는 단일 입력 포트와 두 개의 출력 포트(예/아니요)로 렌더링됩니다.
스위치 - 스위치는 필드의 값을 참조하고 선택한 값을 기반으로 워크플로 경로를 적용하는 다방향 분기 노드입니다.
  • 전환 조건을 적용할 필드를 선택합니다.
  • 참조해야 하는 필드 값을 추가합니다. 각 필드 값에 대해 다른 워크플로 경로를 디자인할 수 있습니다.
  • 스위치 노드는 선택된 값에 따라 단일 입력 포트와 N개의 출력 포트로 렌더링됩니다.
알림 - 변경 워크플로에 대한 사용자 지정 알림을 구성합니다.
  • 기존의 사용자 지정 알림을 선택하거나 알림 이름 드롭다운에서 새 알림을 추가합니다. 편집 아이콘을 사용하여 선택한 알림을 편집할 수도 있습니다.
    • 알림을 추가/수정하려면 알림 이름을 입력하고 설명을 추가하세요.
    • 알림을 받아야 하는 역할/조직 역할 변경을 선택합니다. 사용자를 선택하려면 사용자 이름을 입력하고 드롭다운에서 사용자를 선택합니다.
    • 알림 이메일에 보낼 제목과 메시지를 입력하세요.
    • 저장을 클릭합니다.
  • 기존 알림을 선택하면 선택한 알림 세부정보에 따라 알림 대상, 설명 및 제목이 자동으로 채워집니다.
  • 알림 노드는 단일 입력 포트와 출력 포트로 렌더링됩니다.
승인 - 스테이지 사이에서 승인 수준을 추가하고 승인 이메일 알림을 구성합니다.
  • 승인 이름을 입력합니다.
  • 대기 드롭다운에서 승인 조건 선택- 누구나/모두 승인할지 여부를 선택할 수 있습니다. 승인 액션(조치)으로 승인자의 첫 번째 응답을 구성할 수도 있습니다.
  • 역할/조직 역할 변경을 승인자로 선택합니다. 사용자를 선택하려면 사용자 이름을 입력하고 드롭다운에서 사용자를 선택합니다.
  • 승인 알림 제목과 메시지를 입력합니다. 필요한 경우 변수를 추가할 수 있습니다.
  • 승인 노드는 단일 입력 포트와 두 개의 출력 포트(승인됨/거부됨)로 렌더링됩니다.
필드 업데이트 - 워크플로의 다음 스테이지로 진행하기 전에 필드 값을 업데이트합니다.
  • 기존 필드 업데이트 구성을 선택하거나 필드 업데이트 이름 드롭다운에서 새 구성을 추가합니다. 편집 아이콘을 사용하여 선택한 구성을 편집할 수도 있습니다.
    • 필드 구성을 추가/편집하려면 필드 업데이트 이름과 설명을 입력하십시오.
    • 필드 업데이트 시 적용해야 하는 필드와 값을 선택합니다. 추가 아이콘을 사용하여 여러 필드에 대한 업데이트를 구성할 수 있습니다.
    • 저장을 클릭합니다.
  • 기존 구성을 선택하면 선택한 필드 세부 정보를 기반으로 설명이 자동으로 업데이트됩니다.
  • 필드 업데이트 노드는 단일 입력 포트와 출력 포트로 렌더링됩니다.
노드를 추가한 후 노드를 연결하여 워크플로 방향을 지정합니다. 입력 및 출력 포트를 보려면 노드 위로 마우스를 가져갑니다. 소스 노드의 출력 포트를 클릭하고 필요에 따라 대상 노드의 입력 포트로 경로를 드래그합니다. 기본적으로 제출 및 종료 스테이지가 캔버스에 포함되며 각각 시작 및 종료 노드에 연결됩니다. 기본 스테이지는 편집할 수 없지만 추가된 노드/경로 링크를 아래와 같이 수정할 수 있습니다.
  • 편집하거나 삭제하려면 노드 위로 마우스를 가져갑니다.
  • 노드 또는 경로 링크를 끌어 필요에 따라 캔버스에서 재배치합니다.
  • 경로 링크 위로 마우스를 가져가 꼭짓점을 클릭하여 정점을 추가하거나 닫기 아이콘을 사용하여 정점을 제거합니다.
  • 경로 링크 위로 마우스를 가져가면 소스 노드, 대상 노드 및 꼭짓점이 표시됩니다.
  • 경로 링크의 소스 또는 대상 노드는 입력 또는 출력 원을 드래그하여 변경할 수 있습니다.

스텐실 액션

스텐실 패널 이동 - 스텐실의 왼쪽 상단에 있는 드래그 아이콘을 사용하여 캔버스 내에서 원하는 위치로 이동합니다.
워크플로 실행 취소/다시 실행 - 스텐실 헤더의 해당 아이콘을 사용하여 워크플로 데이터에 대한 액션이나 전환을 실행 취소/다시 실행합니다.
워크플로 재설정 - 스텐실의 닫기 아이콘을 사용하여 새 워크플로를 기본 상태로 재설정합니다. 워크플로가 이전에 저장된 경우 마지막 업데이트 상태로 복원됩니다.
스텐실 축소 - 맨 오른쪽에 있는 드롭다운 아이콘을 사용하여 스텐실 패널을 켜고 끌 수 있습니다.

워크플로 액션

워크플로 저장 - 워크플로 헤더에서 저장을 클릭합니다. 참고 사항: 검증된 워크플로 만 저장할 수 있습니다. 워크플로 구성에 오류가 있는 경우 이를 알리는 설명 경고 메시지가 표시됩니다.
워크플로 확대/축소 - 캔버스의 오른쪽 모서리에 있는 확대/축소 핸들을 사용하여 그래프를 크고 작은 크기로 보기로 볼 수 있습니다.
저장된 워크플로 액션 - 저장된 워크플로에서, 햄버거 아이콘을 클릭하여 워크플로 속성, 기록을 보고 워크플로를 그래프를 PDF로 내보낼 수 있습니다.
