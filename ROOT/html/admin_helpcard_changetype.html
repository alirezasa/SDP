Type denotes the significance of a change/release initiated in the organization. Certain change/release requests may be trivial and may not require an approval process. For such requests, you have an option to mark the type as pre-approved. Also, you can denote the severity of a type with a color code.

By default, the application has four types in the list view. You can add a type by clicking New.

Use the Active/Inactive Types drop-down to view the specified type.

Use the Actions icon to edit or delete a type. To bulk delete types, select the preferred types and click Delete on the header.

You can view edits and changes made to types by clicking View History.

Add New Type

  • Enter a Name for the type.
  • Select a Color to indicate the severity of the type.
  • Give a brief Description about the significance of the type.
  • Select the Pre Approval checkbox if you do not want the requests under this type to undergo the approval process.
  • Click Save.
To save and add another type, click Save and Add New. Click Cancel to discard and go back to list view.
