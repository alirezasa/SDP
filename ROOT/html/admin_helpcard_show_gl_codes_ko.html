GL 코드

총계정원장 계정은 계정의 각 항목에 대해 GL 코드를 할당하여 조직의 거래를 정렬, 저장 및 요약하는 데 사용되는 레코드입니다. 구매 시 GL 코드를 선택하여 특정 거래에 필요한 정보를 추적할 수 있습니다.

새 GL 코드를 생성하려면

  1. 새로 만들기를 클릭합니다.

  2. 다음 정보 제공하십시오:

    • GL 코드: 영숫자 값을 입력합니다.

    • 설명: GL 코드에 대한 관련 설명을 입력합니다.

  3. 마지막으로 저장을 클릭합니다.

GL 코드 편집 또는 삭제

  • GL 코드를 편집하려면 GL 코드 이름을 클릭하거나 이름 옆에 있는 액션 아이콘을 클릭하고 편집을 선택하고 필요에 따라 변경하고 업데이트를 클릭합니다.

  • GL 코드를 삭제하려면 GL 코드를 선택하고 삭제 아이콘을 클릭합니다. 단일 GL 코드를 삭제하려면 GL 코드 이름 옆에 있는 액션 아이콘을 클릭하고 삭제를 선택합니다.
