FOS 配置 故障转移服务 (FOS) 配置可以确保ServiceDesk Plus在遭遇硬件/软件故障时保持可用。
故障转移服务通过热-备用系统来工作：其主服务器运行ServiceDesk Plus，而备服务器处于备用模式，并定期监视主服务器的运行状况。如果主服务器出现故障，它将作为主服务器接管运行。当主服务器恢复故障后，它将作为备用服务器启动。
主备服务器需连接到一个共用的数据库服务器以及一个共用的网络路径。
选择启用 FOS 启动模式复选框，在故障转移服务模式下加载ServiceDesk Plus。
主机器信息：
  • 主服务器IP - 输入ServiceDesk Plus所在的主服务器的IP地址。
  • 主服务器NIC  - 输入主服务器的网络接口卡 (NIC) 地址 (也称作物理地址)。NIC 地址应放在 { } 括号内。
    • 识别NIC地址的工具
    • ServiceDesk Plus内置了工具来帮助您识别您的NIC地址。
    • 在您的主服务器上，打开{SDP_Home}\bin目录，然后执行iflist.exe 工具。
    • 定位适配器状态为 UP的NIC卡，将其适配器名称复制到ServiceDesk Plus。
  • 主服务器的子网掩码 - 输入子网掩码以根据主服务器IP地址确定网络ID和主机ID。 缺省的子网掩码为 255.255.255.0，您可以按需修改为其它有效的子网掩码。

  • 备服务器的NIC - 输入您的备服务器的网络接口卡 (NIC) 地址 (也称作物理地址)。NIC地址应放在 { }括号内。
    • 识别NIC地址的工具

常规信息：
  • 虚拟IP - 确保您所配置的虚拟IP属于主备服务器所在的相同子网内，且未绑定到任务服务器。
    • 如何测试虚拟IP地址？
    • 打开命令提示符窗口，执行命令：：ping {IP地址}
    • 如果您看到请求超时消息，这表示虚拟IP地址可用。
  • 通用别名 -  设置一个可用于访问ServiceDesk Plus的域名地址。
  • 当出现故障转移时通知 -  添加技术员的邮件地址，以在自监控、数据同步、备服务器接管服务时获得告警通知。使用半角逗号来分割多个邮件地址。
注意：在高可用性配置设置完成后，应设置文件复制配置并重启ServiceDesk Plus以使配置生效。
DR 配置 在灾难恢复模式下，资源会被复制到故障区域外、一个不同物理地区下的数据中心中。
主备服务器都会连接到一个共用的数据库服务器和一个共用的网络路径。
选择启用 DR 启动模式复选框，在灾难恢复模式下启动ServiceDesk Plus。
灾难恢复明细：
  • 主服务器IP - 输入ServiceDesk Plus所在的主服务器的IP地址。
  • 备服务器IP - 输入您的备服务器的IP地址。
  • 通用别名 - 设置一个可访问ServiceDesk Plus的自定义域名。
  • 当出现故障转移时通知 -  添加技术员的邮件地址，以在自监控、数据同步、备服务器接管服务时获得告警通知。使用半角逗号来分割多个邮件地址。
注意：在高可用性配置设置完成后，应设置文件复制配置并重启ServiceDesk Plus以使配置生效。
