개인 정보 설정

ServiceDesk Plus에서 요청자 양식의 기본 필드에 캡처된 모든 PII(개인 식별 정보)는 사용자가 조직을 나갈 때 삭제됩니다. 모듈 추가 필드의 데이터에 대해 사용자가 조직을 떠날 때 필드를 PII로 표시하여 익명화하거나 삭제해야 합니다.

You can mark PII in the module additional fields under:

    사건 요청서
    서비스 카탈로그 요청서
    리소스 질의

익명화란 무엇인가?

개인 정보 보호를 위해 사용자 데이터를 제거해야 하지만 조직은 감사 목적으로 정보의 일부가 필요할 수 있습니다. 이러한 경우 데이터의 해당 부분은 PII가 제거되는 동안 데이터베이스에 유지됩니다. 예를 들어, 사건서비스 요청의 경우 요청의 실제 세부 정보는 데이터베이스에 유지되는 반면 전화번호 또는 생년월일과 같이 PII로 명시적으로 표시된 필드는 삭제됩니다. 사용자 이름의 경우 임의의 텍스트로 바꿀 수 있습니다. 이 익명화는 SDP 애플리케이션 전체에 적용됩니다.

Note:

    SDP 익명화는 애플리케이션 내에서 준수 규정이 적용되는 경우에만 가능합니다.
    삭제하는 동안 사용자가 익명화되는 경우(익명화 및 삭제 옵션 사용), PII 데이터 삭제는 8시간마다 실행되는 일정을 통해 발생하는 반면 익명화는 즉시 발생합니다.
    사용자 삭제 옵션을 선택하면 사용자 계정만 삭제되며 삭제된 사용자 목록 보기에서 사용자의 PII 필드를 익명화할 수 있습니다.
