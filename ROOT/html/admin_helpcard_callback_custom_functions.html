Callback custom functions allow you to access or manipulate data in ServiceDesk Plus from external applications. You can build callback custom functions using the Deluge scripting language.

  • To create a new callback custom function, click New.
  • To edit a callback function, click the function name.
  • To delete callback functions, select the functions and click Delete.

You can also edit or delete a single callback function by choosing the appropriate action from the Actions menu against the function.

Note: The page header also includes options to search for functions using keywords, set a limit on the number of entries per page, and navigate through pages.
