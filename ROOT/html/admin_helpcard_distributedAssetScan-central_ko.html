분산 자산 스캔

여러 사이트에 분산된 자산을 스캔할 수 있습니다. 자산을 스캔하려는 원격 사이트에 원격 AE 서버를 설치합니다. 스캔이 완료되면 사이트의 원격 AE 서버에서 데이터를 내보내고 Central Server  에서 수동 또는 자동으로 데이터를 가져옵니다.

중앙 서버에 푸시된 데이터는 데이터를 가져온 사이트, 수신 시간, 가져온 시간 등의 세부 정보와 함께 나열됩니다. 

작업 순서 :

1. 원격 AE 서버에서 워크스테이션 정보(zip 파일 형식)를 내보냅니다.
2. 생성된 정보를 중앙 ServiceDesk Plus 서버로 가져옵니다.
