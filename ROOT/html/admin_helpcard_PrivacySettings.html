Privacy settings

In ServiceDesk Plus, all personally identifiable information (PII) captured in the default fields in the requester form is deleted when a user exits the organization. For data in the module additional fields, the fields must be marked as PII to be anonymized or deleted when the user leaves the organization.

You can mark PII in the module additional fields under:

    Incident Requests
    Service Catalog Requests
    Resource Questions

What is anonymization?

While user data must be removed due to privacy considerations, organizations may need some part of the information for audit purposes. In such cases, that part of the data is retained in the database while the PII is removed. For example, in the case of an incident/service request, the actual details of the request will be retained in the database, whereas fields, such as telephone number or date of birth, that are explicitly marked as PII will be deleted. For user names, you will be able to replace them with any random text. This anonymization will be effected across the application.

Note:

    Anonymization will be possible only when compliance regulations are effected within the application.
    If a user is anonymized (using the Anonymize and Delete option) during deletion, the anonymization happens immediately while the PII data deletion will happen through a schedule which runs every 8 hours.
    If the Delete User option is selected, the user account alone will be deleted, you can anonymize the PII fields for the user from the deleted users list view.
