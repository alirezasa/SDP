Resource sections are used to group resource questions so that they can be associated to service request templates easily.

In the resource sections list view, the active resource sections are displayed by default. Click Associated Templates to view request templates associated with a resource section.

Add Resource Section

  1. Click Add Resource.

  2. Enter the name and description for the resource section.

  3. Choose to display your resource question in one or two columns.

  4. You can add resource questions to the section from the list of existing resource questions by selecting them.

  5. Alternatively, you can also create a resource question from scratch. Click here to learn more.

  6. Click Save or Save and Add New.

Edit Resource Section

Hover over the resource section and click the menu list icon to edit. Edits made on a resource section will reflect in all the request templates associated with it.

In requests, where the resource information is already recorded, the edits will not affect the request details unless the request is edited.

Delete Resource Section

Hover over the resource section and click the menu list icon to delete a resource section.

  • If a resource section is not associated to any request template, it will be deleted permanently.

  • If the resource section is currently in use, it will be moved to an inactive state until it is disassociated completely. Apply Inactive Section filter to view the deleted resource sections.

You can activate inactive sections by selecting Activate resource to edit option while editing them.


Note:
Resource sections with duplicated questions cannot be associated to templates even if the question is under Inactive Resource Section.
