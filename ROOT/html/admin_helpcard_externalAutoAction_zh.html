您可以定义动作规则（触发规则），以便自动地调用自定义类或脚本文件。该规则可以在请求被创建（或者接收到请求）、 被编辑，或者两个都适合的场合被触发。

 

添加新的动作规则

 

要添加新的动作规则，点击右上角的添加新动作 链接。

 

为该动作指定唯一的动作名称，它是各个动作的身份识别符，不能重复。

在描述中，为该动作输入有意义的描述，以便其他用户能充分理解该动作的作用。

为该动作选择执行动作的时机，可选项包括：

  • 当请求被创建时 - 如果需要在某个请求被创建时，执行该动作的话，就选择该选项。
  • 当请求被编辑时 - 如果需要在某个请求被编辑时，执行该动作的话，就选择该选项。
  • 当请求被创建和编辑时 - 如果需要在某个请求被创建或编辑时，都执行该动作的话，就选择该选项。

您可以定义匹配条件，以决定只有符合条件的请求才执行该动作。这样，当请求符合匹配条件时，将自动执行所指定的动作而无需人工干预。

 

从选择匹配标准的下拉框中，选择需要匹配的条件，可点击选择按钮，从中指定相应的值。匹配条件可以一个，也可以多个。对于多个条件，可以选择“与/AND”来匹配全部条件，也可以选择“或/OR”来匹配其中的某个条件。点击添加其他匹配条件可添加更多的匹配条件。

 

设置执行动作，为符合条件的请求指定要执行的动作。

 

可从下拉框中选择 '执行脚本' 或者 '执行类'，如果选择'执行类'的选项，您需要指定相应的自定义Java类文件，如："com.servicedeskplus.integration.JiraActionImplementation"。如果选择'执行脚本'的选项，需要指定该脚本的名称和存放路径。如："cmd / c Index.bat"。默认情况下，脚本将从 "[SDP_Home]/integration/custom_ scripts/" 目录下运行。

您也可以为自定义脚本指定变量参数，如：cmd / c Index.bat $SUBJECT $PRIORITY

支持的其它参数

$COMPLETE_JSON_FILE ---> 完整的请求将以JSON字串对象形式作为参数提供

$DIFF_JSON ---> 当编辑请求时，该变量将以JSON字串对象的形式提供编辑前后的值的差异

Json文件路径 ---> 完整的请求将保存为JSON文件，提供该文件的路径（JSON字串形式），如： (SDP_Home\integration\custom_scripts\request\12_1426143538036.json)。

默认情况下，停止处理后续动作的选项被选中。一旦某个规则应用到某个请求，则其余动作的执行将停止。如果不选中该选项，将按照动作定义的顺序，继续执行后续的动作。

 

自定义触发器的编排
要编排动作，可点击编排动作的链接，在弹出对话框中，通过上移或下移按钮，对动作的前后顺序进行调整。
