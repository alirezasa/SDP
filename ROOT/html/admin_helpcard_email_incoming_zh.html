配置收件服务器设置，以收取来自您机构用户的邮件。
您可以使用邮件协议(POP、IMAP、POPS或IMAPS)、Exchange Web Services (EWS)或Microsoft Graph连接应用到邮箱。
基于所选的连接协议，配置会有所不同。点击以下角标展开相关内容，了解如何配置。
POP / IMAP / POPS / IMAPS
字段解释
认证类型
  • 基本认证 - 使用凭证验证邮箱。
  • OAuth应用支持OAuth 2.0认证协议。了解更多。
服务器名称/IP地址

提供邮件服务器的名称或者IP地址。
用户名

输入邮箱的用户名。
密码 (对于基本认证)

输入访问邮箱的密码。
邮件地址

输入要接收邮件的邮箱地址，若存在，您也可以提供邮箱地址别名。了解更多，参考管理手册。
协议

选择协议 (POP、IMAP、POPS或IMAPS)连接到邮箱。
端口

根据所选协议指定对应端口。
认证服务器明细(对于OAuth认证)

参考这里，从认证服务器获取客户端ID、客户端密钥、验证URL、令牌URL。

在认证服务器中配置重定向URL来获取令牌。

在范围字段，定义在邮箱所获得的OAuth令牌的访问性。了解更多可作为范围填充的值。
注意：如果您使用Office365 GCC High邮箱，需确保在主机名、连接URL、认证URL、令牌URL和范围的TLD (top-level domain)是.us。

输入接收邮件的邮箱地址。
认证服务器明细

参考这里，从认证服务器获取客户端ID、客户端密钥、验证URL、令牌URL。

在范围字段，定义在邮箱所获得的OAuth令牌的访问性。了解更多可作为范围填充的值。

在认证服务器中配置重定向URL来获取令牌。
  • 输入收取邮件的时间间隔。
  • 如果应用需要通过代理服务器连接到互联网，则启用代理服务器。
  • 启用邮件调试以识别与邮件收取相关的问题的具体追踪。
  • 限制将邮件处理为请求，勾选禁用通过邮件创建请求。
    • 您可以指定处理特定邮件地址的邮件为请求，如Heather@zylker.com。
    • 您也可以通过输入星号（*）和@domain-name来指定可以处理请求的特定域，如, *@zylker.com。
  • 您可以将错误邮件移动到一个单独的文件夹，以防止因为此错误导致邮件收取计划停止。
    • 提供错误文件夹的名称。
    • 选择是否要再特定的邮件数字后停止邮件收取进程。
    • 错误文件夹中的邮件数量会显示在用户界面上，如果需要您也可以将其移回收件箱。
    • 启用在邮件从错误文件夹移动到收件箱的通知。
    • 如果需要，您也可以下载错误日志。
  • 点击保存。
