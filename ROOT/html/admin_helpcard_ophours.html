On this page, you can configure Operational Hours for your site. The operational hours for a site depends on the time zone configured for the site. Select the site from the drop-down and choose either Round the clock (24 hours) or input Standard working hours using the start and end time.


You can add a break schedule to standard working hours by clicking the add icon.


Note : If you have selected Standard Working Hours, the number of hours configured here will be used to calculate the SLA response time (in days) and similar attributes across the application. For example, if the response time of a request SLA is 5 days, then the total response time in hours will be 5 times the number of standard working hours configured for the corresponding site


Select the days on which the services will be available and set the working hours for each day. Choose Round the clock/Standard Hours to copy the default schedule, or choose Custom Hours to provide the start and end times. Add a break schedule if required.


Under the Exclusion Rule section, select the day(s) to be marked as non-working days for a month, say the second and fourth Saturdays. You can configure up to two exclusion rules for each site.


The days configured here will be excluded from the list of operational days for every month.
