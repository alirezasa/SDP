Integrate with Endpoint Central (formerly Desktop Central)

 

Integrate AssetExplorer with ManageEngine Endpoint Central to manage all your Desktop & Mobile Device Management functions. Endpoint Central automates desktop management activities like installing patches, deploying software, talking remote control, initiating chat, securing the client computers, applying USB usage restrictions and much more. It also enables managing Mobile Devices with profile management, App management, security management and asset management. If you have installed both these products, you just have to provide the details of the computer where Endpoint Central is installed along with its Port Number.

NOTE: Endpoint Central version should be version 8.1 and above.

Details to be provided:

Server Name: Enter the Server where Endpoint Central application is installed.

Server Port: Enter the Port Number of the Endpoint Central server.

Server protocol: Select the Protocol Settings. Say, http or https.

API Key: Enter the API Key of an Admin user in Endpoint Central server.

 

Click Save. AssetExplorer will try to establish a connection with the Endpoint Central server. Once the connection is established, the configured settings are saved.
