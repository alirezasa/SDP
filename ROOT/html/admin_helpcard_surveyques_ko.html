설문 정의를 사용하면 사용자 설문의 일부가 될 다양한 질문을 추가할 수 있습니다. 질문을 추가하는 것과 함께 사용자가 자신의 경험을 설명할 최상의 답변을 선택해야 하는 각 질문에 대한 답변으로 표시될 만족도 수준을 추가할 수도 있습니다.

설문조사 질문을 추가하려면
  1. 질문 탭에서 + 질문 추가 버튼을 클릭합니다. 질문창이 뜹니다.
  2. 제공된 텍스트 영역에 질문을 입력합니다.
  3. 저장을 클릭합니다. 설문조사에 질문이 추가되었습니다. 질문 탭 아래의 설문 조사 정의 페이지에 표시됩니다.
질문의 순서를 변경하려면 해당 질문에 대해 위로 이동 또는 아래로 이동 링크를 클릭하십시오.

만족도를 추가하려면
  1. 만족도 탭을 클릭합니다
  2. + 만족도 추가 버튼을 클릭합니다. 만족도 창이 나타납니다.
  3. 제공되는 텍스트 영역에 만족도 값을 입력합니다.
  4. 저장을 클릭합니다. 만족도는 목록의 끝에 추가됩니다. 위로 이동 또는 아래로 이동 링크를 클릭하여 만족도 수준 목록을 위 또는 아래로 이동할 수 있습니다.
만족도의 순서는 각 만족도와 연계된 값을 결정합니다. 목록 맨 위에 있는 만족도 수준은 만족도가 가장 낮음을 의미하며 값 1과 연계됩니다. 보고서는 각 만족도 수준에 연계된 값을 기준으로 생성됩니다.
 
사용자가 다국어 라이선스를 구매했다면 설문 번역 탭이 나타납니다. 설문 조사는 다양한 위치에 있는 사용자에게 응용 프로그램에서 지원하는 다양한 언어로 표시될 수 있습니다.  
 
새 번역을 추가하려면
  1. 설문조사 번역 탭을 클릭합니다.
  2. 새 번역 링크를 선택합니다.
  3. 설문조사 언어 드롭다운 목록에서 설문조사를 위한 언어를 선택하십시오. SDP 애플리케이션에서 지원하는 언어들이 표시됩니다. 한 번 선택된 언어는 드롭다운 목록에 표시되지 않습니다.
  4. 설문조사 질문, 만족 수준 입력 및 메시지는 설문조사 언어에서 선택한 언어로 표시됩니다.
  5. 저장을 클릭합니다. 번역된 언어에 대한 설문조사가 목록 보기에 추가됩니다. 기본적으로 새 번역을 추가하는 동안 번역된 언어가 활성화됩니다. 언어를 비활성화하려면 비활성화할 언어 옆의 확인란을 선택하고 비활성화 버튼을 클릭합니다.
요청자를 위한 설문 조사 양식은 설문 번역에서 구성된 언어 목록으로 구성된 표시 언어 드롭다운 상자로 구성됩니다. 설문조사를 볼 언어를 선택하십시오. 비활성화된 언어는 사용자 만족도 조사 양식의 표시 언어 드롭다운에 나타나지 않습니다.
