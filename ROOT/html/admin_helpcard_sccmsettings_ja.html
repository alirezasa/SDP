スキャンされた資産データをSCCMからServiceDesk Plusに読み込むために、Mivrosoft System Centre Configuration（SCCM）とServiceDesk Plusを連携することができます。 資産管理またはインベントリ管理にSCCMを利用しつつ、ServiceDesk Plusの資産を迅速に更新することができます。
詳細な動作につきましては、こちらをご覧ください。

新しくSCCM設定を追加する方法：

  1. ［新規］をクリックした後、必要な詳細情報を入力します。
  2. SCCMのデータベースサーバーのホスト名、データベース名、ポート番号を入力します。
  3. サイトと資産を関連付けることができます。この設定は、サイトのSCCMの資産をインポートする際に特に役立つ機能です。
  4. 認証ライブラリで設定したSCCMの認証情報を入力します。
  5. データを取得するための開始日時と、スキャン頻度を入力します。
  6. ［保存して接続をテスト］をクリックして、SCCMデータベースサーバーとの接続を確立します。

データの取得が成功/失敗したかどうかは、一覧ページの「ステータス」欄に表示されます。
SCCMのデータベースサーバーの認証情報に誤りがある場合や、同サーバーへの接続が未確立である場合、データの取得に失敗する可能性があります。
 

一覧ページのSCCM名横のアイコンのプルダウンメニューから、編集/接続テスト/削除を行うことができます。
