Priority Matrix
The priority matrix helps you to determine the Priority automatically based on Impact and Urgency of a request. Impact is listed in the y-axis, and Urgency list in the x-axis of the matrix.Priority Matrix requires a one-time configuration by the Administrator for given Business Impact and Urgency values.

Once you set the Priority for specific Impact and Urgency in the priority matrix, when a requester selects a similar impact and urgency combination in the new request form, then the priority of the request will be determined based on the matrix.

Best Practice Tip

Based on IT best practices, it is recommended to define and follow priority matrix as it reflects business need. However it is designed flexible enough for technicians and requesters can override the matrix, if they want.

Example:

In priority matrix: You can set, if Impact is Affects Business and Urgency is High then Priority should be High.

Result in request: If requester/technician selects Affects Business for impact and high for urgency in the request then, the priority field gets filled automatically and displays as high.


Setting Up Priority Matrix
You have the impact list in y-axis and urgency list in x-axis. Click the priority link against specific urgency and impact, this opens the drop down box. Select the corresponding priority from the list. The priority will be set for the particular Impact and Urgency combination.

Note: The priority, set in the matrix cannot be edited in the requests. To edit the priority in the new request form, select the Allow Requesters and Technicians to override the Priority Matrix check box.When the check box is selected, application will ignore the Priority Matrix configuration and allow requesters and technicians to set the priority manually.
