소프트웨어 유형은 라이선스됨, 금지됨, 프리웨어, 셰어웨어 등과 같은 다양한 유형의 소프트웨어를 나타냅니다. 기본적으로 편집하거나 삭제할 수 없는 6가지 소프트웨어 유형이 있습니다.

    • 셰어웨어: 무료로 제공되는 소프트웨어는 추가 기능 또는 설명서 등에 대해 요청된 비용과 함께 평가용으로 배포될 수 있습니다.

    • 프리웨어: 무료로 제공되는 소프트웨어

    • 금지됨: 사용이 금지된 소프트웨어

    • 제외됨: 사용에서 제외된 소프트웨어입니다.  

    • 관리됨: 라이선스된 모든 소프트웨어는 이 소프트웨어 유형에 속합니다.

    • 미식별: 알 수 없는 소프트웨어는 이 소프트웨어 유형으로 분류될 수 있습니다.

새 소프트웨어 유형 추가

  1. 페이지 오른쪽에 있는 새 소프트웨어 유형 링크를 클릭합니다.소프트웨어 유형 세부 정보 페이지가 열립니다.

  2. 이름 필드에 소프트웨어 유형 이름을 입력합니다. 개별 소프트웨어의 유형을 유일(고유)하게 식별하는 필수 필드입니다.

  3. 설명 필드에 소프트웨어 유형에 대한 관련 정보를 입력합니다.

  4. 소프트웨어 유형 추가 버튼을 클릭합니다. 그러면 소프트웨어 유형이 추가되고 소프트웨어 추가 양식 아래에 표시됩니다. 해당 오퍼레이션을 취소하려면 취소 버튼을 클릭하십시오.
