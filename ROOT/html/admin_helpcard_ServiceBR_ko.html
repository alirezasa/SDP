비즈니스 규칙을 사용하면 접수 되는 모든 요청서를 편성하고 그룹에 전달하고, 상태 및 기타 요청 매개변수를 할당하는 등의 액션을 수행할 수 있습니다. 비즈니스 규칙은 요청서가 작성될 때(또는 수신될 때), 편집될 때 또는 둘 다일 때 적용할 수 있습니다. 비즈니스 규칙이 실행되면 알림을 기술자에게 보낼 수도 있습니다. 비즈니스 규칙은 사이트에 따라 다릅니다. 따라서 사이트의 비즈니스 규칙을 보려면 콤보 상자의 비즈니스 규칙에서 사이트를 선택합니다.

참고 사항:

    • Admin 관리자는 모든 사이트에 대한 비즈니스 규칙을 설정할 수 있는 권한이 있는 반면, 사이트 Admin 관리자는 그와 연rP된 사이트에 대한 비즈니스 규칙을 설정하고 볼 수 있는 권한이 있습니다.

    • 사이트가 관리설정-사이트에서 구성되지 않은 경우, 콤보 상자에서 해당 비즈니스 규칙이 나타나지 않습니다.  ;

새 비즈니스 규칙 추가
비즈니스 규칙 콤보 상자에서 사이트를 선택합니다. 사이트를 선택하지 않으면 기본 설정 아래에 비즈니스 규칙이 추가됩니다. 비즈니스 규칙 목록 보기의 오른쪽 모서리에 있는 새 비즈니스 규칙 추가 링크를 클릭합니다.
 
비즈니스 규칙 추가 양식은 세 가지 주요 블록으로 구성됩니다. 즉 비즈니스 규칙 세부사항, 기준 및 작업 및 알림.  

규칙 이름은 규칙을 고유하게 식별합니다. 필수 필드입니다.
Business Rules for 콤보 상자에서 선택한 사이트는 편집 불가능한 필드로 표시됩니다.
설명 텍스트 상자에 비즈니스 규칙을 자세히 설명하는 내용을 입력합니다.

비즈니스 규칙은 요청서가 다음 일 때 실행 드롭 다운 목록에서 옵션을 선택하여 한 요청서가 웹 양식이나 편집되어 생성될 때, 그 요청서에 대해 실행됩니다. 기본적으로 '생성됨' 옵션이 선택되어 있습니다.

비즈니스 규칙 비활성화: 비즈니스 규칙을 비활성화하려면 이 옵션을 선택합니다.. 기본적으로 이 옵션은 선택 해제되어 있습니다. 비즈니스 규칙을 비활성화하면 새 요청서이나 편집된 요청서에 대해 해당 규칙이 실행되지 않습니다.

캐스케이드(연속) 실행 켜기: 기본적으로 비즈니스 규칙은 요청서에 규칙이 적용되면 중지됩니다. 캐스케이드(연속) 실행 켜기 확인란을 선택하면 비즈니스 규칙이 한 요청서에 적용된 후에도 (비즈니스 규칙 순서에 따라) 연속적으로 비즈니스 규칙이 실행됩니다.

비즈니스 규칙 값으로 요청서 값을 덮어쓰기: 이 옵션을 활성화하면 비즈니스 규칙에 언급된 값으로 요청서의 값을 덮어씁니다.
예: 요청서의 우선순위가 '높음'으로 설정되고 액션 세트가 설정된 경우, 비즈니스 규칙의 '우선순위를 낮음'으로 설정하면 ,비즈니스 규칙 실행 시 우선순위가 자동으로 '낮음'으로 설정됩니다.

참고 사항: 비즈니스 규칙 활성화/비활성화, 캐스케이드(연속) 실행 켜기/끄기 및 삭제와 같은 비즈니스 규칙에 대한 일괄 액션을 수행하려면 비즈니스 규칙 옆의 확인란을 선택하고, 비즈니스 규칙 목록 보기 페이지에서 액션드롭다운 버튼을 클릭합니다.

 
기준 및 액션에서는 접수되는 서비스 요청서에 대한 기준을 일치시키는 규칙을 정의할 수 있습니다. 요청서에 따라 수행되는 액션은 수동 개입 없이 자동으로 수행될 수 있습니다.

규칙 정의 블록의 드롭다운 목록에서 특정 기준과 조건을 선택합니다. 선택 버튼을 클릭하여 특정 값을 추가합니다. 이제 규칙에 추가를 클릭합니다. 방금 정의한 규칙이 아래 표에 추가됩니다. 모든 기준 세트와 일치하도록 선택하거나 해당 라디오 버튼을 선택하여 임의의 기준과 일치시킬 수 있습니다.

이제 추가한 위의 규칙 기준과 일치하는 요청서에 대해 수행해야 하는 적절한 액션을 설정합니다.

액션 선택 드롭다운 메뉴에서 요청서에 대해 수행할 액션 항목을 선택합니다. 선택 버튼을 클릭하여 요청서에 연계할 값을 선택합니다. 추가를 클릭합니다. 추가된 액션은 액션 표에 추가됩니다.

 

오퍼레이션 생성/편집 무효화: 이 액션을 통해 오퍼레이션(요청 생성/편집)을 무효화(폐기/되돌리기)할 수 있습니다. 예를 들어, 이를 사용하여 구성된 비즈니스 규칙 기준과 일치하는 요청서 생성되는 것을 중지할 수 있습니다. 요청서가 업데이트/편집되는 것을 중지할 수도 있습니다. 이 액션이 수행되면 적용된 모든 규칙이 삭제됩니다.

"선택"을 클릭하여 무료화 오퍼레이션을 수행하는 이유를 제시할 수도 있습니다. 단추. 요청이 거부되면 이유가 표시됩니다.
이 옵션은 규칙에 대한 다른 액션과 공존할 수 없습니다. 이 액션을 선택하면 추가 액션을 추가하는 옵션이 제거됩니다. 연속 비즈니스 규칙 옵션도 제거됩니다.

스크립트 실행: 이 액션을 사용하면 접수/편집된 요청서에 대한 스크립트 파일을 사용하여 사용자 정의 액션을 실행할 수 있습니다. 비즈니스 규칙의 기본 액션 메뉴에서 사용할 수 없는 몇 가지 추가 액션을 수행하는 데 도움이 됩니다. 스크립트를 실행하여 요청서를 업데이트/무효화할 수 있습니다.

참고 사항: '스크립트 실행' 작업이 먼저 실행된 후 다른 작업이 실행됩니다.

지원되는 매개변수:

$COMPLETE_V3_JSON_FILE : 전체 요청 객체가 JSON 파일에 저장됩니다. $COMPLETE_V3_JSON_FILE 문자열은 임시 JSON 파일 경로로 대체됩니다. 동일한 JSON 파일이 출력과 함께 서버에 반환되어야 합니다.

임시 JSON 파일 경로: [SDP_Home]/integration/custom_scripts/requests/1_1234567.json

샘플 스크립트 명령: cmd /c updateRequest.bat $COMPLETE_V3_JSON_FILE

UPDATE/NEGATE와 같은 사용자 지정 작업은 스크립트 파일을 사용하여 지원됩니다.

사용자 정의 함수 실행: 사용자 정의 함수를 실행하여 ServiceDesk Plus 및 기타애플리케이션의 데이터를 조작할 수 있습니다. requestObj 및 context은 사용자 정의 함수에서 지원되는 인수입니다. 필요한 사용자 정의 함수를 선택하거나 새 기능을 추가하십시오.

알림 비즈니스 규칙이 적용된 후 기술자에게 이메일 및 SMS 알림을 보낼 수 있는 곳입니다. 이메일 알림을 활성화하려면

이메일 옆의 확인란을 선택하여 기술자에게 이메일 알림을 보낼 수 있습니다. 기술자는 추가 버튼을 클릭하여 선택할 수 있습니다. 선택한 사이트의 모든 기술자가 표시됩니다. 템플릿 수정 링크를 클릭하여 이메일 템플릿을 수정할 수도 있습니다.

마찬가지로 SMS를 통해 기술자에게 알림을 보낼 수도 있습니다. 알림은 이메일과 동일한 방식으로 구성됩니다.

참고 사항: 메일 서버 설정은 알림을 수신하도록 구성되어야 합니다.

저장 버튼을 클릭하여 비즈니스 규칙을 저장하고 목록 보기로 돌아갑니다. 비즈니스 규칙을 저장하고 다른 비즈니스 규칙을 추가하려면 저장하고 새로 추가 버튼을 클릭하십시오.

비즈니스 규칙 구성
비즈니스 규칙을 구성하려면 비즈니스 규칙 구성 링크를 클릭하고 팝업에서 비즈니스 규칙을 선택하고 위로 이동 또는 아래로 이동 버튼을 클릭합니다. > 들어오는 요청에 규칙이 적용되는 순서를 결정합니다.
