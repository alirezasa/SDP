E-mailコマンド

 
E-mailコマンド機能を使用すれば、ServiceDesk Plus が受信したメールの本文に挿入されているコマンドに応じてフィールドの値を自動で設定したり、指定のオペレーションを実行可能です。

E-mail コマンドを設定するには、

1.メールサーバ設定ページから、E-mail コマンドタブをクリックします。E-mail コマンド 設定ページが表示されます。

2.メールパース機能を有効にするには、E-mailコマンドを有効化 オプションをクリックします。このオプションが選択されていない場合、受信メールの件名にパース文字列が含まれていても通常のメールとして処理されます。

3.メールの件名に含めるパース識別子テキストボックスには、パースする電子メールを識別するための文字列を入力します。このテキストが件名に含まれる場合は様々なフィールドをパースします。例えばメールの件名識別子に @SDP@を指定した場合、件名に@SDP@が含まれるメールはパース対象のメールとして識別されます。

4.コマンド・デリミタにパースで使用する記号を指定します（@@, ##, $$, %%, && など)。フィールドの値を記号の間に入力すると、リクエスト作成時に値が自動的にフィールドに割り当てられます。コマンド・デリミタが @@ で、このメールから作成されるリクエストの「カテゴリ」フィールドを「プリンタ」として設定したい場合は、メールの本文に @@Category=プリンタ@@ を含める必要があります。

メモ ：

  • 技術担当者はメールから、リクエストの作成 / 更新 / クローズ / ピックアップを実行することができます。オペレーション文字列では、"Operation = AddRequest"、"Operation = EditRequest"、"Operation = CloseRequest"、"Operation = PickupRequest" が使用されます。

  • メール経由でリクエストをピックアップする/クローズする場合は、オペレーション文字列(EditRequest / PickupRequest / CloseRequest) と RequestId が含まれている必要があります。これらの文字列が含まれない場合は、新規リクエストとして処理されます。

  • リクエストがメールによって更新された場合、そのメールはリクエストのスレッドとしては残りません（リクエストの表示ページで、「このリクエストのメール」ブロックには表示されません）。そのため、メールの添付ファイルやインラインイメージはリクエストには更新されません。ただし、更新情報はリクエストの「履歴」タブより確認できます。

  • メールの本文で指定したフィールドの値がServiceDesk Plusに存在しない場合は、そのフォールドはパースの対象外となります。

  • メール本文で特定のフィールドに複数の値が含まれる場合、最後の値がパース対象となりその他の値は無効になります。

  • リクエストの件名に "リクエストＩＤ"を含めているリクエストのスレッドメールで、オペレーション文字列（EditRequest) が含まれない場合は、通常メールとして処理されるため、リクエストのスレッドメールとなります。

  • メールの送信者は ServiceDesk Plus のログインアカウントを所有している必要があります。各ユーザに割当てられている役割に応じて、パース可能なオペレーションに制限を設けていることが理由です。リクエストに対する各オペレーションの権限は、ServiceDesk Plus の「役割」機能を使用して設定されています。

  • 依頼者名がメール本文に指定されていない場合は、メールの送信者が「依頼者」としてみなされます。

  • サポートしているパラメータ：

    1. メール送信者が依頼者の場合、パースされるフィールドが制限されます。依頼者は、依頼者がWebからのリクエスト作成フォームに表示されるフィールドのみパースが可能です。

    2. メールの送信者が技術担当者（技術担当者の役割を持っている）の場合は、技術担当者がリクエスト作成フォームを開いた場合に表示されるフィールドに対してパースが可能です。

    3. パース可能なフィールドは次の通りです：LEVEL（レベル）, MODE（モード）, PRIORITY（優先度）, URGENCY（緊急度）, IMPACT（インパクト）, IMPACTDETAILS（インパクト情報）, CATEGORY（カテゴリ）, SUBCATEGORY（サブカテゴリ）, ITEM（項目）, GROUP（グループ）, TECHNICIAN（技術担当者）, TECHNICIANEMAIL（技術担当者メールアドレス）, REQUESTER（依頼者）, REQUESTEREMAIL（依頼者メールアドレス）, REQUESTID（リクエストＩＤ）, REQUESTTEMPLATE（リクエストテンプレート), REQUESTTYPE(リクエストタイプ), STATUS(ステータス), SITE(サイト), ASSET(資産), RESOLUTION(回答), 追加フィールド。追加フィールドの場合は、ラベル名を指定してください。

    4. 依頼者または技術担当者がパース可能なフィールドを変更するには、「管理タブ --> ヘルプデスクのカスタマイズ --> リクエストテンプレート --> デフォルトテンプレート」より、フィールドを追加/削除します。

  • メール本文にリクエストIDが含まれる場合は、メールの件名に含まれるリクエストIDよりも優先されます。
