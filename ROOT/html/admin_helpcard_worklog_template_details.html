Create pre-defined templates for work logs that are repeated. These templates can be applied while adding a work log to a request, problem, change, release, and task.

To add a new work log Template,

  • Click the New button from the work log template list page.
  • Specify a unique Name and Description for the work log template. Name is a mandatory field.
  • Add fields from the Available Fields list in the left pane to the template. You can also add a new field/section instantly from the left pane.
  • Modify the fields /sections by clicking on the edit icon beside each section.
  • Use the delete icon beside each section to remove any section from the template.
  • Use the Customization option at the top right to modify form width, font used in sections and labels, label placement, and the background color of labels and forms.
  • Click Save.

Note: You can associate a maximum of 10 refer additional fields with a single template.
