Manage Tabs

Manage Tabs enables you to create web tabs and manage the visibility of web tabs and modules in the navigation menu. Using web tabs, you can access web pages such as company-wide announcements, internal and external tools, and more, from your instance.

You can reorder, show, and hide web tabs and modules from technicians and allow them to do the same for their profile.

  • In Navigation Tabs:
    • Drag a module/web tab to rearrange its position in the navigation menu. This setting will apply to all technicians.
    • Hover over a module/web tab and use the visibility icon to hide/show it to other technicians.
  • From the All Tabs drop-down, choose All WebTabs to filter out web tabs.
  • Click Reset to restore default settings.

Enable Allow technicians to personalize tabs to allow technicians to override the module/web tab position settings under Navigation Tabs. However, the changes will be applied only to their profile.

Note: When enabled, technicians can manage the visibility of only the modules and web tabs shown to them. To personalize the module/web tab visibility, technicians can go to User Profile > Manage Tabs.

Only SDAdmin can create a web tab. To create a web tab,

  1. Click + New.
  2. On the slider, perform the following:
    • Give the web tab a name.
    • Select any one to define the source of the web tab:
      • URL: Access an existing web page.
        • Provide the URL of the required web page.
        • Choose Same Tab to open the web page within the ServiceDesk Plus instance.
        • Choose New Tab to open the web page as a new tab in your browser.
      • HTML: Use the rich text editor to draft context-rich content to be displayed in the web tab.
      • File: Upload the HTML script of the web tab as a HTML or HTM file. Maximum size: 10MB.
    • Visibility:: Choose any one to define technicians' access to the web tab.
      • Private: For personal use only
      • Public: All technicians can access the web tab
      • Shared: Only selected technicians can access the web tab
  3. Click Add.
