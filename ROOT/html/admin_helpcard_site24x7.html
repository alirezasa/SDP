Integrate with Site24x7

SDP-Site24x7 Integration helps DevOps engineers and IT admins efficiently manage and resolve IT incidents from a central panel. You can associate quick action menus like list file sizes, clear logs, service/process restarts with SDP request templates. Once done, DevOps technicians can remotely execute Site24x7 IT Automation actions to easily redress commonly reported incidents, such as low disk space, application crashes etc. from within the SDP platform. This help card provides you with the steps to create quick action menus for Site24x7 IT automation actions in SDP.


Connect with Site24x7

  1. Login to your SDP account, access Admin > Integration > Site24x7.
  2. You'll find the "Enable Site24x7" check box marked, by default. The check box enables you to show/hide the Site24x7 header tab.
  3. Now, choose a preferred Site24x7 data center (United States, Europe, China, India) from the available list and sign up to use Site24x7 service.
  4. Click the Generate OAuth Credentials link to fetch Client Id, Client Secret and Generated Code.
  5. Click the Test Connection and Save button to confirm whether the integration was successfully set up or not.

NOTE: If you want to disconnect this integration, you can do so by simply clicking the Remove button.


Associate Site24x7 IT Automation action to SDP Request template

Request templates allow you to include information necessary to quickly resolve frequent requests, such as application crashes, printer issues, or incorrect mail fetching. All Site24x7 IT Automation actions are synchronized with SDP and gets automatically listed as Site24x7 actions in SDP. Based on the template action settings, the related IT automation actions are shown in Request > "Action" menu section for defined user roles.

You must perform the following steps to associate automation actions to the SDP request template:

  1. Click on a specific Automation action to edit the Site24x7 action page.
  2. The Edit action page, provide you the actual action names and description of the action.
  3. By using the radio button, you can restrict the template to be used by select support group technicians or all technicians.
  4. Associate the IT Automation action with a predefined incident template, such as "Application crashes frequently" and click the Update button.

SDP Request page and Actions menu

When a service request is added in SDP portal, e.g., a frequent application failure with a particular server host, the technician responsible for resolving the issue can instantly access the "Actions" menu in Request details page and click the quick Action menu button intented to restart service/process. The resultant action is captured as an entry in notes the section of request with the message "Action initiated".
