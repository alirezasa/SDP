ユーザ満足度調査設定では、ユーザへの質問項目の追加とその質問に対する回答レベルを定義します（選択式）。

質問項目の追加方法
  1. ＋質問の追加 ボタンをクリック
  2. テキストフィールドに質問文を入力
  3. 保存をクリック（質問が満足度調査に追加され、質問タブ内に表示される）
質問項目の順番を変更するには、繰り上げ又は繰り下げリンクをクリック

満足レベルの追加方法
  1. 満足レベルタブをクリック
  2. + レベルの追加 ボタンをクリック
  3. テキストエリアは満足レベルの値を追加
  4. 保存をクリック
レベルの順序はそれぞれのレベルに関連付けられている値によって決定されます。満足レベルがリストの上位に表示される程、満足レベルが低いことを示します。最も満足レベルが低い値は１です。 ユーザ満足度調査レポートはそれぞれの満足レベルに関連づけられている値に基づいて作成されます。
 
ユーザが多言語バージョンのライセンスを購入している場合、満足度調査翻訳タブが表示されます。この機能により、複数のロケーションに存在するユーザがそれぞれの言語でユーザ満足度調査を表示できるようになります。
 
満足度調査の翻訳の追加方法
  1. 満足度調査翻訳タブをクリック
  2. 新規翻訳リンクをクリック
  3. 満足度調査言語ドロップダウンリストから調査の言語を選択（ServiceDesk Plusがサポートしている言語が表示されます。一度選択した言語はドロップダウンリストには表示されません。）
  4. 満足度調査言語で選択した言語で、質問項目、満足レベル、メッセージが表示される
  5. 保存をクリック（翻訳された言語での質問項目がリストビューに追加される）
依頼者の満足度調査フォームには、満足度調査翻訳タブで設定した言語リストが表示されます。満足度調査を表示する言語を選択してください。無効に設定した言語は、言語リストには表示されません。
