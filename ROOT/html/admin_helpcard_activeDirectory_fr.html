Vous pouvez configurer l’authentification de la connexion du demandeur à l’aide d’Active Directory (AD).

Remarque: Avant de commencer à configurer l’authentification AD, veuillez vérifier si vous avez déjà importé les demandeurs. Si le compte d’utilisateur est disponible dans  l’application, il sera authentifié à partir d’Active Directory.

Importation des demandeurs depuis Active Directory

  1. Cliquez sur le lien Importer des demandes d'Active Directory pour ouvrir la fenêtre Importer d'Active Directory.

  2. Dans la liste déroulante, sélectionnez le Nom de domaine. Si vous avez déjà indiqué le contrôleur de domaine et les identifiants de connexion pour le domaine sélectionné dans la liste Analyse de domaine Windows, ceux-ci seront affichés automatiquement.

  3. Si les informations ne sont pas renseignées, veuillez indiquer le nom du Contrôleur de domaine. Exemple : winmaster.  Puis, le Nom de connexion et le Mot de passe. Ces champs sont requis.

  4. Sélectionnez ensuite les champs à importer d'Active Directory. Pour ce faire, cochez les champs par défaut : Téléphone, Service, Titre de la tâche, Portable, Nom du site et E-mail.

  5. Renseignez le nom du champ configuré dans Active Directory à côté du champ sélectionné. Par ex. : si « Téléphone » est configuré comme « telephonenumber » dans active directory, puis saisissez le numéro de téléphone dans le champ de texte.

  6. Vous pouvez également Importer les informations du Champ de demandeur supplémentaire depuis Active Directory. Si vous n'avez pas configuré de champ de demandeur supplémentaire, cliquez sur le lien Cliquez ici pour configurer. Vous serez amené à la page Demandeur - Champ supplémentaire, dans laquelle vous devrez configurer les autres champs à importer d'Active Directory. Les champs supplémentaires de demandeur configuré, à avoir les champs Heure/Date, Numérique et Texte, apparaissent dans la fenêtre Importer d'Active Directory en bleu, vert et rouge, respectivement. Cochez les champs de demandeur supplémentaires à importer, et renseignez le nom du champ configuré dans active directory à côté du champ sélectionné. Les champs non sélectionnés ne seront pas importés.

  1. Si le site associé à l'utilisateur/service est modifié dans Active Directory, les équipements appartenant à l'utilisateur/service doivent être déplacés vers le nouveau site. Pour mettre à jour ces informations à chaque importation, cochez Déplacer les équipements associés. Pour ne pas déplacer l'équipement vers le nouveau site, décochez cette case.

  2. Cliquez sur Importer maintenant ! . La page de l’assistant d’importation contenant les différentes unités de l’organisation (OU) disponibles dans ce domaine s’affiche.

  3. En sélectionnant la case, choisissez l’OU spécifique depuis laquelle importer les utilisateurs.

  4. Pour importer les demandeurs, cliquez sur le bouton Démarrer l’importation. Après importation des demandeurs, vous obtenez un rapport signalant la réussite ou l’échec de l’opération.

  5. Cliquez sur Fermer la fenêtre.

Remarque:

1. Durant l’importation des demandeurs depuis Active Directory, les données des demandeurs existants seront remplacées.

2. Les champs numériques supplémentaires peuvent contenir 19 chiffres. Si cette valeur numérique est dépassée, renseignez la valeur dans le champ de texte.

3. Pour configurer le format de date selon vos paramètres dans Active Directory, mettez à jour l'entrée dans le tableau globalconfig (mettre à jour dans globalconfig la valeur du paramètre =«Date-Format » avec catégorie =« AD_DATEFORMAT » et paramètre =« UDF_DATE »). Redémarrez l'application pour prendre en compte les modifications.

 

Configuration de Active Directory

Par défaut, l’authentification AD est désactivée. Pour activer l’authentification AD, cochez la case correspondante.

Vous pourrez vous connecter en tant que demandeur dans l'authentification AD. Pour vous connecter en tant que technicien, l'administrateur doit d'abord sélectionner les techniciens de la liste des demandeurs et leur fournir des identifiants de connexion.

Authentification d'« intercommunication » [authentification unique, SSO]
Une fois l’authentification unique activée, ServiceDesk Plus authentifie directement votre nom d’utilisateur et votre mot de passe système Windows. Par la suite, il ne vous sera plus nécessaire de vous authentifier dans ServiceDesk Plus.
 
L'authentification d'intercommunication de ServiceDesk Plus utilise NTMLV2 qui fournit une meilleure sécurité et valide les informations d'identification à l'aide du service NETLOGON.
 
Après importation de tous les utilisateurs d’Active Directory, vous pouvez activer l’authentification unique.

  1. Pour activer l’authentification unique, sélectionnez la case à cocher.

  2. Vous pouvez activer l'authentification intermédiaire pour les utilisateurs d'un domaine particulier / fôret AD. Dans la liste déroulante, sélectionnez le Nom de domaine. Pour que l'authentification soit appliquée aux autres utilisateurs de domaine, cet autre domaine doit être en relation de confiance / parent-enfant avec le domaine sélectionné. Si il s'agit d'un domaine Parent-Enfant, seul le domaine parent doit être sélectionné ici.

  3. Renseignez l'IP du serveur DNS du domaine dans le champ fourni.

  4. Pour utiliser le fournisseur de sécurité NTML en tant que service d'authentification, un compte d'ordinateur sera créé dans Active Directory avec un mot de passe spécifique. Spécifiez un nom unique pour le Compte d'ordinateur et le Mot de passe pour ce compte.

  5. Le paramètre Chaîne de liaison doit être un nom de domaine DNS complet ou le nom d'hôte DNS complet d'un serveur AD particulier.

  6. Cherchez le Nom du site auquel le contrôleur de domaine est mappé dans « Sites et services Active Directory » du contrôleur de domaine, puis remplissez le champ de texte (si le délai d'expiration intervient après l'activation de SSO)

  7. Cliquez sur Enregistrer..

Remarque : Un compte d'utilisateur actif ne peut pas être spécifié en tant que compte d'ordinateur.

Un nouveau compte d'ordinateur sera créé sur l'Active Directory lors de l'enregistrement des informations (à l'aide de VB Script). Si un utilisateur spécifie un nom compte d'ordinateur existant, le mot de passe spécifié ici sera réinitialisé dans Active Directory pour le compte d'ordinateur. L'utilisateur peut également choisir de réinitialiser le mot de passe du compte d'ordinateur en cliquant sur le lien Réinitialiser le mot de passe.

Même si un problème survient lors de la création du Compte d'ordinateur ou de la Réinitialisation du mot de passe d'un compte d'ordinateur déjà créé à l'aide d'un script Visual Basic depuis le serveur SDP lors de l'enregistrement, le script sera appelé automatiquement), les détails spécifiés ici seront enregistrés et l'utilisateur pourra exécuter le script localement sur le serveur AD en spécifiant les mêmes détails pour créer le compte d'ordinateur/réinitialiser le mot de passe.

Si la création du compte d'ordinateur pose un problème, l'utilisateur peut spécifier un nom de compte d'ordinateur déjà créé et réinitialiser le mot de passe du compte d'ordinateur à l'aide du script de réinitialisation du mot de passe.

 

Planifier l’importation AD

Vous disposez d’une option pour planifier l’importation Active Directory dans un nombre donné de jours.

Sélectionnez la case Planifier l’importation AD. Dans la zone de texte, indiquez le nombre de jours. Cliquez sur le bouton Enregistrer la planification. Les informations de demandeur des domaines disponibles dans l'application seront importés une fois automatiquement dans le nombre de jours indiqués.
