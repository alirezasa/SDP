自身のスクリプトを使って、リクエストページのアクションメニューをカスタマイズできます。アクションメニューを作成して、そのメニューとカスタムクラスやスクリプトファイルを関連付けてアクションを実行します。ここで作成したメニューは、リクエスト詳細ページのアクションメニューに追加されます。

新規メニューの追加

新規メニュー作成には、次の詳細を登録してください:

メニュー名: 作成するメニューに一意の名前を指定します (メニュー名は、リクエストページのアクションメニューの下に表示されます)

説明: メニュー目的の説明を入力します。

関連付ける役割: このメニューにアクセスする技術担当者の役割を指定します(「All Roles（すべての役割」、または「Selected Roles（選択された役割)」より選択）

関連付けるテンプレート: このメニューを表示するテンプレートを選択します(「All Templates（すべてのテンプレート）」、「All Incident Templates（すべてのインシデントテンプレート）」、「All Service Templates（すべてのサービステンプレート）」または「Selected Templates（選択したテンプレート)」より選択）

アクションタイプの選択:「スクリプトを実行」、もしくは「クラスの実行」をアクションタイプ・ドロップダウンから選択します。「クラスの実行」を選択した場合、Executorクラスを指定してください；例、"com.servicedeskplus.integration.JiraActionImplementation"。「スクリプトを実行」を選択した場合、スクリプトファイルのパスと名前を指定してください；
例: "cmd /c Index.bat"。初期設定では、"[SDPインストールディレクトリ]/integration/custom_ scripts/"ディレクトリから実行します。

カスタムスクリプトへパラメーターとして引数を渡すことができます。

例: 

Script用: cmd / c Index.bat $SUBJECT $PRIORITY $STATUS

Class用  : com.servicedeskplus.integration.JiraActionImplementation



その他サポートされているパラメーター

$COMPLETE_JSON_FILE：Complete RequestオブジェクトはJSONファイルに保存され、そのファイルパスはStringオブジェクトとしてパスされます。

JSONファイルパス : (SDP_Home\integration\custom_scripts\request\12_1426143538036.json).

$HTML_DATA_JSON_FILE：Ajaxコールリクエストの"データ"パラメーターはメニュー名、JSONリクエスト、XMLファイルパスと共にJSONファイルに保存され、そのファイルパスがStringオブジェクトとしてパスされます。カスタマイズしたHTMLファイルで使用されます。例、(SDP_Home\integration\custom_scripts\request\12_1426143538036.json)

$HANDSHAKE_KEY：ハンドシェイクキーがStringオブジェクトとしてパスされます。

保存をクリックします。

作成されたメニューが、リクエスト詳細ページのアクションメニューの下に表示されます。


リストの表示

カスタムメニューの有効化/無効化: メニューの有効化/無効化は、リクエストカスタムメニュー・リストビューページから有効化/無効化アイコンをクリックします。

カスタムメニューの編集/削除: メニューの編集/削除は、リクエストカスタムメニューリストビューページから該当メニューの編集/削除アイコンをクリックします。
