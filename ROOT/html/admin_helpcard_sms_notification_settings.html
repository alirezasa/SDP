SMS Notification Settings

SMS Notification Settings allows you to notify Technicians through SMS. This way, the Technician can be notified on the go, for actions done on Requests he/she is associated with.

Option Definition
Send SMS through Mobile Service Provider Message will be sent to the SMS mail ID of the Technician
Send SMS through SMS Gateway Provider Message will be sent directly to the mobile number of the Technician

Any High priority Request or Change will require the Technician to look into it at the earliest. Servicedesk Plus helps Technicians solve their Requests on the go by sending the Notifications through SMS.

SDP offers two options for notifying. One, SDP sends SMS by integrating with service providers like Clickatell and Bulk SMS to notify the Technicians directly to their configured mobile number. Users can buy credits from the service providers and send messages till the credits last. Second, SDP sends notifications as e-mail to SMS mail ID of the Technician.

Choose an SMS provider that you would like to configure. While Clickatell requires Authtoken for Authentication details, Bulk SMS requires Username and Password.
Enabling 'Send SMS using unicode characters' checkbox will send notifications using unicode characters. Unicode provides a unique number for every character, regardless of the platform/program/language.


Custom Vendor settings

  • URL denotes the url of your SMS Gateway Provider. (Ex:http://www.smsserver.com/sendsms)
  • URL parameters are query parameters and they will be dynamically appended to URL.
  • Request headers allow the client and the server to pass additional information with the request or the response
  • Basic authentication is a method for a HTTP user agent to provide a user name and password when making a request
  • Request Payload should have a valid JSON Format and the content type can be
    • application/json (Ex:{ "foo" : "bar", "name" : "John"} )
    • application/x-www-form-urlencoded (Ex:foo=bar&name=John)
  • For message and recipients, please use '${{message}}' and '${{recipients}}'
  • Response from provider : please configure the success message so that application can determine whether the SMS has been sent successfully.
Note:
  • Configure the Technician Mobile Numbers for sending SMS notifications. Also, ensure to prefix the proper country code in Mobile field.
    This is accessible from Admin >> Users >> Technicians >> Technician Details.
  • SMS Messages can be customized in Notification Rules > SMS Templates.
  • 'How to configure' will provide link to sign up for that particular service provider and reveal instructions to do the same.
