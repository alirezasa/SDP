契約満了通知テンプレート

契約期間が満了を迎える際に技術担当者に通知するメールのテンプレートを作成できます。メールの件名と本文を入力してください。

件名

テンプレートで指定した内容の件名で技術担当者にメールを送信します。.

 

デフォルトでは変数名として$Contract Name と $Contract ID が挿入されています。必要に応じてこれらの変数を変更してください。変数を追加/変更するには、右横にある変数ボックスから件名に含めたい変数を選択します。

本文

メッセージフィールドの右横にあるリストから、メールの本文に含めたい変数を選択します。また、必要に応じて本文を作成してください。

保存ボタンをクリックして設定を保存します。契約が満了になると、ここで定義したテンプレートの通知メールが送信されます。.
