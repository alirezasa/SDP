개인 정보 설정


ServiceDesk Plus에서 요청자 양식의 기본 필드에 캡처된 모든 개인 식별 정보(PII)는 사용자가 조직을 나갈 때 삭제됩니다. 모듈 추가 필드의 데이터에 대해 사용자가 조직을 떠날 때 필드를 익명화하거나 삭제하려면 PII로 표시해야 합니다.


다음의 모듈 추가 필드에 PII를 표시할 수 있습니다.

사건 요청서
서비스 카탈로그 요청서
리소스 질의


익명화란 무엇인가요?

개인 정보 보호를 위해 사용자 데이터를 제거해야 하지만 조직은 감사 목적으로 정보의 일부가 필요할 수 있습니다. 이러한 경우 데이터의 해당 부분은 PII가 제거되는 동안 데이터베이스에 유지됩니다. 예를 들어, 사건/서비스 요청서의 경우 요청서의 실제 세부 정보는 데이터베이스에 유지되는 반면 전화번호 또는 생년월일과 같이 PII로 명시적으로 표시된 필드는 삭제됩니다. 사용자 이름의 경우 임의의 텍스트로 바꿀 수 있습니다. 이 익명화는 SDP 애플리케이션 전체에 적용됩니다.

Note:

  • 익명화는 SDP 애플리케이션 내에서 준수 규정이 적용되는 경우에만 가능합니다.

  • PII가 익명으로 표시된 사용자가 삭제되면, 즉시 익명화되며, PII 데이터는 8시간마다 실행되는 일정에 따라 삭제됩니다.



파일 보호 패스워드:

암호 보호를 적용하여 보고서 내보내기, 예약 보고서, 요청 목록 보기와 같이 애플리케이션 내에서 생성된 파일에 대한 보안 액세스를 보장합니다. 파일 보호 패스워드를 활성화한 후 각 사용자가 보고서를 트리거하면 개별 사용자 로그인에 대해 고유한 암호가 생성됩니다. 사용자는 패스워드 변경 마법사에서 패스워드를 보고 수정할 수 있습니다. 이 페이지에 저장하는 공통 패스워드는 로그인하지 않은 사용자를 위한 것입니다.
