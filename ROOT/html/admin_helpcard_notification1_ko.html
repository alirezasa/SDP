알림 규칙

알림 규칙은 이벤트를 기술자에게 알려야 할 때 유용합니다. 예를 들어 구매 주문이 기한이 지난 경우 또는 탐색 중 감사(자산) 변경 또는 탐색 중 소프트웨어 규정 준수 위반 또는 탐색 중에 금지된 소프트웨어가 식별된 경우입니다. 이러한 상황을 적절히 관리하면 기술자가 자산을 효율적으로 관리하는 데 도움이 될 뿐만 아니라 조직의 비용 절감 효과도 얻을 수 있습니다.

Enabling Notification Rules

알림 규칙을 설정하려면 확인란을 활성화하여, 관련 알림 규칙을 선택합니다. 이러한 알림 규칙은 규칙 이름으로 구분이 가능합니다.

기한이 지난 구매 주문을 제외하고 다른 모든 알림 규칙을 충죽하지 못하는 부분에 대해 알리도록 기술자를 지정할 수 있습니다.

1. 기술자를 지정할 때, 선택 버튼을 선택하면 기술자 이름 선택 페이지가 나타납니다.

2. Ctrl 또는 Shift 키를 사용하여 목록에서 원하는 기술자를 선택합니다.

3. 확인 버튼을 클릭하여 저장합니다. 회색으로 표시된 기술자 선택 필드에 선택된 기술자가 표시되는 것을 볼 수 있습니다.

저장 버튼을 클릭하여 설정된 알림 규칙을 저장합니다. Admin 관리자 또는 기술자에 대한 알림은 일반적으로 이메일을 통해 전송됩니다..

메시지 템플릿 사용자 정의

구매 주문 및 계약에 대한 메시지 템플릿이 있습니다. 이러한 이메일 템플릿을 사용자 정의할 수도 있습니다. 메시지 템플릿을 사용자 정의하려면

해당 모듈 옆에 있는 이메일 템플릿 링크를 클릭합니다. 메시지 템플릿 페이지가 열립니다. 메시지 템플릿 편집 양식에서 알림 유형은 편집할 수 없는 필수 필드입니다.

알림 유형에 대해 제공되는 제목을 변경할 수 있습니다.

메시지 블록에서, 알림의 일부가 될 콘텐츠 변수를 추가하려면 , 데이터베이스 필드 목록에서 필드를 선택하고 >> 버튼을 클릭합니다. 알림 필드 목록에서 필드를 제거하려면 해당 필드를 선택하고 << 버튼을 클릭합니다.

알림 필드를 재정렬하려면 앞으로 화살표 또는 뒤로 화살표 버튼을 를 선택할 수 있습니다.

수정이 완료되면, 저장을 클릭하여 설정을 저장합니다.
