Custom functions allow users to manipulate data within the application and other external services. Custom functions are built on Deluge, Zoho's propriety scripting language.

Global functions are custom functions that can be called from automations via other custom functions. They can store information that is essential to connect with external applications, common functionalities, and configurations.

  • Use the New button to create a global function.
  • The Delete button allows you to remove a global function.
  • To edit or delete a global function, use the Hamburger icon next to a custom function.
  • Use keywords to search through global functions in the field provided.
