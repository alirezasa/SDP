Details Tab

To start setting up your release template, enter the following basic details of your template. This information will be displayed to all users who can access the template:

  • Enter a template name. This is mandatory.
  • Add a description for the template.
  • Select the type of template - General or Emergency. Note that only emergency workflows can be configured with emergency templates.
  • Select a workflow to associate with the template. If no workflow is configured with the template, the default workflow will be used.

By default, the Details tab is displayed first when you add or edit the release template. It allows you to design the release request form to be displayed to technicians.
You can design the technician layout of the release form in the canvas present under the Details tab. You can add various fields, color-code the form, and configure users to roles with respect to the template.

Customize Fields and Columns

You can add built-in default fields, create new fields to fit your requirements, or add additional fields created previously.

  • Add default fields - Drag and drop the default fields to the required location in the canvas.
  • Create new fields - Click the Add New Field icon on the left panel. The available field types will be listed. Drag-and-drop a field type to the canvas, configure, and save the field properties. To learn how to configure release additional fields, click here.
  • Add Additional Fields - Additional fields configured earlier for the Release Management will be listed in the left panel under Custom Fields. Drag-and-drop them as required.

When you create a new field that may contain confidential information, select the Encrypt the Field check box to protect confidential data. . The encrypted data will not be displayed in reports, advanced search, or custom filters.

To add sections and group your fields into columns:

  1. In the left panel, click Add New Field icon.
  2. From the Section Types heading, you can drag and drop a section to your canvas based on the number of columns needed (Single Column, Double Column, Three Column, or Four Column). To customize the columns on the go, select Flexible Column.
  3. Some sections are untitled. Hover over the section name and click the edit section icon to define its properties. Sections without a title will not be displayed distinctly in the release form.
  4. Click Save.

Customize Form Layout

You can customize the layout of the template, sections, and fields to highlight important elements of the template. You can customize the font, including its size and color, background color, and field orientation.

To customize the template, click the Customization icon displayed on the top-right of the canvas. To customize a section or field, hover over the respective element and click the Edit icon. In the pop-up window, go to the Customization tab to modify the layout of the element.

To learn more about Form Customization, click here.

Note:

Stage, Status, and Comment fields are added to release templates by default. They cannot be moved or removed.

Site, Created Time, Completed Time, Title, and Description are also added to release templates by default. These fields can be relocated within the form but they cannot be deleted.


Roles Tab

After the details tab is saved, the Roles tab will be displayed. You can associate users with various release roles or create new roles.

Customize Roles and Columns

You can add built-in default roles, create new roles to fit your requirements, or add release roles created previously.

  • Add default roles - Drag and drop the default roles required location in the canvas.
  • Create new roles - Click the Add New Roles icon beside the Available Roles heading. Drag-and-drop Add Roles to the canvas, configure, and save the role properties. To learn how to configure release roles, click here.
  • Add Existing Release Roles - Release roles configured earlier for the Release Management will be listed in the left panel under Default Fields. Drag-and-drop them as required.

By default, the release roles will be added to release templates. The Release Manager, Release Requester, and Release Engineer roles are hard-coded in the template. The other roles can be removed from the template if needed.

  1. In the left panel, click Add New Roles icon beside the Available Roles heading.
  2. From the Section Types heading, you can drag and drop a section to your canvas based on the number of columns needed (Single Column, Double Column, Three Column, or Four Column). To customize the columns on the go, select Flexible Column.
  3. Sections are generally untitled. Hover over the section name and click the edit section icon to define its properties. Sections without a title will not be displayed distinctly in the release form.
  4. Click Save.

Customize Form Layout

You can customize the layout of the template and sections to highlight important elements of the template. You can customize the font, including its size and color, and background color.

To customize the template, click the Customization icon displayed on the top-right of the canvas. To customize a section, hover over the respective section and click the Edit icon. In the pop-up window, go to the Customization tab to modify the layout of the section.

To learn more about Form Customization, click here.

Note: You cannot edit the role permissions from the Roles tab.
