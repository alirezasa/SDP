Step-by-Step procedure for Integration : Video | Help Document

Integrate ServiceDesk Plus with ManageEngine Endpoint Central (formerly Desktop Central) to manage all your Desktop & Mobile Device Management functions. Endpoint Central automates desktop management activities like installing patches, deploying software, talking remote control, initiating chat, securing the client computers, applying USB usage restrictions and much more. It also enables managing Mobile Devices with profile management, App management, security management and asset management. If you have installed both these products, you just have to provide the details of the computer where Endpoint Central is installed along with its Port Number.

NOTE: Endpoint Central version should be version 8.1 and above.

Server Name: Enter the Server where Endpoint Central application is installed.

Server Port: Enter the Port Number of the Endpoint Central server.

Protocol Settings: Select the Protocol Settings. Say, http or https.

 

To display Desktop Management and MDM drop-down menus, select Enable Desktop Management Menu and Enable MDM (Mobile Device Management) Menu check boxes respectively. The Desktop Management menu will be displayed only for Endpoint Central build number #80100 and above. If you are not interested in integrating Desktop Management or MDM functions and want to remove the Desktop Management or MDM drop-down menus, deselect the check box respective check box and Save.

 

Click Save. The settings are saved successfully and ServiceDesk Plus will try to establish a connection with the Endpoint Central server. Once the connection is established, the configured software details from Endpoint Central server are fetched.

 

ServiceDesk Plus automatically sync with Endpoint Central server for configured software packages day-to-day. So, if you need to fetch the configured software packages instantly, select click here link.
