요청서와 관련된 우선 순위는 요청서에 부여될 중요도를 정의합니다. 새 우선순위를 추가하려면 우선순위 목록 표의 오른쪽 모서리에 있는 새 우선순위 추가 링크를 클릭하십시오.

새 우선순위 추가
우선 순위 추가 양식에는 우선 순위 이름과 설명이라는 두 개의 필드가 있습니다.

이름: 각 우선순위를 식별하는 유일한 이름을 지정하십시오.
색상: 색상 팔레트를 사용하여 우선순위를 나타내는 색상을 선택하거나 텍스트 상자에 색상 코드를 지정합니다.
설명: 설명 입력란에 우선순위에 대한 간단한 설명을 입력합니다. 이것은 우선순위 이름에 언급된 이름과 관련된 우선순위의 종류를 이해하는 데 도움이 될 수 있습니다.

우선순위를 저장하고 목록 보기로 돌아가려면 저장 버튼을 클릭하십시오.
우선순위를 저장하고 다른 우선순위를 추가하려면 저장하고 새로 추가 버튼을 클릭합니다.
