Les règles de clôture de demande peuvent être utilisées pour sélectionner les champs que le technicien devra obligatoirement compléter lors du classement de la demande. Vous pouvez également confirmer la reconnaisance de l'utilisateur au technicien et clôturer les demandes manuellement / automatiquement.

Exemple: Si, sur cette page, vous avez sélectionné Resolution en tant que champ obligatoire, le technicien en charge de la résolution du problème devra alors saisir la cause et la solution au problème dans le champ correspondant. Dans le cas contraire, un message d’erreur vous invite à saisir les détails dans le champ adéquat. Si Oui, faire apparaître un message est coché, un message de confirmation apparaît pour le technicien concerné si l'utilisateur a reconnu la résolution.

Pour définir les règles de clôture de demande :

  1. En sélectionnant des cases dans la liste, choisissez les champs obligatoires pour la clôture de la requête.

  2. Si vous souhaitez que le technicien reçoive un message de confirmation demandant si l'utilisateur a reconnu la résolution, cochez Oui, faire apparaître un message. Dans le cas contraire, cochez Non, ne pas faire apparaître de message.

  3. Une demande peut être fermée manuellement ou automatiquement.

Clôture manuelle : Si la case d'option est cochée, la demande doit être clôturée manuellement par le technicien concernée une fois celle-ci résolue.

Clôture automatique: Un e-mail est envoyé au demandeur une fois la demande consignée comme résolue. Le demandeur peut clôturer la demande à l’aide du lien de clôture indiqué, ou rouvrir la demande en répondant au courrier. Si le demandeur n'accomplit aucune action, la demande sera clôturée automatiquement après le nombre de jours indiqué dans la liste déroulante.

Cochez la case d'option Clôture automatisée. Sélectionnez le nombre de jours après lequel la demande résolue doit être clôturée dans la liste déroulante Clôturer la demande résolue après.
