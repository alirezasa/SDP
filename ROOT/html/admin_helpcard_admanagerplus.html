SDP-ADMP Integration :

ServiceDesk Plus integration with ADManager Plus helps Active Directory (AD) administrators and help desk technicians efficiently manage their AD user accounts from both applications. Administrators and technicians can create perform multiple AD related actions right from ServiceDesk Plus.

If you want ServiceDesk Plus technicians to perform only repetitive user management operations such as user creation, password reset, and account unlock, use the AD management plug-in.

Prerequisites: ADManager Plus version should be 6640 or higher.

Set Up the Integration

Configure ADManager Plus server details in ServiceDesk Plus before configuring ServiceDesk Plus settings in ADManager Plus.

Configure ADManager Plus Server Settings in ServiceDesk Plus:

  1. Enter the URL where the application is currently hosted.
  2. Click Test Connection and Save to check for an established connection between ServiceDesk Plus and ADManager Plus in their respective ports.

Click Remove to remove the established connection between the two applications.

Configure ServiceDesk Plus Server Settings in ADManager Plus:

  1. In ADManager Plus, go to ADManager Plus > Admin > Integrations > ServiceDesk Plus.
  2. Enter the server name and server port where the ServiceDesk Plus is currently running and choose the protocol settings.
  3. Select Enable tight integration with ServiceDesk Plus to ensure fixed integration between ServiceDesk Plus and ADManager Plus.

Note:If ADManager Plus server settings are configured in ServiceDesk Plus, the ServiceDesk Plus server details will be automatically added in ADManager Plus.

This integration will be available only for ServiceDesk Plus technicians configured as help desk technicians in ADManager Plus. To configure the ServiceDesk Plus technicians as technicians in ADManager Plus:

  1. Go to AD Delegation > Help Desk Delegation > Help Desk Technicians > Add New Technician.
  2. Select the domain, AD users, help desk roles, and organizational units.
  3. Enable Impersonate as Admin checkbox to configure the technician as an admin.
  4. Click Save.

Note: Login name and Domain name of the Technician should be same in both ADManager Plus and ServiceDesk Plus.

Domain Configuration:

Domain creation for the user is necessary to configure ServiceDesk Plus - ADManager Plus integration

Domain for an existing user in ServiceDesk Plus can be configured under Admin> Technician > Login Details > Select Domain.

New domain can be added in ServiceDesk Plus using Admin > Discovery > Windows Domain Scan.

Based on the actions enabled for each request template, technicians can perform the permitted actions. The enabled actions will be listed under Custom Actions menu in request details page.
