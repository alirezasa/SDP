Closure rule enables the administrator to select the mandatory fields to be filled out before closing each stage of the change request. The selected mandatory fields in any stage should be filled before moving from one stage to the next stage.

For instance, if Impact and Urgency options are enabled, then impact and urgency fields should be configured before moving from Submission stage to Planning stage. If fields are not configured, and a status change operation triggers a change of stage, then a warning message will pop up prompting you to fill the mandatory fields specific to the Submission stage.

To select mandatory fields,

  • Select the mandatory fields for closing a given stage of the change request by enabling the check box.
  • Click Save.
Click View History to view edits made to closure rules.
