集成ADManager Plus

通过将ServiceDesk Plus与ManageEngine ADManager Plus的集成，可以很方便地管理您的Active Directory用户账户。ADManager Plus是专门管理Windows Active Directory的解决方案，可对AD进行用户管理、组管理、计算机管理等等。如果您已经在使用ADManager Plus，只需要简单提供它所在的服务器的名称/IP地址和运行端口，即可完成集成配置。

要提供的信息：

服务器名称: 输入运行ADManager Plus的服务器名称或IP地址。

服务器端口: 输入ADManager Plus所使用的端口号。

协议设置: 选择ADManager Plus所使用的通讯协议，如：http 或 https.

 

点击保存按钮，保存设置，ServiceDesk Plus将尝试与所设置的ADManager Plus建立连接。一旦连接建立，使用页面右上角的跳转功能，即可切换到ADManager Plus。

集成ADSelfService Plus

通过将ServiceDesk Plus与ManageEngine ADSelfService Plus集成，允许您的Active Directory用户，自行进行密码重置、账户解锁。ManageEngine ADSelfService Plus是专门用于活动目录自助服务的软件，它可以帮助域用户，在不求助帮助台的情况下，自己重置密码、解锁账户、更新自己的信息等。如果您已经在使用ADSelfService Plus，只需要简单提供它所在的服务器的名称/IP地址和运行端口，即可完成集成配置。

要提供的信息：

服务器名称: 输入运行ADSelfService Plus的服务器名称或IP地址。

服务器端口: 输入ADSelfService Plus所使用的端口号。

协议设置: 选择ADSelfService Plus所使用的通讯协议，如：http 或 https。

 

选择 为技术员启用AD自助服务的菜单选项，将为技术员显示AD自助服务的菜单。不管这两个产品的集成是否成功，都将显示该菜单给技术员。

选择 为请求人启用AD自助服务的选项，则只有当集成成功之后，才会在请求人的页面显示“AD自助服务”。

 

点击保存按钮，保存设置，ServiceDesk Plus将尝试与所设置的ADSelfService Plus建立连接。一旦连接建立，使用页面右上角的跳转功能，即可切换到ADSelfService Plus。

集成Desktop Central

集成步骤 : 视频 | 帮助文档

通过将ServiceDesk Plus与ManageEngine Desktop Central集成，可以很方便地管理您的桌面机和移动设备。ManageEngine Desktop Central是专门用于桌面管理的软件，它可以帮助用户，进行补丁安装、软件部署、远程控制、策略配置等活动，也可以管理移动设备。如果您已经在使用Desktop Central，只需要简单提供它所在的服务器的名称/IP地址和运行端口，即可完成集成配置。

注意: Desktop Central必须是8.1及以后的版本。

要提供的信息：

服务器名称: 输入运行 Desktop Central 的服务器名称或IP地址。

服务器端口: 输入Desktop Central 所使用的端口号。

协议设置: 选择Desktop Central 所使用的通讯协议，如：http 或 https。

 

注意: 要显示桌面管理和MDM下拉菜单，请选中 启用桌面管理和启用MDM（移动设备管理）的选项。桌面管理的菜单只有版本为#80100及以后的Desktop Central才能显示。如果您对桌面管理和移动设备管理不感兴趣，希望删除桌面管理和移动设备管理的菜单，请反选这两个选项，然后保存。

 

点击保存按钮，保存设置，ServiceDesk Plus将尝试与所设置的Desktop Central 建立连接。一旦连接建立，将会从Desktop Central获取配置的软件信息。

 

集成OpManager

通过将ServiceDesk Plus与ManageEngineOpManager 集成，可以很方便地监控您的网络。ManageEngine OpManager是专门用于网络管理的软件，它可以对网络中路由器、交换机、服务器等进行细致的管理，它提供自动化工作流、智能化告警，满足用户的网关需求。如果您已经在使用OpManager，只需要简单提供它所在的服务器的名称/IP地址和运行端口，即可完成集成配置。

要提供的信息：

服务器名称: 输入运行 OpManager 的服务器名称或IP地址。

服务器端口: 输入OpManager 所使用的端口号。

协议设置: 选择OpManager 所使用的通讯协议，如：http 或 https。

 

点击保存按钮，保存设置，ServiceDesk Plus将尝试与所设置的OpManager的服务器建立连接。一旦连接建立，使用页面右上角的跳转功能，即可切换到OpManager 。

 

集成(运行于HTTPS模式)ME产品时需要另外执行以下步骤：

  1. 从以下链接下载 .zip 文件，并解压缩到<servicedesk安装目录>，(例如：C:\ManageEngine\ervicedesk)。

    http://bonitas.zohocorp.com/servicedesk/11Mar2010/certgeneration.zip

  2. 打开命令行窗口，切换目录到<servicedesk安装目录>，(例如：C:\ManageEngine\ervicedesk)，然后按照下面的格式运行gencert.bat：

    C:>ManageEngine\ServiceDesk>gencert.bat servername:portnumber

    这里的servername是指要集成的应用所在的服务器的名称，portnumber为要集成的应用所使用的端口。

  3. 执行这个命令的时候，会出现一个PKIX例外，并要求输入一个值。这时输入值为1，然后会在<servicedesk安装目录>(如：C:\ManageEngine\ervicedesk)目录中，生成一个叫jssecacerts的文件。

  4. 复制该jssecacerts 文件到<servicedesk安装目录>\jre\lib\security (如：C:\ManageEngine\Servicedesk\jre\lib\security)目录中，然后重新启动ServiceDesk服务。
