常规设置

计划数据库维护并配置磁盘使用量阈值，优化ServiceDesk Plus性能。

数据库维护计划

查询优化器使用表统计信息来创建查询计划。为了确保查询计划的最佳性能，必须定期更新表统计信息。在不同的数据库系统中，此数据库维护活动的执行方式有所不同。在Postgres中，使用“ VACUUM ANALYZE”操作，在MS SQL中，使用“ sp_updatestats”操作。  

将数据库维护计划为每天或每周至少运行一次

  • 要配置计划维护，计划表统计信息更新，请使用切换按钮启用维护计划。 
  • 选择频率并设置开始日期及时间。注意在非业务时间执行，避免对业务的影响。 

阈值

监视磁盘使用情况对于防止应用程序故障或停机至关重要。为此，请配置阈值以向管理员用户发送电子邮件通知。  

磁盘使用率阈值 -随着时间的推移，磁盘使用量会增加，最终所有可用磁盘空间将被消耗，从而导致应用程序故障。为防止这种情况，您可以配置磁盘利用率阈值以触发向管理员用户的通知。 

要设置磁盘利用率阈值，请在磁盘空间字段中以百分比形式输入首选值。 

MS SQL Server维护一个事务日志文件（.LDF）以记录所有事务。如果不进行监控，此文件可能会变大并填满磁盘，并导致应用程序停机。为防止这种情况，为MS SQL用户启用了一个附加选项，以配置触发向用户发送电子邮件通知的日志文件大小阈值。

要设置日志文件大小阈值，请在数据库日志文件大小字段以MB为单位输入首选文件大小  。

报表设置

为优化稳定性，您可以设置或修改各种报表生成条件的限制，例如行限制，最大同时用户数以及报表生成超时。
