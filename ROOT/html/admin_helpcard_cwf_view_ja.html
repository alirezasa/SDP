組込みのグラフィカルなツールを用いて、ワークフローのエディターで、ワークフローの基本的な詳細情報と方向性のパスを設定することができます。
ワークフローを作成するには、以下の基本的な詳細情報を入力します。
  • ワークフロー名
  • 説明
  • タイプ（一般/緊急）
ワークフローエディターには、ワークフロー図とステンシルパネルを作成するための拡張可能で、スクロール可能なキャンバスが用意されています。ステンシルパネルには、「ステージ」、「条件」、「スイッチ」、「通知」、「承認」、「フィールド更新」といった様々なノードがあります。シンプルなドラッグ&ドロップの操作で、キャンバスにノードを追加することができます。キャンバスにノードを追加する際に、ポップアップウィンドウが開き、そこでノードのプロパティを入力する必要があります。
様々なノードの使い方は、以下をご参照ください。名称をクリックすると、詳細説明が展開します。
ステージ - ワークフローに変更のステージを追加します。
  • ステージとステータスのそれぞれのドロップダウンリストから追加したいステージ・ステータスを選択します。
  • 1つのステージに複数のステータスを含めることができます。ノードの入力 / 出力の数は、選択したステータスの数に依存します。
  • デフォルトとして、グローバルに設定されているステータスの通知は、変更のワークフローによる影響を受けず、管理設定内で設定した通りに動作をつづけます。ワークフローに基づいて通知を上書きするには、ステータスにカーソルを合わせ、メールアイコンをクリックします。必要に応じて通知を保存し設定します。
  • 通知の上書きが有効化されているステータスは、黄色いメールアイコンで表示されます。
条件 - 変更が次のステージに進む前に満たす必要のある条件を入力します。
  • ノードの条件名を入力します。
  • カラム、条件、値を選択し、基準を入力します。
  • AND / OR演算子を用いて複数の基準を追加するには、プラス［+］アイコンをクリックします。条件を別の条件の下のインデントスペースにドラッグ&ドロップして、サブ基準として追加することができます。サブ基準を含む基準はドロップダウンアイコンで表示されます。
  • 条件のノードには、1つの入力ポートと、2つの出力ポート（はい / いいえ）で構成されています。
スイッチ - スイッチは、フィールド内の値を参照し、選択した値に基づいてワークフローのパスを適用する多方向分岐型のノードです。
  • スイッチの条件を適用したいフィールドを選択します。
  • 参照する必要のあるフィールドの値を追加します。それぞれのフィールドの値に対して異なるワークフローのパスを設計することができます。
  • スイッチのノードは、1つの入力ポートと、選択された値の数に基づいたN個の出力ポートで構成されています。
通知 - 変更のワークフローでカスタム通知を設定することができます。
  • ドロップダウンメニューから、既存のカスタム通知を選択するか、［新規］をクリックして新規通知を追加します。編集アイコンをクリックして、選択した通知を編集することができます。
    • 通知を追加/編集するには、通知名と説明を入力します。
    • 通知を送信したい、変更の役割・組織の役割を持つユーザーを選択します。特定のユーザーを選択するには、ユーザー名を入力し、ドロップダウンリストから特定のユーザーを選択します。
    • 通知メールで送りたい件名とメッセージを入力します。
    • ［保存］をクリックします。
  • 既存の通知を選択した場合はその通知の詳細情報に基づいて、通知先、説明、件名フィールドが自動的に入力されます。
  • 通知のノードは1つの入力 / 出力ポートで構成されています。
承認 - ステージ間に承認段階を追加し、承認のメール通知を設定することができます。
  • 承認の名称を入力します。
  • ドロップダウンリストから、承認待ち条件を選択することができます。誰か一人による承認/すべての承認者による承認/最初の承認者による承認を設定することもできます。
  • 承認者として設定する変更の役割/組織の役割を選択します。特定のユーザーを選択するには、ユーザー名を入力し、ドロップダウンリストから特定のユーザーを選択します。
  • 承認通知の件名とメッセージを入力します。必要に応じて、変数を挿入することができます。
  • 承認のノードは、1つの入力ポートと2つの出力ポート（Approved / Denied）で構成されています。
フィールド更新 - ワークフローの次のステージに進む前に、フィールドを更新することができます。
  • ドロップダウンメニューから、既存のフィールド更新を選択するか、［新規］をクリックして新規フィールド更新を追加します。編集アイコンをクリックして、選択した設定を編集することができます。
    • 設定を追加/編集するには、フィールド更新名と説明を入力します。
    • フィールド更新時に適用したいフィールドとフィールドの値を選択します。プラス［+］アイコンをクリックして、更新したい複数のフィールドを設定することができます。
    • ［保存］をクリックします。
  • 既存の設定を選択した場合、選択したフィールドの詳細に基づいて説明フィールドが自動的に入力されます。
  • フィールド更新ノードは、1つの入力 / 出力ポートで構成されています。
ノードを追加した後は、ノードを接続しワークフローの流れを設定します。ノードにマウスのカーソルを合わせると、入力 / 出力のポートを確認することができます。ソースノードの出力ポートをクリックし、必要に応じたターゲットノードの入力ポートへドラッグ&ドロップでパスを接続します。デフォルトとして、「Submission」と「Close」のステージはすでにキャンバスに用意されており、それぞれに「開始」と「終了」のノードが接続されています。デフォルトのステージを編集することはできませんが、以下のように追加されたノード/パスのリンクを修正することができます。
  • ノードにマウスのカーソルを合わせ、編集/削除することができます。
  • 必要に応じて、ドラッグ&ドロップで、キャンバス上のノード/パスの位置を変更することができます。
  • パスにマウスのカーソルを合わせ、クリックして頂点を追加したり、閉じる［x］アイコンでパスを削除することができます。
  • パスにカーソルを合わせることで、ソースノード、ターゲットノード、頂点を表示することができます。
  • パスのソースノード/ターゲットノードは、入力/出力の円をドラッグ&ドロップすることで変更することができます。

ステンシルアクション

ステンシルパネルの移動 - 左上にあるドラッグ&ドロップアイコンを用いて、ステンシルをキャンバスの好きな場所に移動することができます。
ワークフローのやり直し/元に戻す - ヘッダーにあるそれぞれのアイコンを用いて、ワークフローの任意のトランジションやアクションをやり直す/元に戻すことができます。
ワークフローのリセット - 閉じる［x］アイコンを用いて、新規ワークフローをリセットし、デフォルトの状態に戻すことができます。ワークフローを事前に保存していた場合、最後に保存した状態に復元することができます。
ステンシルを畳む- 右上のトグルアイコンを利用し、ステンシルパネルを畳む/開くことができます。

ワークフローアクション

ワークフローの保存 - ワークフローのヘッダーから［保存］をクリックします。なお、検証済みのワークフローのみが保存できます。ワークフローの設定にエラーがある場合は、それを知らせる警告メッセージが表示されます。
ワークフローのズームイン/ズームアウト - キャンバスの左角にあるズームアイコンを用いて、ワークフローを拡大/縮小することができます。
保存されたワークフローへのアクション - ワークフローの保存が完了すると、 ハンバーガーアイコンのドロップダウンメニューからワークフローのプロパティや履歴を閲覧したり、ワークフローをPDFとしてエクスポートしたりできます。
