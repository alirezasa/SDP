Project Types classify projects based on the goals they are trying to meet.

On this page, you can create new Project Types to classify various projects under this section.

Add Project Type

To add a Project Type, click New and fill out the displayed form.

Name: Specify a unique name to identify Project Type.

Description: Provide a short description about Project Type.

Color: Select a color to denote Project Type using a color palette.

Click Save or Save and Add New.
