Le cycle de vie d'une demande de modification implique généralement six étapes. Chacune d'elle peut comporter de nombreux états. Pour chaque état, une notification est envoyée aux utilisateurs avec certains rôles de modification pour les alerter sur la progression de la demande de modification.

L'Assistant de configuration d'état - Étape vous permet de définir l'état de chaque étape. Il vous permet également de modifier / supprimer l'état existant. Pour ajouter un état à une étape, cliquez sur le bouton Ajouter sous une étape.

  1. Dans le formulaire Ajouter un nouvel état, renseignez le champ Nom de l'état. Ce champ est obligatoire.

  2. Donnez une brève Description des activités de cet état.

  3. Lorsque la demande de modification saisit cet état, vous pouvez alerter les utilisateurs par e-mail à l'aide d'une notification. Cliquez sur l'icône Choisir les rôles et sélectionnez les rôles à notifier. Cliquez sur OK. Les rôles sélectionnés sont affichés dans le champ Notifier à.

  4. La section Configurer le modèle de notification comporte les champs Sujet et Message. Ils peuvent être modifiés par l'ajout de texte et variables de contenu.

  5. Renseignez le Nom de l'action pour cet état. Le Nom de l'action est une forme raccourcie et actionnable du Nom de l'état. Par ex. : « Envoyée pour autorisation » peut être « Obtenir une autorisation ». Le Nom de l'action est répertorié dans le menu déroulant Actions de l'état dans page d'informations de la modification.

Remarque : Si vous avez renseigné un Nom d'action, le flux de travail pour cet état peut être configuré dans l'Assistant de flux de travail.   

  1. Cliquez sur le bouton Enregistrer. L'état est ajouté à la liste des états existants sous l'état correspondant.

Remarque : Chaque étape comporte deux états par défaut : Approuver/Accepter/Terminer et Rejeter/Échec/Annuler. L'état par défaut ne peut pas être supprimé. Si toutefois vous souhaitez modifier ces états, veillez à utiliser un nom renseignant sur l'état, comme Oui et Non.
