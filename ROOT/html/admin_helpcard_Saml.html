ServiceDesk Plus supports SAML 2.0, which simplifies the process of user authentication by exchanging data between an Identity Provider (IdP) and the Service Provider (SP).

On this page, you can:

  • Configure and enable/disable SAML authentication.
  • Use SP details to configure the application in the IdP portal.
  • Enter IdP Details.
  • Create a detailed user profile for SAML logins and enter the attribute name in the Default Fields and User Additional Fields section as configured in IdP. When a user logs in for the first time, the IdP will send the attribute value for the corresponding application fields. This information will not be used to update already existing users.
  • Select specific fields whose data has to be imported to ServiceDesk Plus.

Note: If the login name generated by the IdP does not match with the login name of a user in ServiceDesk Plus, the user will be newly added because dynamic user addition is enabled by default. If dynamic user addition is disabled, users whose login names do not match will not be able to log in to ServiceDesk Plus
