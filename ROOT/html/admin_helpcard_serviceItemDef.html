To start setting up your service request template, enter a name and description and upload a descriptive icon for your template. This information will be displayed to all users who can access the template.

By default, the Technician tab is displayed first when you add or edit the service request template. It allows you to design the service request form to be displayed to technicians.

You can design the technician layout of the service request form in the canvas present under the technician tab. You can add various fields, resource-related questions, color-code the form, and restrict the template's availability to select support groups.

Customize Fields and Columns

You can add default fields that are built-in or from the left panel, create new fields to fit your requirements.

  • Add default fields - Drag and drop the default fields to the required location in the canvas.
  • Create new fields - Click the Add New Field icon beside the Available Fields heading. The available field types will be listed. Drag-and-drop a field type to the canvas and enter the field properties. Click Save.
  • Add Additional Fields - Additional fields configured for the Service Catalog will be listed in the left panel under Custom Fields. Drag-and-drop them as required.

When you create a new field that may contain confidential information, select the Holds personally identifiable information (PII) check box to protect your users' confidential data. You can also choose to encrypt the information by selecting Encrypt the Field. The encrypted data will not be displayed in reports, advanced search, or custom filters.

To add sections to group your fields in single or double columns:

  1. In the left panel, click Add New Field icon beside the Available Fields heading.
  2. Under the Column Types heading, the sections are listed as Single Column and Double Column.
  3. Drag and drop the relevant section to your canvas.
  4. Sections are generally untitled. Hover over the section and click the edit section icon to define its properties. Sections without a title will not be displayed distinctly in the request form.
  5. Click Save.

Customize Resource Sections

Configure resource questions from the Admin >> Service Catalog block and group them as resource sections. These sections will automatically be reflected in the left panel of your template customization form.

Scroll to the end of the left panel and click the Resource Section heading to expand it. The configured resource sections will be listed here. Add them instantly to your form using a drag-and-drop motion.

To add a new resource section, click the Add Resource icon. In the pop-up window, enter a name and description. You can add questions to a resource section in two ways:

  • Select from the existing questions configured in the application.
  • Click Add Resource Question to create a resource question manually. Select the resource question type depending on your requirements:
    • To allow the users to record an individual answer, create a plain text resource question.
    • To prompt your users to choose their answer from a range of provided choices, create check box/radio/drop-down questions.

While adding your own resource questions, you can add the cost of each resource and add images for your users' reference. For each resource, you can add up to 5 images in .jpg, .jpeg, .png, or .gif formats. Ensure that the image size is less than 5MB.

You can lay out your resource questions in one or two columns within a resource section.

Customize Form Layout

You can customize the layout of the template, sections, and fields to highlight important elements of the template. You can customize the font, including its size and color, background color, and field orientation.

To customize the template, click the Customization icon displayed on the top-right of the canvas. To customize a section or field, hover over the respective element and click the Edit icon. In the pop-up window, go to the Customization tab to modify the layout of the element.

To learn more about Form Customization, click here.

Specify Cost Details and Guidelines

Select the Cost Details check box to specify the cost of the overall service, if any.

Toggle on the Use this area to display a short description or any instruction, notes, or guidelines for Technician option to specify special instructions or guidelines to technicians.

Restrict Template Accessibility

Limit the template's usage by associating the template to select support groups. If you don't associate the template to any support group, the template will be accessible for all technicians.

Select Show to Requester if you want the template to be displayed to the requester. You can also restrict the template to be used by specific user groups by associating the user groups with the template.

Choose to allow requesters to view and/or edit individual fields from the technician form while editing the fields. Only the fields selected for requesters to set will be displayed as default fields in the requester template.

Note: Fields selected for requesters to view will be displayed only in the request details page.

Customizing Requester Template

Customize the template per your requirement.

You can customize the font including its size and color, background color, and field orientation by clicking the Customization icon displayed for the template or section.

Add default fields to the form. (You cannot edit the fields.)

The default values for the fields can be set only under the Technicians tab.

Use sections to group fields.

Configuring Workflow

  • Approvals: You can configure up to five approval levels each with a custom name; mandate approval from all approvers or apply first approval action; assign technicians based on approval status; and configure automated notifications.
  • SLA: You can associate multiple SLAs to the template from existing SLAs or create new SLAs and associate them. Designate an SLA as default for the template.
  • Checklists: You can configure checklists to guide technicians to complete the requests in a systematic way. Checklist supports multiple field types such as radio button, single-line textbox, numeric-only text box, and decision box.
  • Tasks: You can configure multiple tasks for the service template, organize, and establish dependencies. You can also make tasks visible to requesters, choose when to add tasks (after request creation or approval), and choose when to trigger tasks (after request creation, approval, or manual).
  • Template Actions You can configure template actions to perform functions from applications integrated with ServiceDesk Plus. Currently, ManageEngine ADManager Plus, Mobile Device Manager Plus, Password Manager Pro and UEM Product actions are supported.
