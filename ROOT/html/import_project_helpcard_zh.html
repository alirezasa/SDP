导入项目，允许您将使用Microsoft工具创建的项目导入到本产品中。每个MS项目将作为单独的项目被导入。在导入时，需要将MS项目的属性与ServiceDesk Plus中的项目建立等值关系。因此，必须按照以下步骤进行匹配。

注意：若选择“创建为新的优先级”被选中，当任意缺省的优先级 (低、正常、中等、高)为删除状态，如果导入的优先级仍在删除的范围内，则它会被重新创建。
