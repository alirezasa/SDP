설문조사 설정을 통해 환영 메시지, 이메일 내용, 설문조사 성공 또는 실패 메시지, 감사 메시지에 대한 기본값을 구성할 수 있습니다.
 
설문조사 활성화

설문 조사를 활성화하거나 비활성화하도록 선택할 수도 있습니다. 설문조사를 활성화하면 설문조사 수행 주기를 예약할 수 있습니다.
설문조사를 활성화하려면 사용자 설문조사 활성화 확인란을 선택합니다. 설문 조사 세부 정보 블록 아래에 다음 필드에 대한 값을 입력합니다.
 
설문조사 세부 정보

환영 메시지: 사용자가 설문조사 페이지에 도달하는 즉시 표시할 환영 메시지를 입력하십시오.
이메일 콘텐츠: 이메일 콘텐츠 텍스트 필드에 이메일의 목적을 지정합니다. 이 내용은 요청자에게 보낸 메일에 표시됩니다. $RequesterName 와 $SurveyLink는 요청자와 애플리케이션 URL 에 따라 변경되는 변수입니다.
성공 메시지: 설문조사에 성공적으로 응답하면 표시될 메시지를 입력하십시오.
실패 메시지: 사용자가 이미 설문조사에 참여한 경우 표시될 메시지를 입력합니다.
감사 메시지: 감사 메시지를 입력합니다. 이 메시지는 설문조사 양식의 제출 버튼 바로 앞에 표시됩니다.

설문 조사 일정 잡기
 
설문조사를 예약하려면 설문조사 예약 블록에 제공된 라디오 버튼 중 하나를 선택합니다. 선택하십시오.
한 요청서가 종료될 때: 한 요청서가 종료될 때마다 설문 조사 메일이 전송됩니다    
요청서들이 종료됨: 텍스트 상자에 종료될 요청서 수를 입력하십시오. 이 지정된 수의 요청서가 종료되면 한 설문조사 메일이 발송됩니다.
요청서들(한 사용자의)이 종료됨: 텍스트 상자에 한 요청자의 종료될 요청서 수를 지정합니다. 이 지정된 수의 요청서가 종료되면, 한 설문조사 메일이 해당 요청자에게 전송됩니다.  이 텍스트 상자는 정수 값만 입력할 수 있습니다.
수동으로: 요청서 세부 정보 보기 페이지의 '액션' 메뉴에서 필요할 때 수동으로 설문조사 실행합니다.

설문조사 예외
 
특정 사용자 또는 조직은 설문조사 보내기에서 제외될 수 있습니다.
사용자의 필요에 따라 다음 예외를 활성화하거나 비활성화할 수 있습니다.
기술자가 요청자인 경우 설문조사 비활성화: 이것을 활성화하면 기술자가 요청자일 때 설문조사를 받지 않게 됩니다.
다음 규칙 중 하나라도 일치하는 경우 설문조사 제외: 최대 10개의 규칙을 설정할 수 있으며 각 규칙 아래에 우선순위, 요청 방식,난이도(수준), 사이트, 요청자 이름 및 이메일 ID와 같은 6가지 기준을 추가할 수 있습니다. 규칙 중 하나라도 일치하면 설문조사가 해당 특정 사용자/조직으로 전송되지 않습니다.
새 규칙을 클릭하여 새 규칙을 추가하고 삭제를 클릭하여 특정 규칙을 삭제합니다.

참고 사항: 일단 한 규칙이 일치하면 목록의 후속 규칙은 확인되지 않습니다. 따라서 중요도에 따라 규칙의 우선 순위를 지정하면 선택한 사용자가 설문 조사를 받을 때 누락되지 않습니다.

저장을 클릭하여 설문조사 설정을 저장하고 재설정을 클릭하여 모든 작업을 취소합니다.
