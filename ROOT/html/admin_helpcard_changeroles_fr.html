Rôles de modification Ajouter des rôles  

Les Rôles de modification sont des autorisations d'accès exclusivement destinées au module de modification. Contrairement aux rôles de système hiérarchisés à modules, les rôles de modification sont définis en fonction des étapes du cycle de vie de modification. Tandis que les Rôles du système sont pré-assignés aux utilisateurs avec une autorisation de connexion, les Rôles de modification sont dynamiques. Ces derniers peuvent être assignés aux utilisateurs connectés et non connectés au moment de la création ou de la modification d'une demande de modification.

Les Rôles de modification assignés aux utilisateurs différent pour chaque demande de modification. Un Rôle de modification assigné à un utilisateur lui permet d'effectuer des tâches définis dans ce rôle (pour cette demande de modification uniquement).

Par exemple, un utilisateur peut avoir le rôle de Gestionnaire de modification pour une modification avec l'autorisation de la modifier à toutes les étapes. Dans le même temps, l'utilisateur peut également jouer le rôle d'Examinateur pour une autre modification, avec l'autorisation de contrôler uniquement l'Étape d'examination.

Les utilisateurs ayant l'accès total au module de modification via le Rôle du système peut accéder à toutes les demandes de modifications, qu'un rôle de modification leur soit assigné ou non.  Ces utilisateurs n'ont toutefois pas l'autorisation d'approuver les modifications, à moins qu'un Rôle de modification avec Autorisation d'approbation ne leur soit assigné.

Par ex. : un technicien ayant le rôle de Gestionnaire de modification SD peut modifier toutes les demandes du module de modification, qu'un rôle de modification lui soit assigné ou non. Si ce même technicien se voit assigner le rôle de Gestionnaire de modification pour une demande de modification, alors, indépendamment des autorisations de modification, il possèdera le privilège d'approuver/rejeter la demande de modification.

Lorsqu'un Rôle de modification est assigné à un utilisateur sans aucune autorisation de connexion, une notification contenant une URL non-connectée est envoyé par e-mail à l'utilisateur. Cette adresse URL permettra à l'utilisateur de réaliser des tâches en fonction de l'autorisation définie dans ce rôle.

Remarque : Les Utilisateurs connectés assignés à un Rôle de modification doivent posséder un Rôle système avec Autorisation d'afficher activée pour le Module de modification.

Les rôles de modification par défaut et leurs descriptions sont détaillés dans la colonne du tableau ci-dessous :

Rôles

Description

Comité consultatif sur les modifications (CAB) Groupe de personnes dynamique assistant le Gestionnaire de modification dans l'évaluation, la priorisation et la planification des modifications. Ils ont l'autorité de recommander une modification.
Approbateur de modification Personne ayant l'autorité d'approuver/rejeter la modification à l'étape d'approbation.
Gestionnaire de modification Personne ayant l'autorité totale sur la modification et l'autorisation d'approuver/rejeter une modification.
Modifier le propriétaire Personne désignée comme propriétaire d'une modification et veillant à son achèvement.
Demandeur de modification Personne ayant initié la modification.
Responsable d'implémentation Personne ou groupe responsable de l'implémentation planifiée de la modification.
Gestionnaire de ligne Personne autorisant le niveau initial d'acceptation d'une nouvelle demande de modification.
Examinateur Personne examinant l'ensemble des tâches pour une demande de modification et veillez à son achèvement.

 

Remarque 1 :  : Certaine rôles de modification ne peuvent pas être supprimés : CAB, Gestionnaire de modification, Propriétaire de modification et Demandeur de modification.

Remarque 2 :  : Les rôles Gestionnaire de modification et Approbateur de modification sont les seuls possédant l'autorisation d'approuver/rejeter les demandes de modification lors de l'Étape d'approbation.

 

Pour ajouter un nouveau rôle de modification, cliquez sur Ajouter un rôle de modification.

Ajout d'un rôle de modification

  1. Cliquez sur le bouton Ajouter un rôle de modification.

  2. Renseignez le Nom du rôle de modification dans le champ prévu à cet effet.

  3. Donnez une brève Description du rôle de modification.

  4. Lors de la sélection des utilisateurs pour ce rôle, vous pouvez choisir de répertorier Tous les utilisateurs dans l'application, ou uniquement les Techniciens. Cochez la case appropriée.

  5. Choisissez les Autorisations d'accès des différents étapes pour le rôle de modification. Par ex. : si vous souhaitez accorder l'Autorisation d'approbation pour les étapes Envoi et Vérification, cochez les cases d'approbation à côté des étapes.

Ci-suit les autorisations d'accès pour les six étapes par défaut du cycle de vie de modification.

      • Afficher : Les autorisations de consultation permettent aux utilisateurs d'afficher la demande de modification pour l'étape sélectionnée. Ils sont limités à cette seule opération.

      • Editer : Les autorisations de modification permettent aux utilisateurs de modifier la demande de modification pour l'étape sélectionnée. Ils l'ont pas l'autorisation d'approuver/rejeter une modification. Si l'option Modifier est sélectionnée pour une étape, l'autorisation Afficher est activée automatiquement.

      • Approuver : Les autorisations d'approbation permettent aux utilisateurs d'approuver/rejeter la demande de modification pour l'étape sélectionnée. Si l'option Approuver est sélectionnée pour une étape, l'autorisation Afficher est activée automatiquement.

        Les utilisateurs avec accès total au module de modification via un Rôle système tel que Gestionnaire de modification SD ou Admin SD n'ont pas le privilège d'approuver/rejeter une modification.

  1. Un accès complet à l'ensemble des étapes est également possible, il suffit pour cela de cocher Toutes les autorisations d'accès.   

  2. Cliquez sur le bouton Enregistrer. Le rôle de modification est enregistré et répertorisé dans l'Affichage liste des rôles de modification. Pour revenir à l’affichage liste des rôles de modification, cliquez sur le bouton Modifier.
