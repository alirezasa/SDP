关系类型

关系类型用于描述一个配置项与另一个配置项之间的关系特性。它用两种方式加以表述：关系类型和反向关系类型。就是说从一个配置项看是关系类型，而反过来从另一个配置项看就是反向关系类型。如：运行::运行在...上（Runs::Runs On），发送数据到::从...接收数据（Sends data to::Receives data from） 等等。

比如：服务器与软件的关系，就可以表述为：Server1 Runs Application1, 反过来，软件与服务器的关系就是：Application1 Runs On Server1。

本软件缺省提供了若干关系类型。您可以通过点击新添关系类型的链接，来添加新的关系类型。

要提供的信息包括：

关系类型: 一个配置项对另一配置项的关系特征。如：发送数据到

反向关系类型: 另一配置项对前述配置项的关系特征（反过来看时的特征），如：从...接收数据

描述: 为该关系类型，输入简要的描述，以便让用户了解其特征。

点击保存按钮，保存关系的明细。
