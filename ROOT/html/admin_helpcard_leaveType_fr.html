Les Types de congé vous permettent de configurer les raisons de congé les plus courantes. La configuration des types de congé est essentielle. Elle permet au technicien de demander rapidement un congé dans le Planificateur. Chaque type de congé est identifié de manière distincte par un code de couleur. Cette couleur permet à l'administrateur de saisir la raison du congé demandé par le technicien.

Cliquez sur le lien Nouveau type de congé dans l’angle droit de la page de liste des types de congé.  

 

Nouveau type de congé

  1. Renseignez le Nom du type de congé dans le champ prévu à cet effet. Par ex. : Malade, En service, Facultatif, etc. Le nom renseigné doit être unique. Ce champ est obligatoire.
  2. Sélectionnez une Couleur pour renseigner le type de congé vis-à-vis du Graphique de disponibilité du technicien.
  3. Donnez une brève description du type de congé dans le champ Description.
  4. Cliquez sur Enregistrer. Le type de congé apparaît dans l'affichage liste.
  5. Cliquez sur Enregistrer et ajouter nouveau pour enregistrer et créer un autre type de congé.
