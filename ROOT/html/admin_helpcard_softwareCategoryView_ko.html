Asset Explorer에서 사용할 수 있는 소프트웨어는 소프트웨어 범주에서 분류되고 그룹화됩니다. Asset Explorer에서 사용할 수 있는 기본 소프트웨어 범주 중 일부는 회계, 인터넷, 그래픽, 멀티미디어, 운영 체제 및 게임입니다.

소프트웨어 범주 추가

  1. 새 소프트웨어 범주 링크를 클릭합니다. 그러면 소프트웨어 범주 세부 정보 페이지가 열립니다.

  2. 이름 필드에소프트웨어 범주 이름을 제공합니다. 필수 입력란입니다.

  3. 설명필드에 범주에 대한 관련 정보를 지정합니다.

  4. 소프트웨어 범 추가 버튼을 클릭하여 목록 보기에 소프트웨어 범주를 추가합니다.
