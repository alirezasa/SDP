Task Types allow categorization of similar Tasks. For example, Tasks related to troubleshooting of various kinds can be grouped under Task Type "Troubleshooting". Such Task Categorization helps create Request, Problem, Change & Project specific Task Types which can be used to categorize Tasks as and when they are created making them more granular.

Add Task Type
Add Task Type form has three fields, namely, Name, Description & Inactive Checkbox.

Name: Specify a unique name to identify Task Type.
Color:Select a color to denote Task Type using the color palette or specify the color code in the text box.
Description: Enter a short description about the Task Type in the Description field.

Click the Save button to save Task Type and return to the list view.
Click the Save and add new button to save Task Type and add another.
