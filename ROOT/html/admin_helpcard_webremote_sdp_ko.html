도움말 카드

Web Remote는 클라이언트 시스템(Windows 시스템)에서 원격 세션을 용이하게 하는 내장 도구입니다. 이 도구는 클라이언트 컴퓨터에 설치하지 않고도 AE 애플리케이션에서 사용할 수 있습니다. 또한 세션 캡처 및 재생 옵션도 제공합니다. Web Remote는 기본 포트 8083에서 실행되는 별도의 서비스로 작동합니다. 기본 포트는 포트 번호를 구성하여 변경할 수 있습니다.

Web Remote에 대해 자세히 알아보려면 여기를 클릭하십시오

Web Remote 사용

  • 워크스테이션의 서버 이름이 자동으로 채워집니다.
  • 서버 포트 번호를 입력합니다.
  • 원격 세션을 녹화하려면 '세션 녹화 활성화' 확인란을 선택하십시오.
  • Web Remote를 활성화하려면 'Enable web 활성화' 확인란을 선택하십시오.
  • 웹 원격 포트 번호를 입력합니다. 기본 포트는 3389로 설정되어 있습니다.
  • 제출을 클릭합니다.
