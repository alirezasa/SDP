사용자 정의 액션은 사용자가 ServiceDesk Plus 및 기타 외부 애플리케이션에서 데이터를 조작할 수 있도록 하는 실행 가능한 사용자 정의 함수입니다. 사용자 정의 함수는 Zoho의 적절한 스크립팅 언어인 Deluge를 기반으로 합니다.

사용자 지정 액션은 작업 사용자 정의 트리거에서 작업, 기타 모듈 및 외부 애플리케이션에 대한 액션을 수행하는 데 사용할 수 있습니다.

  • 새로 만들기 버튼을 사용하여 사용자 정의 액션을 만듭니다.
  • 액션 버튼을 사용하면 사용자 정의 액션을 일괄 삭제, 비활성화 및 활성화할 수 있습니다.
  • 개별 사용자 정의 액션을 수정하려면 사용자 정의 액션 옆에 표시된 아이콘을 사용하십시오.
  • 키워드를 사용하여 제공된 필드에서 사용자 정의 액션을 검색합니다. 상단의 필터를 사용하여 특정 기능에 사용된 사용자 정의 액션을 표시합니다.

참고: 사용자 정의 액션 트리거에서는 활성 사용자 정의 액션만 사용할 수 있습니다.
