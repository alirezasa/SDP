Ajoutez et consultez les différents services de votre organisation (et au travers des branches) situés sur plusieurs sites. Chaque service est géré par un responsable de service.

Si les sites sont configurés, le service de chacun d'entre eux peut être consulté en sélectionnant le site dans la liste déroulante Services pour.

Remarque: L'administrateur du site peut exécuter différentes opérations sur les services auxquels il est associé. La liste déroulante Service n'apparaîtra pas si les sites ne sont pas configurés.

Ajouter un nouveau service

Pour ajouter un nouveau service à un site, sélectionnez ce site dans la liste déroulante Service pour. Cliquez sur le lien Ajouter un nouveau service dans l’angle droit du tableau Liste des services.

Nom du service : Renseignez le nom du service à ajouter dans le champ Nom du service. Ce nom doit être unique dans la mesure où un même service peut exister dans différentes branches d'une firme. Ce champ est obligatoire.

Site : Le site du service créé apparaît dans un champ de texte non modifiable. Ce champ n'apparaît que lorsque des sites sont configurés.

Description :Vous pouvez fournir une brève description des activités du service dans le champ Description.

Responsable de service : Sélectionnez le responsable de service en cliquant sur l'icône de recherche d'utilisateur. Une liste des utilisateurs apparaît. Sélectionnez le nom de l'utilisateur à assigner comme responsable de service.

Cliquez sur Enregistrer.Le service est ajouté sous le site sélectionné.
