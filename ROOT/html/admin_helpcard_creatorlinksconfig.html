Enable Apps : Enabling the checkbox will display the app in the quick links tab along with the drop-down.

Allow Requesters to access : Enabling the checkbox will provide access to the external links for the requesters and fill out forms. Disabling the checkbox will hide the entire list of links and remain inaccessible to the requesters.

App Display Name : Enter the name that you wish to display in the quick links tab. If apps other than Zoho Creator are used, then the display name can be re-named accordingly.

Link name : Enter a prominent name for the link to the app. Proper description can be entered about the app in the space provided.

URL : Paste the URL to access the app. This URL will open the app in a new tab.

Show to Requesters : Show to Requesters is different from Allow Requesters to access in the sense that, each individual link can be chosen to be exposed or concealed from the requester by choosing 'Yes' or 'No' from the drop-down.

Click 'Save' to save the settings and the same can be viewed by clicking the app name in the quick links tab.

Facts : Links can be added and deleted by clicking the ' +' and '-' options accordingly .The order in which the apps have to displayed can be arranged by making use of the drag and drop option on mouse hover.        

Sample scenario : External links useful to the organization can be listed under the apps tab.

Booking a shuttle service or a cab can be easily done through Zoho Creator forms. The employees of the organization can be provided with a quick link for 'Book a cab' form and thus be provided with hassle-free shuttle services.

Booking of a conference room for a scheduled meeting can be done in advance by providing a quick link to the form and filling it. The App Display Name can be given as 'Conference hall booking form' and the creator link can be pasted in the URL space. The requesters can be allowed to access this form by choosing 'Yes' for 'Show to Requester'.
