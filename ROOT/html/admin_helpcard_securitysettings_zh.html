安全设置：

配置安全设置，以保护您的应用程序免受潜在的漏洞和安全漏洞的影响。使用安全表来监测和衡量您是如何有效地配置各种内置安全功能的。

安全仪表：

监测和衡量您如何有效地配置各种内置安全功能。安全仪表提供了以下内容：

  • 以百分比表示的安全分数
  • 基于安全评分的安全等级分类：不安全、弱安全、中度安全和高度安全。
  • 查看和管理可用安全功能清单的选项

常规设置：

  • 配置账户锁定阈值和持续时间：使用此选项，您可以确保用户账户在预设的登录失败次数后被锁定。这里设置的配置同时适用于工作站和移动设备。

    要配置账户锁定的阈值和持续时间，
    • 启用 配置账户锁定的阈值和持续时间。
    • 指定账户锁定阈值。
    • 指定允许的登录尝试次数和重置锁定用户账户的时间。
    • 选择是否只在尝试登录的电脑/手机上锁定用户账户，还是在所有设备上锁定。
    • 自定义用户账户被锁定时显示的信息。
    • 选择通过电子邮件或铃声通知技术人员。

  • 禁止并发登录：选择此选项可以禁用并发登录的功能，可以禁止同一账户同时进行多次登录，取消选择该选项可以启用并发登录功能。默认情况下，允许并发登录。

  • 服务器端口和协议配置：
    选择以 HTTP 或 HTTPS 模式运行应用程序。
    对于HTTP：指定应用程序必须运行的默认服务器端口。
    对于HTTPS：在指定服务器端口后，指定TLS版本和密码，以确保数据的适当加密，防止黑客窃取。

  • 启用“保持登录”：为用户在登录页面选择启用“保持登录”选项。一旦启用，您也可以设置用户保持登录的期限。默认的期限是45天。到期后，用户必须使用他们的登录凭证重新认证。

  • 启用忘记密码功能：这将在登录页面中启用/禁用本地认证的忘记密码选项。用户可以通过输入他们的用户名和域名来获得一个密码重置链接发送到他们的主电子邮件地址。如果没有配置电子邮件，或者在多个配置文件中配置了特定的电子邮件，那么邮件将不会被发送。在这种情况下，管理员可以手动重置密码。

  • 会话超时配置：在此选项下，您可以设置用户不活动的时间，之后用户将被注销。使用适当的选项为基于Web的会话和移动应用程序会话独立配置会话超时。对于移动应用程序，会话超时的配置可以根据需要启用/禁用。

  • 为所有文件附件启用密码保护：通过在服务器层面加密，保护存储在您的应用程序中的文件附件不被非法访问。这将防止服务器数据的安全漏洞。

高级设置：

    • 从列表中选择所需的安全响应标头。
    • 输入响应标头的值。
    您也可以包括或排除一个或多个响应标头。您可以为响应标头Access-Control-Allow-Origin提供多个用逗号分隔的值。.

  • 在登录期间启用域下拉菜单：此选项如果启用，将在登录和忘记密码页面上列出域名。如果禁用，域名将对除用户以外的任何人保持匿名。
    • 此选项如果启用，将根据输入的用户名过滤登录时（以及在忘记密码页面）列出的域。如果禁用，将显示整个域列表，减少黑客知道特定用户所在域的概率。

密码策略：

密码策略允许管理员配置和执行创建密码的标准。这确保了用户数据的更高的安全性。

要配置密码策略，

  • 启用密码策略。
  • 在8和99之间选择最小密码长度。
  • 选择密码是否必须包括：
    • 大写和小写字母
    • 特殊字符或符号
  • 选择要记住的先前密码的数量。该应用程序最多可以记住8个密码。
  • 选择密码的有效期限。

密码政策将只在更改密码时对现有用户密码生效。

首次登录时强制重置密码：

配置强制新用户在首次登录时重置密码。

注意：必须重新启动应用程序，才能使保存的设置生效。
