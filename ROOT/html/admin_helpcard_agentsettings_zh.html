代理设置

 

AssetExplorer对Windows工作站和服务器进行扫描时，支持无代理和代理两种模式。无代理模式，通过WMI对Windows工作站和服务器进行扫描。代理模式则是使用本应用程序提供的代理进行扫描。该代理可以通过多种方式部署在网络工作站中，一旦部署完毕，就会扫描所在的工作站并提供便捷的远程协助。如果您已经启用了代理模式，程序会在代理模式下运行，反之，则会在非代理模式下运行。

 

一个成功的扫描，代理程序应该和AssetExplorer服务器建立通讯。服务器明细可以在代理设置中配置。默认情况下，安装本应用的机器就是缺省的服务器。您能够编辑这些配置来生成您自己的代理配置。

  • 服务器名称： 就是安装了AssetExplorer的机器的名称或IP地址。代理程序使用服务器名称和IP地址从客户端与AssetExplorer服务器进行连接。 

  • 服务器端口： 配置应用程序的端口号。

  • 协议： 连接服务器时所用的协议。

  • 代理端口： 代理的端口号。

  • 在系统启动时扫描： 开启此选项，代理将在机器每次启动时进行扫描。

注意：如果代理已被安装在所有Windows机器上，并且发生了以下情况，则需要更改所有代理的配置，这时可通过执行脚本 ( AgentConfiguration.vbs)来更改配置。

  1. AssetExplorer程序被从一个服务器移动到另一个服务器或者如果AE端口或者协议（http或 https)被改变了。
  2. 如果需要在所有机器上改变代理端口或者更改系统启动时是否扫描的选项。

可以把脚本 ( AgentConfiguration.vbs) 作为在活动目录中登录脚本来运行或者手动在每台机器上更新代理配置。当通过活动目录执行脚本或者手动（作为AgentConfiguration.vbs脚本执行）时，脚本的参数应该是这种格式""-servername <AE 服务器名称> -port <AE 端口号> -protocol <http 或 https >"。
