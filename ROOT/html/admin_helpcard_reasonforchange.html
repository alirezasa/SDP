Reason for Change denotes the purpose for initiating a change request. For instance, if a printer in your organization does not work due to a damaged printer cartridge, then the reason for change can be Printer is not working, and the change request initiated can be Change the printer cartridge.

Choose to view Active or Inactive Reasons For Change using the drop-down.

Use the Actions icon to edit or delete a reason for change.

Use the Search icon to find your preferred reason for change.

Click View History to view edits made to reasons for change.

Adding Reason for Change

  • Click New.
  • Enter the reason for change in the Name field.
  • Provide a brief Description about the reason for change.
  • Click Save.
