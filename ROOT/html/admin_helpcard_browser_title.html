Customizing Browser Title

Default Title: Choose this option to have the title ManageEngine ServiceDesk Plus for all pages in the application irrespective of the modules. Selected Module: Choose this option to customize the browser title to match the module name of the current page.

Details Page: You can configure titles of details page separately. To do this, click the respective checkbox and enter the custom title. Add variables using the dollar sign for dynamic custom titles. For example, if you want the browser title of the request details page to display request id and subject enter #$id, $subject in the text box.

Note:
  • Click Reset to revert to default values.
  • Custom Details Page title will also be applied for Edit forms.
