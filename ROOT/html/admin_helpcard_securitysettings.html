Security Settings:

Configure security settings to safeguard your application from potential vulnerabilities and security breaches.Use the security meter to monitor and gauge how effectively you have configured various built-in security features.

Security Meter::

Monitor and gauge how effectively you have configured various built-in security features.The security meter provides the following:

  • A security score in percentage
  • A security level classification based on the security score: unsecured, weak security, moderate security, and highly secure
  • An option to view and manage the list of available security features

General Settings:

  • Configure account lockout threshold and duration: Using this option, you can ensure a user account is locked after a pre-specified number of failed login attempts. The configuration set here applies to both workstations and mobile devices.

    To configure account lockout threshold and duration,
    • Enable Configure account lockout threshold and duration.
    • Specify the account lockout threshold.
    • Specify the number of login attempts allowed and the duration to reset a locked user account.
    • Choose whether to lock the user account only on the computer/mobile where the login was attempted or all devices.
    • Customize the message to be displayed when the user account is locked.
    • Choose to notify technicians either by email or as bell notification.

  • Disable Concurrent Logins: Selecting this option disables the concurrent login functionality. Use this to disable multiple login from a same account at the same time. Unselecting this option enables concurrent login functionality. By default, the concurrent login is allowed. 

  • Remove exif metadata:  Enable this option to remove exif (Exchangeable image file format) metadata from images attached in the application.   

  • Server Port and Protocol Configuration:
    Choose whether to run the application in HTTP or HTTPS mode.
    For HTTP: Specify the default server port where the application has to run.
    For HTTPS: After specifying the server port, specify the TLS versions and Ciphers to ensure proper encryption of data, preventing hackers from stealing it.

  • Enable Keep me signed-in: Selecting this enables "Keep me signed in" option for users in the login page. Once enabled, you can also set the duration for which the users can be kept signed into the application. The default duration is 45 days. On expiry, users have to re-authenticate using their login credentials.

  • Enable Forgot Password: This will enable/disable the Forgot Password option for local authentication in the login page. Users can get a password reset link sent to their primary email address by entering their username and domain. If email is not configured or if the particular email is configured in multiple profiles, the mail will not be sent. In such cases, the admin can reset the password manually.

  • Session timeout configuration: Under this section, you can set the duration of user inactivity after which the user will be logged out from the web application.

  • Enable password protection for all file attachments: Protect the file attachments stored in your application from unauthorized access by encrypting them at the server level. This will prevent security breach over the server data.

  • Disable API calls that use loopback addresses: API calls to domains that use loopback addresses are vulnerable to SSRF attacks. Therefore, disable API calls through loopback addresses.

Advanced Settings:

  • Add security response headers: Configure security headers to safeguard the application from vulnerabilities.
    • Choose the required security response header from the list.
    • Enter the response header value.
    You can also include or exclude one or more response headers.You can provide multiple values separated by commas for the response header Access-Control-Allow-Origin.

  • Enable Domain drop-down during login: This option, if enabled, will list the domain names on the login and forgot password pages. If disabled, the domain names will be kept anonymous to anyone apart from the users.
    • during Login: This option, if enabled, will filter the domains listed during login (and in the forgot password page) based on the username entered. If disabled, the entire domain list will be displayed, reducing the probability of hackers knowing the domains where a particular user is present.

  • Disabling HTTP compression will prevent BREACH attacks since this type of attack only occurs on data transferred via HTTP compression. However, this will lead to a slight increase in the network's bandwidth.

  • Selecting this option disables the last successful/unsuccessful login details banner that is displayed on the top right of the screen when a user logs into the application.

  • All actions/operations can be performed as per the configured rate limit.

      Notifications are sent to SDAdmins when URLs rate are accessed via the UI and integration keys.

Password Policy :

Password Policy allows the administrator to configure and enforce the criteria for creating passwords. This ensures better security of user data.

To configure the password policy,

  • Enable password policy.
  • Select the minimum password length between 8 and 99.
  • Select if the password must include:
    • Both uppercase and lower case letters
    • Special characters/symbols
  • Choose the number of previous passwords to remember. The application can remember up to 8 passwords.
  • Select the expiry period for the password.

The password policy will take effect on existing user passwords only upon the password change.

Force Password Reset at First Login :

Configure to enforce new users to reset their password at first login.

Note: Application must be restarted for the saved settings to take effect.

Mobile :

Under the Mobile tab, you can configure security settings related to the mobile app.

  • Allow copy/paste: Permit or restrict copy/paste operations in the mobile app.
  • Allow attachment operations: Permit or restrict attachment operations such as add, view, download, and delete in the mobile app.
  • Allow screen captures: Permit or restrict screen captures in the mobile app.
  • Enable session timeout for mobile app: Configure session timeouts to ensure users are logged out from the mobile application after a certain period of inactivity. You can configure the period of inactivity in minutes.
  • Enable Azure Pre Authentication: Enable this if the application is hosted using an Azure application proxy and pre-authentication is configured as Entra ID (users must verify their identities using their Microsoft Accounts). Provide the Client ID, Client Secret, Authorization URL, and Token URL from the Azure application.
