Request timer actions allow you to execute time-delayed automated actions. You can configure ServiceDesk Plus to calculate the wait time for all requests that satisfy a precondition and schedule the timer actions to be executed.

Configuring During and After rules is essential for the smooth execution of timer actions.

 Configure Timer Actions
  • Click New Timer Action.
  • Name and Description: Provide a name and description for the timer action.
  • Action applies for: You can apply the action for all templates or for selected templates.
  • Conditions: Configure the criteria-conditions to be satisfied by the request from the drop-down list.
  • Stage: After defining the criteria-conditions, you can configure stages that will be executed sequentially.
    • Initial delay: Set the delay time to hold execution of during and after rules.
    • Repeat Every: Choose whether, when, and how many times to repeat the timer action.
    • Consider delay time on: Choose whether to consider the initial delay time only during business hours or SLA hours. If you choose SLA hours, you can pause the timer when the request moves to onhold, completed, or resolved states. If the delay time is not configured, the timer will run 24x7.
    • Configure During rules and After Rules. They will be executed sequentially.
      • During Rules and After Rules.
      During Rules
      During rules are used to automate actions on requests when the stage scheduled time is reached for a request. For each stage, you can add up to 5 during rules which will be executed in sequence. The request data modified by a during rule will be considered when the next rule is validated.

      Note: You can reuse during rules for other stages and timer actions.

      Create During Rules
      • Click Add New Rule and fill out the form. If the rules already exist, select the rules you want to associate from the available list and click Associate.
      • Rule name and Description: Provide a name and description for the rule.
      • Execute during: Choose when to apply the rule: Anytime, Within Operational Hours, or Outside Operational Hours.
      • Criteria: Configure the criteria to match the requests from the drop-down list. You can create up to 50 criteria using AND/OR combinations.
      • When a request arrives: Choose to execute custom action or abort process execution.
        • Execute custom actions - Select the custom actions from the available options: Field Update, Custom scripts, Custom Functions, If-If action, or If-Else action. You can configure a maximum of 5 actions in a during rule. Script/custom function (1), field update (2), If-If (1), and If-else (1).
        • Abort process execution - This option stops current stage execution. In case of stage repetition, executes actions after the wait time and proceeds to the next stage.
      • Click Save and Associate or Save.
      List View Actions
      • Click Edit to modify the details of during rules.
      • You can delete, enable, or disable rules in bulk. Select the during rules, click Actions and select the required action.

      After Rules
      After rules are used to automate actions within ServiceDesk Plus or third-party applications when the stage scheduled time is reached for a request. For each stage, you can add up to 5 after rules which will be executed in sequence.

      Note: You can reuse after rules for other stages and timer actions.

      Create After Rules
      • Click Add New Rule and fill out the form. If the after rules already exist, select the rules you want to associate from the available list and click Associate.
      • Rule name and Description: Provide a name and description for the rule.
      • Execute during: Choose when to apply the rule: Anytime, Within Operational Hours, or Outside Operational Hours.
      • Criteria: Configure the criteria for requests from the drop-down list. You can create up to 50 criteria using AND/OR combinations.
      • Select Custom Action: Choose the custom action to be executed on a request that satisfies specified criteria. You can configure email/SMS notifications, custom scripts, custom function, webhook, If-If action, or If-Else action as custom action on requests. You can configure a maximum of 24 actions in a after rule. Script/custom function (1), webhook (1), notification action (20), If-If (1), and If-else (1).
      • Click Save and Associate or Save.
      List View Actions
      • Click Edit to modify the details of after rules.
      • You can delete, enable, or disable rules in bulk. Select the after rules, click Actions and select the required action.
    • After configuring the during/after rules,
      • Use Cascade icon to turn ON or OFF the cascade execution for during/after rules.
      • Click Dissociate to remove the rule and
      • Use Reorder to organize the during/after rules.
  • Click New Stage to add another stage. You can add up to 10 stages.
  • Click Save or Save and Add New.
Note: Admins can add up to 50 timer actions.

List View Actions
  • Use the Toggle button to enable or disable the timer action.
  • Use Edit to modify the details of the timer action.
  • To delete, enable, or disable timer actions in bulk, select the timer actions and click Actions.
Note: When a timer action is deleted, the timers associated with the requests are removed.
