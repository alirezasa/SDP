On this page, administrators can mandate task-related fields which they consider as significant for the task. If the Task Closing Rules are defined, the technicians working on the task will have to adhere to these rules; else an error message will be displayed prompting them to fill the mandatory fields.

For example, if you set Worklog as mandatory field, the technicians will be able to complete tasks only after filling in the Worklog details.

To set Task Closing Rules, select the mandatory fields for closing the task by enabling the respective checkboxes.

Task completion Status: Enable the checkbox to consider only the task with closed status as a completed task.

Click Save.
