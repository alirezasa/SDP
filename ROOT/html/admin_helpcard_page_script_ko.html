페이지 스크립트를 사용하면 요구 사항에 따라 페이지별로 응용 프로그램을 사용자 지정할 수 있습니다. 사용자용 페이지 스크립트를 사용하여 SDP 애플리케이션에서 UI 요소와 페이지 기능을 수정할 수 있습니다. 예를 들어 사용자의 요청서 목록 보기 또는 요청서 세부 정보 페이지에서 특정 버튼을 숨길 수 있습니다. 또한 모듈의 여러 페이지에서 요청자 또는 기술자를 위한 새 위젯, 동영상, 웹 페이지 및 양식을 추가하도록 선택할 수 있습니다. 


페이지 스크립트를 실행하려면 먼저 규칙을 정의하고 조건을 구성해야 합니다.

  • 규칙 이름을 추가하고 규칙을 적용할 대상을 선택하여 새 규칙을 만듭니다. 예: 요청자/기술자 또는 모든 사용자.  
  • 규칙을 적용할 위치를 선택하십시오. 예: 요청서 목록 보기/요청서 세부정보 페이지/모든 페이지(모든 모듈의 페이지) 
  • 페이지 스크립트가 실행되어야 하는 조건을 구성합니다. 여러 조건을 추가할 수 있습니다. 
  • 규칙을 구성하고 나면 사용자 정의 스크립트를 작성하여 사용자 정의를 실행할 수 있습니다. 
  • 일부 기본 사용자 정의 스크립트가 기본적으로 제공됩니다.  필요한 경우 사용할 수 있습니다. 

자신만의 스크립트를 작성하고 실행할 수도 있습니다.
