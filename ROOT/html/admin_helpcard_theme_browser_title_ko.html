1) 테마 탭

색상 변경

사전 설정 색상의 경우: 사전 설정 색상 조합 중 하나를 선택합니다. 사용자 정의 색상의 경우: 사용자 정의 색상을 클릭하여 색상을 변경한 다음 UI 요소에 대한 색상 선택 상자를 클릭하여 색 영역을 사용하여 원하는 색상을 선택합니다.

글꼴 변경

글꼴 섹션 아래의 드롭다운 목록에서 원하는 글꼴을 선택합니다.

변경사항 미리 보기

오른쪽에 있는 대화형 미리 보기를 사용하여 사용자 정의를 미리 볼 수 있습니다.

사용자 개인화

SDAdmin은 다른 사용자가 테마 및 글꼴을 개인화할 수 있도록 허용 확인란을 사용하여 사용자가 애플리케이션의 색상 및 글꼴을 사용자 정의하도록 활성화/비활성화할 수 있습니다. 이 옵션은 기본적으로 활성화되어 있습니다.

참고:
  • 테마 설정에서 변경한 사항은 모든 기술자와 요청자에게 적용됩니다.
  • 다른 사용자가 테마 및 글꼴을 개인화할 수 있도록 허용 확인란을 선택하면, 사용자 개인화가 색상 및 글꼴의 Admin 관리자 구성보다 우선 적용됩니다.

2) 브라우저 제목 탭

브라우저 제목 사용자 정의

기본 제목: 모듈과 상관없이 애플리케이션의 모든 페이지에 대해 ManageEngine ServiceDesk Plus라는 제목을 사용하려면 이 옵션을 선택합니다. 선택된 모듈: 현재 페이지의 모듈 이름과 일치하도록 브라우저 제목을 사용자 지정하려면 이 옵션을 선택합니다.

세부 정보 페이지: 세부 정보 페이지의 제목을 별도로 구성할 수 있습니다. 이렇게 하려면 해당 확인란을 클릭하고 사용자 지정 제목을 입력합니다. 동적 사용자 지정 제목에 달러 기호를 사용하여 변수를 추가합니다. 예를 들어 요청 세부 정보 페이지의 브라우저 제목에 요청 ID와 제목을 표시하려면 텍스트 상자에 #$id, $subject를 입력하십시오.

참고:
  • 기본값으로 되돌리려면 재설정을 클릭하십시오.
  • 사용자 정의 세부 정보 페이지 제목은 편집 양식에도 적용됩니다.
