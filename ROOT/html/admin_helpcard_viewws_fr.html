Gérer les groupes

L’explorateur des équipements vous permet de regrouper des équipements en fonction de leurs propriétés. Vous pouvez grouper les équipements d’utilisateurs appartenant à la même équipe et se trouvant sur un même site. L’organisation des équipements en groupes permet un contrôle plus précis et une gestion efficace.

En d’autres termes, vous pouvez grouper des équipements en fonction du système d’exploitation, des Service Packs, de la quantité de mémoire, etc. Lorsque vous préparez une migration, vous pourrez repérer les équipements dotés de 256 Mo de mémoire vive exigeant une mise à niveau avant l’installation de Windows Vista.

Modifier les groupes

Dans la colonne Gérer les groupes, cliquez sur le lien Modifier du groupe que vous souhaitez modifier.
La page Modifier le groupe affiche les Détails du groupe, les Ressources du groupe et la Sélection des ressources pour ajouter de nouvelles ressources au groupe.

Dans le coin gauche de la colonne de détails Groupe, cliquez sur le bouton Modifier.
Le formulaire contenant les détails du Groupe s’affiche. Vous pouvez consulter les détails du groupe et y apporter les modifications requises (notamment le Nom et la Description du groupe).
Pour réaliser des modifications, cliquez sur le bouton Modifier.

Supprimer les groupes

Cliquez sur le lien Supprimer du groupe à supprimer. Le groupe sera supprimé de la liste.

Ajouter des ressources au groupe

Pour Ajouter des ressources au groupe, sélectionnez les critères du filtre dans la liste déroulante. La liste des ressources filtrées est affichée. Sélectionnez la ressource dans la liste en sélectionnant la case.

Cliquez sur le bouton Ajouter. Les ressources sélectionnées sont ajoutées au groupe et sont affichées dans la colonne Ressources du groupe.

Supprimer des ressources du groupe

Pour Supprimer des ressources existantes du groupe, sélectionnez leur nom dans la liste au moyen des cases de la colonne Ressources du groupe.

Cliquez sur le bouton Supprimer. La ressources sélectionnée est supprimée de la liste.

Créer un groupe

Pour un classement plus facile, les utilisateurs peuvent être organisés en groupes Statiques et Dynamiques.
Sous le groupe Statique, vous définissez le groupe en répertoriant ses membres. Sous le groupe Dynamique, les ressources sont groupées automatiquement sur la base de certains critères définis par l’administrateur.

Créer un nouveau groupe

Cliquez sur le lien Ajouter un nouveau groupe, dans le coin droit de la page Gérer les groupes. La page Créer un groupe s’affiche. Elle comporte trois champs : Nom du groupe, Description et Type de groupe. Les champs Nom du groupe & Type de groupe sont obligatoires.

Dans le champ Nom du groupe, indiquez un nom.
 
Dans le champ Description, indiquez toute information pertinente sur le groupe que vous venez de créer.

Sélectionnez un Type de groupe au moyen d’un bouton radio.

Groupe statique : Vous définissez le groupe en répertoriant ses membres.
Groupe dynamique : Les ressources sont groupées automatiquement sur la base de certains critères.

Pour enregistrer le groupe, cliquez sur le bouton Enregistrer.
Si vous souhaitez effacer les détails saisis pour la création d’un groupe, cliquez sur le bouton « Annuler ».
