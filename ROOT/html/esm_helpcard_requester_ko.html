이 페이지에서, 사용자에게 역할을 검색, 추가, 삭제 및 배정할 수 있습니다. 또한 VIP 사용자를 표시하고 사용자 계정을 병합할 수 있습니다. 여기에 추가한 사용자들을, 인스턴스 담당자가 조직 전체의 여러 인스턴스로 가져올 수 있습니다.

사용자 추가

Active Directory에서 가져오거나 CSV 파일을 사용하여 수동으로 사용자를 SDP 애플리케이션에 추가할 수 있습니다.

수동으로 사용자 추가

신규 버튼을 클릭하고 표시된 양식을 작성한 다음 저장합니다.
사용자의 로그인 이름과 패스워드를 만듭니다. 이것은 사용자가 SDP 애플리케이션에 로그인할 때 사용하는 자격 증명입니다. Active Directory를 통해 사용자를 추가할 수도 있습니다. 자세한 내용은 Active Directory 섹션을 참조하십시오.
사용자의 API 키를 생성하도록 선택할 수도 있습니다. API 키는 웹 서비스 API에 액세스하는 데 사용할 수 있습니다. 필요한 경우 API 키의 만료 날짜를 설정합니다.

사용자 편집

사용자 목록 보기에서 사용자 옆에 있는 편집 아이콘을 클릭합니다. 필요한 세부 정보를 편집하고 저장을 클릭합니다.
참고: 사용자의 부서/사이트를 추가/업데이트하면 특정 인스턴스에 사용자를 추가하는 데 사용된 기준에 따라 해당 인스턴스에서 사용자가 자동으로 추가/제거됩니다.

사용자 역할

ESM 디렉토리에서는 사용자에 대한 조직 관리자(Organization Administrator: Org Admin) 권한만 부여할 수 있습니다. 사용자에게 이 권한을 부여하면 ESM 디렉토리에 대한 액세스 권한이 부여됩니다. 확인란을 사용하여 사용자에게 조직 관리자 (Org Admin) 액세스 권한을 부여합니다.

Active Directory에서 사용자 가져오기

새로 만들기 드롭다운을 클릭하고 Active Directory에서 가져오기를 선택하고 표시된 양식을 작성한 다음 지금 가져오기를 클릭합니다.

Admin->Windows Domain Scan 아래에 도메인 관련 세부 정보를 이미 입력한 경우 세부 정보가 자동으로 채워집니다. 그렇지 않으면 IT HelpDesk의 관리 설정->Windows 도메인 스캔으로 이동하여 ESM 디렉토리 아래에서 사용자를 가져옵니다.

CSV 파일에서 사용자 추가 + 새로 만들기 드롭다운을 클릭하고 CSV에서 가져오기를 선택한 다음 파일을 선택한 다음 제출을 클릭합니다.

사용자 병합(기준 없음) 중복되거나 유일한 사용자 계정을 수동으로 선택하고 액션 드롭다운에서 사용자 병합을 클릭합니다.
상위 계정을 선택하고 사용자 병합을 클릭합니다.

중복된 사용자 병합(기준 있음) 다른 도메인에 있는 중복된 로그인 이름 또는 이메일 ID가 있는 계정을 병합합니다. 속성 값도 병합됩니다.

사용자 병합을 클릭하고 중복을 식별하는 기준으로 로그인 이름 또는 이메일 ID을 선택한 다음, 도메인 이름들(2개의 도메인, 1개의 도메인 또는 없음으로 표시된 도메인)을 입력하고, 필터 적용을 클릭합니다.

선택한 도메인들에서 중복 계정 쌍이 나열됩니다. 병합할 계정을 선택하고 사용자 병합을 클릭합니다. 상위 도메인을 선택하고 사용자 병합을 클릭합니다.

사용자 삭제

목록 보기에서 사용자를 선택하고 액션을 클릭한 다음 사용자 삭제를 선택합니다. 사용자를 삭제하면 모든 인스턴스에서도 사용자가 삭제됩니다.
개인정보 보호 설정에서 GDPR 설정을 활성화한 경우 삭제하는 동안 사용자 이름을 임의의 텍스트로 변경할 수 있습니다. 이 변경 사항은 SDP 애플리케이션 내의 모든 모듈에 적용됩니다.
