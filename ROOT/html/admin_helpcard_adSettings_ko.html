Active Directory(AD)로 요청자 로그인을 인증하도록 구성할 수 있습니다.

참고: AD 인증 구성을 시작하기 전에 이미 요청자를 가져왔는지 확인하십시오. AssetExplorer 프로그램에서 사용자 계정을 사용할 수 있는 경우에만 활성 디렉터리에서 해당 사용자 계정의 암호를 인증합니다.

Active Directory 구성
AD 인증은 기본적으로 비활성화되어 있습니다. 활성화 버튼을 클릭하여 AD 인증을 활성화합니다.

여기에서 선택한 Active Directory의 요청자를 가져올 수도 있습니다. Active Directory에서 요청자 가져오기 링크를 클릭합니다. 그러면 Active Directory에서 가져오기 대화 상자가 열립니다.

도메인 목록 상자에서 요청자를 가져올 도메인을 선택하십시오. 도메인 검색 목록에 도메인 컨트롤러 이름, 사용자 이름 및 암호를 이미 입력한 경우 동일한 항목이 채워집니다. 지금 가져오기!를 클릭합니다.

가져오기 마법사는 해당 도메인에서 사용할 수 있는 다양한 OU(조직 구성 단위)를 표시합니다. 옆에 있는 확인란을 선택하여 사용자를 가져올 특정 OU를 선택하십시오.

가져오기 시작을 클릭합니다.

요청자를 가져오고 가져오기가 끝나면 성공적으로 가져온 사람과 실패한 사람에 대한 보고서가 화면에 표시됩니다. 창 닫기를 클릭합니다. 이미 요청자를 추가한 경우 AD에서 가져오는 동안 이미 존재하는 이름을 덮어씁니다.
