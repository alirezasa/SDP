与Mobile Device Manager Plus集成

集成过程步骤：帮助文档 : 帮助文档

将ServiceDesk Plus与Mobile Device Manager Plus集成以直接从ServiceDesk Plus控制台管理和保护移动设备。移动设备管理器自动化各种移动设备管理任务，如应用程序分发、设备管理和限制、电子邮件管理和资产管理。它还通过限制应用程序、设备和第三方云服务之间的数据传输为移动设备提供了额外的安全性。它有助于管理员在丢失设备的情况下定位设备，并在必要时擦除数据。如果已经安装了两个产品，只需输入安装Mobile Device Manager Plus服务器的计算机的详细信息以及端口号。

注释： 您应该运行Mobile Device Manager Plus加上版本92370和以上。

细节：

服务器名称：输入安装Mobile Device Manager Plus服务器的服务器信息。

服务器端口：输入Mobile Device Manager Plus服务器的端口号。

协议设置：选择协议设置。比如说HTTP或HTTPS。

 

注释：若要显示Mobile Device Manager Plus下拉菜单，请启用MDM（Mobile Device Manager Plus）菜单。只有在使用MDM Bug 92263时，此选项才可用。若要从下拉框中移除MDM选项，请取消选择该选项。单击“保存”。一旦成功保存设置，SDP服务器将与MDM服务器建立连接。然后，从MDM服务器获取配置细节。

 

点击保存。 设置保存成功，服务事务处理将尝试建立与Mobile Device Manager Plus服务器的连接。


与其他ME产品集成（运行在HTTPS模式下）

  1. 从下面给出的链接中下载.zip，并将其提取到"ManageEngine\ServiceDesk":

    2. Linux: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1af3b3o2010mg10kbj961mdt18sq1/lincertgeneration.zip

    Windows: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1af360niepdjr7j1flk1o323fa1/wincertgeneration.zip

  2. 连接到命令提示符。转到"ManageEngine\ServiceDesk"并以以下格式运行批处理文件:

    3. For Linux:
    C:>ManageEngine\ServiceDesk>gencert.sh servername:portnumber

    For Windows:
    C:>ManageEngine\ServiceDesk>gencert.bat servername:portnumber

  3. 在运行命令时，您将收到一个异常PKIX然后它将要求您输入一个值。提供值1，它将生成一个名为jssecacerts在"ManageEngine\ServiceDesk"下面。

  4. 复制jssecacerts文件在 "ManageEngine\ServiceDesk\jre\lib\security" 下面，然后重启桌面应用程序。
