Purchase request - Additional fields


Use Purchase Request Additional Fields, To add your own organization specific fields in the Purchase Request Form apart from the fields that are set by default. You can add new fields such as, Text fields, Numeric fields and Date/Time fields.

To add a new additional field,

1. Select a new tab and add the label name and description.

2. Select the text field type such as Single-line, Multi-line or a Pick list(drop down menu list) by clicking the corresponding button.
