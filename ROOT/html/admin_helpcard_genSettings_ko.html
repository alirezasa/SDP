솔루션 페이지에서 FreeAnswers.net 링크를 표시하거나 제거하려면 필요에 따라 예 또는 아니요 라디오 버튼을 선택해야 합니다.

대체 URL을 제공하려면
  1. http:// 텍스트 옆에 제공된 텍스트 필드에 URL을 입력합니다(필요한 경우 포트 번호와 함께).
  2. 텍스트 필드 바로 아래에 있는 별칭 URL을 새 창에서 열기 링크를 클릭하여 별칭 URL이 작동하는지 테스트합니다.
사용자 정의 로고를 표시하도록 선택하여, 애플리케이션을 사용자 정의할 수 있습니다. 로그인 페이지 용과 로그인 후 페이지의 왼쪽 상단 모서리에 표시되는 헤더 이미지 용의 2차원 로고를 추가해야 합니다. 로그인 페이지 이미지의 크기는 252픽셀 x 61픽셀(W x H)이어야 하고 헤더 이미지는 166픽셀 x 46픽셀이어야 합니다.

로그인 페이지 이미지를 가져오려면
  1. 이미지 가져오기... 버튼을 클릭합니다.
  2. 찾아보기 버튼을 클릭합니다.
  3. 파일 선택기 창에서 가져올 파일을 선택하고 열기를 클릭합니다.
  4. 가져오기를 클릭합니다.
방금 가져온 이미지가 로그인 페이지 이미지 대신 대체됩니다. 헤더 이미지에 대해서도 동일한 프로세스를 따르십시오. 저장을 클릭하여 설정 변경 사항을 저장합니다.
