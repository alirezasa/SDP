Vous pouvez classer tous les utilisateurs ServiceDesk Plus de votre organisation dans différents groupes d'utilisateurs. Sur une implémentation de site, le classement des utilisateurs en groupe est particulièrement utile pour interdire l'accès à certains éléments.

Par exemple, pour l'annonce « Le réseau Nortel du site de New York est arrêté pour raison de maintenance ». Cette annonce n'est essentielle que pour les utilisateurs du site de New York. Un groupe d'utilisateurs peut alors être créé afin que l'annonce ne doit rendue disponible qu'aux utilisateurs associés au site de New York. Le groupe d'utilisateurs peut également être filtré par Service, Adresse de messagerie, Titre de la tâche et Nom.

 

Ajouter un groupe d’utilisateurs

Pour ajouter un groupe d'utilisateurs, cliquez sur le lien Ajouter un groupe d'utilisateurs dans la page de liste des groupes d'utilisateurs.

Renseignez un Nom et une brève Description de groupe d'utilisateurs. Le champ Nom est obligatoire.

Configurer le filtre en sélectionnant le critère et la condition dans la liste déroulante. Saisissez la valeur dans le champ de texte. Vous pouvez également effectuer une recherche des valeurs à l'aide de l'icône de recherche. Pour ajouter un autre critère, cliquez sur le bouton d'ajout et répétez le même processus.  

Cliquez sur le bouton Enregistrer pour enregistrer le groupe d'utilisateurs et revenir à l’affichage liste.
Pour enregistrer le groupe d'utilisateurs et en ajouter un autre, cliquez sur le bouton Enregistrer et ajouter nouveau .
