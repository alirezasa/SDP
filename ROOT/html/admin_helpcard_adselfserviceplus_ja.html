ServiceDesk Plus - ADSelfService Plus連携:

ServiceDesk PlusとManageEngine ADSelfService Plusを連携することで、Active Directoryユーザーは簡単に自分のパスワードとアカウントを管理できます。ManageEngine ADSelfService Plusはセキュアでウェブベースのパスワードリセット管理ツールです。このツールによりドメインユーザーはMicrosoft Windows Active Directoryのパスワードセルフサービス、アカウントセルフサービス、自身の情報に対するセルフサービス（電話番号やメールアドレス）を実行できます。ServiceDesk PlusとADSelfService Plusをインストールしている場合は、ADSelfService Plusがインストールされているコンピューターの情報（ポート番号など）を入力する必要があります。

入力情報:

サーバー名:ADSelfService Plusがインストールされているサーバーを入力します。

ポート番号:ADSelfService Plusサーバーのポート番号を入力します。

プロトコル設定:プロトコル設定で"http"か"https"を選択します。

 

技術担当者にADSelfServiceメニューを公開するためには"技術担当者にADSelfServiceメニューを有効にする"を選択します。このメニューはServiceDesk PlusとADSelfService Plusの連携有無にかかわらず表示されます。ADSelfService Plusタブを依頼者に公開するには、"依頼者にADSelfService Plusタブを有効にする"を選択します。ADSelfService PlusタブはServiceDesk PlusとADSelfService Plusが連携している状態でログインすると表示されます。

 

設定が保存されると、ServiceDesk PlusとADSelfService Plus間での接続設定が完了します。 一度完了すると、リンクを利用してADSelfService Plusサーバーに遷移できます。


その他ManageEngine 製品との連携（HTTPS接続での起動時）

  1. .zip file を以下のリンクからダウンロードし、"ManageEngine\ServiceDesk"に展開します。

    2. For Linux: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1af3b3o2010mg10kbj961mdt18sq1/lincertgeneration.zip

    For Windows: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1af360niepdjr7j1flk1o323fa1/wincertgeneration.zip

  2. コマンドプロンプトに接続し、"ManageEngine\ServiceDesk"に進み、以下のようにバッチを実行します。

    3. For Linux:
    C:>ManageEngine\ServiceDesk>gencert.sh servername:portnumber

    For Windows:
    C:>ManageEngine\ServiceDesk>gencert.bat servername:portnumber

  3. コマンドを実行している際に、PKIX例外が発生したら、値を入力してください。値を入力すると、"ManageEngine\ServiceDesk"配下にjssecacertsという名称のファイルが生成されます。.

  4. jssecacertsファイルを"ManageEngine\ServiceDesk\jre\lib\security"フォルダー配下にコピーし、ServiceDesk Plusを再起動します。
