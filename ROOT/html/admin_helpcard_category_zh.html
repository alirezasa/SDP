您可以将不同类型的请求划分到不同的种类中。  (例如: 所有关于安装软件的请求都可以划分到“软件安装”一类中)。 它支持分类 -〉子分类 -〉条目三层结构。可以根据具体情况逐步地进行具体的划分。基于不同的分类就可以配置系统自动将案例分派到适当的技术人员。例如，所有与因特网连接相关的问题就可以自动指派给网络工程师。

创建新分类
 
点击新建分类按钮，将显示新建分类表单。
在给定的文本字段中指定分类名称。比如：打印机，此为强制性字段。
在描述字段中指定新建分类的相关信息。
选择指派到技术员组合框指定关联到新建分类的技术员，所有与该分类有关的问题将被分配给所选的技术人员。
点击保存按钮以保存信息。您可以在分类列表视图中查看该分类。
点击保存并添加子分类按钮以保存信息并添加子分类。
 
新建子分类
 
点击新建子分类按钮，将显示新建子分类表单。
在给定文本字段中指定子分类名称。比如：纸，此为强制性字段。
在描述字段中指定新建子分类的相关信息。
从组合框中选择分类。例如：打印机，此为强制性字段。    
 
新建条目
 
点击新建条目按钮，将显示新建条目表单。
在给定文本字段中指定条目名称，比如：卡纸，此为强制性字段。
在描述字段中指定新建条目的相关信息。
在组合框中选择子分类。比如：纸，此为强制性字段。
点击保存按钮以保存信息。
 

快速添加分类/子分类/条目(CSI)

'快速添加CSI'选项允许您立即添加分类、子分类和条目，而不是使用‘新建’选项一个一个进行添加。事实证明，当需要添加大量的分类或子分类或条目时，此选项可以减少时间消耗。

  • 在弹出窗口的文本框中，输入的文本如果没有使用tab键，将被视为分类。
  • 用单个tab键输入的文本内容将被视为子分类，而用两个tab键输入的文本则被视为条目。
  • 点击 "保存"将展示 "结果"以及成功添加的记录数量。

关于快速添加CSI的提示

1. “全部展开”和 “全部收起”可以让您看到所添加的CSI的扩展和收起后的情况。
2. 为分类、子分类和条目提供一个特殊的名称，如果为两个或多个分类提供了相同的名称，预览将只显示相应的分类。
3. 一个分类的名称可以在子分类和条目中使用，但同一名称不能再次作为分类名称使用。如果该分类已存在，那么它将不会被添加。此条件同样适用于子分类和条目。
4. 点击“清除”将重置文本框。


注： 您也可以在分类列表视图中点击相应的分类来添加新的子分类&条目。
