Scheduled Request Data Deletion

Data deletion lets you delete any old request data that is unnecessarily taking up space in your system memory. Enable this option to delete any active or archived requests that match your set criteria.

  1. For example, you can set a criteria to delete all completed requests created before 1 year. To do that select the following values under rules section; Request status is Any completed status, AND Created Date, is before 1 year.

  2. If you want certain requests to be left out from the scheduled deletion, you can do so by enabling the Allow exception for deletion option and setting the criteria for that.

  3. For example, you can exempt requests from the administration department from being deleted in the scheduled data deletion. To do that, select the following values under the rules section; Column Name - Department, Criteria - is, Value - Administration. You can add multiple rules by clicking on the plus icon. Once you have set the criteria, set the schedule for data deletion by specifying the hours and minutes and Save.

 

Scheduled Request Data Archiving

Data Archiving is the process of backing up any requests regularly, improves application performance significantly.Enable this option to archive requests that matches your set criteria.

  1. For example, you can set criteria to archive all Resolved/Closed requests that were created before 1 year. To do that select the following values under the rules section; Request status is Resolved/Closed, AND Created Date, is before 1 year. Click save after you have set the criteria.

  2. If you want to leave out some requests that match your set criteria from being archived, you can do so by selecting Allow exception for archiving and set criteria for exempting requests.

  3. Once you have configured criteria and exception, schedule request archival time by specifying the hours and minutes.

 

Note:

  1. Archived requests cannot be modified but can be deleted.

  2. Archived requests will not be listed under the current active requests list.

  3. To view, search, or generate reports of archived requests, go to the Archived Request filter in the Request module.

  4. Any reply to archived requests will be added as a new request.

  5. If both data archive and data deletion is enabled, then the data deletion will be executed first.

  6. The schedule for data deletion and archiving is the same. If you change the schedule for archiving, then it will applied for the deletion too.
