Les valeurs d'achat par défaut vous permet de définir des valeurs par défaut pour le formulaire Nouveau bon de commande.

  • Devise par défaut : Devise par défaut affichée sur tous les bons de commande (BC) générés et à tout emplacement où la devise sera utilisée. Par ex. : USD, $.
  • Taux de taxe par défaut (%) : Taux de taxe par défaut affiché dans le formulaire Bon de commande. Vous pouvez toujours utiliser un taux de taxe différent pour un bon de commande en particulier. Il vous suffit de saisir ce taux de taxe lors de la création du bon de commande.
  • Autorité signataire : Nom de l'autorité de signature affiché dans le formulaire Bon de commande.
  • Taxe d’expédition : Cochez la case si une taxe supplémentaire est impliquée dans l'envoi.
  • Adresse de livraison : Sélectionnez le site par défaut auquel les éléments du bon de commande doivent être envoyés.
  • Adresse de facturation : Sélectionnez le site par défaut pour la facturation des éléments du bon de commande.
  • Centre de coût : Code du centre de coûts par défaut à afficher.
  • Approbateur(s) : Approbateur(s) par défaut du bon de commande. Il peut s'agir d'utilisateurs ou techniciens de votre organisation possédant le rôle d'approuver les bons de commande.
  • Propriétaire de bon de commande agissant comme approbateur : Cochez cette case si vous souhaitez que les propriétaires des bons de commande approuvent leurs propres bons de commande.
  • Multi approbation : Si cette case est cochée, l'état du bon de commande ne sera « Approuvé » qu'une fois ce bon de commande approuvé par tous les approbateurs. L'état du bon de commande sera « Rejeté » si l'un des approbateurs le rejette.
  • Conditions et remarques : Conditions et remarques lors de l'achat.
  • N° de début du BC : Personnalisation du numéro du bon de commande.

Champs obligatoires pour la fermeture d'un bon de commande

Les champs répertoriés dans cette sectoin sont les champs supplémentaires du bon de commande configurés dans l'application. Cochez la case des champs à remplir avant la clôture du bon de commande. Pour enregistrer les informations saisies, cliquez sur Enregistrer.
