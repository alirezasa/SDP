集成OpManager

将ServiceDesk Plus与ManageEngine OpManager集成，可以帮助您更好地管理和监视您的网络。OpManager是完全基于Web的网络管理解决方案，可管理各类网络设备，它提供自动化工作流、智能化告警引擎、可配置发现规则、可扩展设备模板等，可帮助IT团队不间断地监视其基础架构设施。两个产品的集成，可自动将监视系统产生的告警转换为帮助台的工单，从而加快问题的排除与解决。如果您已经安装了这两款产品，只需要在此指定运行OpManager的计算机名称和Web端口，即可完成集成。

需要提供的信息:

服务器名称: 输入安装了 OpManager的服务器的名称或IP地址。

服务器端口: 输入访问OpManager的端口号。

协议设置: 选择访问OpManager的协议，如：http 或 https。

 

注意: 要显示桌面管理和移动设备管理（MDM） 下拉菜单，需要分别选中“启用桌面管理菜单”和“启用移动设备管理菜单”的选项。如果不想显示这些菜单，可以反选上述选项，然后保存。

 

点击 保存按钮，保存设置的信息，ServiceDesk Plus将尝试与OpManager服务器进行链接，一旦连接建立，使用跳转链接，就可以切换到OpManager的页面。


集成(运行在HTTPS模式)ME产品

  1. 从以下链接，下载.zip文件，并将下载的文件解压到"ManageEngine\ServiceDesk":

    2. 对于Linux: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1af3b3o2010mg10kbj961mdt18sq1/lincertgeneration.zip

    对于Windows: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1af360niepdjr7j1flk1o323fa1/wincertgeneration.zip

  2. 打开命令行窗口，导航到"ManageEngine\ServiceDesk"目录，以以下格式执行命令：

    3. 对于Linux:
    \ManageEngine\ServiceDesk>gencert.sh servername:portnumber

    For Windows:
    C:>ManageEngine\ServiceDesk>gencert.bat servername:portnumber

  3. 执行命令后，将会提示一个PKIX例外，然后要求您输入一个值，输入1，将在"ManageEngine\ServiceDesk"目录下生成文件名为 jssecacerts的文件。

  4. 将文件jssecacerts复制到"ManageEngine\ServiceDesk\jre\lib\security" 目录下，然后重启ServiceDesk Plus 。
