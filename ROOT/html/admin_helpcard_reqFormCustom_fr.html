L’Outil de personnalisation du formulaire de requête vous permet de créer un Formulaire de requête sur mesure afin de vous assurer que les utilisateurs soumettent toutes les informations requises avec leur requête.

Le personnel du service d’assistance peut concevoir un Formulaire de requête personnalisé. Le formulaire de requête peut comporter :
  • Certains champs obligatoires.
  • Certains champs visibles par l’utilisateur.
  • Des champs modifiables par l’utilisateur.
Toutes les informations indispensables aux techniciens pour résoudre la requête sont définies comme obligatoires. Les champs uniquement visibles ou modifiables permettent au service d'assistance de créer des formulaires de requête simples et efficaces.
 
Exemple : Lorsque vous personnalisez le formulaire de requête, vous pouvez définir :
  • Le titre du champ de requête comme obligatoire.
  • Le niveau et le mode de requête peuvent être masqués à l’utilisateur. La case Demandeur peut visualiser vous permet de masquer les champs aux demandeurs.
  • Les champs Station de travail peuvent être modifiés et affichés, dans la mesure où les utilisateurs peuvent signaler des problèmes sur tout ordinateur dont ils sont propriétaires.
Cliquez sur Enregistrer, pour enregistrer les paramètres et sur Enregistrer et prévisualiser, pour enregistrer et afficher l’aperçu du formulaire Nouvelle requête de l’identification du demandeur.
