Page Scripts allows you to customize the application page-wise as per your requirement. You can modify the UI elements as well as the functionalities of a page in the application using page scripts for users. For example, you can hide certain buttons in the requests list view or request details page for users. You can also choose to add new widgets, videos, web pages, and forms for requesters or technicians across pages in modules. 


To execute a page script, you need to first define a rule and configure a condition.

  • Create a new rule by adding a rule name and selecting for whom the rule should be applied ; for e.g, Requesters/Technicians or All Users.  
  • Select where the rule should be applied; for e.g, Request List View/ Request Details Page/ All Pages (Pages in all modules). 
  • Configure a condition under which the page script must be executed. You can add multiple conditions. 
  • Once you have configured the rule, then you can write a custom script to execute the customization. 
  • Some basic customization script is given by default.  You can use them if required. 

You can also write your own script and execute them.
