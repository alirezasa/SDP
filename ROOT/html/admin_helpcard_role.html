Each technician accessing the help desk tool will have a set of permissions and tasks to execute in the application. These permissions are termed as Roles in the application. Multiple roles can be created and assigned to each technician based on the requirement. The list of technicians assigned to a particular role can be viewed from the Role List View page by clicking the 'View technicians configured with this role icon. The roles for requesters is predefined and hence cannot be configured. To add a new role, click the Add New Role link on the right hand side corner of the Role List view.

 

Add New Role

  1. Specify the Role Name to uniquely identify the role you are defining in the given text field. It is a mandatory field.

  2. Give a brief description about the role in the Description text field.

  3. Set the Permissions by enabling the check box of the privileges of various modules.

  4. The permissions for Request, Purchase and Asset modules are further categorized and defined under Advanced Permission.
    Example:     If you do not wish to provide certain specific permissions to the technicians say, a technician should not change the request status to resolved, then disable 'Resolving a Request' check box. Similarly, if a technician can add a product/vendor while creating a purchase order then enable 'Add New Product' and 'Add New Vendor' permission.
    The Scan Now option in the workstation details page will made available to the technician when Scan Now check box is enabled.

NOTE:

i. Enabling Complete Access check box for a module say, Request under permissions will automatically enable all the request operations in advanced permissions.

ii. If an operation in advanced permissions is disabled say, Adding Requester is disabled in the request module then, the Complete Access is automatically disabled.

iii. Even if all advanced operations are disabled under a main category say Edit, the user is still permitted to have other Edit permissions such as changing the mode, level and so on.

iv. View operation is automatically enabled if any of the advanced operation is selected for a given module.

  1. Enable any of the following radio button to allow the technicians to view,

    All: The technicians can view the requests, problems, changes and assets for all the sites configured in the application.

    All in associated sites: The technician can view the requests, problems, changes and assets for his/her associated sites alone.

    All in group & assigned to Technician [Requests, Problems and Changes]: The technician can view only the requests, problems and changes assigned to them or their associated group.

    Assigned to Technician [Requests, Problems and Changes]: The technician can view only the requests, problems and changes assigned to them alone.

NOTE: Please note that the technician has permission to view Requests, Problems, Changes and Assets only if the View permission for these modules is enabled under Permissions.

  1. Allow technician to approve solutions - Enable technician to approve solutions.

  2. Allow technician to share request - Enable technician to share requests.

  3. Allow task technician to access request - Enable task technician to access requests.

  4. Allow technicians in task group to access request - Enable technicians in task group to access requests.

  5. Allow technician to view resource management - Enable technicians to view resource management data.

  6. Click Save. The role gets listed in the list view. Click Save and Add New button to save the role and add another role.
