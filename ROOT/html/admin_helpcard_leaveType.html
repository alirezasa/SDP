Leave Types is where you can configure the most common reasons for applying leave. Configuring leave types is essential as it enables the technician to quickly apply for leave in Scheduler. Each leave type is distinctly identified with the help of a color code, which facilitates the administrator to comprehend the reason for applying leave by the technician.

Click New Leave Type link on the right hand side of the leave type list view page.  

 

New Leave Type

  1. Enter the Name of the leave type in the given text field. For example, Sick Leave, On Duty, Optional and so on. The specified name should be unique and is a mandatory field.
  2. Select a Color to denote the leave type in the Technician Availability Chart.
  3. Specify brief description about the leave type in the Description text field.
  4. Click Save. The leave type gets listed in the list view page.
  5. Click Save and Add New to save and add another leave type.
