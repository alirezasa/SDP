Microsoft SCCM(System Center Configuration Manager)에서 스캔한 자산 데이터를 Asset Explorer로 가져오는 단방향성의 통합을 이용합니다.
Asset Explorer 애플리케이션에서 자산 데이터를 즉시 업데이트하면서, 재고 관리를 위해 SCCM을 계속 사용할 수 있습니다.


작동 방식을 알아보려면 이동하세요. 새 SCCM 구성을 추가하려면:

  1. 새로 만들기를 클릭하고 표시된 필드의 세부정보를 입력합니다.
  2. SCCM 데이터베이스 서버의 호스트 이름, 데이터베이스 이름 및 포트입니다.
  3. 해당 자산을 사이트에 연결할 수 있습니다. 이는 한 사이트 SCCM의 자산을 가져올 때 특히 유용합니다.
  4. 자격 증명 라이브러리에 구성되어 있는 SCCM 자격 증명을 입력합니다.
  5. 데이터 가져오기를 시작할 시기와 프로세스를 반복해야 하는 빈도를 지정합니다.
  6. 연결 테스트와 저장을 클릭하여 SCCM 데이터베이스 서버가 연결되었는지 확인하고 저장합니다.


데이터 가져오기 성공 또는 실패는 목록 보기 페이지에서 상태로 표시됩니다.
SCCM 데이터베이스 서버의 잘못된 자격 증명 또는 해당 서버에 대한 연결이 성공하지 못하여 때문에 실패할 수 있습니다.

목록 보기 페이지에서 바로 SCCM을 수정/연결 시험/삭제할 수 있습니다.
