Mobile Device Manager Plus와 통합

통합 단계적 절차 : Help Document

ServiceDesk Plus를 Mobile Device Manager Plus와 통합하여 ServiceDesk Plus 콘솔에서 직접 모바일 장치를 관리하고 보호하십시오. Mobile Device Manager Plus는 앱 배포, 장치 관리 및 제한, 이메일 관리, 자산 관리와 같은 다양한 모바일 장치 관리 작업을 자동화합니다. 또한 앱, 장치 및 타사 클라우드 서비스 간의 데이터 전송을 제한하여 모바일 장치에 추가 보안을 제공합니다. 사용자가 장치를 분실한 경우, Admin 관리자가 위치를 찾고 필요한 경우 장치의 데이터를 지우는 데 도움이 됩니다. 두 제품을 모두 설치했다면 Mobile Device Manager Plus 서버가 설치된 컴퓨터의 세부 정보와 포트 번호를 입력하기만 하면 됩니다.

입력할 상세 정보:

서버 이름:MDM server 서버가 설치된 서버의 상세 정보를 입력하십시오.

Server Port: MDM server의포트 번호를 입력하십시오.

포르토콜 설정: 프로토콜 설정을 선택하십시오. http 혹은 https 중에서 하나를 선택하십시오.

 

참고 사항: MDM 드롭다운 메뉴를 표시하려면 MDM(모바일 기기 관리) 메뉴를 활성화합니다. 드롭박스에서 MDM 옵션을 제거하려면 옵션을 선택 해제하세요. 저장을 클릭합니다. SDP 서버는 설정이 성공적으로 저장되면 MDM 서버와 연결을 설정합니다. 그런 다음 MDM 서버에서 구성 세부 정보를 가져옵니다.

 

저장을 클릭합니다. 설정이 성공적으로 저장되고 ServiceDesk Plus가 MDM 서버와의 연결을 시도합니다.


다른 ME 제품들과 통합 (HTTPS 모드에서 운용 중인)

  1. .zip 파일을 아래 링크에서 다운로드하고, "ManageEngine\ServiceDesk"에서 압축을 풉니다:

    2. Linux 용: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1cb6g423n1gp9135o97nfchub1/lincertgeneration.zip

    Windows 용: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1cb6g2tdh126s6hmhpvjja2si1/windowscertgeneration.zip

  2. 명령 프롬프트에 연결합니다. "ManageEngine\ServiceDesk"로 이동하여 다음 형식으로 배치 파일을 실행합니다.

    3. Linux 용:
    C:>ManageEngine\ServiceDesk>gencert.sh servername:portnumber

    Windows 용:
    C:>ManageEngine\ServiceDesk>gencert.bat servername:portnumber

  3. 명령을 실행하면 PKIX 예외가 발생한 다음 값을 입력하라는 메시지가 표시됩니다. "ManageEngine\ServiceDesk" 아래에 jssecacerts라는 파일을 생성하는 값 1을 입력하십시오.

  4. "ManageEngine\ServiceDesk\jre\lib\security" 폴더 아래에 jssecacerts 파일을 복사한 다음 ServiceDesk Plus 애플리케이션을 다시 시작합니다.
