Możesz ustawić autentykację logowania zgłaszających z Active Directory (AD).

Nota: Przed włączeniem autentykacji AD upewnij się, że zaimportowałeś użytkowników z domeny. Tylko jeśli konto użytkownika jest dostępne w aplikacji ServiceDesk, będzie można logować się do aplikacji używając poświadczeń Active Directory.

Konfiguracja Active Directory

Domyślnie, autentykacja AD jest wyłączone. Zaznacz opcję, aby włączyć autentykację AD.

Autentykacja przechodnia "Pass-through" [Single Sign-On]
 
Włączając autentykacje przechodnią, SerciceDesk Plus automatycznie zaloguje Cię, używając twojej nazwy użytkownika i hasła z systemu windows. Dlatego nie będzie potrzeby logowania się za każdym razem wchodząc do ServiceDesk Plus.
 
Nota:
  • Wszyscy użytkownicy z active directory powinni być zaimportowani, aby włączyć single sign-on.
  • Włączona domena powinna być zaufana. 
  • Single sign-on działa tylko z przeglądarką Windows Internet Explorer.
Włączanie autentykacji przechodniej "Pass-through"
 
Po zaimportowaniu wszystkich użytkowników z active directory możesz włączyć single sign-on.
Zaznacz pole Check box aby aktywować opcję single sign-on. Domyślnie będzie można logować się tylko jako zgłaszający. Administrator powinien wybrać serwisantów z listy zgłaszających i nadać im odpowiednie role.

Importowanie zgłaszających z Active Directory.

Możesz zaimportować zgłaszających z Active Directory. Aby to zrobić,

Kliknij link Importuj użytkowników z katalogu Active Directory otworzy to stronę importu z Active Directory.
Wybierz Nazwę domeny listy rozwijanej. To pole jest wymagane.
Wprowadź nazwę Kontrolera Domeny Np: winmaster. To pole jest wymagane. Jeśli wprowadziłeś nazwę kontrolera domeny, nazwę użytkownika i hasło podczas skanowania domeny, dane te zostaną pobrane w pola automatycznie. W przeciwnym wypadku,
Wprowadź Nazwę logowania i hasło. Oba pola są wymagane.
Masz równiez możliwość wyboru pól do importu z domeny. Pola niezaznaczone nie zostaną zaimportowane.
Kliknij przycisk Importuj!. Otworzy to stronę kreatora importu, na której zostaną wyświetlone jednostki organizacyjne (OUs) dostępne w domenie.
Zaznacz właściwe OU, aby zaimportować użytkowników, zaznaczając przy OU pole check box.
Kliknij przycisk Rozpocznij import , aby rozpocząć import zgłaszających. Po zakończeniu importu, otrzymasz raport o pomyślnie i błędnie zaimportowanych kontach.
Kliknij przycisk. Zamknij


Nota: Podczas importu użytkowników z Active Dierctory, istniejące konta zgłaszających zostaną nadpisane.

Harmonogram importu z AD

Masz możliwość ustawienia harmonogramu importu z Active Directory w określonym odstępie dni.

Zaznacz pole Wykonaj synchronizację katalogu AD. Określ liczbę dni w polu tekstowym. Szczegóły zgłaszających będą automatycznie importowane raz na określoną ilość dni.

Kliknij przycisk Zapisz harmonogram, aby zapisać ustawienia automatycznego importowania zgłaszających.
