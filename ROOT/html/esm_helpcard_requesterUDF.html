Each time a new user is added, you may have to collect all the necessary information. You can do that by using user additional fields.
The following types of additional fields are available for you to choose from:

Single Line: For specific information like the user's nickname or employee code.
Multi Line: For descriptive information like address for communication or any special requirements for persons with disabilities.
Pick List: To provide options to choose from. Could be for the type of assets necessary.
Numeric: For adding any numeral-related information such as insurance numbers.
Date/Time: To add a specific date, such as date of joining.

To add a new user additional field, click Add Field, choose the field type, provide a Field Name and a description, and click Save.
