Integration Key

Integration Key is a token based authentication which can be used for performing secure REST API calls.

New Integration Key

  • Click +New to generate a new integration Key.
  • Enter a Unique Name for the Key.
  • Associate necessary roles to the integration key.
  • Choose an expiry date for the Integration Key by clicking on Expires On and select a date.
  • You can also select Never expire to set an indefinite validity for the key.
  • Enter a description for the key and click Generate to create a new key.

Reassign Integration Key

You can reassign the integration key to a different user. For example, when a user exits the organization, you can reassign the key to another user. Select an integration key from the list view and click on Reassign and select technicians (SDAdmins only).

List View

Generated Keys will be listed in the list view. From there you can reassign them to users or edit or delete them.

Notification Settings

Configure notifications to alert technicians about the expiry of integration keys.

  • Click Notification Settings on the top-right of the page.
  • Enable expiry notification for integration keys.
  • Specify the number of days to send notifications before the key expires.
  • Select technicians to be notified.
  • Click Save.
URL rate limit violations:

You can view the list of URLs that have violated access limits. Note that these URLs are accessed by using an integration key. You can also modify the violation access limits of these URLs.
Click URL rate limit violations to display the URLs.
Select the required URL and click Edit in the displayed window.
Add the rate limit, select the integration keys applicable, and click Update.
