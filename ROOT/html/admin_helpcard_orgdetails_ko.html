여기에 귀하의 조직에 대한 완전한 정보를 제공하십시오.

이름:여기에 조직의 전체 이름을 입력합니다. 이것은 구매 주문을 생성하는 헤더로 사용됩니다.
설명: 조직이 하는 일에 대한 간략한 정보 또는 관련성이 있다고 생각하는 기타 세부정보를 제공하십시오.
이메일 ID: 조직의 일반 연락처 이메일 ID를 입력합니다.

나머지 필드인 주소, 도시, 우편 번호, 주, 국가, 전화 번호, 팩스 번호 및 웹 URL에는 관련 정보를 지정합니다. 이러한 세부 정보는 다양한 모듈에서 사용됩니다.

회사 로고를 가져와서 조직 세부 정보가 사용되는 위치에서 사용할 수 있습니다.

  1. 회사 로고 필드 옆에 있는 이미지 가져오기 버튼을 클릭합니다.
  2. 찾아보기 버튼을 클릭하고 파일 선택기 창에서 이미지 파일을 선택한 다음 열기를 클릭합니다.
  3. 가져오기를 클릭합니다.
기본적으로 이 이미지 사용 확인란이 활성화되어 있습니다. 이 이미지를 사용하지 않으려면 확인란을 비활성화하십시오.

저장을 클릭하여 설정을 저장합니다.
