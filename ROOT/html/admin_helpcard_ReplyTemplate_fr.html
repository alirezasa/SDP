Les techniciens sont régulièrement amenés à envoyer des réponses similaires à de nombreuses demandes. Le modèle de réponse permet aux techniciens de créer des modèles de réponse répétitive destinés à optimiser et faciliter le travail. Pour ajouter un nouveau modèle de réponse, cliquez sur le bouton Ajouter nouveau sur la page de liste des modèles de réponse.

Nouveau modèle de réponse

Renseignez un Nom unique pour le modèle de réponse.

Saisissez le contenu du modèle dans le champ Description. Les champs Nom et Description sont obligatoires.

Vous pouvez désactiver le modèle en cochant Marquer ce modèle comme INACTIF. Le modèle inactif sera grisé et n'apparaîtra pas dans la liste déroulante des modèles de réponse lors de la réponse aux demandes.

Cliquez sur Enregistrer. Pour enregistrer et ajouter un autre modèle de réponse, cliquez sur Enregistrer et ajouter nouveau.
