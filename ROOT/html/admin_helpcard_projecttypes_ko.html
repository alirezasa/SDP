프로젝트 유형은 달성하려는 목표에 따라 프로젝트를 분류합니다.
예: 어떤 종류의 유지 관리를 위해 생성된 여러 프로젝트는 프로젝트 유형 ‘유지 보수’로 선언될 수 있습니다.

같은 방법으로 새 ​​프로젝트 유형을 만들어 이 섹션에서 다양한 프로젝트를 분류합니다.

프로젝트 유형 추가
프로젝트 유형 추가 양식에는 이름과 설명이라는 두 개의 필드가 있습니다.

이름: 프로젝트 유형을 식별하기 위해 고유한 이름을 지정합니다.
설명: 설명 필드에 프로젝트 유형에 대한 간단한 설명을 입력합니다.

비활성 확인란: 프로젝트 유형을 비활성화하려면 이 옵션을 선택합니다. 재활성화를 위해 선택을 취소하십시오.
색상: 색상 팔레트를 사용하여 프로젝트 유형을 나타내는 색상을 선택하거나 텍스트 상자에 색상 코드를 지정합니다.

저장 버튼을 클릭하여 상태를 저장하고 목록 보기로 돌아갑니다.
저장하고 새로 추가 버튼을 클릭하여 상태를 저장하고 다른 상태를 추가합니다.
