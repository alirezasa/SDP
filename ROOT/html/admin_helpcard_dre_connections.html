CONNECTIONS

Connections are an authentication mechanism used to integrate ServiceDesk Plus with external applications. You can use connections to integrate with any third-party application and access the data stored there.

You can set up connections after registering the third party application as a service in ServiceDesk Plus.

Connections are equipped with three modes of authentication - API key, basic authentication, and OAuth 2.0.

Create Service

The third party application details are stored as custom services. Under Connections pane, select Custom Services and click Create Service.
  • Provide a display name for the service.
  • Provide a unique link name to identify the custom service. The link name must contain only alphanumeric characters in snake_case.
  • Choose an authentication type based on the third-party service's API documentation:
    • API Key - Specify the parameter type, key, and display name to connect with the service.
    • Basic Authentication - The service is authenticated using the username and password details.
    • OAuth2 - Specify the identity provider details. Ensure the callback URL is: {sdp_base_URL}/integration/oauth/callback and the domain name is the alias URL configured under Advanced Portal Settings.
  • Click Create Service.


Create Connection

You can authenticate the service integrated via connections. Under Connections pane, select My Connections and click Create Connection.

Pick the service for which the connection must be created. You can also create a new service.
  • Provide a display name for the connection.
  • Provide a unique link name to identify the connection. The link name must contain only alphanumeric characters in snake_case.
  • For services authenticated via OAuth2, choose the relevant permissions.
  • Click Create and Connect.
  • Provide the relevant authentication details.
    •

    List View Operations
    • In the list view, hover over a connection or service to edit/delete/revoke it.
    • Use the Filter icon to view only connected or revoked services.


    Note:
    • You can also edit/delete a connection or service by clicking the Ellipsis icon on the details page. Similarly, you can also revoke a connection from the connection details page.
    • Services with existing connections cannot be deleted or edited, except for Service Name field and Separator field (if OAuth2 is configured).
    • You can edit or delete any connection created by you. SDAdmins can connect (authenticate) any connections available.
    • Connections can be revoked only by authenticated users or by the user who created the connection.
