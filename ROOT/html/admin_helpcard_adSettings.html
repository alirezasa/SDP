You can configure to authenticate the requester login with the active directory (AD).

Note: Please ensure that before you start configuring the AD Authentication, you have already imported the requesters. Only if a user account is available in ServiceDesk application, it will authenticate the password for that user account from the active directory.

Configuring the Active Directory
The AD authentication is disabled by default. Click the button Enable, to enable AD authentication.

You can also import requesters from the Active Directory of your choice from here. Click Import Requesters from Active Directory link. This opens the Import From Active Directory dialog.

From the Domain list box, select the domain from which you wish to import the requesters. If you have already entered the Domain Controller name, user name, and password in the Domain Scan list, then the same will be populated. Click Import Now !.

The import wizard displays the various Organizational Units (OUs) available in that domain. Choose the specific OU from which you wish to import users by selecting the check box beside it.

Click Start Importing.

The requesters are imported and at the end of the import, a report on how many successfully imported and how many failed is displayed on the screen. Click Close Window. If you already have requesters added, then the already existing names will be overwritten while importing from AD.
