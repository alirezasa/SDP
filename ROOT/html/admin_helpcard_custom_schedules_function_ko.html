사용자 지정 액션은 사용자가 AssetExplorer 및 기타 외부 응용 프로그램에서 데이터를 조작할 수 있도록 하는 실행 가능한 사용자 지정 일정 기능입니다. 쿼리 보고서에서 데이터를 가져오고 가져온 데이터를 기반으로 액션을 실행하는 스크립트를 작성할 수 있습니다. 사용자 지정 일정 기능은 Zoho의 적절한 스크립팅 언어인 Deluge를 기반으로 합니다.

새로 만들기를 클릭하여 사용자 지정 액션을 만듭니다. 사용자 지정 액션을 만든 후 이를 사용하여 사용자 지정 일정을 만들 수 있습니다. 사용자 지정 액션이 활성화된 사용자 지정 일정은 사용자 지정 액션 목록 보기에 표시됩니다.

키워드를 사용하여 사용자 정의 액션을 검색할 수 있습니다. 검색창 옆에 있는 드롭다운 메뉴를 사용하여 특정 기능에 사용되는 사용자 지정 액션을 필터링하십시오.

액션 드롭다운을 사용하면 사용자 지정 액션을 일괄 삭제, 비활성화 및 활성화할 수 있습니다. 개별 사용자 지정 액션을 수정하려면 사용자 지정 액션 옆에 있는 햄버거 아이콘을 사용합니다.
