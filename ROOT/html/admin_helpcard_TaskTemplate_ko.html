작업 템플릿은 반복되는 작업에 대해 미리 정의된 템플릿을 만드는 데 도움이 됩니다. 요청, 문제, 변경 및 프로젝트에 작업을 추가하면서 적용할 수 있습니다.

새 작업 템플릿 추가

아래 포인터를 참조로 사용하십시오.

모듈 - 일반 작업 템플릿은 모든 모듈과 연계될 수 있습니다. 그러나 요청/프로젝트 작업 템플릿은 해당 모듈에만 연계될 수 있습니다.

템플릿 이름 - 작업의 고유한 이름을 입력합니다.

제목 - 적절한 제목을 입력합니다.

상태 - 드롭다운 메뉴에서 상태를 선택합니다.

설명 - 템플릿의 목적을 간략하게 설명합니다.

예상 시간 - 작업을 완료하는 데 필요한 예상 시간을 언급합니다.< /p>

우선순위 - 작업의 우선순위를 표시합니다.

추가 비용 - 작업에 발생할 수 있는 추가 비용을 언급합니다.

그룹 - 작업을 처리할 그룹을 선택합니다.

담당자 - 작업을 수행할 기술자를 선택합니다.

표시/할당 - 언제 기술자에게 작업을 할당할지 결정합니다. 즉시 할당하거나 작업을 표시하고 나중에 수동으로 할당할 수 있습니다. 작업 알림은 작업이 할당된 후에만 기술자에게 전송됩니다.

작업 유형 - 작업 유형을 선택합니다.

설명 - 기술자에게 표시될 관련 설명을 입력합니다. 예: 특별 지침, 예외 등

저장을 클릭합니다. 추가 저장 옵션을 보려면 저장 버튼 옆에 있는 화살표를 클릭하십시오.

요청서 템플릿과 작업 템플릿 연계

추가 저장 옵션에서 요청서 템플릿을 저장하고 연계할 수 있습니다. 요청서 속성 연계 기능을 사용하면 작업에 할당된 기술자가 요청서의 특정 필드를 볼 수 있습니다. 자세한 내용은 여기를 클릭하십시오.
