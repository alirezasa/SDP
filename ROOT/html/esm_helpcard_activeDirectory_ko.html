Active Directory 통합을 통해 Active Directory 서버에서 ServiceDesk Plus로 사용자 정보를 가져올 수 있습니다.

모든 사용자 세부 정보가 있으면 인증 세부 정보를 구성하고, 가져오기를 예약하고, 삭제된 사용자의 세부 정보를 동기화할 수 있습니다.

로컬 인증 비밀번호 설정

AD를 통해 가져온 사용자의 기본 로컬 인증 암호를 설정합니다. 사용자가 보안 설정에서 처음 로그인한 후 이 비밀번호를 업데이트하도록 강제할 수 있습니다. .

각 사용자에 대해 임의의 암호가 생성되도록 하거나 모든 사용자에 대해 미리 정의된 암호를 설정할 수 있습니다. 사전 정의된 비밀번호가 비밀번호 정책의 모든 요구 사항을 충족하는지 확인하십시오.

Active Directory에서 사용자 가져오기

ServiceDesk Plus는 네트워크의 모든 Windows 도메인을 자동으로 가져와 Active Directory에서 즉시 사용자를 가져올 수 있습니다.

사용자를 가져오는 동안 사용자 가져오기를 클릭하여 AD에서 세부 정보와 추가 정보를 가져올 수도 있습니다.

  1. 도메인 이름 드롭다운에서 사용자를 가져올 도메인을 선택합니다. Windows 도메인 스캔에서 도메인에 대한 도메인 컨트롤러 및 로그인 자격 증명을 이미 제공한 경우, 해당 도메인을 선택하면 도메인 컨트롤러 및 로그인 자격 증명이 자동으로 채워집니다.
  2. 도메인 컨트롤러 세부 정보를 지정합니다.
  3. 로그인 자격 증명
    4. 을 입력합니다.
  4. 포트 636을 통해 ServiceDesk Plus와 Active Directory 간의 보안 통신을 활성화하려면 LDAP SSL 필드를 켜십시오. 이 필드를 활성화하기 전에 Active Directory가 SSL을 지원하는지 확인하십시오.
  5. Active Directory에서 가져올 사용자 필드를 선택하고 선택한 필드 옆에 Active Directory에 구성된 필드 이름을 지정하여 매핑합니다.
  6. ServiceDesk Plus에서 사용자 추가 필드를 구성한 경우 UDF 필드를 선택할 수 있습니다. 선택한 필드 옆에 Active Directory에 구성된 필드 이름을 지정합니다. 예를 들어 다음 표를 참조할 수 있습니다.

    7. 필드 이름

    필드 유형

    Active Directory에서 Distinguished Name (DN)

    설명

    Email 주소

    텍스트

    메일

    사용자 이메일 주소

    Country Code

    숫자

    국가 코드

    사용자의 국가 코드

  7. 사용자/부서와 연결된 사이트가 Active Directory에서 변경되면 사용자/부서에 속한 자산도 새 사이트로 이동해야 합니다. 가져올 때마다 이 정보를 업데이트하려면 연계된 자산 이동을 선택하십시오.
  8. 다음을 클릭합니다.
  9. 도메인의 OU(조직 구성 단위)가 표시됩니다. 가져올 OU를 선택하십시오.
  10. 지금 가져오기를 클릭합니다. 나중에 가져오려면 일정에 따라 저장 및 가져오기를 선택하십시오.

지금 가져오기 및 일정에 따라 저장 및 가져오기의 결과는 ESM이 아닌 설정의 경우 SDAdmins에게, ESM 설정의 경우 SDOrgAdmins에게 종 모양 알림을 통해 전송됩니다. 예약된 가져오기의 경우, 가져오는 사용자 정보는 가져오기 일정에서 구성된 가져오기 일정 유형에 따라 다릅니다.

가져온 사용자는 ESM 디렉토리 >> 사용자 아래의 사용자 목록 보기에 나열됩니다. 사용자 목록 보기에서 가져온 사용자에 대해 추가 액션을 수행할 수 있습니다.

NOTE:

1. 가져올 때마다 기존 사용자 데이터를 덮어씁니다.

2. 숫자 추가 필드는 최대 19자리까지 사용가능합니다. 숫자 값이 19자리를 초과하는 경우 텍스트 필드에 값을 구성하십시오.

 

가져오기 일정 설정

정기적인 간격으로 Active Directory 가져오기를 예약합니다. SDP 애플리케이션에서 사용할 수 있는 모든 도메인의 사용자 및 사용자 세부 정보는 다음 두 가지 방법으로 ServiceDesk Plus에 동기화됩니다.

  • 전체 동기화 - 모든 일정 동안 모든 사용자 정보를 업데이트합니다.
  • 델타 동기화 - 30분마다 데이터의 차이를 업데이트합니다. 이렇게 하면 전체 동기화를 자주 업데이트할 필요가 줄어듭니다.

가져오기 일정을 구성하려면

  1. 일정 가져오기 필드 위로 마우스를 가져간 다음 편집을 클릭합니다.
  2. AD 가져오기를 한 번씩 예약 옵션을 활성화하고 가져오기 기간을 지정합니다. 일정을 시작할 날짜와 시간을 지정할 수도 있습니다.
  3. 저장을 클릭합니다.

도메인의 사용자 세부 정보는 시작 날짜 및 시간 이후에 지정된 일수에 따라 주기적으로 가져옵니다.

삭제된 사용자 동기화

Active Directory에서 ServiceDesk Plus로 삭제된 사용자의 세부 정보 동기화. 동기화가 완료되면 삭제된 사용자 목록이 표시됩니다. 목록에서 삭제된 사용자를 수동, 자동으로 제거하고 삭제된 사용자의 동기화를 예약할 수 있습니다.

  1. Active Directory에서 삭제된 사용자 동기화 확인란 위로 마우스를 가져간 다음 편집을 클릭합니다.
  2. 삭제된 사용자를 ServiceDesk Plus에서 자동으로 제거하거나 목록에서 사용자를 선택하여 수동으로 제거하도록 선택할 수 있습니다. 삭제된 기술자는 자동으로 제거되지 않습니다.
  3. 주기적 삭제 동기화 - 기간: 옵션을 활성화하고 동기화 기간을 지정합니다. 삭제된 사용자의 동기화를 시작할 날짜와 시간을 지정할 수도 있습니다.
  4. 저장을 클릭합니다.

수동 삭제가 활성화된 경우 삭제된 사용자 목록은 Active Directory 구성 페이지 상단에 메모로 표시됩니다. 메모의 링크를 사용하여 ServiceDesk Plus에서 삭제된 사용자를 제거하십시오.

참고:

  • 삭제된 사용자에 대해 동기화가 비활성화된 경우 수동 또는 예약 가져오기 중에 AD에서 삭제된 사용자 세부 정보를 ServiceDesk Plus로 가져오지 않습니다.
  • 삭제된 사용자가 수동 또는 예약된 가져오기로 구성된 경우 ESM이 아닌 설정의 경우 SDAdmins 및 ESM 설정의 경우 SDOrgAdmins에 종 모양 알림이 전송됩니다.

Active Directory 인증

Active Directory를 통해 ServiceDesk Plus에 로그인하는 사용자를 인증합니다. 두 가지 방법으로 AD 기반 인증을 구성할 수 있습니다.

로그인 중 Active Directory 자격 증명 입력: 사용자가 Active Directory 자격 증명을 사용하여 ServiceDesk Plus에 로그인할 수 있도록 허용합니다.

  1. Active Directory 인증 필드 위로 마우스를 가져간 다음 편집을 클릭합니다.
  2. Active Directory 인증 사용 확인란을 선택합니다.
  3. 저장을 클릭합니다.

로그인 화면에서 사용자는 Active Directory 로그인 자격 증명을 지정하고 도메인을 선택하여 ServiceDesk Plus에 로그인할 수 있습니다. 또한 도메인 드롭다운에서 로컬 인증을 선택하고 로컬 자격 증명을 지정하여 로그인하는 동안 AD 인증을 우회할 수 있습니다. AD 인증을 활성화한 후 적절한 자격 증명을 사용하면 로그인하는 동안 사용자를 동적으로 추가할 수 있습니다. AD 인증 및 동적 사용자 추가가 제대로 작동하려면 도메인 세부 정보 및 속성이 사용자 가져오기 팝업에서 한 번 이상 구성되어 있는지 확인하십시오.

ADFS를 ID 공급자(IdP)로 구성하여 SAML을 통해 싱글 사인온(SSO)을 활성화할 수 있습니다. 로그인 사용자가 IdP로 인증된 경우 SAML을 사용하면 AD 사용자가 로그인 자격 증명을 제공하지 않고도 ServiceDesk Plus에 즉시 액세스할 수 있습니다.

ADFS를 IdP로 구성하는 방법을 알아보려면 여기를 클릭하십시오.

참고:

  • Okta 또는 OneLogin과 같은 다른 ID 공급자를 구성하여 SSO를 활성화할 수도 있습니다.
  • SSO를 구성하기 전에 AD 사용자를 IdP로 가져와야 합니다.
