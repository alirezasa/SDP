Les types d’équipements spécifiques sont qualifiés de produits. Par exemple, Dell Lattitude D600 est un produit représentant les ordinateurs portables de Dell. Pour ajouter un nouveau produit, cliquez sur le lien Add New Product  (Ajouter Nouveau Produit) à l’angle droit du tableau Product List (Liste des Produits).

Ajouter Nouveau Produit
Le formulaire add product affiche cinq champs : nom de produit, fabricant, type de produit, référence de pièce et commentaires, le nom et le type de produit étant des champs obligatoires.

Dans Product Name (Nom de produit), vous devez indiquer le nom du produit qui identifiera en particulier chaque produit.

Si vous connaissez le nom du fabricant du produit, saisissez-le dans le champ Manufacturer (fabricant).

À partir de la liste déroulante énumérant les différents types de produits disponibles, sélectionnez le type de produit approprié sous lequel le produit peut être classifié.

Si le produit a une référence de pièce, saisissez la valeur dans le champ Part No.

Vous pouvez faire des Commentaires sur le produit dans l’espace réservé à cet effet.

Cliquez sur le bouton Enregistrer pour sauvegarder le Produit et continuer avec l’association fournisseur. Ce faisant, le produit sera ajouté ainsi qu’un onglet fournisseur. Cette opération sert à associer le produit à son fournisseur dans votre organisation. Vous pouvez associer plus d'un fournisseur au produit si vous l'achetez à plus d'un fournisseur. Pour associer des fournisseurs au produit, cliquer sur fournisseurs puis sur le bouton Associate Vendor.

Cliquez sur le bouton Save and add new  (Enregistrer et Ajouter) pour sauvegarder le produit et ajouter un autre produit. Dans ce cas, vous devez associer le fournisseur en allant au produit spécifique à partir de la vue liste, puis en cliquant sur l’onglet Vendor et Associate Vendor.

Associate Vendor
Le formulaire Associate Vendor possède six champs :  nom de produit, nom de fournisseur, prix, période de garantie, service après-vente, et commentaires. Parmi ces champs, le nom du fournisseur et le prix sont des champs obligatoires qui ne peuvent avoir une valeur nulle. Le nom de produit est un champ d’affichage non éditable.

À partir de la liste des fournisseurs disponibles dans la boîte, sélectionnez le fournisseur de votre choix pour le champ Vendor Name (nom de fournisseur).

Saisissez le prix évalué par le fournisseur pour le produit ci-dessus dans le champ Prix.

S’il existe une période de garantie (warranty period) donnée par le fournisseur, sélectionnez-la.

Si le produit a besoin d’entretien, choisissez maintanence vendor dans la liste déroulante.

Écrivez tous les commentaires utiles pour les informations sur le produit et le fournisseur ci-dessus.

Cliquez sur Enregistrer pour sauvegarder les informations saisies.
