요청된 서비스에 대한 추가 정보를 수집하기 위해 리소스 질문을 만들 수 있습니다. 리소스 질문은 리소스 섹션을 통해 여러 서비스 템플릿과 연결할 수 있습니다.

자원 질문 목록 보기에서 활성 자원 질문은 기본적으로 표시됩니다. 리소스 질문과 관련된 섹션을 보려면 관련 리소스 섹션을 클릭하십시오.

리소스 질문 추가

일반 텍스트, 확인란, 라디오 및 드롭다운의 네 가지 유형의 리소스 질문을 만들 수 있습니다.

사용자가 여러 줄의 텍스트와 함께 개별 답변을 입력할 수 있도록 하려면 일반 텍스트 리소스 질문을 만드십시오.

  1. 새 질문을 클릭합니다.

  2. 일반 텍스트를 선택합니다.

  3. 질문 이름을 입력하십시오.

  4. GDPR 규정에 따라 리소스 질문에 개인 식별 정보(PII)가 포함되어 있는지 여부를 표시할 수 있습니다. 이는 사용자 데이터를 보호하는 데 중요합니다.

  5. 저장을 클릭합니다.

또는 확인란/라디오/드롭다운 질문을 만들어 다양한 옵션을 제공하고 사용자가 제공된 선택 항목에서 선택하도록 할 수 있습니다.

  1. 새 질문을 클릭합니다.

  2. 확인란을 선택하면 사용자가 단일 질문에 대해 여러 리소스를 선택할 수 있습니다. 답변을 한 가지 선택으로 제한하려면 라디오 또는 드롭다운을 선택하십시오.

  3. 질문 이름을 입력하십시오.

  4. GDPR 규정에 따라 리소스 질문에 개인 식별 정보(PII)가 포함되어 있는지 여부를 표시할 수 있습니다. 이는 사용자 데이터를 보호하는 데 중요합니다.

  5. 비용 활성화를 선택하여 각 리소스의 비용을 사용자에게 표시할 수 있습니다. 선택한 경우 하나 이상의 리소스 옵션에 대한 비용을 추가해야 합니다.

  6. 사용자가 3가지 방법으로 선택할 수 있는 선택 항목을 추가할 수 있습니다.

    1. 선택 항목을 수동으로 추가 - 옵션 텍스트 상자에 선택 항목을 입력하고 선택 항목의 비용을 추가한 다음 추가 아이콘을 클릭합니다.

    2. XLS 파일에서 가져오기 - 선택 항목과 비용을 XLS 파일에서 가져옵니다. 시트 번호가 자동으로 채워집니다. 이름 및 비용 필드를 XLS 파일의 관련 열에 매핑하고 가져오기를 클릭합니다.

    3. 애플리케이션에 있는 자산에서 선택 - 제품 유형을 선택하고 화살표 아이콘을 사용하여 옵션을 선택한 옵션 영역으로 이동합니다.

  7. 이미지 사용을 선택하여 각 리소스에 참조 사진을 추가합니다.

    • 이미지가 활성화된 경우 새 옵션 버튼을 사용하여 수동으로만 옵션을 추가할 수 있습니다.

    • 옵션과 비용을 입력하십시오.

    • 장치에서 사진을 업로드합니다. 사진은 .jpg, .png, .jpeg, .bmp 형식일 수 있습니다. 리소스 질문에 대해 최대 5개의 이미지를 추가할 수 있습니다. 파일 크기는 5MB를 초과하지 않아야 합니다.

    • 필요한 경우 편집기 텍스트 상자에 설명을 추가합니다.

    • 저장 또는 저장하고 새로 추가를 클릭합니다.

  8. 추가한 데이터를 재설정하지 않고 리소스 질문 유형을 변경하려면 유형 드롭다운을 언제든지 사용하십시오.

  9. 저장을 클릭하여 질문을 만듭니다.

리소스 질문 편집

리소스 질문 위에 마우스를 놓고 메뉴 목록 아이콘을 클릭하여 리소스 질문을 편집합니다. 리소스 질문에 대한 편집 사항은 관련된 모든 리소스 섹션 및 요청 템플릿에 반영됩니다.

리소스 정보가 이미 기록된 요청서에서, 해당 요청서가 수정되지 않는 한 편집 사항은 요청서 세부 정보에 영향을 미치지 않습니다.

리소스 질문 삭제

리소스 질문 위에 마우스를 놓고 메뉴 목록 아이콘을 클릭하여 리소스 질문을 삭제합니다.

  • 리소스 질문이 요청 템플릿과 연계되어 있지 않으면 영구적으로 삭제됩니다.

  • 리소스 질문이 현재 사용 중인 경우 완전히 연계 해제될 때까지 비활성 상태로 이동됩니다. 삭제된 리소스 질문을 보려면 비활성 질문 필터를 적용하십시오.

편집하는 동안 편집할 질문 활성화 옵션을 선택하여 비활성 질문을 활성화할 수 있습니다.

참고: 리소스 섹션에 리소스 질문이 하나만 있는 경우:

  • 리소스 질문이 삭제되면 리소스 섹션이 삭제됩니다.

  • 리소스 질문이 요청서에서 사용되는 동안 삭제되면 리소스 섹션은 비활성으로 표시됩니다.
