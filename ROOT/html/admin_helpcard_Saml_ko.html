ServiceDesk Plus는 IdP(Identity Provider)와 SP(Service Provider) 간에 데이터를 교환하여 사용자 인증 프로세스를 간소화하는 SAML 2.0을 지원합니다.

이 페이지에서 SAML 인증을 구성 및 활성화/비활성화할 수 있습니다.

여기에서 제공되는 서비스 제공 업체 세부정보를 사용하여 IdP 포털에서 해당 애플리케이션을 구성하십시오.

IdP 세부 정보 섹션 아래에 IdP 포털에서 수집한 세부 정보를 입력합니다.

IdP에서 생성한 로그인 이름이 ServiceDesk Plus의 사용자 로그인 이름과 일치하지 않으면, 기본적으로 동적 사용자 추가로 되어, 해당 사용자가 새로 추가됩니다. 동적 사용자 추가가 비활성화되면 위에서 설명한 사용자는 ServiceDesk Plus에 로그인할 수 없습니다.

참고 사항: 이름 ID 형식이 미지정 또는 이메일 주소로 각각 설정된 경우, UPN 기반 로그인 및 이메일 기반으로 로그인 할 때에 동적 사용자 추가가 작동하지 않습니다.
