Achat - Champs supplémentaires

 

Vous pouvez définir les champs propres à votre organisation qui doivent apparaître dans le formulaire de Nouveau bon de commande en plus des champs prédéfinis qui ont été fournis par défaut. Vous pouvez ajouter des champs de type texte, des champs de type numérique, des champs de type date et des champs de coûts dans le formulaire.

 

Sélectionnez chacun des onglets et ajoutez le nom du libellé et la description de chaque champ que vous voulez ajouter au formulaire de nouveau Bon de commande.

Lors de l’ajout de champs de texte, vous disposez d’une option pour choisir le type de champ de texte. Le champ de texte peut être un champ de texte à une seule ligne, un champ de texte à plusieurs lignes ou une liste déroulante. Pour sélectionnez le type du champ de texte, cliquez sur le bouton radio correspondant.

 

Vous disposez également de deux types de champs coût, Ajouter un coût (pour ajouter un coût) et Retirer un coût (pour soustraire un coût). Cliquez sur le bouton radio correspondant pour sélectionner les champs coûts.

Si vous souhaitez ajouter une valeur par défaut au champ Texte et au champ Coût, indiquez les valeurs appropriées dans la boîte de texte prévue à cet effet.

Pour enregistrer les informations saisies, cliquez sur Enregistrer.
