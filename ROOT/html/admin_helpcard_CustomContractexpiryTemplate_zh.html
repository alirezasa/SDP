合同到期通知模板

您可以创建邮件模板，用于在合同到期时通知相应的技术员。在这里需要在给定的文本框中定制邮件的主题和内容。

主题内容

模板中指定的主题和变量，将作为通知邮件的主题发送给技术员。

 

默认情况下，主题内容中已经包含 $Contract Name 和 $Contract ID，如果需要，也可以更改或添加主题内容与变量。可以从页面右侧的主题变量列表中选择主题变量。例如：主题变量 $Contract Name & $Contract ID分别代表合同名和合同ID，实际邮件中将会使用实际的值进行替换。

消息明细

指定消息的内容，也可从列表页面的右侧选择提供的内容变量。

保存该模板，每当合同到期时，将根据该模版生成电子邮件发送给相关的技术员。
