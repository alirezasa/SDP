다른 유형의 요청서를 다른 유형으로 분류할 수 있습니다. 카테고리.  (예: 소프트웨어 설치에 대한 모든 요청서는 "소프트웨어 설치" 범주로 분류될 수 있습니다.) 또한 범주 -> 하위 범주-> 항목의 계층 구조가 지원되어, 사건 요청서 유형이 세분화하여 분류할 수 있습니다.  다양한 범주를 사용하여 사례를 적절한 기술자에게 자동으로 라우팅하도록 애플리케이션을 구성할 수 있습니다. 예를 들어 모든 인터넷 연결 관련 문제는 네트워크 엔지니어인 김철수에게 자동으로 할당될 수 있습니다.

새 범주 생성
 
새 범주 버튼을 클릭합니다. 범부 양식이 표시됩니다.
이름 텍스트 필드에 범주 이름을 입력하십시오. 예를 들어 인쇄기. 이것은 유일한 필수 필드입니다.
설명 필드에 새로 생성될 범주에 대한 설명을 입력합니다.
기술자에 배정 콤보 상자에서 새로 생성된 범주에 배정할 기술자를 선택합니다. 이 범주와 관련된 모든 문제는 선택한 기술자에게 배정됩니다.
저장 버튼을 클릭하여 이 정보를 저장합니다. 범주 목록 보기에서 범주들이 나열되는 것을 볼 수 있습니다.
하위 범주 저장하고 추가 버튼을 클릭하여 해당 정보를 저장하고 다른 하위 범주를 추가합니다.
 
새 하위 범주 추가
 
새 하위 범주 버튼을 클릭합니다. 그러면 하위 범주 양식이 표시됩니다.
하위 범주 텍스트 필드에 하위 범주 이름을 지정합니다. 예를 들어 종이. 필수 필드입니다.
설명 필드에 새로 생성된 하위 범주에 대한 설명을 입력합니다.
콤보 상자에서 범주 를 선택합니다. 예를 들어 프린터. 필수 필드입니다.    
 
새 항목 생성
 
새 항목 버튼을 클릭합니다. 그러면 새 항목 양식이 표시됩니다.
이름 텍스트 필드에 항목 이름을 입력합니다. 예를 들어 용지 걸림. 필수 필드입니다.
설명 필드에 새로 생성된 항목에 대한 설명을 입력합니다.
콤보 상자에서 하위 범주를 선택합니다. 예를 들어 종이. 필수 필드입니다.
저장 버튼을 클릭하여 저장합니다.
 

빨리 범주, 하위 범주, 항목 (Category,Sub-Category and Item(CSI))추가

'빨리 CSI 추가' 옵션을 사용하면 개별 '새로 만들기' 옵션을 사용하여 추가하는 대신 새 범주, 하위 범주 및 항목을 즉시 추가할 수 있습니다. 이 옵션은 많은 수의 범주 또는 하위 범주 또는 항목을 추가해야 할 때 시간 소모를 줄이는 것으로 증명되었습니다.

  • 팝업 창의 텍스트 영역에서 탭 없이 입력된 텍스트는 범주로 간주됩니다.
  • 단일 탭으로 입력된 텍스트는 하위 범주로 간주되고 두 개의 탭으로 입력된 텍스트는 항목으로 간주됩니다.
  • '저장'을 클릭하면 성공적으로 추가된 레코드 수와 함께 그 '결과'가 표시됩니다.

빠른 CSI 추가에 대한 참고 사항

1. '모두 펼치기' 및 '모두 접기'는 추가된 CSI의 확대 및 축소 보기를 제공합니다.
2. 범주, 하위 범주 및 항목에 대해 유일한 이름을 입력합니다. 두 개 이상의 범주에 동일한 이름이 제공되면 미리 보기에 해당 범주가 한 번만 표시됩니다.
3. 범주 이름은 하위 범주와 항목에서 사용할 수 있지만, 같은 범주 이름을 다시 사용할 수는 없습니다. 범주가 이미 존재하는 경우 추가되지 않습니다. 하위 범주 및 항목에도 동일하게 적용됩니다.
4. '지우기/삭제'를 클릭하면 텍스트 영역이 초기화됩니다


참고: 범주 목록 보기에서 해당 범주를 클릭하여 하위 범주 & 항목을 추가할 수도 있습니다.
