Remote Control Tools List

This feature helps you employ different remote desktop software within AssetExplorer / ServiceDesk Plus. By default, there are four remote control tools configured in the application. Out of the four, the Windows Remote Desktop is available by default on all the Windows machines. The Agent tool, on the other hand, is available by default in the product. The remaining remote control tools should be installed in the machine from which the remote control is initiated (client machine).

NOTE:Remote Control is performed from the machine you are currently accessing (client machine) and not from the AssetExplorer host server.

The configured Remote Control tools are listed as options under the Remote Control drop down menu in the details page of a workstation/server. You can choose to perform remote control from any of the tools.

The Remote Control tool list depends on the OS on the client and user machine. If the OS is other than Windows or MAC, then the Remote Control option will not be available.
