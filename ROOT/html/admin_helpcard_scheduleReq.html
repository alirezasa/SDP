You can create Preventive Maintenance Task for regular maintenance such as changing printer toner every month or performing a regular service shutdown. You can create a Preventive Maintenance Task in two steps :
 
Create a Task Template
Specify the task template on how request must be generated. If you are trying to create a preventive maintenance task for changing printer cartridges, you can specify the request to be open and of level tier 1. It can be assigned to a group so that any technicians can take this task. You can also set priority level based on the usage of the printer. You can specify title and content of the task. Based on this task template, maintenance task will be generated as per your schedule.

Click the Next button to move to Scheduling part.
 
Task Scheduling
To schedule a task, select the time frame from the listed options :
    • Daily Schedule
    • Weekly Schedule
    • Monthly Schedule
    • Periodic Schedule
    • One Time Schedule
Say, if you want to schedule monthly task to change printer cartridges, you can select monthly schedule, select the check box every month and choose the date (say 3rd of every month) and choose the time (say 1500 hrs). Once you save this schedule, a task to change cartridge will be sent to you every month on 3rd at 1500 hrs. This preventive maintenance task can help you reduce your incoming maintenance calls.

Enter the schedule details.

Click Save to save the Preventive Maintenance Task .
