Define organization-specific fields to collect additional details from users while creating problem requests.

Create Additional Fields

  1. Click New Field.
  2. In the popup header, select the additional field type - Single Line, Multi Line, Pick List, Numeric or Date/Time.
  3. Specify a unique name for the field.
  4. Add a description, if needed.
  5. Depending on the field type selected, you can configure the following:

    6. Single Line
    • Set a default value to be populated in the field.
    • Set a fixed length of characters to be input in the field.
    • You can limit the input to only numbers, if needed.
    Multi Line
    • Set a default value to be populated in the field.
    Pick List
    • Type a value to be displayed in the drop-down and click Enter.
    • You can also bulk add items or import them from XLS files. Use the Drag or Sort icon to rearrange the listed values.
    • You can remove the added values by hovering over a value and clicking the Delete icon.
    Numeric
    • Set a default value to be populated in the field.
    • Set a fixed length of characters to be input in the field.

  6. Click Save.

Note:
You can create up to 90 additional fields.

Edit/Delete Additional Fields
You can edit or delete additional fields using the respective icons in the list view.
After an additional field is deleted,

  • The field will be removed from the associated problem templates.
  • The data stored under the additional field in problem requests will be deleted permanently.
