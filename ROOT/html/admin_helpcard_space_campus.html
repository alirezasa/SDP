Campus Templates

Create and save templates for frequently created campuses, schools, colleges, etc., to aid users while they create similar campuses.

On this page, you can create a new campus template, edit or delete the existing ones.

To create a new campus template, click New Campus Template.

The new campus template form has two sections,

1. Details : Here, you can define the campus template, such as by adding a display name, name, and description for it.

2. Fields : Once you have saved the details section, you can add new fields to the campus template by dragging the required fields from the New Field Section on the right side.

To name a section, click Untitled text and type in the desired section name.

Finally, save the field configuration.
