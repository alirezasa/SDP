서비스 요청서 템플릿 설정을 시작하려면 이름과 설명을 입력하고 템플릿에 대한 설명 아이콘을 업로드하십시오. 이 정보는 템플릿에 액세스할 수 있는 모든 사용자에게 표시됩니다.

기본적으로 서비스 요청 템플릿을 추가하거나 수정할 때 기술자 탭이 먼저 표시됩니다. 이를 통해 기술자에게 표시될 서비스 요청서 양식을 디자인할 수 있습니다.

기술자 탭 아래에 있는 캔버스에서 서비스 요청서 양식의 기술자 레이아웃을 디자인할 수 있습니다. 다양한 필드, 리소스 관련 질문을 추가하고, 양식에 색상 코드를 지정하고, 지원 그룹을 선택하기 위해 템플릿의 가용성을 제한할 수 있습니다.

필드 및 열 사용자 정의

기본 제공되는 기본 필드를 추가하거나 왼쪽 패널에서 필요에 따라 새 필드를 만들 수 있습니다.

  • 기본 필드 추가 - 기본 필드를 캔버스의 필요한 위치로 끌어다 놓습니다.
  • 새 필드 만들기 - 사용 가능한 필드 제목 옆에 있는 새 필드 추가 아이콘을 클릭합니다. 사용 가능한 필드 유형이 나열됩니다. 필드 유형을 캔버스에 끌어다 놓고 필드 속성을 입력합니다. 저장을 클릭합니다.
  • 추가 필드 추가 - 서비스 카탈로그에 대해 구성된 추가 필드는 사용자 정의 필드 아래 왼쪽 패널에 나열됩니다. 필요에 따라 끌어다 놓습니다.

기밀 정보를 포함할 수 있는 새 필드를 만들 때 사용자의 기밀 데이터를 보호하려면 PII(개인 식별 정보 보유) 확인란을 선택하십시오. 필드 암호화를 선택하여 정보를 암호화하도록 선택할 수도 있습니다. 암호화된 데이터는 보고서, 고급 검색 또는 사용자 정의 필터에 표시되지 않습니다.

섹션을 추가하여 필드를 단일 또는 이중 열로 그룹화하려면:

  1. 왼쪽 패널에서 사용 가능한 필드 제목 옆에 있는 새 필드 추가 아이콘을 클릭합니다.
  2. Column Types(열 유형) 머리글 아래 섹션이 Single Column(단일 열)과 Double Column(이중 열)으로 나열됩니다.
  3. 관련 섹션을 캔버스에 끌어다 놓으십시오.
  4. 섹션은 일반적으로 제목이 없습니다. 섹션 위에 마우스를 놓고 섹션 편집 아이콘을 클릭하여 해당 속성을 정의합니다. 제목이 없는 섹션은 요청서 양식에 명확하게 표시되지 않습니다.
  5. 저장을 클릭합니다.

리소스 섹션 사용자 정의

관리 >> 서비스 카탈로그 블록에서 리소스 질문을 구성하고 리소스 섹션으로 그룹화합니다. 이 섹션은 템플릿 사용자 정의 양식의 왼쪽 패널에 자동으로 반영됩니다.

왼쪽 패널의 끝까지 스크롤하고 리소스 섹션 제목을 클릭하여 확장합니다. 구성된 리소스 섹션이 여기에 나열됩니다. 끌어서 놓기 동작을 사용하여 양식에 즉시 추가하십시오.

새 리소스 섹션을 추가하려면 리소스 추가 아이콘을 클릭하십시오. 팝업 창에서 이름과 설명을 입력합니다. 다음 두 가지 방법으로 리소스 섹션에 질문을 추가할 수 있습니다.

  • SDP 애플리케이션에 구성된 기존 질문에서 선택합니다.
  • 리소스 질문 추가를 클릭하여 리소스 질문을 수동으로 생성하십시오. 요구 사항에 따라 리소스 질문 유형을 선택합니다.
    • 사용자가 개별 답변을 녹음할 수 있도록 하려면 일반 텍스트 리소스 질문을 만드세요.
    • 사용자가 다양한 선택 항목에서 답변을 선택하도록 하려면 확인란/라디오/드롭다운 질문을 만드십시오.

자신의 리소스 질문을 추가하는 동안 각 리소스의 비용을 추가하고 사용자가 참조할 수 있도록 이미지를 추가할 수 있습니다. 각 리소스에 대해 .jpg, .jpeg, .png 또는 .gif 형식의 이미지를 최대 5개까지 추가할 수 있습니다. 이미지 크기가 5MB 미만인지 확인하십시오.

리소스 섹션 내에서 하나 또는 두 개의 열에 리소스 질문을 배치할 수 있습니다.

리소스 섹션에 대해 자세히 알아보려면 여기를 클릭하세요.

양식 레이아웃 사용자 정의

템플릿, 섹션 및 필드의 레이아웃을 사용자 지정하여 템플릿의 중요한 요소를 강조 표시할 수 있습니다. 크기와 색상, 배경색, 필드 방향을 포함하여 글꼴을 사용자 정의할 수 있습니다.

템플릿을 사용자 정의하려면 캔버스 오른쪽 상단에 표시된 사용자 정의 아이콘을 클릭하십시오. 섹션 또는 필드를 사용자 지정하려면 해당 요소 위에 마우스를 놓고 편집 아이콘을 클릭합니다. 팝업 창에서 사용자 정의 탭으로 이동하여 요소의 레이아웃을 수정합니다.

양식 사용자 정의에 대한 자세한 자료는 여기를 클릭하여 보십시오..

비용 세부정보 및 지침을 표시

비용 세부 정보 확인란을 선택하여 전체 서비스 비용을 구체적으로 나열합니다(있는 경우).

이 영역을 사용하여 기술자에게 간단한 설명이나 지침, 메모 또는 지침을 표시한다는 옵션을 선택하도록 하여 기술자에게 특별 지침이나 안내를 구체적으로 나열합니다.

템플릿 접근성 제한

템플릿을 선택된 지원 그룹과 연계하여 템플릿 사용을 제한합니다. 템플릿을 지원 그룹에 연계하지 않으면 모든 기술자가 템플릿에 액세스할 수 있습니다.

템플릿을 요청자에게 표시하려면 요청자에게 표시를 선택합니다. 사용자 그룹을 템플릿과 연계하여 특정 사용자 그룹이 사용하도록 템플릿을 제한할 수도 있습니다.

요청자가 필드를 편집할 때 기술자 양식에서 개별 필드를 보거나 편집할 수 있도록 선택합니다. 요청자가 설정하도록 선택한 필드만 요청자 템플릿의 기본 필드로 표시됩니다.

참고 사항: 요청자가 보도록 선택한 필드는 요청서 세부 정보 페이지에만 표시됩니다.

요청자 템플릿 사용자 지정

필요에 따라 템플릿을 사용자 정의합니다.

템플릿 또는 섹션에 표시되는 사용자 정의 아이콘을 클릭하여 크기와 색상, 배경색, 필드 방향을 비롯한 글꼴을 사용자 정의할 수 있습니다.

양식에 기본 필드를 추가합니다. (필드는 수정할 수 없습니다.)

필드의 기본값은 기술자 탭에서만 설정할 수 있습니다.

섹션을 사용하여 필드를 그룹화합니다.

워크플로 구성

  • 승인: 최대 5 스테이지의 승인을 구성하고, 모든 승인자의 승인을 필수로 하거나, 첫 번째 승인자의 결정을 적용하고, 승인 상태에 따라 기술자를 할당하고, 자동 알림을 구성할 수 있습니다.
  • SLA: 여러 SLA를 기존 SLA의 템플릿에 연계하거나 새 SLA를 만들어 연계할 수 있습니다. 템플릿의 기본값으로 한 SLA를 지정합니다.
  • 체크리스트: 기술자가 체계적인 방식으로 요청서를 완료하도록 안내하는 체크리스트를 구성할 수 있습니다. 체크리스트는 라디오 버튼, 한 줄 텍스트 상자, 숫자 전용 텍스트 상자 및 결정 상자와 같은 여러 필드 유형을 지원합니다.
  • 작업: 서비스 템플릿에 대해 여러 작업을 구성하고 종속성을 구성 및 설정할 수 있습니다. 요청자에게 작업을 표시하고, 작업을 추가할 시점(요청서 생성 또는 승인 후)을 선택하고, 작업을 트리거할 시점(요청서 생성, 승인 또는 수동 이후)을 선택할 수도 있습니다.
  • 템플릿 액션 ServiceDesk Plus와 통합된 애플리케이션에서 함수를 수행하도록 템플릿 액션을 구성할 수 있습니다. 현재 ManageEngine ADManager Plus, Mobile Device Manager Plus, Password Manager Pro 및 Desktop Central 액션이 지원됩니다.
