송신 메일 서버 설정

 

EWS(Exchange Web Service)를 사용할지 SMTP와 같은 외부 메일 서버를 사용할지 선택합니다.

인증 유형을 선택합니다. OAuth를 선택하는 경우 이메일 서비스 제공업체의 인증 서버에서 애플리케이션 서버를 애플리케이션으로 구성하고 클라이언트 세부 정보를 생성해야 합니다. 여기에서 방법을 알아보세요.

그런 다음 구성을 진행합니다.

아래에 제공된 포인터를 사용하여 표시된 필드를 채우십시오.
필드 설명
서버 이름/IP 주소 모든 메일을 보내야 하는 서버를 입력합니다.
대체 서버 이름/IP 주소 가능한 경우 백업 서버 세부 정보를 입력합니다.
발신자 이름 발신자 이름 지정(발신자 이메일에 표시됨)
회신 주소 모든 회신을 위한 주소. 수신 서버의 이메일 주소 필드 값과 동일합니다.
이메일 유형 발송 유형을 선택합니다. 필요한 경우 TLS를 활성화하십시오.
포트 포트 번호를 지정합니다.
인증 필요 보안을 위해 인증을 선택하는 경우, 필요한 로그인 자격 증명을 제공하십시오.
