使用LDAP认证，可以从LDAP服务器导入用户。然后，通过启用LDAP认证，用户可以使用他们的LDAP的凭证登录。缺省情况下LDAP认证是禁用的。

 

注意 : 在启用LDAP认证之前，请确保用户信息已经导入。LDAP认证支持Windows和Linux用户。因此，对于Windows用户，如果启用LDAP认证，将自动禁用AD认证。

 

要从新的域中导入用户，

  1. 点击域控制器部分的新建域按钮，进入新添域控制器的画面。
  2. 在域控制器字段，指定需要导入用户的域控制器，如：ldap://<server name>:<port number>，缺省端口为389。
  3. 输入用户名以及组织单元。如：CN:john, CN=Users, DC=domain name, DC=com.
  4. 指定对应的密码。
  5. 指定基本识别名称(Base DN), 如： CN = Users, DC = domain name, DC = com.
  6. 指定搜索域控制器时要用的匹配标准。如: mail=* 将在指定的域控制器中从邮件参数导入用户。
  7. 从下拉框中选择LDAP服务器类型，如：Linux的OpenLDAP。

注意: 如果选择服务器类型为缺省的LDAP，如：微软的Active Directory, Novell eDirectory和OpenLDAP，则登录属性标签、邮件属性标签以及识别名属性标签将缺省设置，不可编辑。

  1. 如果LDAP服务器类型为 其它 ，则需要指定登录属性标签 和邮件属性标签 。
  2. 识别名属性标签与Base DN类似。
  3. 点击保存按钮，保存域控制器明细。如果想立即导入用户，可点击保存并导入按钮。

您也可以从已有的域中导入用户，通过点击对应的域控制器旁的 立即导入。一旦从相同的域中导入用户，原来的数据将被覆盖。用户导入后，可以选中启用LDAP认证选项。

点击保存，用户即可使用他的LDAP凭证登录到本系统中。
