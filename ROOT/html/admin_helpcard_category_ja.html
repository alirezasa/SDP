リクエストをカテゴリー毎に分類することができます。また、インシデントのタイプを細かく分類するため、カテゴリー -> サブカテゴリー -> 項目の３レベルでの分類が可能です。また、カテゴリー毎に担当者を事前に設定しておくことで、リクエストにカテゴリーが指定されている場合は自動的に担当者が設定されます。

新規カテゴリーの作成
 
1.新規カテゴリーボタンをクリックします。カテゴリーフォームが表示されます。
2.テキストフィールドにカテゴリー名を指定します（例：プリンター）
3.説明フィールドに新規に作成するカテゴリーに関する情報を指定します。
4.技術担当者への割当てボックスから新規作成したカテゴリーに割当てる技術担当者を選択します。
5.保存をクリックします。カテゴリー一覧にカテゴリーが表示されます。
 
新規サブカテゴリーの作成
 
1.新規サブカテゴリーボタンをクリックします。サブカテゴリーフォームが表示されます。
2.テキストフィールドにサブカテゴリー名を指定します。
3.説明フィールドに新規に作成するサブカテゴリーに関する情報を指定します。
4.サブカテゴリーの上位カテゴリーとなるカテゴリーを選択します。    
 
新規項目の作成
 
1.新規項目ボタンをクリックします。項目フォームが表示されます。
2. テキストフィールドに項目名を指定します。
3.説明フィールドに新規に作成する項目に関する情報を指定します。
4.項目の上位カテゴリーとなるサブカテゴリーを選択します。
5.情報を保存するには、保存ボタンをクリックします。
 

カテゴリー、サブカテゴリー、項目（CSI）をクイック追加

"クイックCSIを追加"オプションにより、個々の"新規"オプションを使用することなく、新規カテゴリー、サブカテゴリー、項目を直ぐに追加することができます。このオプションを使用すると、複数のカテゴリー、サブカテゴリー、項目を追加する際の作業時間を削減できます。

  • ポップアップ画面にあるテキストフィールドにおいて、入力されたタブを持たないテキストがカテゴリーと認識されます。
  • 入力されたシングルタブを持つテキストはサブカテゴリーとして認識され、ダブルタブを持つテキストは項目と認識されます。
  • "保存"をクリックすると、追加されたレコード数と共に"結果"が表示されます。

"クイックCSIを追加"の詳細情報

1."すべて表示"と"すべて隠す"オプションにより、追加したCSIの表示方法を選択できます。
2. カテゴリー、サブカテゴリー、項目に一意の名前を指定します。2つ以上のカテゴリーに同じ名前が指定されると、プレビューには合致するカテゴリーが一度だけ表示されます。
3.カテゴリーの名前はサブカテゴリーと項目に使用できますが、カテゴリーには再使用できません。これは、既存カテゴリーと同じ名前で新規に追加できないからです。サブカテゴリーと項目についても同様です。
4."クリア"をクリックすると、テキストエリアをリセットします。


メモ： カテゴリー一覧からカテゴリーをクリックして、サブカテゴリーと項目の追加も可能です。
