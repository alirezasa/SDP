État de la ressource

Les ressources peuvent être classer selon leur état en cours dans l'organisation. Ex. : Ressource En cours d'utilisation, En magasin, Expirée, etc.

Pour ajouter un nouvel état de ressource :

  1. Cliquez sur le lien Ajouter un nouvel état de ressource, sur la droite de la page. La page Informations sur l'état de la ressource s’affiche. Cinq états de ressource sont disponibles par défaut dans ServiceDesk Plus. Vous ne pouvez pas modifier ou supprimer ces états de ressource.

  2. Renseignez le nom de l'État de la ressource dans le champ prévu à cet effet. Ce champ est obligatoire.

  3. Dans le champ Description, indiquez les informations relatives à l'état de la ressource.

  4. Cliquez sur le bouton Ajouter un état de ressource pour ajouter une ressource à l'application.
