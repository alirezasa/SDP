Facilitates one-sided integration of Microsoft System Centre Configuration Manager (SCCM) with our application, where we fetch scanned asset data from SCCM into ServiceDesk Plus. 
You can continue to use SCCM for inventory management while promptly updating the asset data in our application.  


To learn how it works, go here. To add a new SCCM Configuration:

  1. Click New and fill out the details of the fields displayed.
  2. Host name, Database name and Port are that of the SCCM database server.
  3. You can associate the assets to a site. This is especially useful when assets of a site SCCM are imported.
  4. Enter SCCM credential configured in the credential library.
  5. Specify when to initiate data fetching and the frequency at which the process has to be repeated.
  6. Click Test Connection & Save to make sure that SCCM database server is connected.


Success or failure of the data fetching is displayed as Status in the list view page.
Failure can be due to incorrect credential of SCCM database server or unestablished connection to the same.
 

You can edit/test connection/delete the SCCM right in the list view page.
