Integrate with UEM Product
Step-by-Step procedure for Integration :

Integrate ServiceDesk Plus with ManageEngine UEM Product to manage all your Desktop & Mobile Device Management functions. UEM Product automates desktop management activities like installing patches, deploying software, talking remote control, initiating chat, securing the client computers, applying USB usage restrictions and much more. It also enables managing Mobile Devices with profile management, App management, security management, and asset management. If you have installed both these products, you just have to provide the details of the computer where UEM Product is installed along with its Port Number.

Set Up the Integration

  1. Select the UEM application to be integrated.
  2. Enter the URL where the application is currently hosted.
  3. Enter the API Key of an admin user in UEM application.
  4. Select Enable Desktop Management Menu to display the desktop management menu for technicians. The menu will be displayed only for UEM Product build number #80100 and above.
  5. Select Enable MDM (Mobile Device Management) Menu to display MDM functions as a drop-down menu to technicians.
  6. Click Test Connection and Save to check for an established connection between ServiceDesk Plus and UEM product in their respective ports

Based on the actions enabled for each request template, technicians can perform the permitted actions. The enabled actions will be listed under Custom Actions menu in request details page.
