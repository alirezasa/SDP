On this page, you can add members to a project and assign roles.

Add Template Members

To add members to a Project Template,

  1. Click Add, select the users from the available users list.
  2. Assign a project role for the selected user using the Select Project Role drop-down and click Add.

    3. Note: It is not mandatory to assign a project role for a user if he/she holds a default project role. However, you can assign a new role.

  3. The selected user will be listed under the Members tab.

If a project is created using this template, the members under the Members tab of the template will be automatically assigned to the project.
