Urgency
 
Urgency is about the necessary speed of solving an incident of a certain impact. By default you have four Urgency details listed in this page.
 
Add New Urgency
 
Click on the New Urgency link on the right hand side of the page. This opens the Add urgency details page.
Specify the Name of the Urgency in the given text field. This is a mandatory field.
Specify the urgency details in the Description field.
Save the changes.  
Click the Save and add new button to save the urgency and add another urgency.
