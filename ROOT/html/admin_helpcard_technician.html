Technician / Site Association Model

The IT help desk team will comprise of the help desk team manager, help desk agent, and technicians who will be handling the requests posted / raised by various employees in the organization. You can add, edit, or remove the technicians in the application and also provide them with various access privileges that suit their role and need. You can also view the list of technicians in a particular site by selecting the site from Technicians for combo box. To add a new technician click the Add New link available.

Note :
The Site Admin can add and view the technicians available to the sites which he is associated from the Technicians for combo box. If the site is not configured in Admin- Sites, then the Technicians for combo box will not be available.
If the Technicians of a particular site refers to another site's settings, then during the site change, a pop-up denoting the selected site's refer site will be displayed. If the Technicians configured for the Site to be deleted is being referred by one or more Site(s), then during the Site deletion process, the Site(s) to be deleted will be listed along with the Technicians whom they refer. You can either choose the refer Site's settings to refer default settings or change to any other Site's settings that you require.

 

Add New Technician
Personal Details: Specify the personal details of the technician such as Name and Employee ID.

Contact Information: Enter the contact information of the technician such as the E-mail ID, Phone, Mobile and SMS Mail ID.

Cost Details: Enter the Cost per hour value of the technician.

Department Details: Select the Department Name of the technician from the drop-down menu. Also, specify the Job Title of the technicina.

 

Associate the site(s) with technician:

If you have added Sites then you can associate multiple sites to a technician. Select the sites to which you want to associate the technician from the popup that is available near to Associated Sites field. Similarly you can also dissociate the sites. You can also associate/dissociate sites from the technicians in the Technicians list page.

 

Assign the group(s) for the technician:

You can also assign Groups for the technician. Select the groups from the popup that is available near to Associated Groups field.

 

 

Additional Technician Details:

If there were any user defined fields added, then enter the same under Additional Technician Details. To enable privilege as a Purchase Order Approver to the technician, enable the check box.

 

Login Details:

To enable login permissions for the technician, select the check box, Enable Login for this Technician. Now enter a Login Name and Password. The login name needs to be unique. You can also select the Domain of the technician from the drop-down menu.

Now you need to assign a role to the technician, which will define his access privileges to various modules in the application. If you want the technician to have complete administrator access then select the SDAdmin role from Assigned Roles drop down. This option will not be available when a Site Admin logs in to the application using his login credentials. (OR)

If you want the technician to have complete administrator access for the sites selected above then select the SDSiteAdmin role.

Else, choose the roles from the drop down of Assigned roles

 

Enable Access to Desktop Management Functionality:

While enabling login permission to a technician, you can also provide the technician with Endpoint Central (formerly Desktop Central) login access and Endpoint Central Role. The two Endpoint Central Roles are Endpoint Central Admin and Endpoint Central Guest. Select the check box Enable to access Desktop Management Functionality and provide either of the role to the technician. When the technician logs into the application using his/her credentials, the technician can view the Desktop Management drop-down menu, from where, the technician can perform Desktop Management functionality from within this application web console.

 

NOTE:

  1. Selecting the check box Enable to access Desktop Management Functionality and a Endpoint Central Role will create an user with same login credentials in Endpoint Central application.
  2. You will be able to select Enable to access Desktop Management Functionality check box only when the connection between Endpoint Central and this application is established successfully. If the integration is not successful, then this option is greyed.

Authtoken details:
The Authtoken for the technician is essential while integrating this application with REST API or with Endpoint Central application. The Authtoken performs as an authentication mechanism between the two applications.
Select/Unselect checkbox against Allow to generate their own authtoken to allow/restrict technicians generating their own Authtoken.

Click the Save button to save the technician and return to the list view.
Click the Save and add new button to save the technician and add another technician.

 

Delete Technician(s)

From the technician list, enable the check box adjacent to the technician(s) whom you want to delete.

Click Actions button --> Delete Technician(s). A pop up window confirming the delete action appears. Click Ok to continue. The technician gets deleted from the list.

If you have enabled the GDPR settings under Privacy Settings, you can change the technician names to any random text during deletion. This change will be effected across all modules within the application.

 

Associate/Dissociate Site

You can associate/dissociate the technicians to/from sites using this option.

  1. From the technicians list view page, enable the check box adjacent to the technician for whom you want to associate/dissociate site.
  2. If you want to associate the technician to a site, click Actions button --> Associate to Site. The Associate Technician(s) to site pop up window appears. Select the Site to which you want to associate the technician from the combo box. Click Associate button.      
  3. If you want to dissociate a technician from the site, click Actions button --> Dissociate from Site. The Dissociate Techncian(s) from site pop up window appears. Select the Site from which you want to dissociate the technician from the combo box. Click Dissociate button.

Assign Project Role

From technician list it is possible to assign project role to the technicians.

Click Actions button --> Assign Project Role . Select Project Role from Project Role Drop Down and click Associate.
