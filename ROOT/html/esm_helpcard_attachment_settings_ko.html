첨부 설정

  • 최대 첨부 파일 크기(MB): 첨부 파일의 최대 크기를 설정합니다. 기본적으로 10MB로 설정되어 있습니다.
  • 첨부파일 저장 경로 구성: 첨부파일을 저장할 특정 경로를 구성합니다. 재설정 옵션을 클릭하여 경로를 재설정할 수 있습니다.
    참고 사항:
    1. 특정 경로가 지정되지 않은 경우 첨부 파일을 저장하는 데 기본 경로가 사용됩니다.
    2. 홈 디렉토리 <ASSETEXPLORER HOME> 첨부 파일 경로로 구성할 수 없습니다.
    3. 첨부 경로에서 ".."의 사용이 제한됩니다.

  • 첨부파일 필터링: 포함 또는 제외 섹션에서 파일 확장자를 선택하여 애플리케이션에서 허용할 첨부파일과 제한할 첨부파일을 구성합니다. 모든 파일 형식을 허용하려면 모든 파일을 선택합니다.
