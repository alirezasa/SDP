有多种方式/方法可以将服务请求提交到您的支持团队，并在系统中跟踪解决。您可以通过下列几种方式提交服务请求：
  • 利用基于web的新建请求表单提交问题
  • 通过致电服务台代理提交请求，请求将被存档
  • 发送Email到支持团队，将被自动记录为服务请求
要添加新模式，请点击模式列表右侧的添加新模式链接。

添加新模式
添加模式表单包含两个字段，即模式名称和描述。

模式名称就是您所指定的用来识别某种模式的独有名称。

您可以在描述字段输入该模式相关的简要描述。这将便于您了解如何追踪该模式下生成的服务请求。

点击保存按钮，并返回到列表视图。
点击保存并新建按钮，保存该模式并添加其它模式。
