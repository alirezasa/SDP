This integration enables you to import scanned asset data such as network devices, workstations, and servers from SolarWinds to AssetExplorer/ServiceDesk Plus.

To configure the integration,

  • Make sure you have Admin access.
  • Enter the machine details where the SolarWinds application is hosted. If SolarWinds and SWIS API servers are hosted on different machines, then enter the SWIS API machine details under Server Name.
  • Enter Username and Password.
  • Set a start date for the data fetch schedule.
  • Under Scan Frequency, you can configure how often the data fetch should happen in days.
  • Finally, click Test Connection and Save.


The schedule will be initiated on the set date. You can also check the status of the current schedule, last schedule, and next schedule on this page.

Note:

  • For unknown OIDs imported, you can select the Product Type manually under SNMP Configurations > Configure product for unknown sysOID. Model and Manufacturer details will be auto-populated from SolarWinds.
  • By default, the SWIS API server will be running in port 17778 and via HTTPS protocol.
