How it works?

   This option would merge two resource (including the data) and delete one of the resource. This is useful to delete duplicate resource which could have been renamed or received from a Purchase Order (PO).

For example, when receiving resource(s) from a PO, the received resource name is set by the System. When this resource gets scanned from the physical network the resource name is set as available in the resource. To copy the System generated resource select both these resource and click Reconcile button. The Reconcile would copy the data of the resource received from PO to the resource scanned from the network and delete the resource received from PO.

This option could also be used to merge two resource which has been scanned from network. In this case the resource which has been recently added would be retained.
