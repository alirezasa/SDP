How to Configure Clickatell in ServiceDesk Plus?
  1. Go to the Clickatell website and Sign Up for an SMS Gateway Clickatell Central account. Signing up to Clickatell Central is free.
  2. Click GET another API under the "APIs".
  3. Click on Add Rest API.
  4. Copy the REST API Auth Token and paste it in the Auth Token Field.
  5. Click on Save.
