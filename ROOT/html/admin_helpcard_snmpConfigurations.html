SNMP Configuration

On this page, you can configure Object Identifiers (OIDs) for SNMP device attributes and remap OIDs to the right attributes. In addition, you can configure products for unknown sysOIDs and manually add sysOIDs.

SNMP configuration is equipped with the MIB Browser, which stores MIB files of various network devices. The MIB Browser allows you to navigate within the MIB of the selected network device and retrieve the value of any MIB variables. The MIB Browser is available as a separate module as well as a stripped version.


SNMP Device Scan

When you scan an SNMP device, its sysOID will be initially fetched. The sysOID uniquely identifies the device's model, product type, and manufacturer. Once the device is identified, the inventory will be initiated to fetch values of the device attributes, including asset additional fields, CI attributes, and default fields.

SNMP devices that are identified during the scan using the sysOIDs in the application will be added under Device Identification. Under this tab, you can edit available sysOIDs and add new ones.


Configuring Product for Unknown SysOIDs

Devices whose sysOIDs are not available will be added under Configure product for Unknown sysOIDs. Here, you can manually configure the model, product type, and manufacturer of sysOIDs. Once configured, the sysOID will be moved to the Device Identification tab.


Configuring OIDs

Under Device Inventory, you can configure OIDs of SNMP device attributes. To configure OID for an attribute of a device, say HP Printer, choose the appropriate filters. Then click the attribute (field) for which the OID must be configured for, or click Configure OIDs and choose the attribute.

To fetch the attribute's OID from the corresponding MIB file, click From MIB. This opens the stripped version of the MIB Browser in the current dialog box. Choose the MIB file and select the corresponding node in the MIB file. (You can also upload the file from here.)

Using the Test Device option, you can optionally sample query a device to check whether the OID returns the right attribute value.

Note that 'Size' attributes require you to specify the unit in which the OID returns the value. Values returned in Bytes, KB, and MB will be converted to GB, whereas values returned in GB will be converted to TB and displayed in the application.


MIB Browser

Besides retrieving values of MIB variables, the MIB Browser provides a Table view for attributes with multiple values and allows you to set up SNMP v1/v2, and v3 credentials.
