Mobile Device Manager Plusとの連携

連携手順はこちら：ヘルプドキュメント

ServiceDesk PlusとMobile Device Manager Plusを連携することで、ServiceDesk Plusのコンソール画面から直接、モバイルデバイスの保護、および管理をすることができます。Mobile Device Manager PlusはAppの配布、デバイスの管理や制限、メール管理、資産管理などのモバイルデバイス管理のタスクを自動化をすることができます。また、Appやデバイス、サードパーティーのクラウドサービス間の通信を制限することで、モバイルデバイスの安全性を確保することもできます。さらに、モバイルデバイスをなくしてしまった場合に、管理者が位置を特定したり、必要であればデータを削除することが可能です。両製品をインストールした場合は、Mobile Device Manager Plusがインストールされているコンピューターの詳細とポート番号を入力するだけで連携ができます。

注意：対応しているMobile Device Manager Plueはビルドは93370以降になります。

入力する必要のある詳細事項について：

サーバー名：Mobile Device Manager Plus (MDM)がインストールされているサーバー名を入力します。

サーバーポート番号：MDMサーバーのポート番号を入力します。

プロトコル設定：http/httpsといったプロトコル設定を選択します。

 

注意：MDMのドロップダウンメニューを表示するには、MDMメニューを有効化します。このオプションは、MDMのビルドが92263以降のみで可能です。MDMオプションをドロップボックスから除外するには、「MDM（モバイルデバイス管理）メニューを有効にする」のチェックを外して、［保存］をクリックし、設定を保存してください。設定の保存に成功すると、ServiceDesk PlusサーバーはMDMサーバーと接続を確立します。その後、詳細な設定がMDMサーバーから取り込まれます。

 

Click ［保存］をクリックして設定を保存します。設定の保存に成功すると、ServiceDesk PlusはMDMサーバーと接続を確立します。a connection with the MDM server.


その他のME製品と連携する方法（HTTPSモードで動作している場合）

  1. 下記のリンクからzipファイルをダウンロードし、＜インストールディレクトリ＞\ManageEngine\ServiceDesk配下に解凍してください。

    2. Linux用ダウンロードリンク：https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1cb6g423n1gp9135o97nfchub1/lincertgeneration.zip

    Windows用ダウンロードリンク：https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1cb6g2tdh126s6hmhpvjja2si1/windowscertgeneration.zip

  2. 管理者権限にてコマンドプロンプトを起動し、＜インストールディレクトリ＞\ManageEngine\ServiceDeskに移動して、以下のバッチファイルを実行してください。

    3. Linux用コマンド：
    C:>ManageEngine\ServiceDesk>gencert.sh [サーバー名]:[ポート番号]

    Windows用コマンド：
    C:>ManageEngine\ServiceDesk>gencert.bat [サーバー名]:[ポート番号]

  3. コマンドを実行すると、PKIXの例外を受け取り、その後値の入力を求められます。値「1」を入力し、＜インストールディレクトリ＞\ManageEngine\ServiceDesk配下に「jssecacerts」というファイルを生成します。

  4. 生成されたファイル「jssecacerts」を＜インストールディレクトリ＞\ManageEngine\ServiceDesk\jre\lib\security配下にコピーして、SerbiceDesk Plusを再起動してください。
