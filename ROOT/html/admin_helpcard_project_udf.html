Configure additional fields into the Project form to collect different types of information.

  • You can add single line, pick list, multi line, numeric, date/time, and decimal fields.
  • Single line, pick list, and multi line fields can be used to collect textual information, whereas numeric, date/time, and decimal fields can be used to collect number-related information.
  • To collect numeric information under the single line field, select the Allow only numbers option.
  • Under each field, as you enter information on the left, a preview of the field will be displayed on the right. 
  • All the configured additional fields will be automatically added into the project template. You do not have to manually configure them inside the template.
