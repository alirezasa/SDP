Des modèles de résolution peuvent être crées pour faciliter le traitement des requêtes similaires. Les solutions des demandes les plus courantes, comme la configuration de l'imprimante, peuvent être réalisées à l'aide d'un modèle de résolution. De cette manière, les techniciens n'ont pas à saisir les mêmes résolutions de manière répétée.

Pour ajouter un nouveau modèle de résolution, cliquez sur le bouton Nouveau sur la page de liste des modèles de résolution.

Ajouter un nouveau modèle de résolution

Pour ajouter un modèle de résolution :

Renseignez un Nom unique pour le modèle de résolution. Par exemple : Solution de configuration de l'imprimante.

Saisissez la résolution dans le champ Description. Les champs Nom et Description sont obligatoires.

La résolution peut être rendue inactive en cochant la case Rendre inactive.

Pour revenir à l’affichage liste, cliquez sur le bouton Enregistrer.
Pour enregistrer et ajouter un autre modèle de résolution, cliquez sur Enregistrer et ajouter nouveau.
