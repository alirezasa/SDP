Custom Widgets
 
Custom Widgets extend the capabilities of ServiceDesk Plus by bringing external services inside the application. Widgets are embeddable UI components that you can create on your own, using a custom widget package. Custom widgets allow you to access third-party applications and webpages from within ServiceDesk Plus. Custom widgets can be accessed from dashboards, request details page, change details page, release details page, asset details page, web tabs, and custom modules.

Add Custom Widgets
  1. Click New.
  2. Provide a name for the widget.
  3. Shortly describe the widget in the description.
  4. Upload the zip file that contains the custom widget package. Note that the file size should not exceed 5 MB.
  5. Click Save.
List View Actions
On the custom widgets list view, you can perform the following actions on the widget.
  • Edit/Delete Custom Widget: Use the Actions icon beside the widget name.
  • Enable/Disable Custom Widget: Use the Enable/Disable icon in the Enabled column.
Inline Actions
Click the widget name. The inline details page displays all the widget items and their locations in the widget package. From the inline details page, you can:
  • Edit/Delete the custom widget.
  • Enable/disable widget items and make them accessible from select locations.
  • Enable/disable a widget item using the Toggle button displayed beside the widget item name.
  • Click Add Location to add or remove the required widget location. You can also enable/disable the locations using the Toggle button beside the widget item location.
Note: Additional configuration details such as Connections and Modules will not be displayed for Configuration Widgets.
