Migrate to New Status

In the new Change Workflow, the change old status, which denoted the status of the change request, would no longer be in use. Instead, this tool enables you to pick up an equivalent new stage and status for the Change Old Status.
NOTE: This tool is available only for users who have upgraded from the older versions of ServiceDesk Plus.

To migrate to new status,

  1. Select the new stage and status from the drop-down menu.
  2. If you do not find an equivalent status in a stage, then you can create a new status under a stage.
    1. Hover on the status to find the Create New Status link.
    2. Select the Stage from the drop-down menu.
    3. Enter the Status Name and click the Add button. The newly added status will be added in the stage and status list view.
  3. Click the Start to Migrate button to save the settings.
