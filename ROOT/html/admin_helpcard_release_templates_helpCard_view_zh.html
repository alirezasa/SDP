详细信息

要开始设置您的发布模板，请输入以下详细信息。这些信息将显示给所有可以访问该模板的用户：

  • 首先，请输入您的模板名称，这是一项必要操作。
  • 为模板添加一个描述。
  • 选择模板类型-常规模板或紧急模板。注：只有紧急发布工作流能够配置紧急模板。
  • 选择一个工作流以关联模板。如果没有为模板配置工作流，将使用默认工作流。

默认情况下，当您添加或编辑发布模板时，会首先显示详细信息。它允许您设计显示给技术人员的发布请求表。
您可以在详细信息中编辑表单，您可以添加各种字段，对表格进行颜色编码，并将用户配置成与模板有关的角色。

自定义字段和列

您可以添加内置默认字段、分段，创建新字段以满足您的需求，或添加以前创建的其他字段。

  • 添加默认字段-将默认字段拖放到画布中所需的位置。
  • 创建新字段-单击左侧面板上的“新添字段”图标。将列出可用字段类型。将字段类型拖放到画布上，配置并保存字段属性。要了解如何配置并发布附加字段，请点击此处。
  • 添加其他字段-先前为发布管理配置的其他字段将列在左侧面板的自定义字段下，根据需要拖放它们。

创建可能包含机密信息的新字段时，请选中“加密该字段”复选框以保护机密数据。加密数据不会显示在报告、高级搜索或自定义筛选器中。

要添加分段并将你的字段分组为列：

  1. 在左侧面板中，单击新添字段图标。
  2. 从“分段类型”标题中，可以根据所需的列数（单列、双列、三列或四列）将分段拖放到画布中。要在移动中自定义列，请选择“灵活列”。
  3. 有些分段没有标题，将鼠标悬停在分段名称上，然后单击编辑分段图标以定义其属性。没有标题的部分不会在发布表单中清晰显示。
  4. 点击保存。

自定义表单布局

您可以自定义模板、分段和字段的布局，以突出显示模板的重要元素。您可以自定义字体，包括其大小和颜色、背景色和标签方向。

要自定义模板，请单击画布右上方显示的定制图标。要定制分段或字段，请将鼠标悬停在相应的元素上，然后单击“编辑”图标。在弹出窗口中，转到“定制”选项卡以修改元素的布局。

若要了解有关表单自定义的详细信息，请点击此处。

注：

默认情况下，阶段、状态和注释字段将添加到发布模板中。它们无法移动或移除。

默认情况下，站点、创建时间、完成时间、标题和描述也会添加到发布模板中。这些字段可以在表单中重新定位，但不能删除。


角色选项卡

保存详细信息选项卡后，将显示角色选项卡。您可以将用户与各种发布角色关联或创建新角色。

自定义角色和列

您可以添加内置默认角色，创建新角色以满足您的需求，或添加先前创建的发布角色。

  • 添加默认角色-拖放画布中所需的默认角色位置。
  • 创建新角色-点击“可用的角色”标题旁边的“添加新角色”图标。将“添加角色”拖放到画布中，配置并保存角色属性。要了解如何配置发布角色，请点击此处。
  • 添加现有发布角色-先前为发布管理配置的发布角色将列在左侧面板的默认字段下。根据需要拖放它们。

默认情况下，发布角色将添加到发布模板中。发布经理、发布请求者和发布工程师角色在模板中进行了硬编码。如果需要，可以从模板中删除其他角色。

  1. 在左侧面板中，点击“可用角色”标题旁边的“添加新角色”图标。
  2. 从“分段类型”标题中，可以根据所需的列数（单列、双列、三列或四列）将其拖放到画布中。要随时自定义列，请选择“灵活列”。
  3. 分段通常没有标题。将鼠标悬停在分段名称上，然后单击编辑分段图标以定义其属性。没有标题的部分不会在发布表单中清晰显示。
  4. 点击保存。

自定义表单布局

您可以自定义模板和分段的布局，以突出显示模板的重要元素。您可以自定义字体，包括其大小、颜色和背景色。

要自定义模板，请单击画布右上方显示的自定义图标。要自定义分段，请将鼠标悬停在相应的分段上，然后单击“编辑”图标。在弹出窗口中，转到“自定义”选项卡以修改部分的布局。

若要了解有关表单自定义的详细信息，请点击这里。

注：您不能从“角色”选项卡编辑角色权限。
