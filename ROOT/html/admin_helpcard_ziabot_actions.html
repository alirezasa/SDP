Zia Bot helps users perform 20 different operations including raising tickets, assigning technicians to requests, accessing service catalogs, raising service requests, and viewing solutions/announcements, etc., by just typing a command or asking Zia via the chat box.

On this page, you can enable or disable the Zia Bot. Once enabled, the Zia Bot icon will be displayed at the right bottom bar for users and will show actions only as per the users' scope. When you enable the auto-open option, the Zia Bot will open automatically each time a requester logs in.

On the Actions List View, you can perform the following actions:

Enable or disable actions

Edit or delete actions using the hamburger button

Note: You can disable or delete only the actions that are NOT used within the workflow. For unused/disabled actions, you'll be able to view only the successor nodes.

You can edit each Action by clicking on the hamburger button or on the name of the action. This will display all the nodes where the action is used throughout the workflow. In this view, you can also select and view other actions from the drop-down on the header.

View History lists when Zia Bot was enabled and disabled, details about enabling, disabling, and deletion of specific actions, along with timestamp and role information.
