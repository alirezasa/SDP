On this page, you can search, add, delete, and assign roles to users. In addition, you can mark as VIP users and merge user accounts.


Adding Users


Individual Users

Click New, fill out the displayed form, and save.

Make sure you provide a unique login name for the self service portal.


User Roles:

While adding or editing a user, you can grant project roles, purchase approver roles, and service request approver roles for an user. You can also set a purchase amount limit for an approver to approve.


Import from Active Directory

Click Import from Active Directory, fill out the displayed form, and click Import.

If you've already entered the domain-related details in the Domain Scan page, they will be auto-populated. Otherwise, enter the details manually.


Add from a CSV file

Click Import from CSV, select the CI type, choose your file, and click Submit.


Assign Department/Roles

Select the users, click Actions, and select Assign to Department.

Select Site and Department Name from the drop-downs and click Associate.


Send Password Reset Link

You can send a password reset link to the users who have forgotten their passwords.
Select a user from the list view to go to the user's details page.
Click Actions menu in the details page and select Send Password Reset Link.
An email with the password link will be sent to the user. The link will be valid for 15 minutes.
Incase if the outgoing mail server is not configured, or if the user doesn't have a primary email ID, or if the user doesn't have a unique email ID, then the email will not be sent. In such cases, a popup with the password reset link will be displayed to the administrator who can share the link with the user.


Merge Users (without criteria)

Select duplicated or unique user accounts manually and merge them.

Select the user accounts and click Merge user(s) from the Actions drop-down.

Select the parent account and click Merge user(s).


Merge Duplicated Users (with criteria)

Merge accounts with duplicate Login Name or Email Address in different domains. Their attribute values will also be merged.

Click Merge user, select criteria to identify duplication as Login name or Email Address, enter the domain names (two domains/one domain and no domain labelled as None), and click Apply Filter.

The duplicate account pairs across the selected domains will be listed. Select the accounts to be merged and click Merge user(s).

Select the parent domain and click Merge user(s).


Following are common to both merge processes:

  • You can initiate a merge process only when no other merge process is underway.
  • All SDAdmins will be notified when a merge process is completed.
  • Site association of user assets will remain unchanged when you merge users from different sites.
  • After a merge process is completed, you can view its summary in notification or in Community>>System Log Viewer.

Note:

When you merge accounts without criteria, attribute values of the selected accounts will not be merged; instead, the parent account's attribute values will be retained. The only exception is the email address of the child account(s), which will be added to the parent account.


Deleting Users

Select users from the list view, click Actions, and select Delete User(s).

If you have enabled the GDPR settings under Privacy Settings, you can change the user names to any random text during deletion. This change will be effected across all modules within the application.
