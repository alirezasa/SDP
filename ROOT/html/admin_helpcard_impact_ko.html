영향도
 
영향도는 사건 또는 문제의 업무상 중요도를 측정한 것입니다. 영향도는 종종 영향을 받는 사람이나 시스템의 수로 측정됩니다.
기본적으로 목록 보기에는 네 가지 영향도 세부 정보가 나열됩니다. 영향도 세부 정보를 편집하려면 영향도 세부 정보 제목을 클릭합니다.
 
새 영향도 추가
 
페이지 오른쪽에 있는 새 영향도 링크를 클릭하십시오. 그러면 추가 영향도 세부정보 페이지가 열립니다.
주어진 텍스트 필드에 영향도의 이름을 입력합니다.
제시된 설명 필드에 해당 영향도에 대한 상세 정보 를 입력합니다.
변경 사항을 저장합니다.
저장하고 새로 추가 버튼을 클릭하여 영향도를 저장하고 다른 영향도를 추가합니다.
