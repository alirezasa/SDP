Flash Reports - Help

Using the new Flash Reports, you can view various reports based on Created Time, DueBy Time etc for a selected period. To use the Flash Reports follow the steps stated below.

1. Select the time based on which you need the report from the 'Filter' column
2. Select predefined time periods by selecting the "During" option or custom time periods by filling in the required from and to dates and click the 'OK' button
3. The report loads with information such as the total requests within the time period, the count of Pending, Completed and Violated requests.
4. You can further drill down from there based on the parameter of your choice. For example, if you wish to see the count based on technicians, click the technician button. This loads the split up based on the technicians

 INFO : Requires Flash version 9.0 and above
