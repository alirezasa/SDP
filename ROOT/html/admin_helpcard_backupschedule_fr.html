Planification des sauvegardes
 
Vous pouvez configurer la planification des sauvegardes de sorte que tous les fichiers seront sauvegardés à intervalle régulier.
 
Cliquez sur le lien Modifier la planification sur la droite de la page.
Activez la planification de sauvegarde en cliquant sur le bouton Activer. Pour désactiver la planification, cliquez sur le bouton Désactiver.
Sélectionnez le nombre de jours dans zone de liste déroulante pour planifier le processus de sauvegarde. Pour chaque nombre n de jours sélectionnés, la sauvegarde sera réalisée pour les données disponibles.  
Indiquez la date de début de sauvegarde à l’aide du calendrier. Sélectionnez également l’heure en heures et minutes dans la zone de liste déroulante. Ce champ est obligatoire.
En cas d’échec de la sauvegarde, indiquez l’adresse de notification par email, dans le champ prévu à cet effet. Ce champ est obligatoire.
Sélectionnez l’option Pièces jointes ou Base de données ou les deux pour effectuer la sauvegarde. Ce champ est obligatoire.  
Indiquez l’Emplacement de sauvegarde dans le champ de texte correspondant pour stocker les données de la sauvegarde.
Enregistrez les modifications.
