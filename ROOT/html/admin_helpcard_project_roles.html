Configure various Project Roles each with unique set of access permissions to be assigned to Project Members. These roles decide ‘which project member accesses what’ within the project. Project Role Examples: Project Admin, Milestone Supervisor, Task owner etc. By default there are four project roles, of which two are editable.


Add Project Role
The Add Project Role form has 4 fields: Name, Description, Inactive checkbox & Access Permissions Table.

Name: Specify a unique name to identify Project Role..
Description: Enter a short description about the Project Role in the Description field.

Inactive Checkbox: Enables project role inactivation; uncheck to activate role again..
Access Permission Table: Choose access permissions for the project role.

Click the Save button to save Project Role and return to the list view.
Click the Save and add new button to save Project Role and add another.
