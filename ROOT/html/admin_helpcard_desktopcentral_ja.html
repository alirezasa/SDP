Desktop Central連携 :

連携手順 : ビデオ | ヘルプ

ServiceDesk PlusとDesktop Centralを連携させることですべてのデスクトップやモバイル端末を管理することができます。Desktop Centralによってパッチのインストールやソフトウェアの展開、リモートコントロール管理、チャット機能、クライアントマシンの管理、USB制御などを自動化できます。さらにモバイル端末では、プロファイル管理やアプリ管理、セキュリティ管理、資産管理ができます。ServiceDesk PlusとDesktop Centralをインストールした場合、Desktop Centralがインストールされているコンピューターの情報（ポート番号など）を入力する必要があります。

メモ: Desktop Centralのバージョンは8.1以上である必要があります。

入力情報:

サーバー名:Desktop Centralがインストールされているサーバーを入力します。

ポート番号:Desktop Centralサーバーのポート番号を入力します。

プロトコル設定:プロトコル設定で"http"か"https"を選択します。

 

メモ:Desktop CentralとMDMのドロップダウンメニューを表示するには、"Desktop Centralメニューを有効にする"と"MDM（モバイルデバイス管理）メニューを有効にする"をそれぞれ選択します。Desktop Centralのビルド80100以上がインストールされていればメニューが表示されます。ドロップダウンメニューを表示させたくない場合は、チェックボックスの選択を外して保存してください。

 

設定が保存されると、ServiceDesk PlusとDesktop Central間での接続設定が完了します。一度完了すると、Desktop Centralサーバーから構成されたソフトウェア情報を取得します。


その他ManageEngine 製品との連携（HTTPS接続での起動時）

  1. .zip file を以下のリンクからダウンロードし、"ManageEngine\ServiceDesk"に展開します。

    2. For Linux: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1af3b3o2010mg10kbj961mdt18sq1/lincertgeneration.zip

    For Windows: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1af360niepdjr7j1flk1o323fa1/wincertgeneration.zip

  2. コマンドプロンプトに接続し、"ManageEngine\ServiceDesk"に進み、以下のようにバッチを実行します。

    3. For Linux:
    C:>ManageEngine\ServiceDesk>gencert.sh servername:portnumber

    For Windows:
    C:>ManageEngine\ServiceDesk>gencert.bat servername:portnumber

  3. コマンドを実行している際に、PKIX例外が発生したら、値を入力してください。値を入力すると、"ManageEngine\ServiceDesk"配下にjssecacertsという名称のファイルが生成されます。.

  4. jssecacertsファイルを"ManageEngine\ServiceDesk\jre\lib\security"フォルダー配下にコピーし、ServiceDesk Plusを再起動します。
