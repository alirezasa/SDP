SDP-ADMP 的集成:

SDP-ADManager Plus的集成，可以帮助AD的管理员和帮助台的技术员，充分利用这两款产品，来有效地管理其活动目录。利用它们，管理员可以从ServiceDesk Plus来重置AD中的用户密码、在AD中创建/删除/解锁用户，启用/禁用AD中的用户。

在ADMP中ServiceDesk Plus 服务器配置及认证:

必须在ADManager Plus中配置以下信息，确保ADMP和SDP能互相通讯。设置步骤为：ADMP >> 管理 >> 常规设置 >>ServiceDesk.

  • 服务器明细: 输入正在运行的SDP的服务器名称、端口号及通讯协议。
  • 选中 '启用紧密集成ServiceDesk Plus' 的选项，它将确保这两个产品的集成，并从SDP交换相关的任务。
  • 认证明细: 输入ServiceDesk Plus的登录名称及其相应的密码。点击 '测试连接并保存'，将检查SDP与ADMP之间的通讯连接，并保存所配置的信息。

这种集成只适用于在ADMP中被配置为帮助台技术员的SDP中的相应技术员。要将AD中的用户配置为SDP技术员：

  • 进入AD委派 >> 帮助台委派 >> 帮助台技术员 >>添加新的技术员
  • 然后选择域、AD用户、帮助台角色和组织单位。如果想让该技术员也作为管理员，选中'模拟管理员'选项。然后保存。

注意: ADMP 和 SDP中的相同技术员的登录名和域名，应保持一致。

在SDP中配置ADManager Plus服务器的信息:

  • 输入正在运行的ADMP的服务器名称、端口号和协议。
  • 点击测试连接并保存，将测试ADMP和SDP之间的连接，并保存所设置的信息。
  • 如要移除已经设置的配置信息，可点击移除按钮。

ADManager Plus的动作:将显示可用的动作列表及其描述，点击动作的编辑图标，可编辑相应的动作信息。

关联角色：可以选择所有角色或选择的角色。选择所有角色，将为所有技术员提供执行该动作的权限，而选择指定角色时，将显示SDP中的所有可用角色，管理员可以选择指定角色下的技术员，允许该相应的技术员执行该动作。

关联模板: 可以选择所有模板、或者所有事故模板、或者所有服务请求模板、或者选择的模板。当选定选择的模板时，需要指定模板。利用所指定的模板所创建的请求，在请求明细页面中的动作菜单中，将显示该动作。

从SDP中，在ADManager Plus创建用户:

根据不同请求模板所启用的动作，技术员在处理SDP的请求时，可以执行相应的动作。

例如: 当在请求明细页面中调用动作'Create user in AD'时，将弹出对话框，要求填写所需的字段（注意：这些字段需要在两个产品中进行精确匹配，建立映射关系），在提供相应的信息之后，点击创建ＡＤ用户，将会在ＡＤ中创建相应的用户。要添加更多字段，

  • 打开位于 [ADMP_Home] >> integration >> resources >> admp >> conf目录下的Admp.xml文件。
  • 点击"create_user" 菜单，包含所需要添加的附加字段（字段可以是文本／日期／精选列表类型）。

注意: 要包含该附加字段，需要预先知道在ADManager Plus中相应附加字段的ID。该ID的值可以在管理员指南中找到。

域配置:

对于SDP-ADMP集成，必须知道需要创建用户的域的信息。

  • 在SDP中，已有用户的域可以在 管理 >>技术员>> 登录明细 >> 选择域 中进行配置。
  • 在SDP中，可以在 管理 >> 发现 >> Window域扫描 的页面中添加新的域。
