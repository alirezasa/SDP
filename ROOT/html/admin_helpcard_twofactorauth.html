Two-factor authentication provides an extra layer of security besides passwords. In ServiceDesk Plus, two-factor authentication is available for login and admin configurations.

You can use any one of the following authentication methods.

  • Email Verification:

    A verification code will be sent to the user's email. The user will have use the code to authenticate.

  • Google Authenticator:

    Users will have to enter the code generated by the Google Authenticator app from their Android, Apple, or Blackberry phones.

  • Backup Verification Code:

    This code is used only for user logins when users do not have access to their mobile devices and other authentication methods.

Two-Factor Authentication for User Login

When you enable this option, user accounts must use the configured authentication method for logging in.

  • Choose the TFA criteria: users or user types.

  • To configure TFA for specific users, select the users from the combo box.

  • For user types, you can configure TFA for all users, only technicians or only requesters.

  • Switch between AND and OR operators for multiple criteria.

Two-Factor Authentication for Admin Configurations

When you enable this option, SDAdmins must use another authentication method to save any operation.

  • Users will be forced to enroll, if not already enrolled.
  • When an unenrolled user saves any operation, they will be enrolled.

Session Settings

When you enable two-factor authentication trust:

  • Admins will be able to configure the interval period for reauthentication.
  • All TFA-verified operations will be bypassed during the reauthentication interval.

Two-Factor Authentication for Portal-Specific Admin Configurations

Only a portal admin can enable TFA for portal configurations. However, this is possible only when an OrgAdmin has already enabled any of the authentication methods under the ESM Directory.

  • Once enabled, portal-specific configurations will be listed here
  • Enable any of the configurations listed for TFA

Portal-Specific Session Settings

When you enable two-factor authentication trust:

  • Portal Admins will be able to configure the interval period for reauthentication.
  • All TFA-verified operations will be bypassed in this portal during the reauthentication interval.
