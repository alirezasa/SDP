중복된 계정 병합

이 페이지에서 중복된 로그인 이름 또는 다른 도메인에 있는 이메일 주소가 있는 계정을 병합할 수 있습니다.

중복을 식별하는 기준을 로그인 이름 또는 이메일 주소로 선택하고 도메인 이름(2개의 도메인/1개의 도메인 및 없음으로 표시된 도메인 없음)을 선택하고 필터 적용을 클릭합니다.

선택한 도메인의 중복 계정 쌍이 나열됩니다. 병합할 계정을 선택하고 사용자 병합을 클릭합니다.

상위 도메인을 선택하고 사용자 병합을 클릭합니다.

병합 프로세스가 완료된 후 알림 또는 커뮤니티>>시스템 로그 뷰어에서 요약을 볼 수 있습니다.


참고 사항:

  • 진행 중인 다른 병합 프로세스가 없을 때만 병합 프로세스를 시작할 수 있습니다.
  • 병합 프로세스가 완료되면 모든 Admin에게 알림이 전송됩니다.
  • 사 용자 자산의 사이트 연결은 다른 사이트의 사용자를 병합할 때 변경되지 않은 상태로 유지됩니다.
