Integrate ChatGPT with ServiceDesk Plus to simplify help desk management and enhance Zia capabilities.

To enable the integration,

  • Select the Enable ChatGPT check box.
  • Enter your organization name, organization ID, and API key. Click the links beside the fields to obtain the respective credentials.
  • Enable the features that you would like to access via this integration.
    • Approval Prediction: Enable ChatGPT to act as a backup when Zia cannot predict approval actions.
    • Reopen Prediction: Set ChatGPT as a fallback option when Zia cannot predict reopening request actions.
    • Ask ChatGPT in Zia Bot: Access ChatGPT within the Zia bot.
    • Reply Assistant: Generate content, create replies, rephrase text, and check grammar when responding to or forwarding requests.
    • Request Summarization: Generate a summary of the request details.
    • Search Solution in Zia Bot: Search ChatGPT solutions in the Zia bot
    • Search Solution while creating request in the Zia Bot: Generate solutions while creating a request through the Zia bot.
    • Context-aware solution suggestion in Zia Bot: Provide solution summaries with reference solutions when reporting an issue, requesting a resource/service, or searching for answers through the Zia bot.
    • Template Prediction in Zia Bot: Predict templates while creating requests through the Zia bot.
