Vous pouvez également importer des utilisateurs depuis le serveur LDAP à l'aide de l'authentification LDAP. L'utilisateur aura a saisir ses identifiants LDAP si l'authentification LDAP est activé. Par défaut, l’authentification LDAP sera désactivée.

Remarque: Vérifiez que des utilisateurs ont été importés avant de passer à la configuraton de l'authentification LDAP. L'authentification LDAP prend en charge les utilisateurs Windows et Linux. Cela signifie que sous Windows, activer l'authentification LDAP aura pour effet de désactiver l'authentification AD.

Pour importer des utilisateurs depuis un nouveau domaine :

  1. Cliquez sur le bouton Ajouter un nouveau domaine dans la section Contrôleurs de domaine. Le formulaire Ajouter un nouveau contrôleur de domaine apparaît.
  2. Indiquez le contrôleur de domaine à partir duquel les utilisateurs doivent être importés dans le champ Contrôleur de domaine. Par exemple : ldap://<nom du serveur>:<numéro du port>. Le port par défaut est 389.
  3. Renseignez le Nom d'utilisateur et l'unité de l’organisation (OU) dans le champ prévu à cet effet. Par ex. : CN:john, CN=Utilisateurs, DC=nom du domaine, DC=com.
  4. Renseignez le Mot de passe dans le champ prévu à cet effet.
  5. Indiquez le ND de base réprésentant dinstinctement le nom de base, tels que CN = Utilisateurs, DC = nom de domaine, DC = com.
  6. Renseignez le critère à appliquer à un contrôleur de domaine dans le champ Filtre de recherche. Par exemple : mail=* les utilisateurs seront importés du message de paramètre dans le contrôleur de domaine spécifé.
  7. Sélectionnez le Type de serveur LDAP dans la liste déroulante. Par exemple : Ouvrir LDAP.

Remarque : Si vous avez choisi le Type de serveur comme LDAP par défaut (tels que Microsoft Active Directory, Novell eDirectory et OpenLDAP), le Libellé d'attributs de connexion, le Libellé d'attribut de messagerie et le Libellé du nom distinctif attribué ne seront pas modifiables.

  1. Si le Type du serveur LDAP est défini sur Autres, renseignez leLibellé d'attribut de connexion et Libellé d'attribut de messagerie dans les champs prévus à cet effet.
  2. Le Libellé du nom distinctif attribué est similaire au ND de base.
  3. Cliquez sur Enregistrer pour enregistrer le contrôleur de domaine. Cliquez sur Enregistrer et importer si vous souhaitez enregistrer et importer les utilisateurs.

Vous pouvez également importer des utilisateurs depuis le domaine existant. Pour ce faire, cliquez sur le bouton Importer maintenant des contrôleurs de domaine correspondants. Si les utilisateurs du domaine ont déjà été importés, les données existantes seront remplacées. Une fois les utilisateurs importés, cochez la case de l'authentification LDAP pour l'activer.

Cliquez sur Enregistrer. L'utilisateur peut désormais se connecter à l'application à l'aide de ses identifiants LDAP.
