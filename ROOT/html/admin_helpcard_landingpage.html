Instance Landing Page

Configure a default instance landing page to be shown to users or technicians as soon as they log in to the application.

Users

Under this, you can select a default module such as the Dashboard, Requests, Changes, Projects, Release, or Solutions to be displayed to the end users when they first log in.

If the selected module is not enabled for the user, then the home tab will be shown.

You can also configure to display a default request template to the users when they first log in. Use the Request template option and select a template from either the incident template list or service template list.

Click Save.

Technicians

Under this, you can select a default module such as the Dashboard, Requests, Changes, Projects, Release or Maintenance, Assets, Admin, etc., to be displayed to the technicians when they first log in. In addition to that, you can also choose to set a default view under Home for technicians. The available options include: My View, Scheduler, Backup Approver, Resource Management, All my Pending Approvals.

You can also configure to display a default request template to the technicians when they first log in. Use the Request template option and select a template from either the incident template list or service template list.

You can also allow the technicians to configure their own instance landing page under User Profile > Instance Landing Page. Use the relevant option.

Note: If the configured request template is deleted, the default request template will be displayed.
