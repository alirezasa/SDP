여기에서 새 서비스 데스크 인스턴스를 만들고 동일한 인스턴스에 대한 담당자를 지정할 수 있습니다. 조직 관리자(Org Admin)는 자신을 인스턴스 담당자로 추가하거나 다른 사용자를 담당자로 선택할 수 있습니다. 인스턴스 담당자는 해당 인스턴스에 대한 인스턴스 구성 권한과 함께 .Admin 관리자 권한을 갖습니다. 기본적으로 IT 서비스 데스크 인스턴스만 나열됩니다.

새 인스턴스를 만들려면 새 인스턴스 버튼을 클릭하고 필요한 필드를 작성하십시오.

이 페이지에서 특정 인스턴스의 이름, 설명, 담당자, 상태, 관련 라이선스를 편집할 수도 있습니다. 인스턴스의 담당자인 경우에 편집할 수 있습니다.

기술자 라이선스 배정

기술자가 2개의 인스턴스에 속하려면 2개의 기술자 라이선스가 필요합니다. 즉, 사용자가 두 가지 경우에 기술자로 추가되면 해당 사용자에 대해 두 개의 기술자 라이선스가 사용됩니다.
인스턴스의 다른 상태는 다음과 같습니다.

신규: 새로 생성된 모든 인스턴스의 기본 상태는 신규입니다.

사전 프로덕션: 인스턴스에 담당자를 지정하고 담당자가 인스턴스에 로그인하면 상태가 프로덕션 전으로 변경됩니다. 이 시점에서 인스턴스는 담당자에게만 표시됩니다.

프로덕션: 라이선스가 인스턴스에 적용된 후 인스턴스 담당자는 상태를 프로덕션으로 변경할 수 있습니다. 인스턴스 담당자가 모든 구성을 완료하고 상태를 프로덕션으로 이동하면 인스턴스가 최종 사용자(인스턴스에 추가된 사용자)에게 표시됩니다.

사용 중지됨: 사용 중지된 인스턴스는 이 상태로 이동됩니다. 사용 중지되면 인스턴스는 읽기 전용 모드로 전환되고 인스턴스 담당자만 액세스할 수 있습니다. 인스턴스가 사용 중지됨 상태로 이동되면 다시 프로덕션 상태로 이동할 수 없습니다.

라이선스 만료됨 : 인스턴스 라이선스가 만료되면 이 상태로의 전환이 시스템에 의해 자동으로 수행됩니다. 인스턴스는 읽기 전용 모드로 바뀌고 이 상태에서는 인스턴스 담당자에게만 표시됩니다. 라이선스가 적용되면 상태가 자동으로 프로덕션으로 바뀌고 최종 사용자가 인스턴스에 액세스할 수 있습니다.

참고:

    서비스 데스크 인스턴스는 최대 50개까지만 생성할 수 있습니다.
    IT 서비스 데스크의 상태는 변경되지 않습니다.

인스턴스의 관리자 설정을 구성하려면 각 인스턴스 내의 Admin 관리자 탭으로 이동하십시오.
