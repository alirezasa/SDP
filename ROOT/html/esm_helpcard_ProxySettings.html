Secure connection or interaction between your organization and other servers by setting up a proxy server.

Provide the following details while configuring Proxy Settings:

Host : Specify name of the proxy server (example: servicedesk-1212)

Port : Specify port number of the proxy server (example: 8080)

User Name : Specify username for the proxy settings (example: servicedesk)

Password : Specify password for the proxy settings

If the proxy configurations are entered incorrectly, the following features are affected:

  • Mail Server Settings (Incoming/Outgoing)
  • Analytics Plus/Zoho Reports Integration
  • System Updates
  • SMS Notification Settings
  • Other Integrations
