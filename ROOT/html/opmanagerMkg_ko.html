OpManager와 통합

ServiceDesk Plus를 ManageEngine OpManager와 통합하고 네트워크를 효과적으로 모니터링하십시오. OpManager는 대기업, 서비스 제공업체 및 중소기업이 데이터 센터와 IT 인프라를 효율적이고 비용 효율적으로 관리하는 데 도움이 되는 네트워크 및 데이터 센터 인프라 관리 소프트웨어입니다. 자동화된 워크플로, 지능형 경고 엔진, 구성 가능한 검색 규칙 및 확장 가능한 템플릿을 통해 IT 팀은 설치 후 몇 시간 내에 24x7 모니터링 시스템을 설정할 수 있습니다. 이 두 제품을 모두 설치했다면 OpManager가 설치된 컴퓨터의 세부 정보와 포트 번호만 제공하면 됩니다.

제공해야할 정보:

서버 이름:OpManager 가 설치된 서버이름을 입력하십시오.

서버 포트: OpManager 서버의 포트 번호를 입력하십시오.

프로토콜 설정: 프로토콜 설정을 선택하십시오. http 혹은 https.

 

저장을 클릭하십시오. 설정이 성공적으로 저장되고 ServiceDesk Plus가 OpManager 서버와 연결을 시도합니다. 연결이 설정되면 해당 링크로 점프하여 OpManager 서버를 사용할 수 있습니다.

 


다름 ME 제품 통합 (HTTPS mode에서 운영 중인)

  1. 아래 링크에서 .zip 파일을 다운로드하고 "ManageEngine\ServiceDesk"에 압축을 풉니다.

    2. Linux 용: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1cb6g423n1gp9135o97nfchub1/lincertgeneration.zip

    Windows 용: https://uploads.zohocorp.com/Internal_Useruploads/dnd/ServiceDesk_Plus/o_1cb6g2tdh126s6hmhpvjja2si1/windowscertgeneration.zip

  2. 명령 프롬프트에 연결합니다. "ManageEngine\ServiceDesk"로 이동하여 다음 형식으로 배치 파일을 실행합니다.

    3. Linux 용:
    C:>ManageEngine\ServiceDesk>gencert.sh 서버 이름:포트 번호

    Windows 용:
    C:>ManageEngine\ServiceDesk>gencert.bat 서버 이름:포트 번호

  3. 명령을 실행하면 PKIX 예외가 발생한 다음 값을 입력하라는 메시지가 표시됩니다. 1 을 입력하면, "ManageEngine\ServiceDesk" 아래에 jssecacerts라는 파일을 생성하게 됩니다.

  4. "ManageEngine\ServiceDesk\jre\lib\security" 폴더 아래의 jssecacerts 파일을 복사한 다음 ServiceDesk Plus 애플리케이션을 다시 시작합니다.
