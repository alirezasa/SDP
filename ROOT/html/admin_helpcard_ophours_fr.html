Vous pouvez définir les horaires d'ouverture de votre organisation. Les horaires d'ouverture d'un site dépend du fuseau horaire défini pour lui. Cette information est employée pour le calcul du temps d’exécution d’une requête de service basé sur le SLA et la priorité applicable à la requête.

  1. Sélectionnez le site pour lequel vous souhaitez définir les heures d'ouverture dans la liste déroulante Horaires d'ouverture pour Par défaut, les horaires d'ouverture sont enregistrées dans les Paramètres par défaut.

Remarque : L'administrateur du site peut sélectionner les sites auxquels il est associé depuis la liste modifiable Horaires d'ouverture. Si les sites non configurés dans Admin- Sites n'apparaîtront pas dans la liste modifiable Horaires d'ouverture.

  1. Si vous organisation travaille 24 heures sur 24, cochez la case correspondante. Si vous ne travaillez pas 24 heures sur 24, sélectionnez le bouton d’option à côté de Sélectionner les horaires d'ouverture. Dans les zones de liste déroulante de l'heure pour Heure de début et Heure de fin, sélectionnez les valeurs appropriées.

  2. Sélectionnez les jours ouvrables de votre équipe d'assistance en cochant les cases correspondantes.

  3. Pour enregistrer les informations saisies, cliquez sur Enregistrer.
