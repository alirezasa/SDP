项目角色是不同的访问权限的总称，可以配置不同的角色权限，以便指派给不同的项目成员。这些角色决定了“哪些项目成员可以访问项目下的哪些具体内容”，如：项目管理员、里程碑监察员、任务所有者等。默认情况下，有4个项目角色，其中两个是可编辑的。

添加项目角色
在添加项目角色的画面中有4个字段，它们是：名称、描述、休眠复选框和访问权限表。

名称:  各个角色的识别符，请指定唯一的名称，不能重复。
描述: 输入该角色功能的简要描述。

非活动复选框: 选中它，则角色休眠，不选则该角色重新激活。
访问权限表: 为该项目角色选择访问权限。

点击保存按钮，保存该角色，返回至列表视图。
点击保存并新建按钮，则保存目前的角色后，再创建新的角色。
