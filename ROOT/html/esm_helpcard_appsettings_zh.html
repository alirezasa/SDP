应用程序设置

在此页面上，您可以配置适用于整个应用程序的设置。

别名URL

您可以在http: //文本旁边的文本字段中为应用程序服务器提供备用URL（如果需要，还提供端口号）。单击文本字段下方的在新窗口中打开别名URL链接，以检查别名URL是否有效。

显示语言

从下拉列表中选择应显示语言，浏览器默认语言是英语。 

其他定制

使用给出的各种配置来自定义服务台。

选项 '是' '否'
未将用户导入应用程序时是否允许动态添加用户？ 当用户未导入到应用程序中而是通过AD导入时，该用户可以使用AD凭证登录到应用程序。这将自动提供对应用程序的登录访问。 当未将用户导入应用程序时，启用“否”将阻止动态添加用户。
允许自动生成API密钥 启用“是”允许自动生成API密钥。 停止自动生成API密钥。
根据电子邮件ID覆盖用户信息？ 使用Active Directory，CSV和LDAP导入用户时，现有用户信息将基于两个条件被覆盖-第一个条件基于用户名和域，第二个条件基于电子邮件ID。 除非给予足够的特权，否则不允许请求人重新打开自己的请求。
是否提供对通过电子邮件请求创建的用户的登录访问权限？ 首次发送电子邮件请求时，将自动为用户提供登录访问权限。 如果启用“否”，则不会为通过电子邮件请求创建的用户提供登录访问权限。
允许用户基于本地身份验证登录吗？ 允许用户使用本地身份验证登录到应用程序。 启用“否”将阻止用户基于本地身份验证登录
处理从新电子邮件地址收到的电子邮件？ 可以将来自新电子邮件地址的邮件提取到应用程序中。 可以防止来自新电子邮件地址的邮件被提取到应用程序中。

用户的个人资料可访问性

选择您希望用户从其个人资料访问的信息。
您可以从以下三个选项中进行选择：

    • 编辑个人资料：启用此选项后，用户即可编辑其个人资料。
    • 查看基本信息：用户仅可以查看基本信息。
    • 查看附加字段：用户能够查看在附加字段中输入的信息。

添加用户到实例

默认情况下，技术员无法手动将新用户添加到其实例。要在特定实例中启用手动添加用户，您需要选中允许技术员在实例中创建新用户。此选项将在所选实例中向用户角色添加一个名为添加请求人的新设置。使用此设置配置角色，将其与所需的技术员相关联。

文件附件：

您可以选择在ServiceDesk Plus中设置入站/出站邮件附件的最大大小。默认情况下，附件大小为10 MB。附件可以单独保存在指定目录中。如果未指定路径，则附件保存在默认目录中。

标头图片自定义

您可以使用自定义图像替换默认标题图像。单击使用自定义图像，然后单击更改图像 >>  选择文件 >>  导入以上传自定义图像。标头图片的尺寸需要为166 px（x）46 px（W x H）。

登录页面自定义

根据您的要求自定义登录页面，可以上传背景图片，添加样式，修改html文件以适合您的要求。单击立即定制，HTML编辑器打开，您可以在显示的编辑器中进行修改。

注意：登录页面图像的尺寸应为252 px X 61 px（W x H）。
保存设置后，更改将立即生效。如果要放弃所做的所有更改，可以单击右上角的还原为默认值。
