Vous pouvez définir les champs propres à votre licence qui doivent apparaître dans le formulaire de nouvelle licence logicielle en plus des champs prédéfinis. Vous pouvez ajouter des champs de type texte, des champs de type numérique, des champs de type date/heure et des champs de type coût dans le formulaire. Sélectionnez chaque onglet et renseignez le nom du libellé et la description des champs à ajouter au formulaire de licence du logiciel.

Lors de l’ajout de champs texte, vous disposez d’une option pour choisir le type de champ de texte. Le champ de texte peut être un champ de texte à une seule ligne, un champ de texte à plusieurs lignes ou une liste déroulante. Cochez la case appropriée. Lors de l'ajout de champs de coût, vous pouvez sélectionner Ajouter un coût ou Soustraire un coût en cochant la case appropriée.

Si vous voulez ajouter une valeur par défaut pour ces champs, vous pouvez le faire dans le champ de texte prévu à cet effet.

Pour enregistrer les informations saisies, cliquez sur Enregistrer.
