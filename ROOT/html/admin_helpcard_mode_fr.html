Une requête d’assistance peut être soumise à votre équipe d’assistance de plusieurs façons et cela sera suivi dans ServiceDesk. Les modes par lesquels vous pouvez soumettre votre requête d’assistance sont :

1. En soumettant la question à l’aide d’un formulaire par Internet de nouvelle requête.
2. En plaçant votre requête lors d’un appel téléphonique à un agent du service d’assistance qui enregistrera la requête à son tour.
3. En envoyant un email à l’équipe d’assistance, qui sera automatiquement enregistré comme une requête d’assistance dans ServiceDesk.

Pour ajouter un nouveau mode, cliquez sur le lien Ajouter un nouveau mode dans l’angle droit du tableau Liste des Modes.

Ajouter un nouveau mode
Le formulaire Ajouter un nouveau mode a deux champs, à savoir Nom du mode et Description.

Dans Nom du mode vous indiquez le nom unique qui est utilisé pour identifier chaque mode.

Vous pouvez saisir une brève description du mode dans le champ Description. Cela peut aider à comprendre comment la requête d’assistance générée dans ce mode est suivie dans ServiceDesk.

Pour enregistrer le mode et revenir à l’affichage liste, cliquez sur le bouton Enregistrer.
Pour enregistrer le mode et en ajouter un nouveau, cliquez sur le bouton Enregistrer et ajouter un nouveau.
