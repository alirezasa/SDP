요청서 상태는 요청서를 해결하고 종료하기 위해 수행되는 액션을 기반으로 한 요청서의 진행 수준을 나타내는 데 사용되는 옵션입니다. 다양한 상태의 요청서을 그룹화하면 요청서를 적절하게 편성하여 혼란을 줄일 수 있습니다.

새 상태를 추가하려면 상태 목록 표의 오른쪽 모서리에 있는 새 상태 추가 링크를 클릭하십시오.

새 상태 추가
위에 표시된 상태 추가 양식에는 이름, 유형 및 설명이라는 필드가 있습니다.

상태 이름은 각 상태를 식별하는 데 사용되는 고유한 이름을 입력하는 곳입니다.

상태 유형을 사용하면 추가 중인 해당 상태가 아직 진행 중인지 여부를 식별할 수 있으므로 진행 중인 요청서의 일부여야 하는지 아니면 종료된 요청서로 이동해야 하는지 여부를 식별할 수 있습니다. 추가된 상태가 요청서 타이머를 중지해야 될 필요가 있으면, 타이머 중지 확인란을 설정해야 합니다. 설명 필드에 상태에 대한 설명을 입력할 수 있습니다. 이렇게 하면 각 상태 이름 자체가 스스로 설명하지 않는 경우를 제외하고, 각 상태의 의미와 어느 요청서가 이 상태로 분류되어야 하는 지를 파악하는 데 도움이 됩니다.

상태 색상: 색상 팔레트를 사용하여 상태를 나타내는 색상을 선택하거나 텍스트 상자에 색상 코드를 지정합니다.

저장 버튼을 클릭하여 상태를 저장하고 목록 보기로 돌아갑니다.
저장하고 새로 추가 버튼을 클릭하여 상태를 저장하고 다른 상태를 추가합니다.
