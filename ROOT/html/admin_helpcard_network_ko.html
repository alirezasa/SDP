네트워크 스캔을 사용하여 기업 망의 일부 네트워크를 탐색하고 정기적으로 스캔하십시오. Windows, Linux, MAC, Solaris 및 AIX 워크스테이션 과 같은 다양한 운영 체제를 스캔하는 것 외에도 네트워크 탐색을 통해 SNMP 장치 및 VMware 시스템도 스캔할 수 있습니다.


새 네트워크 추가
Linux, MAC, Solaris, IBM-AIX

  1. 새 네트워크 추가링크를 클릭합니다.

  2. 스캔 범위 결정: 전체 네트워크를 스캔하거나 스캔을 위해 특정 IP 주소 범위를 제시할 수 있습니다.

  3. 네트워크 주소를 입력하십시오.

    • 전체 네트워크를 스캔하려면 IP 주소를 192.168.27.0과 같이 제시해야 합니다.
    • 네트워크의 일부를 스캔하려면 다음과 같이 IP 주소 범위를 제시해야 합니다.: 192.168.27.0 - 192.168.27.30

  4. 적절한 설명을 입력하십시오.

  5. Windows, Linux 및 Mac 시스템을 스캔하려면 에이전트 구성이 필요합니다. 에이전트 구성을 클릭하여 에이전트를 다운로드하십시오. 자세한 내용은 에이전트 구성 페이지 도움말 카드를 참조하십시오.

  6. 네트워크의 다른 서브넷을 스캔하기 위한 네트워크 스캔 자격 증명을 지정합니다. 자격 증명 라이브러리에 추가된 스캔 자격 증명은 이 팝업에서 선택할 수 있습니다. 스캔 자격 증명을 추가하지 않은 경우 새 스캔 자격 증명 추가 아이콘을 클릭하여 추가할 수 있습니다. 새 스캔 자격 증명을 추가하는 방법을 알아보려면 자격 증명 라이브러리 도움말 카드를 참조하십시오.

  7. 저장(또는) 지금 저장하고 스캔을 클릭하여 네트워크를 즉시 스캔합니다.

네트워크 스캔

  1. 네트워크 목록 보기 페이지에서 네트워크 스캔 아이콘을 클릭합니다.

  2. 조직이 여러 사이트에 분산되어 있는 경우 워크스테이션/장치가 연계된 사이트를 선택하십시오.

  3. 스캔 시작을 클릭합니다. 스캔이 완료되면 스캔의 성공 및 실패한 워크스테이션에 대한 전체 보고서를 받게 됩니다.

편집 및 삭제 아이콘을 클릭하여 네트워크를 편집 및 삭제할 수도 있습니다.
