Details Tab

To start setting up your problem template, enter the following basic details of your template. This information will be displayed to all users who can access the template:

  • Enter a template name. This is mandatory.
  • Add a description for the template.

By default, the Details tab is displayed first when you add or edit the problem template. It allows you to design the problem request form to be displayed to technicians. You can add various fields, and color-code the form.

After saving the template details, the Tasks tab will be displayed.


Configure Fields

You can add built-in default fields, create new fields to fit your requirements, or add additional fields created previously.

  • Add default fields - Drag and drop the default fields to the required location in the canvas.
  • Create new fields - Click the Add New Field icon on the left panel. The available field types will be listed. Drag-and-drop a field type to the canvas, configure, and save the field properties. To learn how to configure problem additional fields, click here.
  • Add Additional Fields - Additional fields configured for the Problem Management will be listed in the left panel under Custom Fields. Drag-and-drop them as required.


Configure Sections

To group your fields into sections:

  1. In the left panel, click Add New Field icon.
  2. From the Section Types heading, you can drag and drop a section to your canvas based on the number of columns needed (Single Column, Double Column, Three Column, or Four Column). To customize the columns on the go, select Flexible Column.
  3. Sections in problem templates have predefined names. You can edit the section name and properties by hovering over the section name and clicking the Edit Section icon. Sections without a title will not be displayed distinctly in the problem form.
  4. Click Save.


Note: Site,Technicians, Created Date, Completed Date, Title, and Description are added to problem templates by default. These fields can be relocated within the form but they cannot be deleted.


Customize Form Layout

You can customize the layout of the template and sections to highlight important elements of the template. You can customize the font, including its size and color, background color, and field orientation.

To customize the template, click the Customization icon displayed on the top-right of the canvas. To customize a section or field, hover over the respective element and click the Edit icon. In the pop-up window, go to the Customization tab to modify the layout of the element.

To learn more about Form Customization, click here.


Tasks Tab

The work involved in the problem management can be broken down into tasks and assigned to various technicians from the Tasks tab.

  • Use Associate button to associate a task template to the problem template. You can also create a new task template if needed.
  • Click Dependencies to associate parent tasks and child tasks.
  • Set the order of task execution by selecting Organize.
  • To delete associated task templates from the problem template, select the task templates and click the Delete icon on the toolbar.
