웹후크

이 페이지에서 외부 URL 또는 API를 호출하여 ServiceDesk Plus와 타사 애플리케이션 간의 통신을 용이하게 하는 웹후크를 만들 수 있습니다.

SDAdmin만이 웹후크을 정의할 수 있습니다.

웹후크 만들기

  • 웹후크의 고유한 이름과 설명을 입력합니다.
  • 해당 드롭다운에서 필요한 Pre Function 및 Post Function을 선택합니다.
  • 필요한 HTTP 메서드를 선택합니다.
  • API URL을 입력하고 URL 매개변수 및 Request Headers를 입력합니다.
  • 인증 세부 정보 유형을 선택합니다.
  • Request Payload를 입력하고 드롭다운에서 콘텐츠 유형을 선택합니다.
  • 새 웹후크를 만들려면 저장을 클릭하십시오.

목록 보기 액션

웹후크를 생성, 편집, 삭제, 활성화, 비활성화 및 테스트할 수 있습니다.

여기를 클릭하여 자세히 알아보십시오.
