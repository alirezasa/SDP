Organization Roles lets you configure roles that are specific to the Organization, Departments, Sites and Regions.

Creating Roles and Associating users.

The roles can be created by clicking on the Plus icon present in all the four cards.

To add a new role,

  • Click onin the respective card such as Organizational roles card/Regional Roles card.

    For eg, For Organizational roles such as the CEO/COO, click the plus icon in the Organizational roles card.

  • Enter the Role Name and the Description.
  • Click Save. Same applies for the other three Role types.

Note: The Role Name is mandatory.

To associate users to the roles,

  • Click onin the cards.
  • Select an user and click on Associate User.
  • The users can be searched by their User Names, Email Address.

Managing the roles.

The roles created can be edited or deleted.

  • Usepresent in the role cards to edit the roles.
  • Similarly useto delete a role.
  • To remove/change an user associated to a role, click on Associate user icon.
  • Select a new user and click Save.

Note: If you delete a Role, all the user associations will get deleted as well.

Facts:

  1. All the created roles will be listed in the respective cards. The roles/users can be edited from that list as well.
  2. Character length for a Role name should not exceed 48. For Description it should not exceed 250.
