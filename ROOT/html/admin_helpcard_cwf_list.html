Establish a directional path for the change process to adhere to using change workflow. You can define workflows for different change requests specific to your organization, associate them with change templates, and provide privileged (role-based) access for technicians to change stages.
Click New Workflow. In the workflow editor, you can add the change stages, specify conditions and switches, configure notifications, approval and field updates using nodes. Connect the source and target nodes using your cursor to specify the workflow path.
  • Using the Hamburger icon, you can edit, copy, delete a change workflow, set as default or mark the workflow type.
  • You can also copy a workflow by selecting the workflow and clicking the Copy Workflow button.
  • View the template(s) associated with a workflow by clicking the Link icon beside the workflow.
  • To delete the change workflow in bulk, select the workflows and click the Delete icon.

Note:

If a change workflow is deleted while being used in change requests, the workflow will be disabled. Edit an inactive workflow to restore it.
You cannot disable or delete the default workflow.
If a configuration used by the workflow is updated in admin configurations, the workflow becomes invalidated. Invalidated workflows are indicated with an Exclamatory icon. You cannot perform any operations on invalidated workflows, except edit or delete.You can find the reason for the workflow becoming invalid in the history.
