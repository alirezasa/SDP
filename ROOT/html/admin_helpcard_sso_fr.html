Connexion unique
 
Une fois l’authentification unique activée, ServiceDesk Plus authentifie directement votre nom d’utilisateur et votre mot de passe système Windows. Par la suite, il ne vous sera plus nécessaire de vous authentifier dans ServiceDesk Plus.
 
Remarque :
  • Tous les utilisateurs d’Active Directory ont été importés pour activer l’authentification unique.
  • Le domaine activé devra être sécurisé dans les deux sens.
  • L’authentification unique ne fonctionne que dans Windows Internet Explorer.
Activation de l’authentification unique
 
Une fois que vous aurez importé tous les utilisateurs depuis Active Directory, le bouton Activer est disponible sur la page.
Pour activer l’authentification unique, cliquez sur le bouton Activer. Par défaut, vous pourrez uniquement vous identifier en tant qu’invité. Pour vous attribuer le rôle de technicien, l’administrateur devra sélectionner les techniciens dans la liste des demandeurs.
