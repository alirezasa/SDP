L’équipe du service d’assistance informatique comprendra le responsable du service, l’agent et des techniciens qui traite les requêtes postées/signalisées par les employés dans l’organisation. Ces utilisateurs sont importés et ajoutés comme demandeurs dans l'application. Vous pouvez ajouter, modifier, supprimer les demandeurs dans l’application et leur concéder des autorisations de connexion pour accéder à l’accueil du portail libre-service. Ces demandeurs peuvent être ajoutés manuellement, importés depuis Active Directory ou un fichier CSV.
 
Pour importer les demandeurs depuis Active Directory

  1. Cliquez sur le lien Importer depuis Active Directory. Le formulaire Importer depuis Active Directory s’affiche à l’écran.

  2. Sélectionnez le Nom de domaine où l'active directory à importer est installé. Si des données comme le contrôleur de domaine, le nom d’utilisateur et le mot de passe du nom de domaine ont déjà été saisies dans la page Analyse du domaine, elles apparaîtront automatiquement. Dans le cas contraire, renseignez le Contrôleur de domaine et les identifiants de connexion du niveau de domaine dans le champ Nom de connexion et Mot de passe.

  3. Vous pouvez également sélectionner les champs à importer depuis AD : service, nom du site, etc. Le nom des champs configurés dans Active Directory peuvent être renseignés dans les zones de texte correspondantes. Les champs non sélectionnés ne seront pas importés.

  4. Cliquez sur Importer maintenant ! L’assistant d’importation affiche les unités de l’organisation (OU) disponibles dans ce domaine. Choisissez l’OU dont vous souhaitez importer des utilisateurs en sélectionnant la case correspondante.

  5. Cliquez sur Commencer l’importation. Une fois l'importation terminée, un enregistrement affiche le montant de données ajouté, remplacé et en échec.

  6. Cliquez sur Fermer la fenêtre.

Si les informations des demandeurs proviennent d'un fichier CSV, sélectionnez le lien Importer depuis CSV. L’assistant d’importation s’affiche dans une fenêtre à l’écran. Suivez les instructions de l’assistant pour importer les données des demandeurs à partir du fichier CSV.

 

 

Ajouter un nouveau demandeur 

Cliquez sur le lien Ajouter un nouveau demandeur pour ajouter manuellement un nouveau demandeur.

    • Informations personnels : Renseignez le Nom du demandeur, l'Identifiant d'employé et une brève Description du rôle du demandeur. Le champ Nom est obligatoire.

    • Informations sur le contact : Renseignez les informations de contact du demandeur : E-mail, Téléphone et Numéro de mobile.

    • Informations sur le service :La liste déroulante Site s'affiche si les sites sont configurés dans l'application.Sélectionnez le Site et le Nom du service correspondant dans la liste déroulante.

    • Les demandeurs ont plusieurs options d'affichage : leurs demandes uniquement, toutes les demandes de leur service, toutes les demandes du site auquel ils sont associés. Sélectionnez l'option correspondant dans la liste déroulante Demandeur autoriser à afficher Renseignez également le Titre de la tâche du demandeur.

    • Informations supplémentaires sur le demandeur :S’il existe des champs définis par utilisateur supplémentaires, ils apparaîtront dans cette section. Saisissez-y les renseignements requis.

    • Détails de l’accès libre-service : Renseignez les identifiants de connexion pour accéder au portail libre-service dans les champs Nom de connexion et Mot de passe. Saisissez à nouveau le mot de passe. Le nom de connexion doit être unique. Sélectionnez, dans la liste déroulante, le Domaine auquel le demandeur appartient.
      Certains demandeurs ont la possibilité d'Approuver les bons de commande d'une organisation. Si cette option est activée, un lien sera envoyé au demandeur pour lui proposer d'accepter ou rejeter le bon de commande. De la même manière, les demandeurs ont la possibilité d'Approuver les demandes de service créées dans l'application.
      Pour enregistrer le demandeur et revenir à l’affichage liste, cliquez sur le bouton Enregistrer.
      Pour enregistrer le demandeur et en ajouter un autre, cliquez sur le bouton Enregistrer et ajouter nouveau.


Supprimer des demandeurs

Dans la page de liste des demandeurs, cochez la case du demandeur à supprimer.

Cliquez sur le bouton Actions -> option Supprimer un/des demandeurs. Une fenêtre apparaît pour confirmer la suppression. Cliquez sur OK pour confirmer. Le demandeur est supprimé de la liste.

 

Assigner à un service

Vous pouvez assigner plusieurs demandeurs à un service en une seule fois en cochant les cases correspondantes.

Cliquez sur le bouton Actions -> option Attribuer à un service. La fenêtre Associer un/des demandeurs à un service apparaît.

Sélectionnez le Site auquel vous souhaitez attribuer le(s) demandeur(s) dans la liste déroulante.

Sélectionnez le Service correspondant au site dans la liste déroulante. Cliquez sur Associate. Le(s) demandeur(s) sont associés au service.

 

Modifier comme technicien 

Vous pouvez transformer un demandeur en technicien et lui définir des rôles.
Cliquez sur le nom du demandeur dans l'affichage liste.
Cliquez sur le bouton Modifier comme technicien dans le formulaireModifier le demandeur. Le demandeur est modifié comme technicien et le formulaire de modification de technicien s’affiche.
Attribuer un Rôle au technicien et renseignez la valeur Coût par heure.  
Cliquez sur Enregistrer. Si vous ne souhaitez pas modifier le demandeur en technicien, cliquez sur Annuler au lieu de Enregistrer.

 

Afficher les demandes par

Pour afficher la liste des demandes soulevées par un demandeur :

Cliquez sur le nom du demandeur dans l'affichage liste. Cliquez sur le bouton Afficher la requête. La page de liste des demandes comportant celles créées par le demandeur apparaît.   

 

Associer des stations de travail

Vous pouvez également associer des stations de travail au demandeur. Dans la page Modifier un demandeur, cliquez sur le bouton Associer une station de travail.

Sélectionnez les stations de travail à associer avec le demandeur dans la fenêtre Associer une station de travail, dans la Liste des stations de travail , et déplacez-les dans la liste Stations de travail associées en cliquant sur le bouton >>. Pour dissocier des stations de travail, sélectionnez-les dans la liste Stations de travail associées et cliquez sur le bouton <<. Si vous voulez dissocier toutes les stations de travail, cliquez sur Dissocier tout.

Cliquez sur Enregistrer une fois les stations de travail associées.Un message s'affiche. Cliquez sur le bouton Fermer.
