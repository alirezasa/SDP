ServiceDesk PlusとMicrosoft Teamsの連携

ServiceDesk PlusとMicrosoft Teamsを連携することで、ITサポート、エンタープライズサポートの追加チャネルとしてMicrosoftのアプリケーションを活用することができます。連携することにより、Microsoft　Teamsのアカウントから、ServiceDesk Plusのチケットや保留中の承認を確認したり、ヘルプデスクの技術担当者とチャットしたりすることができます。


連携を設定する方法

  1. Microsoft Teamsのアカウントで生成した、アプリケーションパスワードを入力します。
  2. Azureポータルで生成した、ServiceDesk PlusボットのアプリケーションIDとテナントIDを入力します。
  3. 「SDP にホストされたドメイン」下に、SercviceDesk Plusに設定されたエイリアスURLが自動的に入力されます。ただし、ServiceDesk PlusとMicrosoft Teamsを両方インストールしている場合は、Microsoft Teamsがインストールされているコンピュータのドメインを入力しなおす必要があります。
  4. 設定を送信すると、リダイレクトURLとボットエンドポイントが自動的に生成されます。リダイレクトURLとボットエンドポイントは、こちらにしたがって、ServiceDesk Plusボットに設定します。

設定を送信すると、「Microsoft Teamsを有効にする」という新しいチェックボックスが有効化された状態で自動的に生成されます。

注意：Microsoft Teamsで利用される、ServiceDesk Plusボットのコマンドについては、こちらをご覧ください。


連携を更新/解除する方法

連携の設定を更新するには、変更内容を入力し［更新］をクリックします。

設定中に連携を解除するには、連携ページ上部の「Microsoft Teamsを有効にする」のチェックボックスのチェックを外します。

連携を完全に削除するには、ページ下部の［削除］をクリックします。連携を削除すると、全ての設定が完全に削除され、復元できなくなりますので注意してください。
