조직 내의 모든 사용자를 다양한 사용자 그룹으로 분류할 수 있습니다. 사이트 기반 구현에서 사용자를 그룹으로 분류하는 것은 사용자가 특정 항목에 액세스하는 것을 방지하기 위해 특히 필요합니다.

예를 들어, 공지 사항 - Nortel 네트워크가 New York 사이트의 유지 보수 관리로 인해 하루 동안 다운되었습니다. 이 발표는 New York 사이트의 사용자에게만 중요합니다. 공지 사항이 New York 사이트와 연결된 사용자만 사용할 수 있도록 사용자 그룹이 생성됩니다. 사용자 그룹은 부서, 이메일 ID, 직위 및 이름을 기준으로 필터링할 수도 있습니다.

 

사용자 그룹 추가

사용자 그룹을 추가하려면 사용자 그룹 목록 페이지에서 사용자 그룹 추가 링크를 클릭하십시오.

사용자 그룹에 대해이름과 짧은 설명을 입력하십시오. 이름은 필수 필드입니다.

드롭다운에서 기준 및 조건을 선택하여필터링을 설정합니다. 텍스트 필드에 검색 값을 입력합니다. 조회 아이콘을 사용하여 검색 값에 대한 검색 작업을 수행할 수도 있습니다. 다른 기준을 추가하려면 추가 버튼을 클릭하고 유사한 과정을 반복합니다.  

저장을 클릭하여 사용자 그룹을 저장하고 목록 보기로 돌아갑니다.
저장하고 새로 추가를 클릭하여, 사용자 그룹을 저장하고 다른 사용자 그룹을 추가합니다.
