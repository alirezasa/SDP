요청서 난이도(수준)는 요청서의 복잡성을 나타내는 데 사용되는 측정값입니다. 이는 요청서를 처리하기에 충분한 경험이 있는 해당 기술자에게 요청서를 적절하게 할당하는 데 도움이 됩니다.

새 난이도(수준)를 추가하려면 난이도(수준) 목록 표의 오른쪽 모서리에 있는 새 난이도(수준) 추가 링크를 클릭하세요.

새 수준 추가
위에 표시된 난이도(수준) 추가 양식에는 이름 및 설명이라는 두 개의 필드가 있습니다.

이름 수준에서는 각 수준을 식별하는 데 사용되는 고유한 이름을 지정합니다.

설명 필드에 난이도(수준)에 대한 간단한 설명을 입력할 수 있습니다. 난이도(수준) 이름 자체에 설명이 없는 경우 이 난이도(수준)에서 분류할 수 있는 요청을 파악하는 데 도움이 됩니다.

저장 버튼을 클릭하여 난이도(수준)를 저장하고 목록 보기로 돌아갑니다.
난이도(수준)를 저장하고 다른 난이도(수준)를 추가하려면 저장하고 새로 추가 버튼을 클릭합니다.
