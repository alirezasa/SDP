Add new roles and configure each role's access permissions, such as view, edit, and approve.

  1. Specify a Name for the Change Role.

  2. Provide a brief Description about the change role.

  3. You can choose to limit the role to be associated with:

      • All Users: Any user can be associated with the change role.

      • Technicians Only: Only technician can be associated with the change role.

      • Site-Group-Technician: Only technicians belonging to the change request's site or group can be associated with the change role.

      • Support Group: Only support groups in the change request's site can be associated with the change role.

  4. Select the Access Permissions across the Stages for the change role. The following are the access permissions for the six default stages in the change lifecycle:

      • View: View permission enables users to view the change request in the selected stage. They cannot perform any further operations.

      • Edit: Edit permission enables users to view and edit the change request for the selected stage. They cannot approve/reject a change.

      • Approve: Approve permission enables the user to view and perform approval actions on the change request in the selected stage.

  1. You can also provide complete access permission over all the stages by selecting All access permission check box.   

  2. Click Save

Note:

    • If a workflow is associated with a change request, users with edit permission for a change stage will be able to edit the fields in the stage before the stage is crossed.

    • If no workflow is associated with a change request, users with edit permission for a change stage will be able to edit the fields in the stage anytime.
