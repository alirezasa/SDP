Route incoming chat requests efficiently by configuring chat settings. If not, each time a requester initiates a chat conversation, all the logged-in technicians in that site will receive the chat notification. To allow chat notifications only to specific technicians, exclude groups and individual technicians.

Let's consider a scenario:

Zylker Industries, headquartered in New York, has branches in Berlin and Chennai, each with 10 technicians, categorized under Hardware, Network, Software, and R&D support groups. Technicians Heather Graham and Jennifer Doe are site admins of Berlin and Chennai, respectively.

For effective chat request routing, disable Live Chat for New York and exclude the site admins, along with Hardware and R&D support groups, from receiving chat requests.

Now, each time a requester initiates a chat, logged-in technicians in that site and under Network and Software support groups will only receive the chat notification. If the requester selects the support group in the chat window, the chat is routed to the logged-in technicians in that support group only.

Use the History button to locate specific chat conversations through the Filter and Search options. You can narrow down the results by time, requesters, technicians, and groups. By default, the time filter is set to today; manually change it if required.
