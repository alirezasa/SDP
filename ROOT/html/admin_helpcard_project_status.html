Project status denotes the level of progress of a project based on which appropriate actions can be taken. Default Project States are: open (meaning pending), onhold (meaning onhold), canceled and closed. Follow the steps listed below to add new project status:

Add Project Status
The Add Project Status form has three fields, namely, Name, Description & Inactive Checkbox.

Name: Specify a unique name to identify Project Status..
Description: Enter a short description about Project Status in the Description field.

Status Selection:Pending (or) Completed.
Inactive Checkbox: Enable for Status Inactivation; uncheck to activate role again.

Color:Select a color to denote project status using the color palette or specify the color code in the text box.

Click the Save button to save Project Status and return to the list view.
Click the Save and add new button to save Project Status and add another.
