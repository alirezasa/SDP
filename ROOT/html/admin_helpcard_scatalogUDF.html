Service - Additional Fields helps you configure additional fields to be displayed in the Service Request form in addition to the preset fields.

Type
Usage
Example
Single Line
Can accomodate a single-line text
Login Name
Pick List
Can accomodate a list of values
List of available designations
Multi Line
Can accomodate a lengthy description
Manager's comments
Numeric
Fields specific to numeric values
Extension number
Date/Time
Fields specific to Date/Time values
Date of Joining
Decimal
Fields specific to Decimal values
21.11(Cost in Dollars)


Sample Scenario:

Lets walk through a sample scenario for better understanding and usage of Service-Additional Fields. Consider a situation where a new-joinee joins the organization and the Manager requests the Admin to start the process associated to a new hire. Now, in addition to the existing new joinee template fields, the Admin may require some additional fields. This Service Request form can be customized according to the Admin's needs with the following fields to get fulfill the Service.

Login name for the Employee: Login name for the application [Single-line additional field can be used to create this field. ie., for Active Directory, Servicedesk Plus etc]
Type of Employment: Temporary. [Pick list additional field can be used to create multiple options. Eg: Temporary / Permanent / contract-basis]
Manager's comments on the Assets to be provided: If the employee is a designer, provide him/her with a laptop that meets the specifications required. [Multi line additional field can be used to create such fields used for extra details pertaining to the Service.]
Extension Number : 1234 [Numeric additional field can be used to create such types of fields bearing numeric values.]
Tentative Date of Joining: 21st July 2016 [Date / Time additional field can be used to create fields indicating date and time.]
Extra allowances for Day/Night shift Employees (in Dollars) : 3000.34 [Decimal additional field can be used to create fields that can hold decimal values.]

Note: Additional Fields cannot be created with names of Incident / Service Catalog's Common Additional Fields.
