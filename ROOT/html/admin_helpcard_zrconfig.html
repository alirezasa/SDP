The Advanced Analytics module auto-analyzes your ServiceDesk Plus data to offer business intelligence reporting, helping you make better decisions everyday.

Advanced analytics for ServiceDesk Plus is available both on premise and on the cloud.

Initial Setup Additional Setup Reset  

On Premise -

Pre-requisite:
  • Download and Install ManageEngine Analytics Plus.
  • Make sure the port 8443 (default port, unless changed at the time of installation) is accessible between the ServiceDesk Plus server and the ManageEngine Analytics Plus server.
Configuration:
  • Hostname/IP Address - Enter the hostname or the IP address of the server on which ManageEngine Analytics Plus is installed.
  • HTTPS Port Number - Enter the web-server port on which the ManageEngine Analytics Plus web-client is accessed. Default port is 8443, unless changed at the time of installation.
  • Analytics Workspace Name - Enter a unique name for the workspace to be created in ManageEngine Analytics plus. Note that if an existing workspace name is used, the corresponding workspace will be overwritten based on the Configurations in ServiceDesk Plus.
  • Auth Type - Choose the mode of authentication. Oauth is the recommended mode of authentication.Password mode of authentication will be deprecated soon.
  • Username - Enter the username of the admin account used in ManageEngine Analytics Plus. Default is admin.
  • Client ID - Enter the Client ID of the corresponding Analytics Plus admin account.Click here for instructions to generate this.
  • Client Secret - Enter the Client Secret of the corresponding Analytics Plus admin account.Click here for instructions to generate this.
  • Password - Enter the password of the corresponding admin account. Default password is admin.
  • Change Proxy Settings - Configure proxy settings if HTTP(s) requests to the ManageEngine Analytics Plus server are routed through a proxy server.
  • Synchronize From - Pick the date and time period from when ServiceDesk Plus data needs to be pushed to ManageEngine Analytics Plus.
  • Enable SSO - After successful synchronization, you can enable single sign-on with Analytics Plus. To do this, select Enable SSO, and click Save. To learn more, click here.

    Note: When new users are added to Analytics Plus, they can access Analytics Plus from ServiceDesk Plus only after the next periodic synchronization. Alternatively, you can refresh this integration page to provide access to users immediately.

On Cloud -

Pre-requisites:
  • Sign up for a Analytics Plus Cloud account using the appropriate link:
Configuration:
  • Choose Data Center: Select a data center to create an OAuth Client for your Analytics Plus Cloud account. The datacenter you select must correspond to the sign-up URL that you used to create your Analytics Plus Cloud account:
    • Analytics Workspace Name - Enter a unique name for the workspace to be created in Analytics Plus Cloud. Note that if an existing workspace name is used, the corresponding workspace will be overwritten based on the configurations in ServiceDesk Plus.
    • Analytics Plus Email ID - Enter Email ID used to sign up for a Analytics Plus Cloud Account.
    • Client ID/Client Secret - Enter the OAuth Client ID and Client Secret generated for your Analytics Plus Cloud Account. Click here to learn more.
    • Redirect URL - Copy the given URL and paste it to the Authorized Redirect URLs field while creating the OAuth Client.
    • Change Proxy Settings - Configure proxy settings if HTTP(s) requests to the internet are routed through a proxy server.
    • Synchronize From Choose the date and time from which the data from ServiceDesk Plus should be pushed to Analytics Plus Cloud cloud.

    Re-Synchronization : The Re-sync button will appear once the initial save and sync process is complete. The data between ServiceDesk Plus and Advanced Analytics can be manually synchronized using this button.

    Move the workspace to a new admin : Click the edit icon beside the User Name/Analytics Plus Email ID fields. Assign a new admin for the workspace by entering the username or the email ID. Ensure that the new admin does not have any existing workspace with the same name.

    Security Information : Data synchronization between ServiceDesk Plus and the Advanced Analytics module is encrypted and only the current help desk data is synced. The Advanced Analytics module does not write any data to ServiceDesk Plus. For more information about data security on the cloud, click here.

    Note : The data synchronization process will freeze the Advanced Analytics integration page. The sync status will display the status as 'Running' until the synchronization is complete.


    Control data synchronization with Advanced Analytics using the following options.

    • Periodic Data Synchronization: Choose the frequency of data synchronization between ServiceDesk Plus and Advanced Analytics. Default configuration is 1 hour.
    • Data Retention Policy: Configure the time period for which the ServiceDesk Plus data needs to be retained in Advanced Analytics. This policy will be executed every 7 days.
    • User Info: Lists the users who have access to ServiceDesk Plus database in Advanced Analytics. The user list is refreshed every 7 days.
    • License Information: Displays the number of available records and the license expiry information of Advanced Analytics.

    Repopulate Advanced Analytics Integration

    Refreshes all the configured settings and the schema in Advanced Analytics.

    Remove Advanced Analytics Integration

    Removes all the configured settings and deletes ServiceDesk Plus data in Advanced Analytics.
