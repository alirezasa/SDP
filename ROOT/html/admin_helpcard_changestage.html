This page lists the various stages a change request must go through between Submission and Closure. You can change the name and description of these stages, but not delete them.

Depending on approval configurations, the stages may or may not require approval to move to the next stage.

Based on the workflow configured, each stage can have stage statuses. Under each stage, you can add any number of statuses and configure the Change Roles to be notified.

Use the Actions icon to edit a stage.

Click on a Stage name or the drop-down icon beside it to view its active and inactive statuses.

  • Choose to view Active or Inactive Statuses using the drop-down.
  • Use the Actions icon to edit or delete a status.
  • Use the Search icon to find your preferred status.

Each stage has two default statuses such as, Approve/Accept/Complete and Reject/Fail/Cancel. These default statuses cannot be deleted.

Add Change Status

  • Select the stage in which to add or edit a status.
  • Click New Change Status.
  • Provide a Name and Description for the status.
  • Select the Change roles to be notified of the change status.
  • Configure the notification subject and message.
  • Click Save.

Click View History to view edits made to the Stage and Statuses
