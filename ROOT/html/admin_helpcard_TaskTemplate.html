Task Templates help you create pre-define templates for tasks that are repeated. They can be applied while adding a task to a request, problem, change and project.

Adding a New Task Template

Use the pointers below as a reference:

Module - A general task template can be associated with all the modules. However , a request/ project/ problem task template can be associated only with their respective modules.

Template name - Specify a unique name for the task.

Title - Specify an appropriate title.

Status - Select a status from the drop-down menu.

Description - Briefly describe the objective of the template.

Estimated effort - Mention the estimated time required to complete the task.

Priority - Mark the priority of the task.

Additional Costs - Mention the additional costs the task might incur.

Group - Select the group which will handle the task.

Owner - Select a technician to work on the task.

Mark/Assign - Decide when to assign the task to a technician. You can assign immediately or mark the task and assign it manually later. The task notification will be sent to the technician only after the task is assigned.

Task Type - Select the task type.

Comments - Enter relevant comments to be displayed to the technician. E.g: special instructions, exceptions etc.

Click Save. For additional save options, click the arrow beside the Save button.

Associating a Task Template with a Request Template

From the additional Save options, you can Save and Associate Request Templates. The Associate Request Properties feature allows the technician assigned to a task to view specific fields of a request. For more information, click here.
