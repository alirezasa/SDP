Il est nécessaire de définir les détails du serveur de messagerie pour recevoir et envoyer des messages depuis ServiceDesk. Vous devez indiquer à la fois les paramètres du serveur de messagerie entrant et sortant pour envoyer et recevoir des messages sans aucun problème.

Paramètres du serveur de messagerie entrant
Les paramètres du serveur de messagerie entrant contiennent les champs suivants :

Nom du serveur / Adresse IP: Indique le serveur de messagerie entrant d’où les messages devront être récupérés.
Nom d'utilisateur: Le nom de connexion au serveur ci-dessus.
Mot de passe: Le mot de passe pour accéder aux messages du serveur ci-dessus.
Adresse e-mail: Il s’agit de l’adresse de messagerie à laquelle les requêtes d’assistance sont envoyées et seuls ces messages doivent être récupérés.
Type de courriel: Indique le type de messagerie pour la récupération de messages (Par exemple : IMAP ou POP et ainsi de suite). Si vous avez sélectionner IMAP, vous aurez le choix d'activer le protocole Transport Layer Security (TLS).
Port: Le port sur lequel les messages doivent être récupérés.
Extraire les courriers toutes les: Entrez la fréquence à laquelle les messages seront récupérés automatiquement sans avoir besoin de les récupérer manuellement.

Parmi ces champs, à l’exception du champ Type de messagerie, tous les autres sont obligatoires et ne peuvent recevoir une valeur nulle. Cliquez sur le bouton Enregistrer après avoir renseigné les détails ci-dessus. Les configurations seront enregistrées et ServiceDesk essaiera d’établir une connexion avec le serveur de messagerie. Une fois la connexion établie, la récupération de messages est activée. Pour commencer la récupération de messages, cliquez sur le bouton Débuter la récupération. Maintenant, le bouton "Enregistrer" est désactivé. Si vous voulez faire des modifications sur les paramètres de serveur de messagerie entrant, vous devez d’abord arrêter la récupération de messages et seulement alors effectuer les modifications et les enregistrer.

Paramètres du serveur de messagerie sortant
Les paramètres du serveur de messagerie sortant contiennent les champs suivants :

Nom du serveur / Adresse IP: Indique le serveur de messagerie sortant d’où les messages seront envoyés au monde extérieur.
Nom du serveur remplaçant / Adresse IP: Si vous avez un serveur de sauvegarde qui peut prendre le relais si le serveur indiqué plus haut tombe en panne, alors indiquez-le ici.
Nom de l’expéditeur: Le nom qui apparaîtra dans le message à coté de l’identifiant de l’expéditeur de l’email.
Adresse de réponse: L’adresse de messagerie où les réponses devront être envoyées. Généralement, elle aura la valeur indiquée dans le champ adresse de messagerie des paramètres du serveur de messagerie sortant.
Type de courriel: Indique le type de messagerie pour l’envoi (Par exemple : SMTP, SMTPS).
TSL activé : Option d'activation du protocole Transport Layer Security (TLS).
Port: Le port à partir duquel les messages doivent être envoyés.

Parmi les champs ci-dessus, Nom du serveur / Adresse IP, Adresse de Réponse et Port sont des champs obligatoires et ne peuvent donc pas prendre de valeurs nulles.

Si votre serveur de messagerie sortant nécessite une authentification, sélectionnez la case Exige une authentification. Saisissez le Nom d’utilisateur et le Mot de Passe requis pour authentifier les messages sortants.

Pour enregistrer les informations saisies, cliquez sur Enregistrer.

Paramètres du filtre anti-spam
Le filtre anti-spam empêche qu’un message indésirable ne soit transformé en requête dès que le service d’assistance reçoit un email d’information. Les emails de spam sont des emails indésirables qui ne sont pas destinés au service d’assistance. L’utilisation d’un filtre anti-spam vous permet d’éviter que ces messages ne soient transformés en requêtes. La création de nouvelles requêtes peut être interrompue pour les emails provenant d’autres domaines (lorsque le service d’assistance ne se charge que des clients à l’échelle nationale).

Vous pouvez définir une règle désignant les emails n’aboutissant pas à une requête.

Exemple : Vous pouvez créer une règle Expéditeur ne contient pas « @manageengine.com » puis l’ajouter à Répond aux critères. Lorsqu’un email répondant aux critères définis est reçu, aucune requête n’est créée.

Pour enregistrer les paramètres, cliquez sur Enregistrer.
