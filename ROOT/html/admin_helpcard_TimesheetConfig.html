View a technician's work logs from across the application in a time sheet.

On this page, you can configure time sheets to suit the workflow of your organization.

Technicians can access the time sheets tab only when the Time Sheets option is enabled.

  • Select the default Time Sheet Period and Start Day of the Week from the drop-down.
  • Enter the Log hours per Week and Log hours per Day for a technician to achieve.
  • Enable the Allow multi-day work log addition checkbox to add worklogs across days. The start date will be used when generating time sheets for such work logs.
  • Enable the Allow technicians to add or update work logs after time sheet has been submitted or approved checkbox if necessary. This will affect only the following work log fields:
    • Owner
    • Start/End time
    • Time Taken To Resolve
    • Is Billable?
  • Provide the list of technicians to be excluded from logging time sheets in the field given and click Save.
