Associations List View

Predefine dynamic associations across custom modules.

Create New Association

Click New. The form displayed contains 2 tabs, fill out the details using the pointers below.

Configurations :
  • Source Module -The source module is auto-selected.
  • Association Type -Define the nature of association.
  • Associated Module -Select the module to which the source module is associated with.
  • Cardinality -Define the numerical relationship between the records in source and association modules. You can associate a source module record with single/multiple associated module records and vice-versa.
  • Display Name in Source Module -Provide a association title to be displayed in the source module.
  • Source Module API Name & Source Module API Plural Name -Specify the API names for the source module. API names must be in snake_case and cannot be edited. By default, source module API names are prefixed with assoc_.
  • Field to filter list view in Source Module -Select filter values for the association list view in source module. Users can filter the associations listed in the source module based on the fields selected in this drop-down.You can select the following fields to filter associations:
    • User related fields such as Status, Department, Users, Created by
    • Picklist additional fields with reference entities configured
  • Filter criteria in Source Module -Predefine criteria to filter the association module records while displaying them in the source module.
  • Display Name in Associated Module -Provide a association title to be displayed in the associated module.
  • Field to filter list view in Associated Module -Select filter values for the association list view in associated module. Users can filter the associations listed in the associated module based on the fields selected in this drop-down. You can select the following fields to filter associations:
    • User related fields such as Status, Department, Users, Created by
    • Picklist additional fields with reference entities configured
  • Associated Module API Name & Source Module API Plural Name -Specify the API names for the associated module. API names must be in snake_case and cannot be edited. By default, source module API names are prefixed with assoc_.
  • Filter criteria in Associated Module -Predefine criteria to filter the source module records while displaying them in the source module.
Additional Fields

Click New Field to configure additional fields to collect details about the association properties. You can configure single line, multi line, pick list, numeric, decimal, or boolean types additional fields. Learn more.

List View Operations
  • Use the filter drop-down to view associations created based on their active status or the source custom module.
  • Click Edit to update association details. API names cannot be edited.
  • Select the associations and click Delete to remove the association. If the association is currently in use, it will be moved to inactive status.
