La Raison de modification renseigne sur la raison d'une demande de modification. Par ex. : si l'imprimante de votre organisation ne fonctionne plus à cause d'une cartouche défaillante, la raison de modification sera L'imprimante ne fonctionne pas tandis que la demande de modification peut être Modifier la cartouche d'encre

De la même manière, vous avez la possibilité de créer les raisons de demande de modification les plus courantes. Cela afin de faciliter l'obtention des rapports sur les raisons des créations de modification dans l'organisation.

Ajout d'une raison de modification

  1. Cliquez sur le bouton Ajouter une raison de modification.

  2. Saisissez la raison de modification dans le champ Nom.

  3. Donnez une brève Description de la raison de modification.

  4. Cliquez sur le bouton Enregistrer.
