Room Templates

Create and save templates for frequently created rooms such as private offices, storage facilities, pantries, etc., to aid users while they create similar rooms.

On this page, you can create a new room template, edit or delete the existing ones.

To create a new room template, click New Room Template.

The new room template has two sections,

1. Details: Here, you can define the room template by adding a display name, name, and description for it.

2. Fields: Once you have saved the details section, you can add new fields to the room template by dragging the required fields from the New Field Section on the right side.

To name a section, click Untitled text and type in the desired section name.

Finally, save the field configuration.
