While adding new user or technician, you may want to record additional information about the users, apart from the present fields in the form. The User-Additional Fields lets you configure any number of additional fields that would appear in user or technician forms, or common fields for both user and technician.

By default, the User-Additional Fields list view displays the list of User/Technician Additional Fields that are configured in the application. To view the User Additional Fields list, select User Additional Fields option from Filter by Type drop-down menu. Similarly, if you want to view the Technician Additional Field list, select Technician Additional Field option.

To add custom additional fields,

  1. Select an option from Filter by Type drop-down menu. Say, you want to add an additional field that should appear in the user as well as the technician form, then select User Additional Field option.
  2. Click Add Field button.
  3. The Field Types are Text, Numeric and Date/Time fields. The Text fields are of 3 types namely, Single-line, Multi-line and Pick List. Select any one field type.
  4. Specify a unique name for the additional field in Field Name text field.
  5. If you have selected Single-line or Multi-line text fields, then you can enter Default Value. The default value is displayed in the new user/technician form and can be edited, if required.
  6. You can encrypt single line, multi line, or pick list fields that contain sensitive information. The data in encrypted fields will not be reflected in reports or advanced search.
  7. Enable Holds Personally Identifiable Information (PII)/ Electronic protected health information (ePHI) check box to protect your users' confidential details in accordance with GDPR regulations. PII/ePHI data will be deleted permanently from the application when the user is deleted.
  8. Enter brief description about the field in the Description text field.
  9. Click Save button. The additional field would appear in both, user and technician forms.

NOTE:

  1. You can add any number of additional fields for user and technician.
  2. Default Values cannot be entered for Date/Time Fields.
  3. While deleting the additional fields, the value entered for the additional field in the new user or technician form will be lost.
