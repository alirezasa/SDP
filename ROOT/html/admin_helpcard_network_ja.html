ネットワークスキャンでは、Linux、Solaris、MAC、IBM-AIXマシンや、プリンタ、ルータ、スイッチ、アクセスポイントといったIT機器を検知することができます。また、ドメインに所属していないWindowsマシンやワークグループもスキャンすることができます。

メモ：スキャン対象が、Windowsワークステーションである場合、Windowsドメインスキャンでのスキャンを推奨しています。

ネットワークスキャンをするには、新規ネットワークの追加リンクをクリックします。



新規ネットワークの追加

Linux、MAC、Solaris、IBM-AIX

  1. ネットワークビューの一覧ページの右角にある新規ネットワークの追加リンクをクリックします。

  2. スキャンの範囲を全ネットワーク（例：IPアドレス192.168.27.0にあるすべてのワークステーション）と範囲（例：IPアドレス192.168.27.0から192.168.27.30にあるワークステーション）から選択します。スキャンする範囲を選択したら、ネットワークアドレスを入力します。

  3. プロトコルをSSH/Telnetから選択します。

  4. ライセンスソフトウェアがLinuxとSolarisマシンにインストールされている場合、Linux/Solarisワークステーションのソフトウェア情報をスキャンチェックボックスを有効にします。

  5. SSHを有効にしている場合、Linuxマシンの認証オプションが表示されます。

    公開鍵ベースの認証は、通常のユーザ名/パスワードによる認証よりも安全な認証方法です。この認証方法を有効にするには、Linuxマシンから公開鍵と秘密鍵を生成する必要があります。認証に公開鍵を使用するチェックボックスを選択して、フィールドに秘密鍵を入力します。

  6. SSHのログイン認証を入力します。Telnetを使用する場合は、ログイン名とパスワードフィールドにTelnet認証を入力します。

  7. ネットワーク詳細に関連する情報を説明フィールドに入力します。

  8. 保存をクリックします。保存／スキャンボタンをクリックすると、設定の保存後、すぐにWindowsドメインスキャンが開始されます。

プリンター、ルーター、スイッチ、アクセスポイント

  1. ネットワークビューの一覧ページの右角にある新規ネットワークの追加リンクをクリックします。

  2. スキャンの範囲を全ネットワーク（例：IPアドレス192.168.27.0にあるすべてのワークステーション）と範囲（例：IPアドレス192.168.27.0から192.168.27.30にあるワークステーション）から選択します。スキャンする範囲を選択したら、ネットワークアドレスを入力します。

  3. プロトコルがSSHの場合、それに該当するラジオボタンを有効にします。

  4. SSHが有効化されたら、ルーターとスイッチの追加情報を提供できるSSHのログイン認証を入力します。

  5. ネットーワークデバイスのSNMP検出のために、コミュニティStringを入力します。

    SNMPは、プリンター、ルーター、スイッチ、そしてアクセスポイントの識別に使用されます。プリンターの場合、SNMPを使用してインベントリの完全な情報が取得されます。ルーターとスイッチの場合、SNMPを使用してインベントリの通常の情報が取得され、インベントリに関する詳細情報はSSH、もしくはTelnet（認証情報が提供されている場合）を使用して取得されます。

  6. ネットワーク詳細に関連する情報を説明フィールドに入力します。

  7. 保存をクリックします。保存／スキャンボタンをクリックすると、設定の保存後、すぐにWindowsドメインスキャンが開始されます。

Windowsマシン

  1. 新規ネットワークの追加リンクをクリックします。

  2. スキャンの範囲を全ネットワーク（例：IPアドレス192.168.27.0にあるすべてのワークステーション）と範囲（例：IPアドレス192.168.27.0から192.168.27.30にあるワークステーション）から選択します。スキャンする範囲を選択したら、ネットワークアドレスを入力します。

  3. ログイン名とパスワードフィールドに、ドメインコントローラーのログイン認証を入力します。ログイン名は、次のように入力します；<DOMAIN_NAME>/<USER_NAME>： 例；ACME/administrator

  4. ネットワーク詳細に関連する情報を説明フィールドに入力します。

  5. 保存をクリックします。保存／スキャンボタンをクリックすると、設定の保存後、すぐにWindowsドメインスキャンが開始されます。

ネットワークのスキャン

会社組織のすべてのネットワークを検知するために、特定ネットーワークのネットワークのスキャンアイコンをクリックします。スキャン結果の成功／失敗に関わらず、スキャン結果のレポートを取得できます。
