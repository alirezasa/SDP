Software Type denotes the different types of software such as, licensed, prohibited, freeware, shareware,and so on. By default, there are six software types which can neither be edited nor deleted.

    • Shareware: Software that is available free of charge, may be distributed for evaluation with a fee requested for additional features or a manual etc.

    • Freeware: Software that is provided without charge.

    • Prohibited: Software that is prevented from use.

    • Excluded: Software that is omitted from use.  

    • Managed: All licensed software comes under this software type.

    • Un-Identified: Unknown softwares can be categorized under this software type.

Add New Software Type

  1. Click the New Software Type link on the right hand side of the page. This opens the Software Type Details page.

  2. Specify the Software Type name in the given text field. This is a mandatory field which will uniquely identify individual software type.

  3. Specify any relevant information about the Software Type in the description field.

  4. Click Add Software Type button. This adds the software type and gets displayed below the add software form. Click Cancel button to cancel the operation.
