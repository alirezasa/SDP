Using this, you can customize the Actions menu of the Requests page using your own script. You can create different action menus and associate custom classes or script files with the menus to execute the relevant actions. The menus created here get listed under the Actions menu in the Requests Details page.

Add New Menu

You need to provide the following details while creating a new menu:

Menu Name: Specify a unique name for the menu being created (The menu name will be displayed under the Actions menu of the Requests page)

Description: Enter a suitable description indicating the purpose of the menu.

Associate Roles: Decide Technician Roles that will get access to this menu (Options to choose from: All Roles or 'Selected Roles')

Associate Templates: Choose Templates, under which this menu will be displayed (Options to choose from: 'All Templates', 'All Incident Templates, 'All Service Templates' (or) 'Selected Templates')

Custom Html File: To load Custom Html File when menu is invoked, you need to place the html file in "[SDP_Home]/Integration/resources/" directory. Files with htt/htx/htm/html/htmls extensions are only supported for invocation. Also, dependency files like JavaScript and CSS have to be placed in the same location.

Choose Action Type:

For 'Execute Script' or 'Execute Class' option from the Action Type drop down. If you select the 'Execute Class' option, then you need to specify the Executor class in the field provided. For example, "com.servicedeskplus.integration.JiraActionImplementation". If you select the 'Execute Script' option, you must specify the file name of the text file containing the script in the given field. The application will fetch the scripts from the mentioned text file saved under [SDP_Home]/integration/custom_scripts/executor_files directory.

We can also pass arguments for Custom Script/Class. All API parameters are supported as arguments. 

Examples 

For Script : cmd / c Index.bat $COMPLETE_V3_JSON_FILE

For Class  : com.servicedeskplus.integration.JiraActionImplementation

Some of the Other Parameters Supported

$COMPLETE_V3_JSON_FILE ---> Complete Request Object will be saved to a JSON file and the file path will be passed as String Object.

JSON File Path  : (SDP_Home\integration\custom_scripts\request\12_1426143538036.json).

$HTML_DATA_JSON_FILE ---> Ajax call request "data" parameter will be saved to a JSON file along with menu name, request json and xml file path and the file path will be passed as String Object. Used with Custom Html File. For Ex : (SDP_Home\integration\custom_scripts\request\12_1426143538036.json).

$HANDSHAKE_KEY ---> Handshake key will be passed as String Object.

Click Save.

Now, the menu is created and can be viewed under the Actions menu in the Requests Details page.

View List

You can access this while adding a new menu. You can do the following from here:

Enabling/Disabling a Custom Menu: Click the Enable/Disable icon to enable or disable a menu from the Request Custom Menu list view page.

Editing/Deleting a Custom Menu: Click the Edit/Delete icon corresponding to a specific menu, which you wish to update/remove from the Request Custom Menu list view page.
