Enabling OAuth Single Sign-On (OAuth SSO) allows users to log in to the application by using authorization server credentials, instead of login credentials.

Follow the steps below to retrieve user data from an authorization server:

  • Click + New.

OAuth Provider Details

  • From the Provider Name drop-down, choose the authorization server. The Client ID, Authorization URL, Token URL, and Icon fields will be auto-populated and cannot be edited.
  • You can create a new authorization server record by clicking Add New in the drop-down.

OAuth Feature Details

  • Scope: Specify scopes of the user data you want to access.
  • Client Secret: Specify the client secret generated while registering ServiceDesk Plus in the authorization server.
  • User Property: Choose the response JSON property to be used for user authentication.
  • Mapped Property: Choose the ServiceDesk Plus user field to which the user property must be mapped. Use User Principal Name to map fields for AD-imported users.
  • Resource URL: Specify the URL from which the user data is retrieved.
  • Redirect URL: This field is auto-populated and cannot be edited.

Additional Fields

Configure field mapping to create user profile for dynamic users who log in to the application via OAuth SSO.

  • Enable the required user fields (default and user-defined fields) using checkboxes beside them.
  • For each enabled field, specify the relevant response JSON property. Note: This configuration will not be used to update existing user profiles.

After you configure, click Save.

On the list view, enable the authorization server.

Finally, enable the OAuth SSO toggle. Enable or disable Collapse the login form by default to show or hide the default login form.
