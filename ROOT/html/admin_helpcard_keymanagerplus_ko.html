SDP-KMP 통합 :

SDP-Key Manager Plus 통합은 기술자가 대상 단말장치(엔드포인트)에서 만료된 SSL/TLS 인증서를 식별하고, 인증서 갱신을 호출하고, Service Desk Plus 콘솔을 떠나지 않고 직접 해당 애플리케이션에 새로 발급된 인증서를 배포하는 데 도움이 됩니다. 또한 이 통합을 통해 IT 관리자는 네트워크 전체에서 SSL/TLS 암호 강도를 지속적으로 모니터링할 수 있습니다. 기술자는 취약한 암호 제품군과 같은 취약점이 발견될 때마다 경고를 받아 즉각적인 수정 조치를 취할 수 있습니다

SDP에서 KMP 설정 구성:

KMP가 호스팅된 URL : Key Manager Plus 애플리케이션이 설치된 애플리케이션 URL을 입력합니다.

인증 토큰(Auth Token): Key Manager Plus 애플리케이션에서 생성된 인증 토큰을 입력합니다.

 

저장을 클릭하여 설정을 저장합니다.
