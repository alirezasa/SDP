Le formulaire Demande de service consiste en un modèle à glisser-déplacer. Il doit être configuré pour répondre aux besoins de l'utilisateur final. Toute ressource requise par le service peut être configurée sous la section Infos de ressource. Ainsi, approbateurs, contrat de niveau de service et tâches peuvent être assignés à une demande de service individuel.

 

Ajout de services

Pour ajouter des services à une catégorie de service, cliquez sur le bouton Ajouter un service de cette même catégorie. Le formulaire est personnalisable. Il consiste en un modèle destiné à faciliter la configuration. Le formulaire comporte trois sections : En-tête, Champs du service et Aperçu du service.

En-tête : L'en-tête contient le Service, le Nom et la Description.  

Champ du service: Le champ de service contient la liste des paramètres disponibles et une option d'ajout de nouveaux champs.

Aperçu du service : L'aperçu de service est une zone de glisser-déplacer réprésentant l'aspect final du formulaire. Elle comporte également les boutons Annuler et Rétablir. Vous pouvez ajouter/supprimer des champs, configurer les propriétés des champs, réorganiser les champs du formulaire Aperçu de service et ainsi personnaliser un formulaire individuel pour chaque élément de service.

 

Ajout de nouveaux champs

Vous pouvez ajouter de nouveaux champs au formulaire en déplaçant l'option Ajouter un nouveau champ dans la zone de glisser-déplacer. Sélectionnez le type de champ, puis saisissez le nom du libellé et la description du nouveau champ. Si il s'agit d'un champ de texte, sélectionnez son type : Ligne seule, Plusieurs lignes, Liste déroulante. Cliquez sur OK pour ajouter le champ dans la zone glisser-déplacer du formulaire.

Ces nouveaux champs ajoutés sont communs aux services de l'ensemble des catégories de service. Vous pouvez également, sous Champs supplémentaires, créer des champs supplémentaires pour une catégorie de service en particulier. Ici, de plus, les champs peuvent être modifiés et supprimés.  

Glisser et déplacer

Les champs de la section Champs de service peuvent être glissés et déplacés dans le formulaire Aperçu du service. Les champs du formulaire peuvent être réarrangés en les déplaçant sur une cellule vide. La section contenant les informations du demandeur ne peut être déplacée qu'en bloc. Pour annuler/rétablir une modification lors de la réorganisation des champs, cliquez sur le bouton correspondant.

Lors de la création d'une demande, il serait idéal pour l'assistance informatique que toutes les informations nécessaires soient contenues dans le formulaire. Ce n'est malheureusement pas toujours le cas. Si la demande de service est créé avec la moitié des informations requises, il peut être nécessaire qu'un utilisateur modifie et renseigne les informations manquantes. L'Éditeur, le plus souvent un demandeur, peut être configuré pour une demande de service en déplaçant le Champ éditeur dans l'aperçu de service. Si cette demande de service est créée avec le Champ éditeur renseigné, la demande est automatiquement placé En attente. L'état En attente indique que la demande de service requiert une mise à jour de l'éditeur.   

Propriétés du champ Paramètre

Vous pouvez conserver les champs pertinents en personnalisant et supprimant les champs du formulaire existants. Pour personnaliser le formulaire, placez votre curseur sur le champ pour faire apparaître Modifier les propriétés du champ et l'icône Supprimer le champ. Cliquez sur l'icône Modifier les propriétés du champ pour révéler les options suivantes :

Champ obligatoire : Rendre le champ obligatoire en cochant la case d'option correspondante.

Remarque : Si le champ Élément est rendu obligatoire, la catégorie et la sous-catégorie correspondantes le seront également. De la même manière, si les informations sur l'impact sont rendues obligatoires, le champ Impact le sera également.  

Demandeur peut définir : Cette option permet aux utilisateurs de modifier le champ, à savoir qu'il a la possibilité de saisir ou de sélectionner les valeurs du champ lors de la création d'une nouvelle demande de service. L'activation de cette option activera automatiquement « Demandeur peut afficher ».

Demandeur peut afficher: Cette option, activée seule, interdira aux utilisateurs de saisir des valeurs pour ce champ lors de la création d'une demande de service.

Les champs dont l'icône Modifier les propriétés du champ est absente ne peuvent pas être réarrangés, à savoir : Informations sur le demandeur, Sujet, Site, etc.

Cliquez sur l'icône Supprimer le champ pour supprimer des champs du formulaire. Les champs détachés du formulaire sont listés dans la section Champs du service. Les champs État, Description, Informations sur le demandeur, Site et Sujet ne disposent pas de l'icône Supprimer le champ.

 

Infos sur la ressource

Si des ressources sont impliquées, vous pouvez les mentionner sous la section Ressource. Le processus consiste en une série de question, les ressources peuvent être affichées dans l'un des formats suivants : case d'option, liste déroulante, texte brut, oui/non.

  1. Cliquez sur le bouton Ajouter une ressource.

  2. Renseignez le Titre de la ressource et une brève Description sur la raison de l'ajout de cette ressource aux champs correspondants.

  3. Sélectionnez ensuite une question dans la liste des questions existantes. Vous pouvez également cliquez sur le bouton Nouvelle question pour créer une nouvelle question.

  4. Sélectionnez le Type de question parmi les options fournies. Le format de la question peut être : oui ou non, déroulant, case d'options, texte brut.

  5. Si le type de question choisi est Case d'option ou Case de sélection, Ajouter des options s'affiche pour vous permettre de sélectionner le type d'équipement. Les équipements sont répertoriés au-dessous du type d'équipement sélectionné. Sélectionnez les équipements à afficher dans la question en cliquant sur le bouton >> (déplacer à droite).   

  6. Vous pouvez ajouter manuellement en cliquant sur Ajouter manuellement dans les options d'ajout. Saisissez la ressource ; cliquez sur Ajouter pour rendre les ressources disponibles dans la question. Cliquez sur Ok pour enregistrer la question.

  7. Cliquez sur Enregistrer pour enregistrer les informations sur la ressource.

Montrer au demandeur : Pour rendre cette demande de service disponible aux demandeurs, cochez Montrer aux demandeurs. Si des groupes d'utilisateurs sont configurés dans l'application, la demande de service ne peut être rendue disponible qu'à des groupes d'utilisateurs spécifiques. Cliquez sur le bouton Enregistrer et configurer le flux de travail

 

Flux de travail

 

Les demandes de service créées nécessitent l'approbation de l'autorité concernée. Les approbateurs peuvent être des techniciens / demandeurs avec l'autorisation Approuver les demandes de service. Ils doivent également posséder une adresse de messagerie définie dans l'application. Vous pouvez configurer jusqu'à 5 étapes d'approbation pour une demande de service. Chaque étape peut comporter un ou plusieurs approbateurs.

Sélectionnez les Approbateurs pour la demande de service. Le(s) approbateur(s) peuvent également être les responsables de service auxquels le demandeur est associé, à condition que le demandeur a l'autorisation d'approuver les demandes de service. Lors du choix de l'approbateur, les notifications appropriées doivent être sélectionnées.

Envoyer automatiquement une notification d'approbation lorsqu'une demande de service est créée - Cochez cette case pour envoyer une notification d'approbation à l'autorité concernée chaque fois qu'une demande de service est créée. Si vous avez configuré plusieurs étapes d'approbation, la notification est envoyée à la prochaine étape consécutive uniquement sur approbation de l'étape précédente.

Tous les approbateurs configurés peuvent approuver la demande de service - Cochez cette case rend obligatoire l'approbation de la demande de service par l'ensemble des approbateurs configurés. Si l'un des approbateurs rejette la demande de service, indépendamment de l'étape en cours, la demande ne passera pas à l'étape suivante.

    REMARQUE : Dans le cas où plusieurs approbateurs seraient sélectionnés pour une étape, ceux-ci doivent tous approuver la demande.

Ne pas assigner un technicien tant que la demande de service n'est pas approuvée - Si cette option est activée, un technicien ne sera assigné à un service qu'une fois la demande de service approuvée par l'autorité concernée.

Contrat de niveau de service : Sélectionnez dans la liste déroulante le Contrat de niveau de service pour la demande de service. Vous pouvez également ajouter un nouveau contrat de niveau de service à l'aide du lien Ajouter.

Tâches : Les tâches liées à la demande de service peuvent être configurés dans la section Tâches. Cliquez sur le bouton Ajouter une tâche et renseignez le formulaire de tâche. Les tâches configurées dans l'affichage liste peuvent également être organisées pour répondre à vos priorités. Les tâches d'une demande de service sont créées et assignées automatiquement au technicien configuré dès lors que la demande de service est déclenchée.

Actions du modèle : Cette fonctionnalité n'est disponible que lorsque Desktop Central 7.0 et versions ultérieures est intégré à ServiceDesk Plus. Pour bénéficier de cette fonctionnalité, configurez le Nom du serveur et le Numéro de port du serveur Desktop Central dans l'application ServiceDesk Plus.

 

Pour configurer le formulaire Demande de service pour les demandeurs, cliquez sur le bouton Enregistrer et configurer le demandeur.

 

Aperçu de la demande de service pour le demandeur

Vous pouvez consulter l'aperçu de la demande de service destinée aux techniciens et aux demandeurs. Les demandeurs peuvent consulter la demande de service si « Montrer au demandeur » est coché.

Sélectionnez un modèle de demande de service dans la page du catalogue de services. Le formulaire du modèle de demande pour un technicien s'ouvre par défaut. Cliquez sur l'onglet Visualisation du demandeur. L'en-tête est grisée pour signifier qu'il n'est pas modifiable. Vous pouvez glisser et déplacer les champs de la section Champs de service jusqu'au canevas pour réarranger les champs. Cliquez sur Enregistrer.
