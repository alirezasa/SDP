Computer Telephony Integration은 스크린 팝, 클릭 투 다이얼 등과 같은 기능을 사용하여 조직 내 사용자 간의 효율적인 통신을 가능하게 합니다. 다음 포인터를 사용하여 조직에 대한 Computer Telephony 설정을 구성합니다.

참고: ServiceDesk Plus는 Asterisk 및 Avaya 서버를 지원합니다. 스크립트를 사용하여 사용자 정의 서버에 대한 통합을 구성할 수도 있습니다. 자세히 알아보려면 여기를 클릭하십시오.

  • 서비스: ServiceDesk Plus와 통합할 전화 통신 서버를 선택합니다.
  • 전화 통신 서버: 전화 통신 서버의 IP 주소를 입력합니다.
  • 포트: 서버의 포트 번호를 입력합니다.
  • SIP 프로토콜: 조직의 별표 서버 프로토콜을 선택합니다. 이 필드는 서비스에서 >Asterisk를 선택한 경우에만 표시됩니다.
  • TLink: 필드 옆에 있는 TLink 가져오기 버튼을 클릭하여 조직에서 사용 가능한 TLink로 드롭다운 목록을 채웁니다. 필요한 옵션을 선택합니다. 이 필드는 서비스에서 Avaya를 선택한 경우에만 표시됩니다.
  • 사용자 이름 및 비밀번호: 구성된 전화 통신 서버에 로그인하기 위해 통화 관리자의 자격 증명을 입력합니다.

저장을 클릭하여 ServiceDesk Plus와 전화 통신 서버 간의 연결을 설정합니다. 통합에 성공하면 사용자 프로필이 유효한 전화/내선 번호로 업데이트된 경우 애플리케이션 내에서 전화를 걸고 받을 수 있습니다.
