Purchase Request settings


Purchase Request Settings lets you to notify users when the service request changes to a purchase request. It also enables you to select the technicians to be notified in case a purchase request is raised.


To notify technicians of a purchase request,

1. Enable "Send email notification to technicians…" to notify the technicians when a Purchase request is created.

2 .Select the technician’s name with an email id to add it to the notification list


Note : Technician's name without an email id can not be added to the notification list.
