온프레미스에서 클라우드로 마이그레이션

이 페이지에서 관리 모듈 데이터를 ServiceDesk Plus 온프레미스에서 ServiceDesk Plus Cloud로 마이그레이션할 수 있습니다. 시작하기 전에 약관 및 서비스를 읽고 자동으로 이전되는 항목과 수동으로 이전되는 항목의 목록을 찾으십시오.

ServiceDesk Plus는 OAuth 2.0을 사용하여 온프레미스와 클라우드 서버 간에 통신합니다. OAuth 2.0은 암호 대신 웹 토큰을 사용하여 보호된 리소스에 대한 위임된 액세스를 제공하는 인증 방법입니다. 여기를 클릭하여 자세히 알아보십시오.


필요한 엔터티를 수동으로 마이그레이션한 후에는 다음 포인터를 사용하여 마이그레이션 양식을 작성하여 자동 마이그레이션을 시작할 수 있습니다.:

필드 설명
ServiceDesk Plus 클라우드 데이터 센터 Data Center를 선택하여 ServiceDesk Plus Cloud의 도메인 URL을 식별하십시오.
도메인 URL 도메인 URL은 데이터 센터에 따라 자동으로 채워집니다.
클라이언트 ID 및 클라이언트 암호 인증 서버에서 생성된 Client ID와 Client Secret을 제공합니다. 여기를 클릭하여 이 작업을 수행하는 방법에 대해 알아보십시오.
리디렉트 URL 클라이언트 ID 및 클라이언트 시크릿 생성을 위해 제공된 리디렉션 URL을 인증 서버에 복사해야 합니다.
모드 서비스 데스크 데이터의 마이그레이션 모드를 선택합니다. 이는 관리 데이터, 자산 및 솔루션에는 적용되지 않습니다.
  • 평가판 모드 - 지난 30일 이내에 생성된 데이터가 이전됩니다.
  • 전체 모드 - 지난 1년 이내에 생성된 데이터가 마이그레이션됩니다.

다음을 클릭하면 ServiceDesk Plus Cloud 계정에 로그인한 후 동의할 수 있는 창이 팝업됩니다. 데이터를 마이그레이션해야 하는 ServiceDesk Plus Cloud 인스턴스를 선택하고 데이터 이동을 클릭합니다. 마이그레이션 진행 상황을 보여주는 보고서가 표시됩니다.

관리자(관리 설정) 데이터가 마이그레이션되면 시스템에서 마이그레이션되지 않은 관리 엔터티를 수동으로 마이그레이션할 수 있도록 마이그레이션이 일시 중지됩니다. 모듈 데이터를 마이그레이션하려면 다시 시작을 클릭하십시오.

마이그레이션 후 ServiceDesk Plus Cloud로 이동을 클릭하여 클라우드 인스턴스에 액세스합니다.

ServiceDesk Plus Cloud에 추가되거나 업데이트된 데이터의 상태를 보려면 설정 >> 데이터 가져오기 >> 기록 가져 오기로 이동하십시오.

데이터를 온프레미스에서 클라우드로 마이그레이션하기 위한 전제 조건에 대해 자세히 알아보려면 관리자 안내서.

를 참조하십시오.

 

참고 사항

  • 온프레미스의 엔터티/모듈에 대해 라이선스가 활성화되어 있지 않으면 해당 엔터티/모듈 데이터가 마이그레이션되지 않습니다.
  • 인라인 이미지, 첨부 파일, 하위 항목(예: 작업 템플릿, 리소스 및 요청 템플릿의 질문)이 항목 데이터와 함께 마이그레이션됩니다.
  • 비활성 관리자 엔터티도 오류 없이 가져옵니다.
  • ServiceDesk Plus Cloud에서 사용할 수 없는 기능과 관련된 데이터는 마이그레이션되지 않습니다.
  • 온프레미스에서 클라우드로 데이터를 마이그레이션하는 동안 데이터베이스 작업을 피하십시오. 마이그레이션이 실패할 수 있습니다.
  • 이전될 모든 데이터는 압축되어 'Conversion' 폴더 아래의 zip 파일에 저장되며 가져오기가 성공하면 삭제됩니다.
  • 인스턴스 간 마이그레이션이 가능합니다. 즉, 특정 ServiceDesk plus 온프레미스 인스턴스의 데이터를 양식에서 선택한 ServiceDesk Plus Cloud 인스턴스로 마이그레이션할 수 있습니다.
  • 마이그레이션은 동시에 두 인스턴스에서 시작할 수 없습니다. 한 번에 하나의 마이그레이션만 처리됩니다.
  • 첨부 파일을 추가할 수 있는 최대 제한은 없지만 하나의 엔티티(모든 첨부 파일 포함)의 총 첨부 파일 크기는 48MB를 초과할 수 없습니다. 48MB보다 큰 첨부 파일은 마이그레이션되지 않습니다.
  • 라이선스 확인, 기술자 수 및 추가 필드 수는 마이그레이션을 시작하기 전에 Cloud에서 수동으로 확인해야 합니다.
