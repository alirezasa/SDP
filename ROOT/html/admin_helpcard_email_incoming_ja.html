ユーザーからのメールを受信するために、組織の受信メールサーバーを設定します。
メールボックスとServiceDesk Plusを接続するために、メールプロトコル（POP、IMAP、POPS、IMAPs）、Exchange Web Service（EWS）、Microsoft Graphを使用できます。
選択した接続プロトコルに応じて、設定は変わります。 以下のポインターをクリックし、それぞれの接続プロトコルを設定する手順を確認します。
POP / IMAP / POPS / IMAPS
フィールド名説明
承認タイプ
  • メールボックスの認証情報を用いて認証する場合、基本認証を使用します。
  • ServiceDesk PlusはOAuth 2.0認証をサポートしています。詳しくはこちら。
サーバー名/IPアドレス

メールサーバーのサーバー名またはIPアドレスを指定します。
ユーザー名

メールボックスのユーザー名を入力します。
パスワード（基本認証のみ）

メールボックスにアクセスするためのパスワードを入力します。
メールアドレス

メールを取得したいメールアドレスを入力します。必要に応じて、エイリアスメールアドレスを指定できます。
メールタイプ

メールサーバーに接続するプロトコル (POP、IMAP、POPs、IMAPs)を選択します。
ポート

選択したプロトコルに応じたポート番号を入力します。
認可サーバーの詳細（OAuth認証のみ）

こちらにしたがって、認可サーバーのクライアントID、クライアントシークレット、承認URL、トークンURLを取得します。

トークンを取得するため、認可サーバーでリダイレクトURLを設定します。

スコープフィールドでは、メールボックスで得られた承認トークンのアクセシビリティを定義します。スコープとして入力されるデフォルト値はこちらをご覧ください。
注意：Office365 GCC Highメールボックスを使用している場合、ホスト名、接続URL、トークンURL、スコープのTLD（トップレベルドメイン）は.usであることを確認してください。

Microsoft Graph
フィールド名説明
Graphエンドポイント

Microsoft GraphAPIにアクセスするためのエンドポイントです。
メールアドレス

メールを取得したいメールアドレスを入力します。
認可サーバーの詳細

こちらにしたがって、認可サーバーのクライアントID、クライアントシークレット、承認URL、トークンURLを取得します。

トークンを取得するため、認可サーバーでリダイレクトURLを設定します。

スコープフィールドでは、メールボックスで得られた承認トークンのアクセシビリティを定義します。スコープとして入力されるデフォルト値はこちらをご覧ください。
  • メールを取得する間隔を入力します。
  • ServiceDesk Plusがメールサーバーへ接続するために、プロキシが必要な場合、プロキシサーバーを有効にします。プロキシはプロキシ設定で設定できます。
  • メール取得の問題に関連した正確なトレースを特定したい場合、電子メールでバッグを有効にします。
  • メール経由のリクエストの作成を無効にするを選択することで、メールをリクエストとして処理することを制限できます。
    • 起票するリクエストとして処理できるよう、特定のメールアドレスを指定できます。例）heather@zylker.com
    • アスタリスク（*）を用いることで、特定のドメインをリクエストとして処理できます。例）*@zylker.com
  • エラーメールがメール取得のスケジュールを停止するのを防ぐため、エラーメールを別のフォルダーへ移動できます。
    • エラーフォルダー名を入力します。
    • 指定したメール数後のメール取得プロセスを停止したい場合、選択します。
    • エラーフォルダーのメールの合計がUI上に表示されます。必要に応じて、インボックスから移動させることができます。
    • メールが受信トレイからエラーフォルダーへ移動した時、通知の受診を有効化できます。
    • 必要に応じて、エラーログをダウンロードできます。
  • 保存をクリックします。

注意：デフォルトのメールサーバー設定について、詳しくはこちらをご覧ください。
