使用本功能，您可以对请求页面中的动作菜单进行定制。您可以创建不同的动作菜单，并将自定义类或脚本文件与该动作相关联，从而允许用户点击该菜单来执行相关的动作。这里创建的菜单项将显示在请求明细页面的动作下拉菜单中。

添加新菜单

创建新菜单时，需要提供以下信息：

菜单名称: 为所要创建的菜单指定唯一的名称（该名称将显示在请求明细页面的动作下拉菜单中）

描述: 为该菜单输入有意义的描述，以便用户理解该菜单动作的用途。

关联角色: 选定可以访问该菜单的技术员的角色（可以选择：所要角色或特定的角色）

关联模板: 选择请求模板，使用该模板的请求将会显示该菜单（可以选择：所有模板、所有事故模板、所有服务模板、或者特定的模板）

选择动作类型: 可从下拉框中选择 '执行脚本' 或者 '执行类'，如果选择'执行类'的选项，您需要指定相应的自定义Java类文件，如："com.servicedeskplus.integration.JiraActionImplementation"。如果选择'执行脚本'的选项，需要指定该脚本的名称和存放路径。如："cmd / c Index.bat"。默认情况下，脚本将从 "[SDP_Home]/integration/custom_ scripts/" 目录下运行。

您也可以为自定义脚本指定变量参数，如：cmd / c Index.bat $SUBJECT $PRIORITY

点击保存，保存该菜单的信息。

现在，菜单已经创建成功，您可以到请求明细页面的动作菜单中查看相应的菜单选项。

列表视图

当添加新的菜单后，菜单将列表显示在列表视图中，从该视图您可以：

启用/禁用某个自定义菜单: 从列表视图中，点击相应的自定义菜单所对应的启用/禁用图标，即可启用/禁用该菜单项。

编辑/删除某个自定义菜单: 当需要更新/删除某个自定义菜单时，可从列表视图中，点击相应的自定义菜单所对应的编辑/删除图标，即可编辑/删除该菜单项。
