Modèle d'association de site / technicien

L’équipe du service d’assistance comportera le chef d’équipe, l’agent et des techniciens qui traiteront les requêtes postées/signalisées par les employés dans l’organisation. Vous pouvez ajouter, modifier ou supprimer les techniciens dans l’application et également leur donner des privilèges d’accès correspondant à leurs tâches et besoins. Vous pouvez également afficher les techniciens d'un site en particulier en le sélectionnant dans la liste déroulante Techniciens pour. Pour ajouter un nouveau technicien, cliquez sur le lien Ajouter un nouveau technicien.

Remarque :
L'administrateur du site peut ajouter et consulter les techniciens disponibles pour les sites auxquels il est associé dans la liste déroulante Techniciens pour. Si le site n'est pas configuré Admin- Sites, la liste déroulante « Techniciens pour » ne sera pas disponible.

 

Ajouter un nouveau technicien
Informations personnels : Renseignez les informations personnels du technicien : Nom et Identifiant d'employé.

Informations sur le contact : Renseignez les informations de contact du technicien : E-mail, Téléphone, Portable et E-mail SMS.

Détails des coûts : Saisissez la valeur Coût par heure pour le technicien.

Détails du service : Sélectionnez le Nom du service du technicien dans le menu déroulant. Renseignez également le Titre de la tâche du technicien.

 

Associer le(s) site(s) au technicien :

Vous pouvez associer plusieurs sites à un technicien si ceux-ci ont été ajoutés au préalable. Sélectionnez les site à associer au technicien dans la liste des Sites disponibles et déplacez-les et dans les Sites associés en cliquant sur le bouton >>. Vous pouvez dissocier les sites de la même manière. Vous pouvez également associer/dissocier les sites des techniciens dans la page de liste des techniciens.

 

Assigner le(s) groupes au technicien :

Vous pouvez également assigner des groupes au technicien. Sélectionnez le(s) groupe(s) dans la liste Groupes disponibles et déplacez-les dans Groupe associé en cliquant sur le bouton >>.

 

Informations supplémentaires sur le technicien :

Si des champs définis par utilisateur ont été ajoutés, saisissez-les dans Informations supplémentaires sur le technicien. Pour autoriser un technicien à Approuver un bon de commande, cochez la case correspondante.

 

Détails de connexion:

Pour activer les autorisation de connexion du technicien, sélectionnez la case Activer la connexion pour ce technicien. Saisissez un Nom de connexion et un Mot de passe. Le nom de connexion doit être unique. Vous pouvez également sélectionné le Domaine du technicien dans le menu déroulant.

Vous devez maintenant assigner une tâche au technicien, qui définira ses privilèges d’accès à plusieurs modules de l’application. Si vous souhaitez que le technicien ait un accès d’administrateur complet, sélectionnez la case Activer les privilèges administrateur pour ce technicien. Cette option ne sera disponible pour l'Admin Site se connectant à l'application à l'aide de ses identifiants de connexion. (OU)

Si vous souhaitez que votre technicien ait un accès administrateur total aux sites sélectionnés, cochez Activer les privilèges administrateur pour les sites sélectionnées ci-dessus.

Sinon, cochez Activer les privilèges personnalisés, sélectionnez les rôles à partir de la liste Rôles disponibles, puis déplacez-les vers Rôles assignés en cliquant sur le bouton >>.

 

Activer l'accès à la fonctionnalité Desktop Management :

Lors de l'activation d'un accès de connexion d'un technicien, vous pouvez également accorder à celui-ci un accès de connexion à Desktop Central et un Rôle DC. Les deux rôles DC sont Admin DC et Invité DC. Cochez Activer l'accès à la fonctionnalité Desktop Management et renseignez le rôle du technicien. Lorsque le technicien se connecte à ServiceDesk plus à l'aide de ses identifiants, le technicien peut voir le menu déroulant Desktop Management. Il peut utiliser la fonctionnalité Desktop Management à partir de la console Web ServiceDesk Plus.

 

REMARQUE :

  1. Cochez Activer l'accès à la fonctionnalité Desktop Management et un rôle DC aura pour effet de créer un utilisateur avec les mêmes identifiants de connexion dans l'application Desktop Central.
  2. Vous ne serez en mesure de cocher Activer l'accès à la fonctionnalité Desktop Management que lorsque la connexion entre Desktop Central et ServiceDesk Plus est établie avec succès. L'option restera grisée si l'intégration n'est pas réalisée avec succès.

Détails de la clé API :
La Clé API du technicien est essentiel lors de l'intégration à ServiceDesk Plus avec l'API REST ou avec l'application Desktop Central. La Clé API agit comme un mécanisme d'authentification entre les deux applications.
Cliquez sur le lien Générer pour générer une clé API. Vous pouvez sélectionnez le délai d'expiration de la clé ou conserver la même indéfiniment. Un lien Regénérer s'affiche si une clé a déjà été générée pour le technicien.

Pour enregistrer le technicien et revenir à l’affichage liste, cliquez sur le bouton Enregistrer.
Pour enregistrer le technicien et en ajouter un autre, cliquez sur le bouton Enregistrer et ajouter un nouveau.

 

Supprimer le(s) technicien(s)

Dans la liste des techniciens, cochez le(s) technicien(s) que vous souhaitez supprimer.

Cliquez sur le bouton Actions --> Supprimer le(s) technicien(s). Une fenêtre apparaît pour confirmer la suppression de l'action. Cliquez sur OK pour continuer. Le technicien est supprimé de la liste.

 

Associer/dissocier un site

Cette option vous permet d'associer/dissocier des techniciens à des/de sites.

  1. Dans la page de liste des techniciens, cochez la case du technicien à associer/dissocier à un/d'un site.
  2. Si vous souhaitez associer le technicien à un site, cliquez sur le bouton Actions --> Associer au site. La fenêtre Associer un/des techniciens à un site apparaît. Sélectionnez le Site à associer au technicien dans la liste déroulante. Cliquez sur le bouton Associer.      
  3. Si vous souhaitez dissocier le technicien d'un site, cliquez sur le bouton Actions --> Dissocier du site. La fenêtre Dissocier un/des techniciens d'un site apparaît. Sélectionnez le Site à dissocier du technicien dans la liste déroulante. Cliquez sur le bouton Dissocier.
