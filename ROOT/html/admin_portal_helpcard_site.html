On this page you will only be able to edit some of the details to the sites that have already been configured in the ESM Directory.

Note: Adding or deleting a site is possible only from the ESM directory.

Each site is configured with certain settings with respect to Operational Hours, Holidays, Technician/Site Association, Support Groups, and Service Level Agreements. You can choose Refer Settings, or Custom Settings to modify the preset configuration.

Refer settings lets you choose and apply configurations of different sites for specific settings. For example, you can choose SLA settings from Site 1, but Holidays from Site 2.

Custom Settings allow you to provide unique configurations for each of these help desk attributes.

Click the site you want to edit and choose the configuration settings.

Site Deletion

Sites cannot be deleted from under an instance. Only the Org Admin can delete the Sites. Once an Org Admin deletes a site which is used by entities(Asset, Preventive Maintenance Task, Incident Template, Refer Site, Instance user import criteria) in your instance, you will need to move those associations to a different site. The provision will be given to change the entity associations under the Inactive Sites list once a site is deleted by the Org Admin.

Note: While modifying an asset association, if the department of an asset is not available in the new site, then the asset will be moved under In Store state.

Note: All the other fields such as description, region, address, and the like can only be filled in the ESM Directory.

Departments for the corresponding sites can be added only under ESM Directory.
