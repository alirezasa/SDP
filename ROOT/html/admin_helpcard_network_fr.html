L'analyse réseau vous permet de découvrir toutes les machines Linux, Solaris, MAC, IBM-AIX et les périphériques IP de votre réseau : imprimantes, routeurs, commutateurs et points d'accès. Vous pouvez également analyser les machines Windows et le Groupe de travail (à savoir les machines Windows ne faisant pas parti d'un domaine).

REMARQUE : Nous vous recommandons d'analyser vos stations de travail Windows (intégrées à un domaine) à l'aide de l'Analyse de domaine Windows.

Pour analyser un réseau, cliquez sur le lien Ajouter un nouveau réseau.


Ajouter un nouveau réseau

Adresse réseau : Vous pouvez analyser l'Intégralité du réseau. Par ex. : toutes les stations de travail sous 192.168.27.0 ou une Plage réseau particulière, comme 192.168.27.0 à 192.168.27.30. Sélectionnez les options correspondantes et saisissez une adresse réseau.

Protocole : Sélectionnez le Protocole. Par ex. : SSH ou Telnet.  

Case Analyser les logiciels des stations de travail Linux/Solaris : Sélectionnez cette option si vous souhaitez analyser l'ensemble des logiciels sous licence installés sur les stations de travail Linux et Solaris.

Case Utiliser la clé publique pour l'authentification : Cette option apparaît si vous avez activé le protocole SSH. Elle vous permet d'activer l'authentification sous clé pour les machines Linux.
Connue pour être plus sécurisée, l'authentification sous clé est une alternative à l'authentification classique utilisant un nom d'utilisateur et un mot de passe. Pour activer cette authentification sous clé, vous devez générer une paire de clés publique et privée depuis la machine Linux. Cochez Utiliser la clé publique pour l'authentification et saisissez la Clé privée dans le champ prévu à cette effet.  

Identifiants de connexion : Renseignez le Nom de connexion et le Mot de passe du protocole SSH. Saisissez vos identifiants Telnet si vous avez activé ce protocole. Si vous analysez des machines Windows, le nom de connexion doit être au format : <NOM_DE_DOMAINE>/<NOM_UTILISATEUR>. Par ex. : ACME/administrateur.

Chaîne de communauté : Pour la découverte SNMP des périphériques réseau, saisissez la Chaîne de communauté. Le protocole SNMP est utilisé pour identifier les imprimantes, routeurs, commutateurs et les points d'accès. Dans le cas des imprimantes, l'inventaire complet est récupéré à l'aide exclusive du protocole SNMP. Dans les cas des routeurs et des commutateurs, l'inventaire de base est récupéré à l'aide du protocole SNMP tandis qu'un inventaire plus détaillé est récupéré à l'aide du protocole SSH ou Telnet (si les identifiants sont renseignés).

Description : Saisissez des informations sur les détails du réseau.

Cliquez sur le bouton Enregistrer pour enregistrer le réseau et revenir à l’affichage liste.
Cliquez sur le bouton Enregistrer et analyser maintenant pour enregistrer et analyser le réseau.

REMARQUE: Pour que l’analyse des stations de travail soit bien exécutée, les points suivants doivent être vérifiés :

  1. Telnet doit être disponible sur le serveur et sur les machines équipées de Linux.
  2. Pour les stations de travail sous Windows, la connexion fournie par le réseau doit disposer des droits d’administrateur local.
