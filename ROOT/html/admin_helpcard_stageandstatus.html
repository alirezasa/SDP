The lifecycle of a change request usually involves six stages, and these six stages may possess many status. At each status, a notification is sent out to users playing certain change roles alerting them on the progress of the change request.

The Stage - Status Configuration Wizard lets you define status under each stage. And, also allows you to modify and delete the existing status. To add Status under a Stage, click Add button below a Stage.

  1. In the Add New Status form, enter a name for the status in Status Name field. This field is mandatory.

  2. Provide a brief Description about the activities in this status.

  3. When the change request enters this status, you can alert users by sending them an e-mail notification. Click Choose Roles icon and select the roles to be notified. Click OK. The selected roles are displayed in Notify to field.

  4. The Configure Notification Template section consists of Subject and Message fields which can be modified by adding text and content variables.

  5. Specify the Action Name for this status. The Action Name is a short actionable form of the Status Name. For instance, "Submitted for Authorization" can be "Get Authorization". The Action Name gets listed in Status Actions drop down menu in the change details page.

Note: If you have specified an Action Name, then the workflow for this status can be configured in Workflow wizard.   

  1. Click Save button. The status is added to the existing status list under the specific Stage.

Note: Each stage has two default status such as, Approve/Accept/Complete and Reject/Fail/Cancel. The default status cannot be deleted. But, if you want to edit these status, make sure you use a name which signifies the status, like Yes and No.
