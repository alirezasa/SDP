プロジェクトテンプレートのタスク

マイルストーンのタスクにより全体のマイルストーンを細分化することで、実行すべき多くの作業の追跡や監視をすることができます。

  • タスクテンプレートを使用：事前に用意したテンプレートを選択します。
  • 件名：適当な名称を入力します。
  • ステータス：「Open」、「Onhold」、「In Progress」、「Closed」、「Cancelled」、「Assigned」から選択します。［管理］でカスタマイズしたステータスを設定することもできます。
  • 説明：タスクの重要性等を入力します。
  • 見積もり工数：タスクの完了までに必要な推定時間を入力します。
  • 優先度：「High」、「Low」、「Medium」、「Nomal」から選択します。［管理］でカスタマイズした優先度を設定することもできます。
  • 追加コスト：タスクに追加でかかる推定費用を入力します。
  • タスクタイプ：タスクタイプの一覧より選択します。
  • コメント：追加情報や、詳細情報を入力します。
